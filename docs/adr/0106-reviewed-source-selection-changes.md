# 0106 — 扫描选择规则通过影响预览变更，保留旧业务读取

- **Status:** Accepted
- **Date:** 2026-10-23
- **Deciders:** 用户要求完整完成 E04 并实际浏览器验收

## Context

扫描范围会调整，但变更过滤条件不能隐式删除样本或让旧标注失去原图。同计数下接纳定位也可能变化，单凭配置修订不足以约束影响预览。

## Decision

仅允许递归和两组 glob 规则通过 preview/apply 更新。预览只评估有界已接纳路径，不访问外部来源；证明绑定提议规则、来源和位置修订、排序接纳头与活动尝试。确认再次授权、复算证明并拒绝活动任务，原子更新来源修订和代次、记录审计、阻断旧周期计划。旧扫描和预检保持严格修订屏障。

扫描、影响预览和旧路径差异共用选择语义。FS/SFTP 目录排除剪枝，S3 保留平面原始键匹配。新范围外的旧路径显示 excluded，保留所有业务事实。业务 reader 只从定位配置比较中剔除这三个已知选择字段，根、资格、未知配置和原内容身份继续严格验证。

## Consequences

扩大范围的新文件数量需重新扫描，旧检查点不复用；任务可以继续读取原图，即使原路径不再被新扫描纳入。不能在此更换根、位置、路径、节点或所有权。没有新增表、外部文件操作、后台清理或原图缓存。
