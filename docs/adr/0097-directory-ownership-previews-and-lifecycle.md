# 0097 — 目录所有权、鉴权预览与来源生命周期分离

- **Status:** Accepted
- **Date:** 2026-10-23
- **Deciders:** 用户授权推进完整 E03；实现与并发复核
- **Supersedes:** —

## 背景

目录来源可以保留外部原图，也可以明确复制到平台。缓存不能改变原图所有权或替代标注所需的严格内容读取。数据集可能同时包含上传、引用和多个来源复用的托管样本，不能用整个数据集的单一策略决定删除或缓存权限。

## 决策

1. DatasetSource 的 ownership_mode、cache_policy、policy_revision 与定位 config 分列。新来源默认 reference/preview，旧来源迁移为 reference/none。位置可限制为 none。所有权创建后固定；策略变更要求重新扫描和预检，旧内容身份不变。
2. DatasetSourceItem 以来源、路径摘要固定 Item、Asset、内容 SHA 与最初扫描回执；旧引用回填。managed_copy 从安全临时快照写唯一托管键，复用常规 AssetLocation；相同托管内容复用前重新核验实际字节。映射和已绑定 Item/Asset 身份由数据库保护。
3. DatasetSourcePreview 固定父 Asset/SHA、编码规格、策略修订、代次、自身 SHA/字节和位置。预检实际编码测量，失败计为未知；登记预览失败与原图成功独立。管理预览实时复查来源、位置、账号和初始凭据，不发签名 URL，不写旧 thumbnail_path。自然源离线允许读旧 SHA 缓存，标注仍要求原图。
4. 目录独占样本不进入旧缩略图或金字塔管线；复用既有上传 Item 的来源不会接管其旧派生。none 在新预览生成与读取侧均强制。旧缓存保留、单独计量，关闭策略不隐式删除共享对象。
5. 来源停用、恢复和注销使用当前修订及影响摘要确认；来源锁串行失效活动尝试的租约，保留样本、任务、标注和账本。注销为不可恢复 tombstone，停用可恢复。引用写入最终以 NOWAIT 取得位置/来源共享锁并持有至业务提交，生命周期等待已核验在途事务结束；不持来源锁等待已有 Task 锁。
6. 托管复制原图独立于来源生命周期。所有来源操作只读外部树，不调用整个数据集的 unlink。平台 Item/Dataset 删除在持有 Dataset 锁后捕获精确派生键，提交后清理；缓存替换提交后清理旧键，回滚仅清本次唯一键。取消等待不可取消的 I/O 线程结束，再关闭临时文件和清理对象。

## 后果与边界

- 管理预览可用不表示原图在线或可标注。预览失败可通过重新核验生成；缺失、摘要不符的旧缓存不会永远复用 ready 状态。
- 计量区分扫描观测、预检编码估算、此次新增原图字节和来源派生账本。来源合计按精确拥有的对象统计，不把其他来源或外部原件计入托管桶容量。
- 已知提交失败会清本次对象；提交结果未知时保留对象，避免误删已发布原图。清理失败或进程崩溃可能留下对象，日志供运维按数据库与精确键核对；自动垃圾回收由后续存储治理实现。
- 外部 S3/SFTP 的持续引用、周期同步、完整原图缓存、训练冻结分别按各自合同推进。
- 回退保留0200的策略、映射和预览账本；存在映射或非旧版默认策略时拒绝降级，旧应用不能把引用键交给 S3 resolver。
