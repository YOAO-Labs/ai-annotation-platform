# 0100 — 增量差异固定已接纳基线，接纳范围贯穿恢复

- **Status:** Accepted
- **Date:** 2026-10-23
- **Deciders:** 用户授权继续推进 E04；实现与只读复核
- **Supersedes:** —

## Context

可恢复目录扫描和批量登记已有独立账本，但新扫描不等于已接纳业务基线。直接把上一份清单作为基线会漏登曾扫描却未接纳的文件；把未见推成删除会误伤未遍历目录下的历史任务。文件大小和时间不足以证明内容相同，同摘要但身份观测改变也不能重绑旧严格引用。

## Decision

复用 Scan → Registration 的两阶段、租约、权限及 worker。新增预检拥有的分页差异表，在 Location → Source 锁内固定当时 DatasetSourceItem 的样本 ID、内容 SHA、原观测及来源资格锚点。后续并发登记不能改写本轮基线；比较不用上一份扫描，也不修改旧 Reference。

逐项完整读取后列新增、内容与观测相同、变化或核验失败；当前清单明确排除的旧路径列排除，未枚举到列未见。只有完成预检才发布差异，取消、中断或修复重试期间隐藏；完成不声明原子目录快照。单来源已接纳基线和当前扫描各最多50000项，通过 SQL 并集与索引分页，避免整表装入单个 JSON。

确认可固定 additions_only，跳过相同项，仅将新增候选交给现有严格登记。正式登记继续复读原摘要，保持事务内建任务和去重。选择范围贯穿幂等确认与单项恢复，不能用 retry 接纳未选中的旧路径。变化项暂不接纳，不通过重试覆盖；旧样本、任务和标注保持原绑定。差异是预检证据，正式登记失败只更新当前执行结果，不把历史候选伪装成当前可读。

旧账本无比较能力，原无请求体确认继续可用。迁移只增表/列；有差异证据时拒绝破坏性降级，应用回退保留证据与业务历史。

## Consequences

正向：基线可追溯，重复重扫不增长样本或任务，变化与未见不自动销毁历史，复用现有部署和执行授权。

负向：每轮预检仍需完整内容读取；观测改变会保守拦下相同内容；账本持续增长，尚无独立压缩/保留策略。外部覆盖的旧字节不能靠摘要恢复。接受新修订、移动重定位及周期调度需要后续独立合同与验收。
