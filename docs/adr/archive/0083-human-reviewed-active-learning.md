# 0083 — 人工主动选样保留独立对照与不可变决策

- **Status**: Accepted
- **Date**: 2026-10-16
- **Deciders**: Project maintainers
- **Supersedes**: None

## Context

现有任务不确定性排序读取可变 Prediction，无法固定候选模型、输入窗口、历史数据隔离或推理工作量。检测器只提供过滤后的框与置信度，没有完整类别概率。把选样框直接接受为训练真值，或按任务墙钟推算人工工时，都会制造未经审核的数据和收益证据。

## Decision

新增独立 Round、fenced Attempt、完整 PoolMember、推理 Candidate、只追加 Decision／Feedback 和长期 Reference。明确的未标注图片窗口先条件读取实际 SHA256，按内容及场景形成连通组，并用全部保留训练清单／split_history 及 held-out 评估排除身份。任何缺少完整清单、变化或超限都拒绝，不能退化为只检查任务 ID。

评分前随机分开主动与控制候选池，控制池独立随机取相同计划量。主动策略明确命名低框置信度与不同类别重叠启发式，并保留四分之一向上取整的随机探索；没有检测表示未知信号。不能以概率 entropy、跨模型统一分数或确定背景解释这些输出。

共用原有受控推理和原生请求收据合同，在每次实际 POST 前提交持久预算预扣，包含失败及重算；读取／封存不计费。恢复保留同请求、固定部署和原始 24 小时窗口。取消及故障等待所有已保存请求完成或 seal tombstone，失联不释放远端所有权。API、worker、维护和 Celery 信号统一遵守当前尝试围栏。

负责人接纳子集前重验完整来源组、编辑锁、分派和新增不可变历史成员，复用普通草稿批次及任务移动。之后必须由正常标注、提交和审核产生真值。Decision 保存批次身份／名称快照而 live FK 用 SET NULL，普通批次删除不改写审计。完整来源窗口和历史排除引用在存储删除前检查，FK 为事务后防线。

Feedback 只记录实际审核、保留标注、审计驳回和已记录的合格会话区间；会话按人及作业类型取并集，并保留部分／未知覆盖。完整纠正次数和工时没有证据时保持未知。后续评估从已有核验 reader 读取，只对完整且同口径的两个报告计算变化，不宣称选样造成的收益。

## Consequences

无需新服务、模型库或原生推理协议，已有逐样本评估 wire/hash 保持兼容。负责人得到可解释选样、等量随机对照、资源上限和长期历史，代价是严格的图片／历史规模限制、保留来源的删除限制，以及异常状态下必须等待远端停止证明。

当前验证仅证明工作流正确，不证明真实人工效率或模型质量。不同接纳量、审核量、部分工时或缺少后续评估不能用于收益主张。当前没有 Round 删除 API；回退关闭新创建／派发，封存已有请求并保留所有普通任务、人工真值与历史，不对有保留数据的库降级。

## Alternatives considered

- 保存过滤／随机批次：更小，但没有固定模型证据、完整历史排除和远端不确定性治理。
- 直接使用旧 Prediction.score：可变且缺少同轮模型、输入与派发预算身份。
- 引入主动学习服务或 embedding：增加新的执行与资源所有者，当前有界检测启发式无需承担此复杂度。
- 从框差异推算纠正次数，或从创建到审核推算工时：不能证明实际人工作业，拒绝采用。
