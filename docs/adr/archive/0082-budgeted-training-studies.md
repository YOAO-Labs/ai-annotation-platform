# 0082 — 参数搜索复用普通训练并以进程回执结算预算

- **Status**: Accepted
- **Date**: 2026-10-16
- **Deciders**: Project maintainers
- **Supersedes**: None

## Context

参数、配方、最终评估与续训已具备固定身份。负责人需要明确枚举少量组合，限制总工作量并比较结果。训练监控是可缺失的观测，claim 到 finish 又包含下载和上传，都不足以作为原生计算账本。中央调度停止条件不能在网络中断时保证本地训练截止，失联仍必须保留 GPU 所有权。

## Decision

新增持久 Study／Trial，完整网格最多 20 项，明确试验数、计划总轮数和累计原生进程时间。每个组合通过同一参数解析器，预览完整配置并用摘要确认；计划和子实验 ID 确定性派生。只在同一完整兼容评估组内最大化校验后的最终验证指标。

每个 Trial 使用普通 Run、Attempt、GPU 租约和恢复协议，同时最多一个活动子实验。项目锁和 Study 非键写锁序列化准入，部分唯一索引保护所有活动状态；claim／finish 不取得 Study 锁，避免与资源／Run 顺序相反。停止搜索关闭后续 scheduling，手动恢复不会重启其他组合。

Attempt 在入队前固定预留身份与原生额度。预算由全部围栏终态回执派生，涵盖失败、续训、原生准备／评估和停止宽限。预留仅在有效终态结算后释放；恢复重新核对当前余额，不能再次使用已经由后续试验消耗的额度。未知时间阻止新工作，超额完整计入。

执行器在 spawn 前保存意图，Popen 后立即保留单调时钟和独立 watchdog；deadline 不依赖主循环日志、journal 或 API 可用性。停止调用串行且失败重试，直到整个进程组确认退出。精确回执持久化后随固定 finish body 重试，只有围栏提交才能结算并释放租约。重启后缺失回执的 spawn 意图表示未知；GPU flock 证明互斥，不证明计时时长。

Study、Trial、Run 与冻结输入以无互相循环的 RESTRICT 外键长期保留，删除前先检查引用再触及存储。当前不增加删除 Study、并行 GPU、调参服务或自动模型发布功能。

## Consequences

负责人能审计全量组合、每次耗时和可比结果；普通实验队列及历史恢复保持一致，无新增基础设施。进程停止有宽限，实际耗时可能超过预算；Supervisor 被终止时不能承诺 watchdog 继续生效。未知证据会暂停搜索而需要运维调查，不能估算为零。保留历史会限制数据、子实验与项目删除。

部署同步迁移、实际镜像摘要、预算能力和 worker／beat。回退先停止搜索并等待已有租约对账，保留表与历史引用，不对含搜索数据的库执行降级。

## Alternatives Considered

- 手动克隆并比较：无需调度，但没有完整网格、预留与截止时间账本。
- 引入 Ray／Optuna 服务：增加独立执行和资源治理，本轮有限串行网格不需要。
- 只按 claim 时间或资源采样扣费：混入非计算时间，且可缺失。
- 只有中央停止条件：调度或网络离线时不能停止本地进程。
- 重启后按当前墙钟补全：不能证明实际退出时刻，会制造精确证据。
