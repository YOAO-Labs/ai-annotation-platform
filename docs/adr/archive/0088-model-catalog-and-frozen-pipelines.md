# 0088 — 模型目录独立投影，管线按阶段冻结并完整重试

- **Status**: Accepted
- **Date**: 2026-10-20
- **Deciders**: Project maintainers
- **Supersedes**: None; extends ADR 0076's initial single-stage execution scope

## Context

协议能力描述服务会做什么，模型目录描述实际可选的内置规格和项目训练版本。把私有权重追加到后端 `/setup.models` 会污染服务池能力指纹，且把注册权限错误带入普通标注入口。只冻结根模型或在失败时调用一次推理，也无法重现包含裁剪检测的管线；原有 8 KiB 重试字段和作业保留期不足以持久保存完整配置。

## Decision

新增只读目录投影，复用协议词表、注册实例／服务池和不可变训练版本。内置身份包含池或独立实例、任务、原生模型 ID 和合法完整规格；训练身份保持版本 UUID，部署属于放置位置。项目当前发布是选择别名，仅在新请求解析。项目成员可读取所属项目已发布模型，候选管理和运行时管理继续独立授权。

内置检测权重正常加载时读取实际 `model.names`，按文件 SHA、加载器与元数据 schema 保存 sidecar；查询只读取观测，不反序列化权重或预热 GPU。类别声明与观测不符时禁止旧原生索引过滤，已核验观测在实际借出模型上再次核对身份。未核验声明保持可识别的较弱配置保证，不能当作权重真值。

Ultralytics 图片检测可作为整图根阶段和父框裁剪检测阶段，同一 YOLO 实例可执行不同阶段。每阶段独立冻结版本、部署、类别映射、参数和规格；保留现有受控安装、认证、精确路由和推理协议。LibreYOLO 保持已验证的单阶段范围；视频、交互和其他训练任务须单独取得资格。

新增不可变 `prediction_execution_snapshots`，摘要与 payload 一起保存，单份限制 1 MiB。作业和失败项都通过外键引用快照。初跑和单个失败任务的完整重试共用阶段树执行器，不重新解析当前发布，也不静默降级到内置权重。旧的无快照失败保持旧重试行为。默认值冻结遵循显式参数、项目阈值、模型默认值的既有优先级，保持各后端 wire 参数格式。

下游失败保留阶段错误和策略允许的部分候选；只有完整重试成功才删除失败记录，并将旧部分候选标为被新预测替代，保留人工采纳来源。元数据记录每阶段实际实例、shape 和直接父 shape 身份；裁剪回映明确坐标单位。推理前和最终写入锁内均复核账号、项目、任务及分派权限。

清理作业不会级联删除快照。只有超期且既无作业也无失败引用的快照可清理；可恢复的已放弃失败继续保留快照。

## Consequences

正向：

- 模型市场、预标注和工作台共享模型身份、类别语义和可用原因，普通成员无需访问管理员后端接口。
- 已发布训练模型复用现有 YOLO 服务；增加模型不要求增加容器或协议。
- 发布切换、原作业清理、阶段失败后仍能核对原请求和完整重试。

负向：

- 增加一张快照表、引用和不可变数据库触发器，需要先执行迁移再更新 Worker。
- 权重观测校验包含流式 SHA 读取；大权重的健康采集会增加磁盘读取，但不会加载 GPU。没有有效观测时仅展示声明状态。
- 部署失效、权限变化或原实例不可用时，原请求明确失败，需要管理员修复部署或用户重新提交；不能任意改路由以伪装重现。
- 目录是有界查询次数的投影，聚合后分页；大量训练历史的数据库级分页仍可后续优化。

## Alternatives Considered

仅拆分标签并链接原模型页无法支持共享选择和管线。把训练模型放入 setup 会使安装影响池兼容性；每个模型独立服务会重复认证、资源和生命周期管理。把完整管线塞进失败项则会重复数据并受旧字段预算约束。
