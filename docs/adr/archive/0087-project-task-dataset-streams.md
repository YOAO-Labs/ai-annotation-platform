# 0087 — 项目按任务派生版本流，管理关联与冻结身份分离

- **Status**: Accepted
- **Date**: 2026-10-16
- **Deciders**: Project maintainers
- **Supersedes**: None

## Context

项目拥有标注真值、工具绑定与原始媒体，可以分别派生检测、分割等训练数据。现有冻结版本已经固定单一任务，但列表混合分页，父版本和比较基线在客户端筛选后可能遗漏；同时没有持久任务数据集身份与稳定展示序号。已有数据包、请求摘要、训练引用和分区继承不能因改进管理界面而重写。

原始存储数据集可关联多个项目，不适合作为任务版本流。类别、批次、范围和导出契约则会随迭代变化；将它们加入数据集主键会把需要比较的变化拆成不同数据集。

## Decision

以 `(project_id, canonical task)` 唯一标识 `ProjectTaskDataset`，由项目衍生，不新增上传、标注副本或独立生命周期。`TrainingDatasetVersion` 继续拥有冻结快照、清单、请求、状态和包身份；`TaskDatasetVersionMembership` 仅关联版本 UUID、任务数据集和正整数序号。关联不参与训练或包摘要。

手动创建、自动策略与历史回填共用关联助手，按项目 advisory lock、任务流高水位的顺序分配序号。请求重放及重试沿用原关联；失败和取消后的版本仍占号，删除不复用。序号表达发行顺序，`parent_id` 独立表达分区继承，比较基线也不改变父子关系。父版本与比较必须另外核对媒体、几何、桥接及来源分组资格，不能只看任务相同。

版本列表先按认可的冻结任务、项目和状态筛选，再计数分页，外连接管理关联以保留旧写入者生成的待关联版本。完整冻结契约无法识别的行保持原样，使用独立只读诊断资源返回，不默认分配到检测。回填采用显式目标、只读预演／校验和有界写入批次；后发现的历史记录追加序号，保留真实创建时间。

分析适配器按任务、输出媒体、格式、几何和桥接契约选择，仅实现图片矩形框检测及已有简单多边形实例分割。适配器负责任务统计、原生标签语义和比较资格；共享服务负责授权、冻结身份、分页、存储校验及派生缓存。适配器修订只使分析缓存失效，不改数据包或训练身份。各操作独立声明能力与原因；分类、关键点、旋转框和其他媒体需独立资格验证。

检测展示固定大小的服务端聚合和按内容 SHA 的方向性差异，分别说明图片成员、唯一内容、已知实例与未知证据。前后面板各自读取版本内的冻结标签与经校验媒体，不用 IoU、行序或来源 ID 推断真实目标身份，不回退当前项目素材。

## Consequences

正向：

- 一个项目的任务版本独立浏览，类别与范围变化仍能留在同一版本流中核对。
- 管理信息可回填且不影响历史 UUID、冻结字节、摘要、请求重放、训练引用或下载路径。
- 检测得到完整统计与前后检查入口，已有分割路径保留，新增任务有明确资格边界。

负向：

- 列表多一次关联；滚动升级期间需展示待关联状态并执行尾部回填。
- 序号允许缺口，也不保证历史创建时间严格递增；界面须同时显示创建时间与继承关系。
- 空任务流仍保留已发行高水位；删除项目时须在无保留版本的事务内清理空流。
- 比较身份与训练身份分离，消费者须说明采用的计数单位和兼容依据，不能由数据相同推断模型指标可比。

## Alternatives Considered

只增加任务查询参数可以修复分页，但不能提供稳定任务数据集身份与序号。直接给冻结版本增加可空关联和序号更少一次关联，但将管理回填和冻结记录写入混在同一所有者；独立 membership 使回填、旧代码回退及冻结身份边界更清楚。

不建立通用插件引擎或新服务。当前仅有两个已资格任务，类型化的进程内适配器足以表达差异；未来任务必须补齐冻结／桥接／训练、黄金样本、预览和比较规则。
