# 0089 — 实例分割采用原生掩码训练与按任务隔离的在线学习

- **Status:** Accepted
- **Date:** 2026-10-20
- **Deciders:** 项目维护者（授权实施图像实例分割在线学习）
- **Supersedes:** —

## Context

既有简单多边形训练不能表达画笔、SAM 修正后的孔洞及断连实例。项目模型发布与自动策略原先只有项目维度，同项目检测和分割会争用当前模型及语义基线。已有冻结数据、单资源执行器和人工审核机制可以复用。

## Decision

增加 schema 4 的 `aap-instance-rle` 数据契约与 `ultralytics-instance-rle-1` 消费者，首个受控规格为 Ultralytics `yolo11n-seg`。每个实例保留独立原尺寸二值 RLE、来源版本和像素摘要；训练包独立持有冻结字节。简单多边形桥接保持原身份，跨桥接不直接继承父版本。

发布、代次与自动训练策略按 `(project_id, task)` 隔离；迁移先核验历史身份，拒绝猜测未知记录。检测的默认接口与历史冻结摘要保持兼容。项目自动任务与物理 GPU 所有权仍统一串行。

受控模型须绑定最终候选权重、原生 Segment 架构、运行时、掩码解码器和类别顺序。整图原生掩码经平台校验后物化为内容寻址引用；人工接纳、修正并审核后才能进入下一轮。训练成功仅生成候选，发布仍由负责人选择。

逐样本分割评估使用独立 mask IoU 协议，报告已匹配 Dice 与漏检；不声称等同 COCO AP。主动选样使用独立实例置信度及跨类掩码重叠启发式，并保留等量随机对照。项目权重初始化只转移已核验同规格、同类别顺序的权重，新实验重置优化器及训练状态。

## Consequences

正向：

- 孔洞、断连和重叠实例可经过审核、冻结、训练及模型回流，来源可追溯。
- 同项目检测与分割独立发布、回滚和维护训练基线。
- 冻结身份、资源租约和人工审核继续复用现有所有者。

负向：

- 新桥接需要精确匹配的执行器及分割后端镜像；旧执行器不能领取原生 RLE 实验。
- 原生掩码需要额外对象、内存和传输预算；逐样本评估与主动池使用更小的独立像素预算。
- 首批不开放分割 ROI 回拼、SAM 微调、分割参数搜索或自动发布。

## Alternatives Considered

将掩码提取为单轮廓会丢失孔洞或拆开实例；互斥类别图会合并重叠，因此未选。逐标注即时训练无法满足冻结、审核和故障恢复要求，本链路采用有边界的批次再训练。
