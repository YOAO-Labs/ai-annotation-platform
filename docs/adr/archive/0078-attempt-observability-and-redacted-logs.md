# 0078 — 执行观测独立于训练所有权，日志在保存前脱敏

- **Status:** Accepted
- **Date:** 2026-10-15
- **Deciders:** Maintainer-authorized implementation
- **Supersedes:** —

## Context

训练心跳同时推进状态与保留资源租约，不能承担非关键遥测。设备级 GPU 数值可能包含其他进程，容器 PID 与设备 PID 也不一定对应。原生 stdout 包含 URL、凭据或主机路径时，事后隐藏页面不能消除已保存内容。历史日志及其原摘要已有不可变身份，不能直接覆写。

## Decision

在既有 attempt 下增加两个独立有序观测流，复用执行器原 fence、当前项目授权和现有队列。观测接口不更新状态、心跳、租约时间或所有权。分别保存流 UUID、高水位、生产 boot、采集／接收时间、摘要及最后请求回执，清理行后不回退序号。最新值与峰值由已接受采样派生，日志批不能改写已确认的采样摘要。

执行器的采样和传输各有线程、停止标志及超时。私有标准库 SQLite 限制 8 MiB，保存已封存请求、ACK 和游标，丢失响应精确重放，空间压力缩短保留窗口并显式报告缺口。观测故障不取消训练；可选线程停止失败独立保留所有者，等待退出期间不创建新观测会话，不改变已确认发布结果。

每约五秒采样，数据库／客户端每执行最多保留 720 条采样与 512 个 2048 UTF-8 字节日志块；请求最多 12／32 条、128 KiB，紧凑状态 16 KiB。现有 cleanup 队列每小时分批清理 7 天前的原始观测，保留摘要，实验删除级联清理。清单冻结前保存最多 256 KiB 的可选摘要产物，上传期间不改写。

CPU／RSS 只采样已确认 PID 创建时间和进程组的训练子进程；整卡查询以冻结 GPU UUID 为准，限时两秒。PyTorch 分配器数据由已初始化 CUDA 的原生子进程提供。未映射的 PID、不支持的原生吞吐或过期回调保持不可用，零值保留。ETA 至少使用三个同增强阶段的完整可比较周期，排除首个周期，不跨未观测阶段，也不估评估／上传。

管道读取独立于 HTTP，任何日志落盘前先规范化和脱敏。超过 8192 原始字节的整行丢弃到分隔符，最终 head/tail 日志不超过 8 MiB。确认原生进程组退出及管道读取完成后才整理日志，失败只重试整理。历史日志下载在实验共享锁内核验原对象，再生成同一执行前缀下的内容寻址脱敏副本，返回副本与原始摘要的明确对应；不改原对象。

失败使用实际异常类型或明确校验边界，保存来源、阶段与配置绑定。GPU finish 完整回执在请求前落盘，省略的新 failure 字段不改变旧请求摘要。恢复资格由当前已停止执行、已释放租约、正轮次未完成检查点、存储归属／元数据、冻结配置及已知兼容环境共同决定；上传重试继续沿用既有 journal，不启动新训练。

## Consequences

正向：

- 观测故障与有限数据丢失不会改变训练状态或资源释放条件。
- 数值来源、归属、不可用原因及估计依据可核对，历史执行不会借用当前运行数据。
- 新日志从源头避免持久化敏感内容，历史下载保留原始产物身份。
- 有界存储、独立游标和精确重试复用既有执行器及数据库，无需监控服务或额外账户。

负向：

- 新增两张表、紧凑状态和本地 spool，部署需迁移、重建执行器并刷新 worker／beat。
- 近期窗口及上传结束前未送达的少量观测可能丢失；冻结摘要也不包含后续上传耗时。
- 整卡数值不能归因给训练，分配器显存不是全部进程显存；短运行可能没有足够周期形成 ETA。
- 旧日志每次下载需有界读取、核验并生成副本；超限历史日志不能通过此路径下载。

## Alternatives Considered

把遥测加入心跳会将非关键流量与租约续期耦合。外部监控服务扩大部署与凭据范围，而现有系统接口足够提供明确归属的基本测量。只在前端脱敏会保留敏感磁盘与对象内容；覆盖旧日志则破坏不可变摘要。仅凭检查点字段或错误字符串推断恢复与 OOM，会产生与真实进程状态不一致的操作。
