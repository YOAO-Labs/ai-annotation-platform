# 0105 — 周期计划按明确策略自动接纳纯新增轮次

- **Status:** Accepted
- **Date:** 2026-10-23
- **Deciders:** 用户要求完整完成 E04 并实际浏览器验收

## Context

周期扫描默认等待人工接纳，但持续新增目录需要可选的自动登记。混合变化轮次若部分自动接纳，可能破坏用户先判断移动、修订的机会。

## Decision

策略默认 manual，显式 pure_additions 只接纳完整无错误且全为新增或未变化的轮次。策略在扫描开始时固定；当前策略仍必须允许自动接纳。完整核验使用真实来源 worker，并在锁外读取后复查原账号、Key proof 和计划 revision/token。复用 additions_only 登记，不引入第二套建样本逻辑。仅带自动确认标记且原授权相符的正式任务可由计划恢复；人工正式任务仅观察。

IANA 时区控制显示，持久时间仍为 UTC，间隔为实际分钟。旧计划迁移为 manual/UTC；回退前须暂停启用的自动计划。

## Consequences

混合差异保留整轮人工决定权，不自动替换、移动或删除。暂停计划阻止后续协调，已确认任务继续按原授权执行。调度延迟和错过周期不补跑，日历和夏令时墙钟定时不在此合同内。
