# 0085 — 简单多边形实例训练复用原生执行器并独立冻结任务身份

- **Status**: Accepted
- **Date**: 2026-10-16
- **Deciders**: Project maintainers
- **Supersedes**: None

## Context

图片区域标注已保留归一化多边形和来源版本，独立训练执行器中的固定 Ultralytics 原生实现具备实例分割训练、验证和优化器检查点。普通导出允许孔／掩码转换或多部件拆分，不能证明实例训练标签无损；检测身份和框指标也不能代表掩码训练。

## Decision

首先通过受控 YOLO11n 分割权重资格，复用现有进程、GPU 租约、取消、续训和产物发布。新数据契约显式固定任务、简单多边形几何和桥接修订；不新增数据库列、不重写历史检测数据或摘要。17 位有效数字保留矢量顶点，每行绑定来源标注 ID／版本、类别和摘要。

共享标准库校验器限制顶点、实例及整图资源，验证双精度和原生 float32 的简单多边形。拒绝孔、多部件、栅格近似、自接触、退化及原生去重会丢失的重复实例；仅规范闭合点、起点和方向。独立重叠实例保持独立掩码，固定掩码比例为一，未经验证的复合和空间增强关闭。矢量无损不意味着训练分辨率下的栅格覆盖无损。

数据、基础模型、参数定义和执行器必须具有一致任务身份。分割使用独立参数定义与评估描述符，保留框／掩码 summary、分类别结果及实际掩码处理源码／选项；原生 fitness 允许超过一，不作为掩码准确率。洞察显示原生多边形面积和来源版本，跨任务比较拒绝混用。

模型回流、逐样本推理评估、候选初始化、增强预览、参数搜索和自动学习策略保持独立资格。普通实验和配方可复用分割配置。旧检测定义和请求字节保持不变；新镜像领取旧修订 2 配置须绑定来源镜像与完整 schema identity，并通过实际旧检查点续训验证。

## Consequences

项目可完成区域标注到原生分割训练、检查点恢复、最佳权重和报告下载，无需新服务或依赖。代价是只支持已验证的单简单多边形、模型规格及增强组合。其他几何、模型尺寸和分割推理回流继续独立验证，不以原生框架支持范围代替平台资格。

回退先从目录移除新资格并停止新领取，等待现有所有者退出。保留历史分割数据、配置、完整检查点、报告和下载，并提供其已验证镜像。检测身份继续服务，不能改写历史摘要以伪造兼容。

## Alternatives Considered

- 仅导出离线训练包：原生链路已经可验证，不能完成平台内训练与恢复目标。
- 将掩码、孔或多部件近似为多边形：会改变实例或像素语义，当前桥接明确拒绝。
- 为分割新建服务：现有训练所有者和依赖可复用，无需第二套租约与发布流程。
- 复用检测参数／评估身份：掩码处理与指标语义不同，会破坏不可变来源和可比性。
