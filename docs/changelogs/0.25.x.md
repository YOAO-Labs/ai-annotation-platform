# Changelog · 0.25.x

> 已归档。最新版本见仓库根 [CHANGELOG.md](../../CHANGELOG.md)。

## [0.25.4] - 2026-09-15

### Added

- 通知覆盖全工作台：通知 WebSocket 连接移到应用生命周期，主界面与全屏标注 / 审核工作台顶栏显示同一通知铃铛与未读角标；未读数不再只是一个圆点，1–99 显示精确数字、100 以上显示 `99+`，悬停与读屏标签公布精确数值，刷新失败时保留上次数值或提示「未读数暂不可用」。从通知进入目标前会先执行视频 / Mask 离开检查，取消离开保留当前任务与草稿。
- 重要消息瞬时提醒：可见标签页中对任务退回、批次驳回 / 重开 / 管理员锁定、评论提及、问题回复、后台任务失败、导出失败等类型弹出短暂提醒，1 秒内多条合并为一条，按通知去重、不抢焦点、不自动跳转；隐藏标签页只同步角标。断线期间的事件由 30 秒轮询与回前台 / 重连时的立即刷新补齐，不回放历史提醒。
- 通知偏好支持按类型分别设置「接收通知」与「弹出提示」：设置随账号同步，个人设置页与新增的工作台设置「通知」分类共用同一面板；默认仅重要类型弹出，普通完成事件与未知类型默认不弹，关闭接收只禁用弹出、不重置已存选择。修改自动保存，失败时该行恢复上次保存值并可重试。`GET /notification-preferences` 返回每类有效 `toast`；`PUT /notification-preferences` 接受 `type` 加可选 `in_app` / `toast`（至少一项，拒绝 null），只合并提供的键，旧客户端只发 `in_app` 不会清除已存弹出选择；偏好提交后发布 `notifications.sync reason=preferences` 同步其它会话。
- Data Manager 数据区域改为页面滚动：任务与对象列表随页面自然延伸，标题、摘要和查询工具栏滚动让位，表头保持吸顶；任务分页、对象/轨迹游标加载与虚拟化、视图侧栏、筛选和分享链接行为不变。

- Data Manager 新增标注图片只读预览：任务“匹配对象”抽屉与对象详情顶部显示整图叠加已保存标注（含旋转框、带孔多边形、关键点骨骼与像素掩码），可一键对比原图；预览按任务分页加载标注并高亮选中对象，切换或关闭时取消过期请求，不产生任何标注或工作流写入。

- 成员绩效新增“已标注图片”与“保留标注”保存内容指标：统计区间内创建且仍保留的标注（图片按任务实际媒体类型去重），无需提交或审核即计入；项目汇总独立去重，列表、详情与 CSV 同口径，并提供对应排序。

- Data Manager 任务列表新增“未解决问题”和“评论”两列与数值筛选：问题列对齐工作台问题口径（有效、开放的问题主题），评论列对齐工作台评论总数（任务留言 + 标注评论）；旧“反馈”列、排序与筛选保留为兼容别名并修正为问题计数，恢复旧保存视图时自动映射到新列。

- 工作台评论与任务留言的 `@` 候选加入项目负责人（「项目负责人」）和平台超级管理员（「超级管理员」），即使不在项目成员表中也可被提及并收到站内通知；新增项目维度的候选接口，普通成员无需管理权限即可获取。

- 工作台快捷键面板重构：与工作台设置同一几何，按用途分类导航（常用、绘制与工具、选择与编辑、画布与视角、AI 与审核、播放与轨迹、任务与系统、鼠标操作），支持当前工作台 / 全部类型过滤、跨分类搜索动作 / 按键 / 生效条件，并在行内展示实际生效条件；原「按使用频率排」与使用计数展示移除。

- 账号级快捷键改绑：图片 / 视频工具选择、切题、选中态锁定隐藏、视频帧与关键帧导航、书签等命令支持改绑一主一备组合、停用与恢复默认，随账号跨项目生效并参与统一冲突检查；工具坞角标与提示按生效组合展示。项目类别直选改为数字 1-9 加 0（按配置顺序取前十类），字母不再切换类别；类别面板支持方向键导航。视频「实际尺寸」与 3D 三视图缩放重置改用 Shift+0，图片属性数字键仅在选中卡「属性快捷键」区域聚焦后生效。

- 用户可设置个人头像：上传自己的图片（PNG / JPEG / WebP，不超过 2 MB，服务端自动居中裁成方形并缩放到 256×256），或从 32 个内置像素头像中选择，也可一键恢复为姓名首字母。头像随账号跨设备同步，顶栏、任务与批次责任人头像组、项目成员与用户管理列表都会显示；头像存放在独立对象存储桶，长期保留且不计入清理策略。

- 模型市场注册管理支持完整的 URL 状态：子视图（`registry_view`）、各子视图搜索与筛选、以及对象定位键（`pool_id` / `instance_id` / `gpu_id`）都写入地址栏，刷新、前进后退和分享深链可恢复原来的子页与条件；从服务池「查看实例」和问题中心「定位」的跳转改为 URL 导航，支持往返。

- 模型市场各注册子视图拥有各自的工具栏与明确主操作：实例视图突出「注册实例」并支持按池定位的可移除条件，服务池视图突出「新建服务池」，问题中心新增严重度快捷筛选与按对象名称显示的附着筛选，项目绑定提供搜索与池限定。

- 能力目录条件全部写入 URL（搜索、分组、显示方式与任务/模态/模型族/框架多选），工具栏固定为「搜索/分组/视图/刷新 → 快捷筛选 → 结果计数与条件标签」三行，结果计数显示「匹配 N / 总计 M」并区分协议能力类别数；模型卡首层摘要化（徽标 + 输入→输出摘要 + 运行状态 + 详情展开），协议列表「查看全部 N 个模型」可实际展开剩余模型，未接入能力的推荐后端收进展开区。

- Data Manager 新增项目概览、任务缩略图与画廊、可收起的分组视图，以及项目列表直达入口；原有任务、对象、轨迹筛选和分享链接继续可用。

- 项目负责人可在成员绩效看板查看成员提交、审核、首审质量、已记录时长与待处理工作，包含零活动和历史贡献者，支持同范围详情与 CSV；缺失历史或计时证据会明确显示覆盖状态。

- Data Manager 支持最多 200 个明确选定任务的分派预览、局部导出和预标注，操作复核任务权限、状态与锁，并保留异步作业进度和失败原因。

- 工作树支持一条命令启动筛选手动验收环境，提供专用账号、场景入口与预期结果，停止和重启保留验收数据。

- 图片与视频 AI 任务支持独立的筛选链接，文本搜索等待完整输入后同步重置分页；模型目录在不同分组下使用一致条件，历史队列和通知明确已选及已加载范围。

- 成员、邀请、绩效、审计与 BUG 列表支持筛选链接恢复；搜索统一减少连续请求，成员与邀请条件互不覆盖，审计空字符串条件在列表和导出中保持一致。

- 项目、数据集和模板列表支持可分享的筛选链接及浏览器前进后退恢复，搜索减少连续请求；项目状态标签与高级筛选保持一致，日期范围错误会在应用前提示。

- Data Manager 任务、对象和轨迹视图共用类型化筛选编辑器，支持保留并编辑嵌套 AND/OR、多选枚举和完整区间；刷新与浏览器前进后退恢复条件，未完成输入保留已应用结果。

- 文档高清母版录制支持 Mac 原生窗口采集，可为不依赖 ML 的操作选择相同的 4K60、独立帧率和归档验收，复用现有流程与媒体派生命令。

- 多工作树开发支持独立数据库、Redis、对象存储桶及可选本机 worker，提供环境诊断、停止和需精确确认的重建/清理；测试与端到端验收可使用独立模式，避免不同分支的迁移和任务互相干扰。

- 图片、视频和点云任务留言支持 `@` 项目成员，保留提及并发送可静音的站内通知，点击可定位原任务留言。

- 视频单帧和轨迹标注显示评论数量气泡，跟随当前帧可见位置；沿用默认开启的账号级「标注评论提示」设置。

- 图片问题可关联落点时选中的标注，图片和视频均可在提交前取消对象关联并保留画布位置；问题列表与详情显示关联对象，定位时选中仍可用的对象。

- 图片任务在未选标注时也可使用弹窗批注或直接在题图上绘制，并发送纯绘图留言；任务与标注绘图草稿分别保留。

- 图片画布的正式标注显示评论数量气泡，点击可打开对应讨论；同类别实例独立计数，超过 9 条显示 `9+`。新增默认开启、按账号保存的「标注评论提示」开关。

- 工作台支持未选标注时发送任务文字留言；阅读范围与发送目标分开选择，任务和标注草稿在同一次登录会话中随切题、面板调整及站内返回保留。

- 工作台问题支持完整对话、文字回复及上一条／下一条未解决导航；打开详情与画布定位分开，解决问题后可继续阅读，图钉可直接打开筛选外或较早的问题。

- 问题回复、状态变化和标注评论中的 @ 提及会发送站内通知，可按类型静音并直达原对话或评论；较早内容会继续分页查找，不受同一对话后台刷新的干扰，跳转时保留已有草稿确认。

- 标注指引和项目模板指引支持可视化排版、Markdown 源码与预览；BUG 描述和评论共用紧凑编辑器，支持表格、列表与代码。空白指引可插入起步模板，保存和上传失败时保留正文并提供重试。

- 工作台可把当前面板排列另存为命名布局预设，随账号保存、最多 5 组，支持应用、重命名和删除。预设记录保存时的工作类型，只在同类型任务中可应用；应用时保留当前画布、任务、工具与未提交草稿，并可撤销。

- 成员与邀请管理提供分页、组合筛选及同范围统计与导出；批量邀请和分组显示逐项预览与结果，失败项可单独重试。单批次与项目派发前展示负责人变化和任务负载，数据变化后需重新确认；角色编辑可核对跨项目影响，个人设置支持退出其他设备。

- 邀请可指定目标项目，新账号注册时一并加入用户组和项目，已有账号登录后确认加入；接受时重新检查邀请人及项目权限，并展示可开始工作或等待分派的状态。

- 超级管理员可分组管理邀请上限、离线判定、连接器导入预算、建任务阈值与视频预热，查看有效值来源并恢复部署默认；保存保留其他组草稿，并发冲突需核对最新值，SMTP 支持保留、更换和明确清除密码。

- 通知可直达具体任务与最新退回状态，首页退回入口保留待重做筛选；后台任务支持查看历史及该次结果，失去目标权限、导出过期时提供处理入口，批量预标可只重试失败项。

- 人员管理支持启用、停用和全部账号筛选，按项目分别交接负责人、标注员和审核员职责；紧急停用保留待交接事项，明确区分可恢复停用与删除、历史未知状态。

- 支持在现有环境旁部署独立的局域网生产应用：前端 HTTPS 3030、API HTTPS 8080，复用数据库实例、对象存储和模型服务，生产账号、业务数据、存储桶及后台任务独立；提供客户端证书信任和恢复说明。

### Changed

- 移除筛选栏中纯装饰的漏斗图标 + 文字标签（通知、问题、Bug、离线队列、模型市场、AI 预标注等），保留用于区分多组筛选的条件名称标签，筛选栏更紧凑；`aria-label` 无障碍分组名保持不变。

- 点云渲染资格 benchmark 适配当前工作台 UI：进入后自动展开默认折叠的 Scene 时间轴，三视图精修改经工作台设置对话框「面板与高级布局」开关打开，恢复 v0.25.x 布局改造后失效的三轮资格测试；Apple Metal 三轮资格中两轮完整过门（详见 macOS WebGPU 实测报告与 ROADMAP）。

- 工作台居中悬浮面板（设置、快捷键、标注指引）与全局模态统一对背景做同一程度的模糊压暗；3D / 点云工作台只压暗、不模糊，避免软件渲染下 backdrop-filter 拖慢合成清理并导致后续上下文初始化超时。快捷键面板中的图片、视频、点云阶段标签分别使用蓝、紫、琥珀色，便于在「全部类型」视图快速区分适用范围。

- 工作台设置与快捷键面板的搜索结果高亮命中的关键词，便于在长列表中快速定位匹配项。

- 模型市场注册管理的四张主表改为卡片式圆角表框、浅色表头标签带与更宽松的行内边距，表头与数据层级更清晰；行分隔线由正文颜色改为语义边框色，不再在深色主题呈现亮白网格、浅色主题呈现深黑网格。

- 模型市场页面骨架收敛为一个标题 + 下划线式主 TAB，移除父页面重复的全局统计卡；注册管理改为紧凑摘要带 + 带计数的子 TAB（问题徽标按真实最高严重度着色），主表列收敛后身份与操作在 1440px 宽度同屏可见，ID 默认显示短 ID（tooltip / 复制可取完整值）。

- 运行时观测页头的四个大摘要块改为一条紧凑摘要带；服务池卡精简为「身份 + 健康/路由/新鲜度 + 带标签字段带」两行布局，无流量指标的池只显示一条「暂无路由指标」，驻留/CPU 回退未知时不冒充数值；成员首层补充并发与驻留独立字段。刷新与自动刷新不再引起卡片跳动或丢失展开状态。

- 平台概览的最近项目仅保留设置和打开入口，复制项目统一从项目管理进入。

- 项目管理的列表与卡片支持服务端分页和每页条数选择，页码随链接恢复；搜索、筛选或修改条数回到首页，删除导致页码越界时自动回退。日期筛选支持完整结束日，并正确报告无效日期。

- 平台概览最多展示最近创建的 5 个项目，并提供「查看全部项目」链接进入项目管理，避免项目增多时概览列表过长。

- 批次列表操作按钮默认以图标显示，悬停时展开名称，减少操作列的视觉拥挤；键盘聚焦与触屏操作也能查看名称。顶部的分派、创建按钮与视图切换控件统一字号和高度。

- 更新用户手册静态截图：登录、项目与筛选、Data Manager、AI 预标注、审核、设置、离线分析、系统健康与平台管理页面按当前界面重拍，补充悬浮 AI 面板与 AI 追踪面板配图，并同步刷新首页 Hero 配图。

- 重录矩形、旋转框、折线、多边形、Mask 涂抹、批次批量操作、视频章节、大图渐进、单切片恢复、Mask 上限与快捷键面板演示视频，按当前界面与干净工作树录制并重新审片。

- 全站筛选使用统一漏斗图标与紧凑控件；项目高级筛选改为按钮旁展开，成员、邀请、审计和模型附加条件提供可移除摘要，窄屏使用底部面板，工作台筛选保持原位与原有操作范围。

- 项目高级筛选面板改为首次展开时按需加载，减少首屏 JavaScript；入口和已选摘要保持同步显示，关闭与再次打开保留原有交互。

- 文档站按任务重组导航与栏目入口，优化正文宽度、长页目录、代码和表格阅读，统一中文导航标签与深浅色、窄屏布局；操作指南优先展示完成任务的主流程，并保留原页面链接与章节锚点。

- 项目标注指引在停止输入后自动保存，并显示等待、保存中和失败重试状态，减少编辑后忘记保存的情况。

- 工作台标注指引移到顶栏，通过按钮打开与设置同尺寸的阅读窗口，支持点击外部关闭；返回时保留原标注状态，阅读确认和重试入口保持可见。

- 布局预设示意图采用 16:9 画幅，按实际侧栏宽度和上下分区比例展示，方便比较各预设的画布空间。

- 工作台各布局预设的左右侧栏统一为工作区宽度的 15%，审核协作保留右侧详情和底部讨论，AI 审阅与视频追踪不再默认占用较宽的右栏；窄栏下标题、表单和操作按钮自动换行。

- AI 示例框与二次推理的胶囊悬停区支持直接调节已有置信度；二次推理显示当前能力和目标文本，完整面板与 AI 交互工具统一紧凑布局，使用 X 收起。

## [0.25.0] - 2026-09-05

### Added

- 工作台新增“布局”菜单，任务队列、类别面板、标注详情和讨论可停靠、组成标签、浮动或隐藏，并提供标准标注、专注画布、审核协作预设与一次布局撤销。
- 工作台布局按账号及标注或审核、图片或视频或点云分别保存；窄窗口临时显示单个面板，放宽窗口后恢复桌面布局。

### Changed

- 工作台布局读取完成前暂时锁定布局操作；损坏布局可显式重置，来自新版的布局保持只读，避免旧客户端覆盖已保存的位置。

### Fixed

- 视频导出包的抽帧脚本兼容 FFmpeg 9，修复旧参数导致抽帧失败的问题。
- 录制夹具初始化补齐 nuScenes 地图文件，并按数据集隔离路径解析点云资源，修复全新开发库恢复时地图缺失和任务校验失败。
- 3D 点云工作台的选中信息栏会与桌宠共享位置并一起拖动，不再作为独立浮层停在画布右上角。
- KITTI 点云导出会在相机成员或标定变化后失效旧缓存，并按人工相机框的可见性写入遮挡级别，不再复用过期包或误读 3D 属性。
- 点云质量问题按状态筛选时会先刷新过期状态再分页，首屏不会因已失效问题占位而漏掉仍有效的问题。
- AAP JSON 标注导入的 dry-run 会校验相机角色、主 3D 轨迹关系与重复相机成员，预检结果现在与正式导入一致。- 超限大图现在会同时禁用 Mask 按钮和 `M` 快捷键，并显示同一条尺寸上限原因。
- 批量预标现在按实际归一化后会持久化的重试上下文执行 8 KiB 限制，不再因大量空参数误报 422。
