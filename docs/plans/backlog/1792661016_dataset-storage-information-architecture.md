> 实施前须通过 [backlog promotion gate](README.md#promotion-gate)。[草案总览](1792661016_dataset-storage-roadmap.md)、[架构契约](1792661016_dataset-storage-architecture.md)和[交付验收](1792661016_dataset-storage-delivery-acceptance.md)共同约束本系列。

## 1. 产品目标与现状

用户的两个明确要求是：已有图片目录无需搬运原图即可注册为数据集；数据集与存储管理消除信息重复。

当前数据集页面同时承载数据集和数据连接器，详情主要放在列表展开行；存储页面又展示数据集数量、数据集存储概览、文件数和关联项目。这使“去哪里管理数据”和“去哪里配置连接”边界不清。存储页面的“总容量”实际使用对象占用字节，还存在 MinIO 和开发环境协议硬编码。依据：[数据集页面](../../../apps/web/src/pages/Datasets/DatasetsPage.tsx)、[存储页面](../../../apps/web/src/pages/Storage/StoragePage.tsx)。

目标界面围绕四个问题组织：

- 数据集：有哪些样本、质量如何、来自哪里、用于哪些项目和版本？
- 存储：文件位于哪里、连接是否正常、平台占用了多少空间、如何维护？
- 项目：谁在标注、完成了多少、审核到哪一步？
- 后台任务：扫描、复制、缓存、迁移等操作正在执行什么、失败在哪里？

## 2. 唯一权威页面矩阵

同一事实可以在上下文中显示摘要，但只在一个位置维护完整列表、配置表单和主要操作。

| 信息或操作                                | 权威页面                            | 其他页面允许展示                                   | 不应重复出现                                 |
| ----------------------------------------- | ----------------------------------- | -------------------------------------------------- | -------------------------------------------- |
| 数据集目录、名称、类型、说明              | 数据集列表/详情                     | 存储页按权限显示受影响数量及链接                   | 存储页完整数据集表与创建入口                 |
| 样本、场景、原始媒体质量问题              | 数据集详情                          | 项目页显示本项目任务对应样本与来源摘要             | 存储页缩略图浏览器                           |
| 项目标签 schema、标注对象与轨迹、标注质量 | 项目 Data Manager / Workbench       | 数据集按明确项目上下文展示摘要与深链               | 数据集内另建跨项目标签真值或完整标注管理器   |
| 数据集来源根、筛选规则、同步策略          | 数据集详情“来源与同步”              | 存储位置显示引用该位置的来源数                     | 存储页编辑每个数据集的筛选规则               |
| 位置端点、受控根、凭据、可用能力          | 存储位置详情                        | 数据集显示位置名称、类型、只读状态                 | 数据集内完整连接器配置页                     |
| 存储位置健康与物理容量                    | 存储位置详情                        | 数据集显示来源异常摘要及受影响样本数               | 数据集详情重复磁盘/桶仪表盘                  |
| 平台用途到位置的映射                      | 存储管理“用途映射”                  | 迁移任务引用相关用途                               | 数据集页面配置 annotations/training 等用途   |
| 标注进度、人员分配、审核状态              | 项目页面                            | 数据集显示指定项目的摘要及跳转                     | 不指定项目的“数据集全局标注完成率”           |
| 训练版本、冻结清单、版本差异              | 现有项目/训练版本页面及共用版本详情 | 数据集详情显示关联训练版本及带项目上下文的入口     | 存储页维护版本，或数据集页另建无项目版本体系 |
| 扫描、复制、缓存、迁移任务状态            | 既有全局后台任务入口                | 页面展示上下文任务摘要/筛选入口                    | 再创建一套独立任务状态机和历史页             |
| 位置级缓存默认、配额、上限与清理          | 存储管理                            | 数据集来源选择限制内的本来源策略，后端返回生效策略 | 两页维护同一配置，或把预览当作原图副本       |
| 项目与数据集关联/解除关联                 | 数据集详情与项目入口共用同一服务    | 两端只维护自身上下文                               | 两套不同的关联或删除语义                     |

“数据连接器”不再作为数据集页独立页签。已有连接配置迁移为存储位置的连接配置，位置详情可以包含连接器实现信息，但用户只维护一份配置。

## 3. 导航和建议路由

以下是新增/调整建议，实施时应与现有路由、URL 过滤状态工具协调。

| 导航         | 建议路径                         | 主任务                                                     |
| ------------ | -------------------------------- | ---------------------------------------------------------- |
| 数据集       | `/datasets`                      | 搜索、筛选、创建和进入数据集                               |
| 数据集详情   | `/datasets/:datasetId?tab=data`  | 浏览样本；其他 tab 为 sources、quality、projects、versions |
| 存储管理     | `/storage?tab=locations`         | 按位置查看连接和健康                                       |
| 存储位置详情 | `/storage/locations/:locationId` | 配置、容量、缓存、用途、维护                               |
| 用途映射     | `/storage?tab=bindings`          | 管理平台业务用途映射                                       |
| 后台任务     | 复用现有任务入口与详情组件       | 通过 datasetId/locationId/jobId 过滤或打开详情             |

不新增“连接器管理”“数据源管理”“存储位置管理”三个同义导航。数据集的来源配置是对存储位置的引用；存储位置是可复用的基础设施配置。

旧连接器入口在过渡期显示说明并转向对应位置详情。旧数据集展开链接应转换为稳定详情地址，并保留搜索、筛选、分页与返回位置。

## 4. 数据集列表

### 4.1 默认字段

| 字段      | 口径                                  | 交互                         |
| --------- | ------------------------------------- | ---------------------------- |
| 名称/说明 | 逻辑名称，不是存储目录键              | 点击进入独立详情             |
| 类型      | 图像/视频/3D/多模态                   | 延用现有类型筛选             |
| 样本数    | 当前非移除成员数；包含缺失或离线样本  | 点击进入数据浏览             |
| 来源      | 位置别名与来源数；多个来源可折叠      | 点击“来源与同步”             |
| 可用性    | 原图可读、仅预览可用、待核验/异常数量 | 点击打开相应样本过滤器       |
| 关联项目  | 当前用户可见的项目数量与摘要          | 点击“项目关联”               |
| 最近变更  | 数据集成员/元数据变更时间             | 不用存储探活时间冒充数据变更 |

列表不展示存储桶总容量、端点、访问密钥或磁盘剩余空间。M1 保留紧凑表格；高级过滤与保存视图在 M2 扩展。

创建按钮默认突出“从已有目录创建”，并保留“上传文件”“从已有对象存储接入”等路径。若用户没有任何可用位置，先说明需要管理员开放目录；不诱导其填写服务器绝对路径。

### 4.2 数据集详情

页头显示名称、说明、样本数量、可用性摘要、最近同步结果与操作菜单。支持重命名，重命名不改变源目录或对象键。

| 页签       | 主要内容                                                   | 主要操作                                           |
| ---------- | ---------------------------------------------------------- | -------------------------------------------------- |
| 数据       | 样本表格/网格、过滤器、场景分组、选中样本检查器            | 查看、筛选、保存视图、按权限批量操作               |
| 来源与同步 | 来源位置、相对目录、原图策略、缓存策略、过滤规则、同步摘要 | 预览扫描、手动同步、处理变化、调整本来源规则       |
| 质量       | 无法解码、尺寸异常、精确重复、近似重复候选、待处理变化     | 查看样本、标记已处理、创建筛选视图                 |
| 项目关联   | 已关联项目及项目范围进度摘要                               | 关联/解除关联、进入项目                            |
| 关联版本   | 各授权项目与本数据集相关的冻结版本、范围、状态             | 选择项目后进入共用冻结流程；查看版本/差异/训练深链 |

样本检查器展示相对路径、尺寸、格式、内容校验状态、原图/预览可用性、来源别名、所属场景和业务引用。对无存储管理权限用户，不展示内部主机名、绝对挂载路径或凭据。

TrainingDatasetVersion 继续归属于项目。由数据集发起冻结时，必须选择已关联且有权限的项目及其任务/标注范围；从项目进入则继承并显示上下文。未关联项目先引导完成关联，不创建无项目版本。首期不混合多个项目的标注。

“已登记/待校验”与“可标注”明确分开：只有当前内容修订的完整原图经核验可读且有项目权限时才允许编辑标注。仅缩略图可用时只能只读浏览，禁止编辑与提交；经核验的完整原图缓存可以满足同一修订的读取要求。

质量筛选不自动删除或覆盖样本。近似重复只提供候选，阈值、模型和版本必须记录；M1 不要求上线近似重复算法。

## 5. “已有目录直接成为数据集”的主流程

1. 选择“已有目录”，从有权限的存储位置中选择受控根。
2. 在受控根内浏览相对目录；选择递归、文件类型、include/exclude 等规则。
3. 设置数据集名称；原图策略默认为“原地引用”；独立选择是否生成预览缓存。
4. 执行扫描预览，看到新增、重复候选、变化、无法读取、排除文件及预计占用。
5. 确认并创建索引任务；后台任务可继续执行，页面可关闭后重新进入。
6. 首批可用样本出现后即可浏览；“扫描中”与“已完成”有明确区分。
7. 首次同步完成后，展示最终计数及失败项，支持继续处理异常或关联项目。

第一步明确文案：“选择平台已授权访问的服务器或 NAS 目录”。浏览器选择用户电脑目录属于上传，不与服务端原地引用混用。

### 5.1 原图和缓存选择

| 选择     | 用户可见说明                     | 空间影响                                                                           |
| -------- | -------------------------------- | ---------------------------------------------------------------------------------- |
| 原地引用 | 原图保留在所选位置，平台建立索引 | 初始原图持久副本预计为 0；另计元数据、缩略图、受限读取缓冲、按需缓存及后续冻结副本 |
| 复制托管 | 原图复制到平台指定托管位置       | 展示预计原图复制量及目标位置                                                       |
| 预览缓存 | 为列表与快速预览生成缩略图       | 独立计量；不能代替训练所需原图                                                     |
| 按需缓存 | 使用时缓存允许缓存的原图         | 显示配额、保留规则及允许区域                                                       |

预览结果只代表扫描时的观测。提交时源发生变化，应重新核验受影响条目；不得承诺点击确认后结果永远与预览完全一致。

### 5.2 异常提示

| 情况             | 提示与可执行动作                                                 |
| ---------------- | ---------------------------------------------------------------- |
| 位置暂时离线     | 显示最后可读时间、重试；保留原索引，不将所有条目标为已删除       |
| 文件缺失         | 保留成员与历史引用，标为缺失，提供复查和处理入口                 |
| 内容变化         | 标为变化待确认，阻止旧标注静默读到新字节                         |
| 仅预览可用       | 只读查看已有预览；禁止编辑/提交标注以及需要原图的下载或训练      |
| 部分文件无权读取 | 显示脱敏原因和失败数量；有权限用户可查看失败清单                 |
| 取消扫描         | 展示已完成、未处理数量及检查点；下一步依据后台能力恢复或重新扫描 |

## 6. 存储管理

### 6.1 位置列表

默认展示位置名称、类型、站点、启用状态、探测健康、已索引源数据量、平台写入占用、配额、最后检查时间。

已索引源数据量是平台认识的源文件逻辑字节，不能当作平台占用；平台对象字节需要按托管原图、预览/缓存、训练冻结和其他用途解释。对象字节不等于包含副本、纠删码及文件系统开销的物理磁盘占用。真实物理容量只有后端提供可信值时展示，未知显示“未提供”。

跨位置汇总必须说明去重范围。相同内容多个副本的物理占用可相加；同一外部目录被多个数据集引用的源字节不可按数据集机械相加。

### 6.2 位置详情

| 区域       | 内容                                                  |
| ---------- | ----------------------------------------------------- |
| 概览       | 连接类型、只读/可写能力、服务状态、最近探测与探测范围 |
| 连接配置   | 端点或受控根别名、凭据状态、访问范围、连接测试        |
| 容量与缓存 | 带统计时间的用量、配额、缓存清理建议、未知值说明      |
| 用途与引用 | 平台用途映射、受影响来源/数据集计数与跳转             |
| 维护       | 禁用、迁移、退役等操作及影响预览                      |

“查看受影响数据集”跳转至数据集列表并带 locationId 筛选，不在存储详情再次复制完整数据集管理表。无数据集读取权限的运维人员只能看到运维必需的脱敏计数或被授权的引用摘要。

迁移只在存储侧发起；数据集侧展示“来源维护中”和可用性影响。缓存清理明确不等于删除原图或冻结版本。

## 7. 状态、统计与文案字典

| 展示词     | 含义                               | 不能代表                          |
| ---------- | ---------------------------------- | --------------------------------- |
| 已索引     | 平台登记了元数据                   | 已复制原图、已经全面校验          |
| 原地引用   | 原图仍在源位置                     | 无任何额外存储、来源永远可用      |
| 原图可读   | 在所示核验时间/范围内可读取原图    | 永久可用保证                      |
| 仅预览可用 | 缓存预览可读，原图当前不可用       | 可以编辑/提交标注、训练或导出原图 |
| 已冻结版本 | 绑定固定内容与标注，并符合冻结协议 | 一条仍可变化的目录引用            |
| 已占用空间 | 指定统计范围的实际对象/文件占用    | 磁盘总容量                        |
| 配额       | 平台配置的预算或限额               | 底层硬盘真实剩余空间              |
| 来源异常   | 某来源探测或读取失败               | 数据集业务记录已删除              |

容量统计统一带 `measured_at`、统计范围、来源和覆盖状态；样本可用性使用 `last_checked_at`。过期数据保持可见但标注“上次统计”；刷新失败不能把旧数值变为 0。

## 8. 交互和视觉约束

- 延用项目现有语义色、紧凑布局、表格与表单组件；不为两个页面各造一套视觉体系。
- 数据列表和网格共用过滤器、选中状态和服务端分页；样本多时不一次载入全部缩略图。
- 关键状态同时提供文本和图标，不能仅依赖红绿颜色。
- 表格溢出优先保留名称、状态和动作；次要列可配置，窄屏采用详情抽屉。
- 详情页和样本检查器支持键盘操作、可见焦点、Esc 关闭、焦点归还。
- 批量操作显示“已选当前页”与“已选全部筛选结果”的明确范围；执行时绑定查询快照/版本，避免后台变化扩大范围。
- 删除、解除关联、禁用位置使用影响预览和准确动词；源文件只读时不提供“删除原文件”。

## 9. 页面状态与权限

| 状态            | 统一规则                                                         |
| --------------- | ---------------------------------------------------------------- |
| 首次加载        | 显示骨架；不能以空列表掩盖未完成请求                             |
| 空目录/空数据集 | 说明当前状态并给出合理下一步；扫描未结束时不可显示“没有数据”结论 |
| 筛选无结果      | 保留筛选条件，提供清除筛选；与数据集为空区分                     |
| 局部失败        | 保留其他可用区域；失败区域提供重试与原因                         |
| 权限不足        | 页面和接口一致；不在隐藏按钮背后保留可调用的越权接口             |
| 配置变更中      | 显示任务或配置版本，不乐观宣称迁移/凭据轮换已完成                |
| 过期深链        | 提示目标已移除、归档或无权限；不泄露不可见对象名称               |

“可使用某位置创建来源”和“可管理该位置凭据”是不同能力。项目标注人员可以通过已授权任务读取所需资产，并不因此获得列举整个目录或下载全部数据集的权限。

## 10. 前后端合同草案

建议由查询接口直接返回经过权限裁剪的摘要及允许动作，避免前端自行拼接多接口推断权限。

| 对象                   | 关键展示字段草案                                                                                                              |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| DatasetSummary         | id、name、data_type、item_counts、source_summary、project_summary、last_changed_at、allowed_actions                           |
| DatasetSourceSummary   | id、location_id、display_name、relative_path、ownership_mode、cache_policy、effective_cache_policy、sync_status、last_scan_at |
| AssetAvailability      | original_availability、preview_availability、verification_state、reason_code、last_checked_at、allowed_actions                |
| StorageLocationSummary | id、name、kind、site_id、enabled_state、health、usage、quota、measured_at、allowed_actions                                    |
| ImpactPreview          | target_revision、affected_counts、blocked_reasons、required_acknowledgements、expires_at                                      |

这些字段不是现有 API 事实；最终与 [领域设计](1792661016_dataset-storage-architecture.md) 和各 Epic 的接口设计统一。读接口不返回明文凭据、内部签名密钥或超出授权的目录信息。

## 11. 验收与设计交付

1. 用户能从已有目录创建数据集，完整流程只配置一次位置，不需要在两个页面重复填写凭据。
2. 从数据集来源异常进入对应位置后，返回仍保留数据集和筛选上下文。
3. 在数据集页找不到完整容量/桶管理仪表盘；在存储页找不到重复的数据集 CRUD 表。
4. 同一数据集关联两个进度不同的项目时，界面显示各自进度，不合成含义不明的总完成率。
5. 离线、缺失、内容变化、仅预览可用在列表、详情和标注入口具有一致文案与操作限制。
6. 所有容量数值能解释来源、单位、统计时间、去重口径；未知总容量不显示 0 或伪造百分比。
7. 旧数据连接器链接、数据集入口、权限提示和全局任务入口有兼容路径。

交付物包括页面结构、组件状态矩阵、接口字段字典、交互原型、权限样例和回归用例。实现拆分见 [EPIC-08](../archive/1792661016_dataset-workbench-quality.md)、[EPIC-09](../1792661016_dataset-storage-console-boundaries.md)、[EPIC-11](../1792661016_dataset-permissions-lifecycle.md)。
