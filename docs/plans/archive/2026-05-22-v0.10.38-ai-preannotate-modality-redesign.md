# v0.10.38 · AI 预标注模态化重设计 + video-jobs 并入（epic 阶段 2 + 3）

> 落地 [ML Backend 能力协商 epic](../../ROADMAP/archive/2026-05-22-ml-backend-modality-and-ai-preannotate-redesign.md) **阶段 2 + 阶段 3**。依赖 v0.10.37（阶段 1）已落地的 `health_meta["capabilities"]` + `derive_modalities`。
>
> **核心**：`/ai-pre` 从「图像单后端文本批量预标」升级为模态感知（image/video 分流）+ 多 backend 选择 + 按后端参数面板；`/ai-pre/jobs` 统一图像/视频两类 AI 任务历史，把 v0.10.36 临时落在 ModelMarket 的视频追踪监控页并入。

## 决策（2026-05-22 与用户确认）

- **视频执行页 = 引导卡片 + job 历史**：后端无批量 tracker 派发端点（视频 AI 是工作台逐轨迹 Shift+T 发起 `VideoTrackerJob`）。视频项目进 `/ai-pre` 详情面板**不做批量派发**，改为引导卡片（说明在工作台发起 + 跳任务列表 + 本项目视频 job 历史链接）。不造不存在的派发语义。
- **多 backend 选择 + 按后端参数面板**：`POST /{project_id}/preannotate` 已显式收 `ml_backend_id`，项目本就是 1:N 注册 backend——**无需 schema 改动**。前端加 backend 选择器（默认绑定值）+ 复用 `SchemaForm` 按选中 backend 的 `/setup.params` 渲染参数面板，按 backend 分桶持久化（复用 `useAiToolParamPrefs` 的 `User.preferences.ai.params_by_backend`）。
- **统一 job 历史 = 前端 tab**（epic 明示）：复用 `GET /video-tracker-jobs` 端点 + `VideoTrackerJobsPage` 逻辑，在 `/ai-pre/jobs` 加「图像 / 视频」模态 tab；**不新增后端 union 端点、不合表**。
- **参数流**：worker 保持无状态——前端把解析好的 params 显式塞进请求 `params`，worker 只把 `params` 合并进 `/predict` context（覆盖项目级 box/text_threshold 兜底）。worker 不读 per-user 偏好。

## §A 模态感知路由（后端 + 前端）

1. **后端撤症状止血过滤** [admin_preannotate.py:329](../../apps/api/app/api/v1/admin_preannotate.py)：删 v0.10.36 加的 `Project.data_type == "image"` 过滤，让视频项目重新出现在 summary（分流交给前端）。summary 已返回 `data_type`。
2. **改测试** [test_admin_preannotate.py](../../apps/api/tests/test_admin_preannotate.py)：`test_preannotate_summary_excludes_non_image_projects` → 改为断言视频项目**现在出现**（路由移到前端）。
3. **前端按 data_type 分流** [ProjectDetailPanel.tsx](../../apps/web/src/pages/AIPreAnnotate/components/ProjectDetailPanel.tsx)：进面板时按 `summary.data_type` 分流——
   - `image`：现有文本批量预标面板（不变）。
   - `video`：渲染**引导卡片**（工作台 Shift+T 发起说明 + 跳 `/projects/{id}/tasks` + 「本项目视频 job 历史」链接到 `/ai-pre/jobs?tab=video&project_id=`）。
   - `lidar`：占位「暂不支持 AI 预标」。
4. **ProjectCardGrid**：卡片已展示 `data_type`，无需大改；可加模态徽标区分。

**验收**：视频项目能在 `/ai-pre` 列表出现且点进不崩（不再误用图像面板）；图像项目流程不变。

## §B 多 backend 选择 + 按后端参数面板（前端 + 后端 plumbing）

5. **后端 PreannotateRequest 加 `params`** [schemas/preannotate.py](../../../apps/api/app/schemas/preannotate.py)：`params: dict | None = None`，透传给 `batch_predict.delay(...)`。
6. **worker 合并 params** [tasks.py](../../apps/api/app/workers/tasks.py) `batch_predict` + `_run_batch`：签名加 `params`；构建 context 时在项目级 box/text_threshold 之后，用 `params` 覆盖（`context.update(params)`，过滤 None）。无 params 时行为完全不变（向后兼容）。
7. **前端 backend 选择器** [ProjectDetailPanel.tsx](../../apps/web/src/pages/AIPreAnnotate/components/ProjectDetailPanel.tsx)：拉 `mlBackendsApi.list(projectId)` 列项目已注册 backend，下拉选择，默认 `summary.ml_backend_id`（绑定值）。运行时用选中的 backend_id（取代当前写死 `boundBackend.id`）。
8. **前端参数面板**：选中 backend 后拉其 `/setup`（`mlBackendsApi.setup`），用 `SchemaForm`（[Workbench/components/SchemaForm](../../apps/web/src/pages/Workbench/components/SchemaForm/index.tsx)）按 `params` 渲染；值按 backend 分桶持久化（复用/对齐 `useAiToolParamPrefs` 的 `params_by_backend`）。运行时把面板值塞进 trigger payload 的 `params`。
9. **trigger hook** [usePreannotation.ts](../../apps/web/src/hooks/usePreannotation.ts)：`TriggerPreannotationPayload` 加 `params?`。

**边界**：不做「batch×backend 矩阵配置」；不做精细多模型对比 modal。box/text_threshold 项目级字段保留作兜底（params 覆盖优先）。

**验收**：同项目可选不同已注册 backend 跑预标；选中 backend 的 `/setup.params` 参数能传到 `/predict`；参数按 backend 记忆。

## §C 统一 job 历史 + video-jobs 并入（前端 + 路由）

10. **抽离视频 job 表组件**：把 [VideoTrackerJobsPage.tsx](../../apps/web/src/pages/ModelMarket/VideoTrackerJobsPage.tsx) 的过滤 + 计数卡 + 列表逻辑抽成可复用组件（或整体作为「视频」tab 内容）。
11. **`/ai-pre/jobs` 加模态 tab** [AIPreAnnotateJobsPage.tsx](../../apps/web/src/pages/AIPreAnnotate/AIPreAnnotateJobsPage.tsx)：顶部「图像 / 视频」tab 切换——图像=现有 `GET /admin/preannotate-jobs` 表；视频=复用的视频 job 表（`GET /video-tracker-jobs`）。tab 状态用 `?tab=image|video` query 同步（供 §A 引导卡片深链）。
12. **退役 ModelMarket 挂载点**：删 `/model-market/video-jobs` 路由（或 301 重定向到 `/ai-pre/jobs?tab=video`）[App.tsx](../../apps/web/src/App.tsx)；删 [ModelMarketPage.tsx](../../apps/web/src/pages/ModelMarket/ModelMarketPage.tsx) 的视频 jobs 入口链接。
13. **边界守住**：ModelMarket 只留**后端 / 显存池健康**观测（v0.10.36 模态拆分预热面板）；ai-pre 收**任务 job 历史**。

**验收**：`/ai-pre/jobs` 一处看图像 + 视频两类 AI 任务历史；ModelMarket 不再有视频 job 监控入口。

## 不做（边界）

- 不新增后端 union job 端点、不合 `PredictionJob` / `VideoTrackerJob` 两表（只统一前端展示层）。
- 不建批量 tracker 派发端点（视频 AI 仍工作台逐轨迹发起）。
- 不动 `ml_backend_id` 单值 schema（多 backend 选择基于已有 1:N 注册 + 请求显式 `ml_backend_id`）。
- 不做精细单 batch 多模型对比 modal（按客户驱动延后）。
