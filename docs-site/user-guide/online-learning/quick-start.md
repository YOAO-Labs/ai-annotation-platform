# 完成第一轮与第二轮

本教程带你从已有标注得到一个可用于项目预标的模型，再用人工修正后的数据训练第二轮。先选择一种任务完成流程，检测与实例分割分别创建自己的数据版本、实验和默认预标选择。

## 准备项目

准备一个图片项目，完成矩形框或实例区域的类别配置，并检查一批标注。至少需要两组互不重复的图片，以便分别进入训练和验证；正式判断效果还需要有代表性的验证样本。

从「训练队列 → 训练仓库」确认所选任务的训练器和基础模型可用。后续要回流模型时，还需要一个已注册、已在项目启用、认证有效且支持该模型的推理服务。缺少服务时可以先训练，回流前按[服务准备](./models#准备推理服务)完成配置。

本地开发可使用 [COCO8 在线训练夹具](https://github.com/yyq19990828/ai-annotation-platform/blob/main/DEV.md#coco8-在线训练夹具)。夹具预置 8 张已审核图片、30 个检测框和 30 个实例掩码，并分别提供检测与原生 RLE 分割初始版本，保留原始 4 张训练图／4 张验证图划分。它适合检查流程，不用于证明业务精度。实验与自动策略仍由负责人创建或启用。

## 1. 冻结第一版数据

进入项目「在线学习 → 训练数据」，选择目标检测或实例分割，点击「准备新版本」。

1. 选择项目或批次范围，核对本轮类别。
2. 默认使用「已审核数据」。没有审核流程时，切换「负责人确认」，逐项选择已经检查的任务。
3. 对空标注明确确认「无目标」，避免把尚未标注的图片当成负样本。
4. 首轮按需要设置验证比例和随机种子，点击「检查训练数据」，核对正样本、负样本和排除原因。
5. 点击「创建数据版本」，等待状态变为就绪。打开冻结样本，检查图片、类别与标注是否符合预期。

实例分割若包含画笔或 SAM 修正、孔洞、断连部件，选择「原生实例掩码」。它保留同一实例的孔洞、断连和不同实例间的重叠；需要仓库明确支持该能力。简单多边形和原生掩码使用不同的数据桥接，父版本不能跨桥接混用。

到这里，应得到一个可以查看冻结样本和下载训练包的就绪版本。预检问题、版本划分与数据限制见[训练数据版本](./data-versions)。

## 2. 创建并完成首个实验

在「训练实验」点击「新建实验」，或从就绪数据详情选择「使用此版本新建实验」并确认采用。

1. 在「数据与模型」先选实验任务，再选数据版本、训练器与基础模型。实例分割选择受控 `yolo11n-seg`。名称默认带 `detect-` 或 `segment-` 前缀，可以修改。
2. 在「模型初始化」确认初始化方式。首轮可以使用默认预训练基础权重；如果需要比较随机初始化，在支持的 Ultralytics 配置中选择从零训练。
3. 在「配置参数」设置轮数、批大小和图片尺寸等参数。希望观察训练集 Precision、Recall 和 mAP 时，开启「逐轮评估训练集」；它默认关闭，并会增加每轮耗时。
4. 在「核对并开始」点击「检查训练配置」，阅读实际生效参数及调整原因，再开始训练。

实验会先排队，资源可用后执行。打开详情查看训练／验证曲线、资源、日志与产物。完成后确认执行成功，并查看最终最佳权重评估；最近一轮曲线不一定代表最佳权重。完整步骤见[创建与管理实验](./experiments)和[训练监控与指标](./metrics)。

## 3. 注册模型并加载试用

从成功执行记录点击「回流到项目模型」，或在「模型与发布」点击「从训练结果添加模型」。填写名称，把每个原生类别绑定到当前项目对应工具的类别，全部完成后注册候选。

打开模型详情，在「用于加载模型的推理服务」中选择就绪服务，点击「加载模型并试用」。检查固定验证图片中的误检、漏检、类别和耗时；实例分割还要查看原图掩码，尤其是孔洞、断连、小目标和重叠实例。

加载成功说明这条安装和推理路径可用。需要判断一批样本的质量时，再创建[逐样本评估](./sample-evaluation)，按相同基准比较候选。

## 4. 设为默认预标并组织人工使用

查看固定验证样本后，勾选试用确认，点击「设为默认预标模型」并完成确认。在模型列表中核对该行的任务类型与「默认预标」标记。

选择「使用默认预标模型」，核对任务、模型、置信度以及追加或覆盖方式，再选择待处理图片运行预标。新结果进入候选区，标注员接受、修正并提交，审核员按原流程复核。实例分割产生逐实例原生掩码，可继续用画笔或 SAM 修正。

同一任务可以保留多个候选和部署。检测与分割分别选择默认模型；将一个分割模型设为默认，不会替换检测任务的默认选择。显式指定模型的管线与已经排队的任务继续使用其固定来源。

## 5. 用修正后的数据训练第二轮

审核完成后，在同一任务中准备新版本，选择兼容的首轮版本为父版本，继承历史训练／验证划分。用版本比较检查新增、移除与标注修正，并核对验证基准是否变化。

新建第二轮实验，明确选择新数据。若想从首轮学到的权重开始，选择同项目、同规格且原生类别及顺序一致的候选作为初始化来源。第二轮仍是一个新实验，训练状态从第 0 轮开始；如果只是继续一个中断实验，应使用该实验的断点续训。

比较两轮的验证结果和逐样本误差，确认值得采用后，再注册、试用并切换默认预标选择。需要恢复旧选择时，可使用「默认预标切换记录」。

流程稳定后，再考虑[自动训练策略](./automation)；需要决定下一批优先标什么时，可使用带随机对照的[主动学习选样](./active-learning)。
