# 训练配置与复用

配置参数前先选好实验任务与基础模型，界面只开放当前受控配置可以使用的选项。上游仓库拥有某个参数，不等于平台已经开放该参数或组合。

配置窗口的底部操作栏始终可见。滚动参数内容时，可直接使用「上一步」「下一步」或检查与开始操作。

## 设置与核对参数

「配置参数」默认展示常用项。切换「全部可编辑参数」后，可按中文名称、原生键或别名搜索；范围选择与「仅看已修改」并排，便于组合筛选。每项的默认值、约束和原生默认值放在参数标题旁，窄屏时自然换行；区间、枚举与布尔值使用对应控件，学习率支持科学记数法。

勾选「仅看已修改」时，所有包含可编辑参数的章节与分组导航仍保留，没有匹配项的章节显示 0 项。未修改任何参数，或重置最后一项修改后，也能继续查看完整章节结构。

修改后可单项重置，或在章节标题右侧点击「重置本组」。没有修改项时，章节的重置按钮禁用。

进入「核对并开始」后先检查训练配置。参数按服务端实际生效值与受控默认值比较：全默认的组默认收起；有变化的组自动展开，用强调色显示变化项并列出默认值。同组未变参数收在「默认参数」中。依赖调整也计入变化，显式填写相同默认值仍算未变化，所有组均可手动开合。

## 导入与导出 YAML

「导入 YAML」支持当前训练器的可编辑参数片段，或从本页导出的配置文件。文件上限 64 KiB，不接受多文档、重复键、标签、锚点、引用和平台管理参数。导入前会列出差异与错误；应用时替换全部参数覆盖，省略的已修改项恢复默认值，有错误时整批拒绝。导入不会创建实验。「导出 YAML」保留参数覆盖及训练器、基础权重、参数定义与镜像身份，便于复用；不包含训练包路径或下载凭据。

包含项目权重的完整 YAML 使用格式 2，保存模型版本与来源摘要，不保存下载 URL。导入时展示来源变化并重新校验同项目权限；旧格式 1 或纯参数片段只替换参数，保留当前明确选择的初始化权重。

## 查清参数支持范围与依赖

展开「完整参数目录」可按中文名称、原生键或别名搜索，并按分组和支持状态筛选。目录列出当前训练器的参数，同时保留其他任务、平台管理和未验证字段，避免把上游存在的参数误当成可用能力。设备、数据路径、下载脚本、回调和续训由平台管理。完整的原生默认值、平台默认值、允许范围和未开放项，分别见 [Ultralytics 参数对照](./ultralytics#完整参数对照表)与 [LibreYOLO 参数对照](./libreyolo#完整参数对照表)。

扩展配置会固定参数定义、用户输入、有效默认值及其来源。优化器、增强和预热存在依赖：例如 Adam 不使用 SGD 动量预热，关闭 EMA 后不能设置 EMA 衰减。短训练会调整默认预热和末尾关闭增强的轮数，显式提交无效组合会被拒绝。原生框架开始训练前再次核验实际配置；扩展实验的产物包含 `native-config.json`，可查看实际值与验证结果。原六参数实验继续沿用原有配置与续训方式。

## 实例分割的受控配置

分割固定独立实例掩码、`mask_ratio=1`，关闭 Copy/Paste、Mosaic、MixUp、CutMix、仿射／透视和多尺度；当前可配置水平翻转及颜色增强。矢量顶点完整保留不代表缩放后的像素覆盖不变，细小目标仍受训练分辨率影响。报告分别显示框和掩码的精确率、召回率、mAP 与分类别结果；原生最佳权重选择分数是二者 mAP50-95 之和，可大于一，不能当作百分比或单一掩码准确率。版本比较只接受相同训练任务，模型结果还须满足完整评估身份兼容条件。

参数搜索和原生增强预览尚未开放；数据、模型与配置须保持同一任务。模型初始化可以使用预训练权重、从零训练或合格项目候选，具体区别见[模型初始化方式](./experiments#选择模型初始化方式)。

## 查看原生增强预览

Ultralytics YOLO11 图片检测可在「配置参数」下方点击「生成原生预览」。选择独立的预览种子、训练轮次和 1 至 4 张输出；「更换预览种子」只改变预览选择，再生成即可查看另一组随机结果。种子和轮次不会写入训练配置、配方或实验请求。选定的轮次遵循关闭 Mosaic 的尾段设置，矩形批训练也遵循原生增强依赖。

完成后选择输出图片及其实际使用的原始来源，核对类别颜色、完整变换框和坐标。来源标出重复取用次数；读取但最终跳过的混合分支不算已使用来源。裁剪和过滤次数累计原生流水线中的操作，包含中间分支，不能当作唯一目标数或原图与结果框数之差。「实际参数与原生步骤」可核对精确参数、来源池和操作记录。预览只是当前种子的随机样本，未来训练批次可能不同。

预览只读取冻结训练分区中满足上限的最多 16 张图片：单图不超过 8 MiB、1600 万像素和 256 个框，来源池不超过 64 MiB、3200 万像素和 4096 个框。超限或未保留完整标签的图片会被跳过；没有可用图片时明确报错。输出最多每边 2560 像素、4096 个框。

预览使用单独的 CPU 槽，可能排队，也会与训练共享主机的 CPU 和内存。可点击「取消预览」；失联时保留资源直到确认进程退出。参数、数据、目录或登录会话改变后，旧结果立即移除。预览失败、执行器离线或 LibreYOLO 暂不支持时，仍可继续配置、检查并开始训练。

执行器升级时会自动核对上次请求：没有任务的旧请求会被清除，再由当前执行器重新上报预览能力；已有任务仍按原租约恢复。能力恢复后刷新页面，即可重新生成预览。

结果保留 24 小时，过期后需要重新生成。冻结数据在预览清理前仍受引用保护；删除预览的 API 可立即隐藏结果，后台等上传授权到期后清理。预览状态与图片不会在刷新后恢复，训练草稿仍按原规则恢复。

预览创建时固定自身报告和图片的位置，与输入冻结版本独立；修改当前训练桶不会改用另一份同名结果。旧预览缺少归属时仍可查看元数据和取消，报告／图片须由项目管理员经[显式核验接口](/api/guides/training-datasets#辅助产物归属与历史核验)确认当前保留副本后读取。核验不重新生成结果，不延长有效期；未知位置的过期记录保留待核对，后台不会猜测删除。

项目权重选择不参与增强预览的模型加载。预览仅验证数据变换和受控模型结构，不能代替模型初始化资格检查；改变初始化来源也会移除旧预览。

## 保存与采用项目配方

在参数页点击「保存为配方」，填写名称和说明，可新建项目配方或为已有配方创建新修订。每个修订保存完整生效配置、参数定义、原始基础权重、初始化权重和来源，历史修订不会被覆盖。发生并发修改时，编辑内容保留；核对最新修订后，再明确选择以它为基准提交。

展开「项目训练配方」，选择当前或历史修订，核对完整生效参数差异后点击「确认采用配置」。取消不会改变草稿。采用后保留当前名称与已经明确选择的数据，并要求重新预检；配方本身不指定数据版本。继续修改参数时会标记「已修改参数」，来源仍可追溯。目录、权重或参数定义变化时会阻止直接套用，需要明确解除来源并迁移，或保存一份与当前目录兼容的新修订。

## 克隆已有实验的配置

完整配置实验的「训练配置」提供「使用原配置初始化权重新建草稿」。克隆保留该实验原先选择的初始化权重，使用项目模型时仍固定原模型，不会自动选择被克隆实验的新产物。数据版本仍需手动选择；不会继承续训检查点、请求身份、自动触发或执行租约。加载来源时编辑草稿，会丢弃迟到的核对结果，可点击「重新核对克隆来源」再核对；也可取消克隆意图。成功实验还可直接保存为配方。旧六参数实验缺少完整默认值记录，不能声称完整克隆；请在参数工作区明确迁移后另存。

配方与自动策略保留所选初始化权重，解除配置来源不会清除权重选择。配方出现新修订时，当前草稿和策略只显示可更新提示，需重新核对才能采用。归档停止新采用和创建修订，保留历史读取、已排队实验和已采用策略。原实验删除后，保存的配方快照与当时来源仍保留；未保存配方的克隆来源失效时，草稿保持不变，可明确解除来源再继续。

## 复用时如何选择

| 想做的事                 | 入口                         | 仍需明确选择的内容                       |
| ------------------------ | ---------------------------- | ---------------------------------------- |
| 在文件中检查或交流参数   | 导出／导入 YAML              | 当前项目权限、任务、数据与初始化资格     |
| 团队重复使用一组配置     | 项目训练配方                 | 具体修订和本轮数据版本                   |
| 以某次实验的输入继续尝试 | 使用原配置初始化权重新建草稿 | 本轮数据；核对来源与当前目录兼容性       |
| 接着中断的训练继续跑     | 从检查点续训                 | 原实验的当前合格检查点，不重新选一套配置 |

准备好后回到[检查并提交](./experiments#检查并提交)。
