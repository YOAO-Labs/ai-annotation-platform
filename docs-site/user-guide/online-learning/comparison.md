# 实验比较与参数搜索

对比时既要看分数，也要确认分数由同一套数据和评估条件得到。平台保留每个实验的冻结输入与执行结果，只有证据完整且口径兼容时才计算差值或排名。

## 选择实验与精确执行

在项目的「训练实验」点击「比较实验」，从分页列表加入 2 至 4 个不同实验，为每项明确选择执行记录。选择、视图、曲线指标和平滑选项保存在链接中，刷新或返回后恢复；续训不会自动替换已选执行。实验已删除、无权读取或执行不存在时，各项独立提示，可移除或显式改选。

「输入差异」默认只列出变化项，包括数据与冻结验证摘要、原始基础权重、实际续训检查点、框架、运行环境及生效参数与来源。取消「仅显示变化项」可查看全部输入。历史值按保存时的定义显示；旧六参数实验没有保存的原生默认值保持未知。

「指标结果」分为两张表：**Best · 最佳权重最终评估**读取所选成功执行的已发布最佳权重报告，无须先注册模型；**Last · 最近一轮上报指标**读取所选执行最新轮次的原始指标，表头显示对应轮次。Last 不会使用 Best 或其他执行的数值补齐，训练完成后展示最后一轮；续训的 Best 可保留前一次执行的历史最佳权重。

两张表分别以同口径下每行的最大有效值作为最优基线，高亮最优单元格，并列时同时标记。其他实验以绿色显示「较最优 -X.X 个百分点」，这是数值与最优值之差，不是相对百分比；较小差距保留必要的小数位，避免显示为负零。至少两个有效且兼容的结果才参与排名，缺失值显示为`—`。只有冻结验证基准、类别顺序及覆盖、评估器版本与源码、实际选项和指标语义全部兼容时，才计算 Best 差距；Last 还须满足轮次评估参数兼容。不同口径按组计算，不选跨组最优值，旧报告或身份不足的结果仅并列展示。LibreYOLO 在没有预测结果时可能未执行 COCO backend；零指标仍然有效保存，但评估身份标记为不足。这里使用冻结原生类别空间；模型的项目类别绑定仍需在「模型与发布」核对。

最新上报轮次来自该执行的事件，与最终最佳权重结果分别展示。墙钟耗时包含准备、评估和上传，不代表 GPU 计算时间。未记录的最佳轮次和停止原因显示为未知，不将提前完成推断为耐心早停。

「训练曲线」仅叠加评估身份及轮次参数兼容的实验，其余分开绘制，损失保留框架口径。原始零值保留，缺失、不可用哨兵和轮次间断断线。平滑为当前点权重 0.4 的指数平滑，只影响绘图；原始轮次表和最终结果始终保留原值。分类别结果按原生索引分页，不存在的类别结果不会补成零。

训练器目录可提供 Ultralytics 与 LibreYOLO 图片检测。LibreYOLO 使用原生训练、完整检查点和最终权重评估；下载权重可由原生 LibreYOLO 加载。其指标报告明确区分 mAP 与 AR100，原生 `precision`／`recall` 别名不代表常规精确率／召回率；暂不提供分类别指标。续训保留历史最佳权重，但不承诺与不中断训练逐位一致。

LibreYOLO YOLO9 t/s/m/c 的原生检测最佳权重也可按下述流程注册、试用、人工发布与回滚。推理使用独立插件及其经资格检查的 CPU 或 CUDA 配置；规格 E、其他模型家族、任务与量化格式尚未开放。页面以服务端对冻结实验的资格检查为准；未通过检查的实验仍保留原生产物下载。

## 怎样安排一次有效比较

准备一份固定验证基准，在输入差异中核对数据、类别、初始化来源、参数和运行环境。希望判断某个参数的影响时，可以围绕这一变化创建实验，再看相同口径的 Best 结果，并用[逐样本评估](./sample-evaluation)检查具体误差。

若验证图片、真值或重复次数改变，分数变化可能来自评估基准变化。此时保留两组报告分别阅读，另选双方都能使用的固定基准评估；不从跨组分数差推断模型提升。

## 在预算内搜索参数

在项目「训练实验」展开「参数搜索」，点击新建入口；也可在新建训练的确认步骤选择「参数搜索」。先选择就绪数据、训练器、基础权重和完整参数，完成普通训练预检，再填写搜索设置。

1. 用 JSON 对象填写可编辑原生参数和显式候选值，例如 `{"lr0":[0.005,0.01]}`。组合按参数名排序展开，不接受重复值、未知键或当前不生效的条件参数。
2. 明确填写最多试验数、计划总轮数上限和原生计算秒数上限。最多 20 个组合，超过上限会拒绝整个计划，不会悄悄截断。计划总轮数是全部组合的目标轮数之和。
3. 选择要最大化的最终验证指标，点击「预览全部组合与预算」，核对每项参数、配置摘要和计划摘要。修改配置、网格、目标或预算后需要重新预览。
4. 点击「开始参数搜索」。页面保存本次请求，网络中断或刷新后可确认同一搜索的创建结果。

同一搜索同时只排队或执行一个试验，与手动实验和自动训练共用资源；不会为整个搜索独占 GPU。失败试验保留，不自动重试。点击「停止搜索」会阻止后续组合并请求停止当前实验，失联或取消中的实验仍需等待确认退出。

原生计算从训练子进程启动计到整个进程组确认退出，包含原生准备、训练、评估和停止宽限；所有失败与续训都累计计入时长。执行器到截止时间独立请求停止，即使搜索调度暂时离线仍有效。停止宽限可能产生超额，实际耗时完整显示。排队时间和领取至退出结算的占用时间单独展示，不算成原生计算。执行器自身重启而缺少退出计时证据时，时间显示未知，后续试验和续训暂停。

每项显示计划轮数、最新完成轮次及提前停止情况；最新轮次不是续训重复工作的总轮数。只有校验通过且目标指标可用的最终最佳权重评估才参与排名，按完整验证与评估身份分组，不跨组选择总冠军。缺失或损坏报告、失败试验不会补零，可继续打开普通实验查看日志、检查点和续训资格。续训重新检查搜索当前余额，另一子实验活动期间不能续训；停止搜索后手动续训不会恢复后续组合。

搜索历史保留冻结计划、数据与子实验引用，当前不提供删除搜索入口；受引用的实验、数据版本和项目不能删除。搜索不会自动注册、部署或发布模型。

搜索目前用于已开放的图片检测配置，受控实例分割尚未开放。搜索成功后仍需[人工注册、加载试用和选择默认预标模型](./models)。
