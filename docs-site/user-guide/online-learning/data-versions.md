# 训练数据版本

训练数据版本把某一时刻的图片、标注和划分固定下来。训练引用就绪版本，而不是持续变化的项目任务；修改工作台标注后，需要创建新版本才能用于下一轮训练。

先检查标注和负样本，再冻结数据。后续迭代选择兼容父版本，保留历史分区，便于判断新数据或模型带来的变化。

## 检查标注并创建版本

先切换到项目的「训练数据」，选择检测或分割任务，再点击「准备新版本」。数据集由当前项目派生，版本冻结项目标注与所选素材；此处不是另一个上传原图或复制标注的入口。

1. 在居中面板中核对训练任务、版本名称并选择项目或批次范围。名称会预填当前本地时间，例如 `2026-0909-1125`，可继续补充或修改。检测使用矩形框类别，分割使用区域类别；页面会列出本次工具与类别范围。
2. 默认使用「已审核数据」。没有审核流程时，选择「负责人确认」，逐项选中本轮已经检查的任务。
3. 空标注需要本轮审核确认「无目标」，或在负责人确认模式下逐项勾选负样本。未标注图片不会自动成为负样本。损坏、模糊或不可用图片被排除。
4. 保持默认验证集比例 20% 和随机种子 42，或填写适合本项目的值。后续迭代可分页选择同任务、已就绪且数据契约兼容的父版本，继承历史分区；不必选择最近一版。
5. 点击「检查训练数据」，核对正样本、负样本、排除原因和类别数。托管原图会按已登记位置完整读取、核对 SHA 并解码，内容未知或无法通过核验时不能创建版本。数据或选择条件变化后需要重新预检。
6. 点击「创建数据版本」。页面显示后台进度，刷新后仍可查看。就绪后点击「下载训练包」。

### 原地引用图片与冻结副本

已关联项目的原地图片目录（详见[数据来源与增量同步](/user-guide/datasets/sources)）可使用相同的准备版本流程：

- **按需冻结独立副本**：初次登记目录仍按所选原图策略处理，只有主动冻结训练版本时才将选中原图按完整 SHA-256 校验并保存到独立训练存储。预检页面会显示引用图片数量和预计新增原图副本字节数。
- **节点可达性与重试复用**：API 与实际执行构建的 Worker 都需要能读取原图；管理员应先在存储位置核验对应节点。来源离线、图片被覆盖或身份不符会阻止构建，问题任务与错误保留。修复原来源后可重试同一快照，已核验的持久训练副本会直接复用；需要采用变化后的原图时，应明确接纳新内容并创建新版本。
- **冻结后与源目录解耦**：就绪版本的图片、标注与划分均独立保留。后续移动或删除源文件、停用来源、继续修改项目标注，都不会改写已有训练包；冻结样本预览也只读取保留副本。检测、简单多边形和原生实例掩码继续遵守各自已资格的数据桥接。
- **读取限额**：引用原图的严格读取限额为单图 64 MiB、3200 万像素、单帧 JPEG/PNG/WebP；托管来源沿用下方训练数据上限。

### 样本资格与上限

每个版本最多包含 20,000 张图片，总素材最多 20 GiB（原生掩码还计入训练掩码对象），单图最多 256 MiB、1 亿像素。托管图片支持 JPEG、PNG、WebP、BMP 和 TIFF，按 EXIF 方向核对标注使用的逻辑尺寸。先选择「图片目标检测」或「图片实例分割」，分别使用项目已启用的矩形框或区域类别。其他工具的标注会排除并计数；所选工具内的未知类别、非法坐标和无法读取的图片会阻止构建。至少需要两组互不重复的图片，才能分开训练和验证；父版本须与当前训练任务一致。

一个项目可以同时拥有矩形框、多边形等标注，并分别创建多个单任务版本。预检显示所选任务的对象数和其他工具的排除数；只有其他任务标注的图片不会自动算作当前任务的负样本。切换任务后列表、父版本及比较基线按任务重新查询，不混用筛选和页码；各任务的版本表单和未确认请求独立保留。关闭面板后再次打开可继续该任务的草稿。

### 创建请求尚未确认时

创建响应中断或服务暂时出错时，面板保留原创建请求并锁定编辑与重新检查；刷新页面、离开项目再返回也能恢复。点击「确认原创建请求」会原样重试，即使关闭期间源标注发生变化也不会替换请求内容。只有服务端明确成功或拒绝后才解除锁定；网络中断、限流和临时锁繁忙不会丢弃原请求。浏览器无法保存请求时不会发送创建操作，会显示存储错误。

未确认请求按账号、登录会话、项目和任务隔离。同一登录期间刷新或自动更新凭据仍可恢复；更换账号或重新登录不会自动沿用旧会话请求。

检测与分割各有独立版本序号，例如各自的 `V1`。类别、批次或标注范围变化属于同一任务数据集的版本演进，不会自动另建数据集。序号与可编辑时间戳名称分别显示；失败、取消或删除可能留下缺号，不表示数据丢失。旧版本尚未关联序号时会明确显示待关联，不会更改其下载包或已有训练引用。无法识别契约的历史记录显示独立诊断数量和列表，需由管理员核对，不自动归入检测。

当前训练抽取只支持图片项目。视频导出会保留原项目采样与协作参数、原始视频身份及绝对源帧号，供后续按原项目参数派生图片数据集使用。

### 实例分割如何选择数据桥接

数据桥接决定项目几何如何成为训练标签。创建版本前按实际标注选择：

| 标注情况                             | 选择             | 要核对的内容                                     |
| ------------------------------------ | ---------------- | ------------------------------------------------ |
| 每个实例只有一个简单多边形           | 简单多边形桥接   | 顶点与几何是否合法，缩放后是否仍有有效覆盖       |
| 画笔／SAM 修正，或存在孔洞、断连部件 | 原生实例掩码训练 | 仓库是否支持，逐实例像素、类别和原图方向是否正确 |

不同实例之间可以重叠；同一实例的断连部分仍属于同一个实例。原生掩码逐实例保留这些关系，不能通过合并所有前景来替代。不同桥接不能直接互作父版本。

简单多边形桥接接受每个实例一个简单多边形，可包含凹形和相互重叠的独立实例；可省略闭合点，也可精确重复首点闭合。带孔、多部件、栅格掩码、自相交、自接触、重复顶点、零面积以及转换为原生 float32 后退化或重复的实例会被拒绝。单实例最多 512 个顶点，单图最多 300 个实例、8,192 个顶点。平台保留顶点、类别、来源标注 ID 与版本。画笔、SAM 修正后的栅格实例应显式选择「原生实例掩码训练」桥接，逐实例保留孔洞、断连和重叠；不把不支持的几何视为负样本。

## 从数据集当前筛选创建版本

在[数据集工作台](/user-guide/datasets/workbench)的“数据”页应用条件或恢复个人视图后，点击“冻结当前筛选”，在居中窗口中选择有管理权限的关联项目。进入项目后核对显示的筛选条件，确认数据集范围，再检查训练数据。全部匹配范围参与选择，页面当前页码不限制范围；只有该项目中存在任务且满足所选批次和标注资格的图片可冻结。负责人确认模式的任务勾选列表使用同一筛选并在服务端分页。

筛选仍是动态条件，预检会显示所选、合格与排除数量，创建时重新核对；成员变化会要求重新预检。失效 Scene、来源或无效链接明确报错，不会自动变成整份数据集。可明确“清除数据集筛选”后重新确认，切换数据集也会清除旧条件。项目关联和关联版本页的整份数据集入口仍使用整个数据集范围。

创建请求响应尚未确定时，恢复的是此前保存的原请求，筛选定义和摘要保持原样；从另一个筛选链接进入也不会替换原请求。已经创建的版本保留当时成员、原图和标注，后续改视图、新增样本或删除 Scene 不会改写旧包。所有样本属于同一 Scene 时仍按同组划分，无法形成独立训练/验证组的范围需要调整。

## 固定数据与继承划分

### 预检处理原图来源与备用副本

预检提示引用原图不可用时，可从该问题项点击“处理原图来源（新标签页）”，直接打开[数据集工作台](/user-guide/datasets/workbench)中对应样本的检查器。当前训练表单和检查结果会保留：

- 有来源管理权限时，可在样本检查器中核验原图、关联同内容的显式备用来源（详见[数据来源与增量同步](/user-guide/datasets/sources)），或查看存储位置并恢复连接；
- 无管理权限时，请联系来源管理员处理；
- 处理完成后回到训练准备窗口，重新点击“检查训练数据”，检查通过后再创建版本。
  创建时冻结类别、标注内容、范围和原图身份；托管图片沿任务已登记原件的保存位置读取，不按当前桶或同名文件猜测。后台校验并复制原图，图片、掩码和训练包写入后均完整读回核对大小与摘要，通过后才显示就绪。后续编辑或删除原任务不会改变已就绪版本。尚无合格训练副本时，原图身份或字节变化会使构建失败；需要采用新内容时应创建新版本。

重复图片和同一场景归为一组，不能分散到训练集与验证集。相同图片存在冲突标注时构建失败。父版本及其祖先的任务、图片内容和场景分区会持续保留；历史样本暂时移出再加入也不会重新分配。若新的分组合并了历史上的不同分区，需要调整数据范围，不能混用。

## 固定存储归属与历史版本

新版本在开始构建前固定训练包、保留图片和掩码的位置。构建重试、冻结样本预览、训练及评估、增强预览的源素材都沿用同一版本位置；后续改变当前训练桶不会让旧版本改读另一个桶。端点身份不符时会明确阻断，需要管理员核对存储，不能靠修改配置把旧版本指向同名文件。

历史版本若提示“尚未固定存储归属”，请由有项目管理权限的人员通过[历史存储归属核验接口](/api/guides/training-datasets#固定存储归属与历史版本核验)显式核验。查看列表或详情不会自动接管；旧构建需先取消并等后台退出。核验只读取已登记位置的保留副本，不改标注、快照、训练包或源素材。缺失、摘要冲突或无法证明副本对应固定输入时保留原记录与文件；修正存储问题后再核对，需要采用新内容时应创建新版本。

成功固定表示这批当前保留副本已核验，并不证明历史创建位置或提供整个训练桶迁移许可。只有对象自身的摘要元信息、但没有固定输入独立摘要的历史副本，可能无法接管；去重后未入包的保留样本也需要独立证据。平台不会自动覆盖或删除这些文件。

训练输出位置与原图身份分别核验。历史就绪包和合格保留图片仍可使用；旧版本缺少原图身份且训练副本缺失时，不能根据旧文件路径重新取图，需要先登记原图，再创建新版本。固定历史输出位置不会补齐缺失的原图身份。

## 查看冻结数据与比较版本

### 选择与筛选

在线学习各页的「选择模型」「选择部署」「选择数据版本」等未选择提示以灰色显示，展开菜单后只列出实际选项。较长的用途与操作说明显示在控件下方；「整个项目」「首次划分」「预训练基础权重」仍是可以选择的业务选项。分页或重新加载不会自动替换已选择的记录。

已选部署不再就绪时会保留原选择并提示重新选择，不会自动切换到其他部署；需重新选择就绪部署后才能开始评估或创建主动选样轮次。

首次进入「训练数据」显示当前任务的版本表格，不自动打开详情。搜索栏中的数据类型与状态为同级筛选，可选择目标检测、实例分割或全部类型；全部类型列表显示每个版本的数据类型。类型筛选保留搜索和日期条件，重置筛选会显示全部类型。点击版本名称进入该版本的独立详情页，可切换「概览与类别」「冻结样本」「版本比较」。列表的行内操作和详情页操作均作用于对应版本，可下载、重试、取消构建或删除。所选任务、版本、洞察视图、基线和样本筛选保存在 URL，刷新或返回后可恢复；旧的版本详情链接仍可使用。构建完成前保留进度与错误提示，后台刷新不插入加载占位。

### 检查类别与数据分布

概览以实际训练包成员为准，显示图片数、实例数、唯一内容与重复图片项，并区分冻结定义的类别数与已知标注中出现的类别数。训练／验证环形图与类别堆叠柱优先展示，训练使用蓝色、验证使用绿色，未知划分单独显示。环形图以图片成员为单位，重复图片仍是多个训练成员。类别横向图可切换图片和实例频次、全部／训练／验证划分；悬停或键盘聚焦查看分区数量，点击类别或分区进入对应冻结样本列表。类别图明确表示当前页前十类；搜索和分页保留在图表旁，完整类别明细默认收起，包含未使用类别。一张图片可含多个实例，图表会说明分区与计量单位。冻结准备记录、存储证据和更多尺寸／面积明细可在下方展开。

检测还提供图片宽高二维分布、归一化框中心热力图、框宽高热力图和每图目标数分布。各图使用随明暗主题变化的专用配色；热力图可悬停查看坐标区间、数量和占比，点击／触控固定格子，方向键移动、Enter 固定、Escape 清除。可切换线性色阶或增强稀疏区域，色阶变化不改变计数。目标数量柱可悬停、聚焦或点击查看分组占比；这些几何与密度交互用于检查统计，不会生成不存在的样本筛选。图片尺寸以可测图片成员计数，框图以已知有效实例计数，每图目标数排除无法确认标注的成员；各图单独说明已计量与未知数量。每图目标数不是单位面积的物理密度。尺寸与框／多边形面积用于了解分布；缺类、样本少或分布偏斜是可核对事实，不会自动阻止训练，也不构成通用质量评分。分割按自身的数据桥接提供实例统计与预览；原生实例掩码保留像素语义，不被当成检测框。

### 预览实际训练样本

「冻结样本」先在服务端筛选，再按每页 25 项显示。可按类别、分区、有目标、空标注、排除记录或变化类别筛选；类别和比较基线支持继续翻页查找。点击「预览冻结样本」，查看经字节校验的冻结图片及训练包对应的框、多边形或原生实例掩码；实例很多时按页查看并可关闭叠加。多边形同时显示顶点数量、面积与来源标注版本。被移除内容的预览读取比较基线。无法读取或摘要不匹配时会明确报错，不会借用当前原图或当前标注。

预览可展开「冻结来源」。已保留托管原件身份的版本显示数据集原件或任务自有原件、内容 ID、位置 ID、SHA-256 和字节数；引用图片版本显示来源/位置 ID、路径摘要、采纳修订、扫描轮次和验证时间。这里只展示版本已保存的冻结记录，不显示服务器路径或凭据，也不随当前来源改名、停用或注销而改写。历史版本和未保留的事实明确显示未记录或部分证据，不能据此推断当前来源在线。冻结来源证据和保留图片副本能否读取分别判断：预览失败不会抹除已有来源记录。

### 比较两版数据

「版本比较」表示基线到当前版本的方向，按唯一图片内容列出新增、移除、标注修正、分区变化、重复次数变化、来源工作项 ID 变化和祖先内容重新纳入；类别可重叠，列表则展示实际图片项。类别重排与标注修正分开报告；名称增减不能单凭快照判断为重命名。验证基准分别显示去重后的内容／标签身份和包含重复次数、有序类别的评估身份；重复次数也会改变评估权重。基准相同仍需核对训练器与评估条件，不能据此直接排名模型。

比较基线须同项目、同任务且媒体／几何／桥接契约兼容，可跨页选择；选择基线不改变父版本或数据。点击「清除比较基线」可取消比较，同时重置该基线的类别、页码和变化筛选。差异摘要的计量单位为唯一图片内容，前后成员数另外显示，重叠变化不能相加成一个总数。「训练语义未变化」只说明图片与原生训练标签未变化，不表示来源信息完全相同。

从变化内容打开前后冻结样本对照，分别查看标记为基线／当前版本的图片、类别与框。相同内容有多个成员时可分别选择并核对重复次数；新增或移除内容的一侧没有已知匹配成员时会说明原因。若该侧存在缺少内容摘要的成员，只能确认已知内容集合不同，不能证明图片实际不存在，差异卡片会提示待核实。两侧使用各自的类别编码，查看基线移除项不会沿用当前版本的类别索引。标签数量超过一页时会说明当前加载范围。此处不推断每个真实目标的移动、改类或追踪关系。

### 冻结来源谱系比较

比较页的「冻结来源」将共同内容的来源变化与训练语义变化分开展示（详细来源概念见[数据来源与增量同步](/user-guide/datasets/sources)）：

| 来源比较结果                                  | 判定条件                                                                                | 与训练语义差异的关系                                                           |
| --------------------------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| **来源关系变化（`source_relation_changed`）** | 托管原件的原件类型、内容 ID 或位置 ID 变化；或引用原件的来源 ID、位置 ID 或路径摘要变化 | 可与「训练语义未变化」同时成立；记录的身份变化本身不证明物理搬迁或当前来源在线 |
| **来源证据更新（`source_evidence_updated`）** | 来源关系相同，但引用采纳修订、扫描轮次或验证时间戳更新                                  | 图片字节与训练标签未变时，训练语义仍保持未变化                                 |
| **来源证据不足（`source_unknown`）**          | 任一侧为历史版本或缺少完整来源证据                                                      | 平台不把缺失证据当成相同，单独列出待核实                                       |

点击对应项可筛选并打开前后冻结样本；同一内容的重复成员分别保留，不强行一对一配对。

### 如何理解未知与缺失

新版本保留创建时的准备与排除记录。旧版本没有记录时显示未知，不会用当前任务状态补算。元数据缺失时只统计可确认项；未保留的标注不能视为空标注。媒体读取记录显示最近检查时间、已校验、不可用和尚未读取数量，只反映读取时刻；每次预览重新检查。洞察暂不可用不改变版本就绪状态，训练包下载仍独立可用。

未知标注不当成负样本或零目标；若类别分布存在未知成员，零已知频次不能证明整个版本没有该类。缺预览或分析暂不可用也不阻止使用仍符合训练资格的冻结版本训练。分类、关键点、旋转框及视频／点云等新来源尚未开放同样的训练与比较路径，页面会说明具体能力边界。

相同内容缺少分区记录时，不能确认训练语义未变化，也不能推断分区发生变化；此类内容列入「训练语义变化无法确认」，已确认的标注或重复次数变化仍可同时列出。

## 下载与离线训练

ZIP 包含 `images/train`、`images/val`、对应的 `labels`、`data.yaml`、`classes.json` 和 `manifest.json`。清单保存素材校验值、实际分区、内容摘要和验证基准摘要。

检测文本标签包解压后，可使用 `data.yaml` 的绝对路径启动本地已安装的 Ultralytics：

```bash
yolo detect train data=/absolute/path/to/dataset/data.yaml model=yolo11n.pt
```

简单多边形包可由对应的分割训练入口读取。原生实例掩码包的 `labels` 保存逐实例 RLE JSON，需要平台受控掩码数据适配器；不能直接套用上面的检测命令，也不应转成多边形后声称保留了孔洞或断连语义。

训练集和验证集已经分开。验证摘要不同的版本代表不同评估基准，分数不能直接作为新旧模型提升的证据。数据包不含独立测试集。

## 失败、取消与删除

构建失败后可重试同一快照；已经复制的原图经大小与内容摘要核验后复用，不要求源任务或源文件仍存在，也不会读取后续的新标注。训练副本缺失时，只有具备完整冻结身份且当前仍符合该身份的原件才可回源。原图变化或标注需要修正时，应创建新版本。

点击「取消构建」后，后台会等待正在进行的读取、解码、上传或打包实际结束并关闭资源。旧构建或文件操作尚未确认收尾时，重试和删除会提示稍后操作。没有后续版本引用的终态版本可以删除；被引用或仍在运行的版本不能删除。删除先提交该版本固定位置的清理意图，再移除保留图片、掩码和训练包；存储故障时后台继续处理。尚未固定归属或身份无法核实时，不会按当前训练桶删除文件。项目包含数据版本时，需先处理这些版本才能删除项目。

训练包长期保存在独立训练桶；下载链接有效期为 10 分钟，过期后重新点击下载。版本列表与快照不随后台任务历史清理而消失。
