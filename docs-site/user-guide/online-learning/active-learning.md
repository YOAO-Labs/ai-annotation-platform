# 主动学习选样

待标图片较多、人工预算有限时，可以用已注册模型提出一组优先建议，并保留等量随机对照，再由负责人决定接纳哪些图片作为普通人工批次。

主动选样决定下一批检查什么，不会自动生成合格训练真值。它与[自动训练](./automation)分开操作；完成标注和审核后，再准备数据或等待策略检查。

## 创建选样轮次

每轮创建时固定候选 PNG 的存储位置，所有尝试与重试复用同一组冻结派生图片。它与评估报告、来源模型及原始候选分别管理；当前训练桶变化不会替换旧图片。历史轮次缺少归属时，可继续查看 DB 报告和人工决定、请求停止；重新推理或读取候选图片须由项目管理员通过[显式核验接口](/api/guides/training-datasets#辅助产物归属与历史核验)确认保留副本。系统不会在位置未知时先回源重造 PNG，也没有新增轮次删除入口。

在「模型与发布」点击「主动学习人工选样」。每轮由负责人显式发起，不会持续自动占用 GPU。

轮次列表可按检测或实例分割筛选，也可查看全部任务；切换任务或调整每页条数时返回第一页。

1. 新建轮次，选择检测或实例分割任务、同项目已通过共享评估资格的 Ultralytics 模型及就绪部署，填写名称、随机种子、每组数量、推理派发上限和人工审核任务上限。
2. 明确选择 2 至 32 张未分派的待处理图片。任务须没有标注、草稿、编辑锁及提交／审核历史；仅支持未入批次或未分派的默认批次。单图最多 16 MiB，检测最多 1,600 万像素，分割最多 1,280,000 像素且单边不超过 4,096；总原图最多 128 MiB。
3. 点击「核验并预览」。系统核对实际图片 SHA256、模型与推理环境，按相同内容和场景合并来源，排除保留的训练、验证及独立测试成员。历史版本缺少完整清单时会拒绝选样，需先完成构建或按原流程删除可删除的未使用版本。
4. 核对预览后创建轮次。创建时再次核对候选资格和原件身份；发生变化时须重新预览。每组 1 至 16 张，去重／排除后至少需要两组数量之和的独立候选。推理上限最多 96，至少覆盖全部独立候选；人工审核上限最多 32，至少覆盖两组计划。修改候选、模型或预算后须重新预览。

## 理解主动建议与随机对照

核验沿数据集原件或独立任务原件的保存位置读取完整图片，不按当前存储桶猜测位置。新轮次固定原件身份；原位置被覆盖、同内容换为另一原件、权限撤销或维护门禁变化时，补图或接纳会拒绝。已经保存并核验的冻结 PNG 仍可独立查看，不要求再次回源。

结果分为「主动建议」与「随机对照」。两组候选在评分前随机分开，控制组不读取分数来决定顺序；每组保留相同计划数量。主动组将四分之一的名额向上取整用于随机探索，其余优先选择低置信度或不同类别重叠的图片。每组数量为一时，主动组也完全随机探索。没有预测实例表示缺少信号，会使用明确标记的随机补位，不能解释为确定背景。达到 100 个预测实例时会提示输出可能截断。

检测的重叠歧义来自不同类别框的 IoU；分割来自原图实例掩码的像素 IoU，保留面积与重叠计算证据，并受计算预算约束。分割没有逐像素类别概率，不应把实例置信度解释为像素不确定性。这些分数是选样启发式，不能跨模型比较或解释为正确率。

## 接纳候选并创建人工批次

选择计划内候选子集，填写批次名称，点击「接纳并创建人工批次」；也可以拒绝候选。接纳前重新核对整个内容／场景组的媒体、任务资格、分派、编辑锁及当前历史成员。任何变化都会阻止接纳，须重新选样。每个候选在本轮只能决策一次，累计接纳受人工审核预算限制。批次链接进入正常批次管理，后续分派、Workbench 标注、提交与审核与普通任务相同；选样推理结果不会写入标注真值，也不会改变项目发布。

## 预算、停止与恢复

推理预算按每次实际派发预扣，失败或超时不退还。失联不表示停止；恢复先核对同一请求的收据并复用已成功证据，保持原模型、请求与创建后 24 小时的到期时间。取消等待所有已保存请求确认完成或封存，无法确认时继续显示「正在确认停止」。已取消、封存、过期或用完预算的轮次不能通过更换请求逃逸限制，可显式新建下一轮。创建或决策回执中断时，页面保存原请求供原样重试，刷新仍可继续确认。

## 记录反馈与判断收益

普通审核后点击「记录当前人工反馈快照」。两组分别显示实际接纳／计划、已审核任务、保留驳回记录，以及按人和作业类型去除重叠的已记录会话时间。会话时间仅反映部分记录，不证明完整工时；未完整采集的纠正次数保持未知。可选填写两份后续逐样本评估及精确执行尝试，完整且口径兼容时显示第二减第一的指标变化；部分报告、不同口径或没有评估时保持不可比较。部分接纳、不同审核量或缺少完整工时不能证明效率收益。

## 历史与引用保护

轮次、图片、决策和反馈长期保留，当前没有轮次删除入口。被保留历史引用的任务、素材、数据版本、评估、模型部署和项目不能直接删除；普通批次删除仍保留其历史名称及决策。后续编辑不会改写已记录的反馈快照。

缺少原件身份的旧轮次可以继续查看报告与已有的合格冻结图片，仍可按原流程拒绝候选；缺失图片不会用当前路径补造，也不能新增接纳。需要继续选样时，请按当前已登记原件重新预览并创建新轮次。
