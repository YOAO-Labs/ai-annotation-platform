# 在线学习

项目负责人和超级管理员从侧栏「训练队列」查看训练仓库与项目，进入项目后将图片矩形框标注生成固定的数据版本并创建训练实验。项目卡片菜单中的「在线学习」也可进入同一项目训练页。

## 查看仓库与项目

「开始训练」展示已配置的 Ultralytics、LibreYOLO 训练仓库，以及当前账号可管理的项目。仓库卡片用于查看状态和能力；点击「进入项目」，在项目的「训练实验」中选择训练器并新建实验。没有就绪数据的项目可先点击「准备数据」。项目类别未配置或媒体类型不支持时，会显示具体原因。结构配置通过不代表样本已经合格，仍需数据预检。

「队列与历史」集中查看管理范围内的实验，可按进行中、已结束、异常和训练器筛选。点击实验进入项目详情；失联与停止中的实验仍可能占用 GPU。「训练仓库」展示实际执行器、最近心跳、镜像摘要、基础权重与模型回流能力。仓库代表训练框架配置，多个框架可共用一个容器和同一张 GPU，实验依次运行。

项目训练页分为「训练实验」「训练数据」「模型与发布」「自动训练」四个标签页。标签和所选实验保存在 URL，刷新或返回时可恢复对应视图。

## 创建版本

先切换到项目的「训练数据」。

1. 填写数据版本名称，选择整个项目或一个批次。
2. 默认使用「已审核数据」。没有审核流程时，选择「负责人确认」，逐项选中本轮已经检查的任务。
3. 空标注需要本轮审核确认「无目标」，或在负责人确认模式下逐项勾选负样本。未标注图片不会自动成为负样本。损坏、模糊或不可用图片被排除。
4. 保持默认验证集比例 20% 和随机种子 42，或填写适合本项目的值。后续迭代可选择一个已就绪父版本，继承历史分区。
5. 点击「检查训练数据」，核对正样本、负样本、排除原因和类别数。数据或选择条件变化后需要重新预检。
6. 点击「创建数据版本」。页面显示后台进度，刷新后仍可查看。就绪后点击「下载训练包」。

每个版本最多包含 20,000 张图片，总素材最多 20 GiB，单图最多 256 MiB。只支持项目已启用的矩形框类别；其他活跃几何、未知类别、非法框和无法读取的图片会阻止构建。至少需要两组互不重复的图片，才能分开训练和验证。

## 版本和数据划分

创建时冻结类别、标注内容、范围和原图身份；后台校验并复制原图。后续编辑或删除原任务不会改变已就绪版本。原图在复制前发生变化时，构建失败，需要重新创建版本。

重复图片和同一场景归为一组，不能分散到训练集与验证集。相同图片存在冲突标注时构建失败。父版本及其祖先的任务、图片内容和场景分区会持续保留；历史样本暂时移出再加入也不会重新分配。若新的分组合并了历史上的不同分区，需要调整数据范围，不能混用。

## 下载与离线训练

ZIP 包含 `images/train`、`images/val`、对应的 `labels`、`data.yaml`、`classes.json` 和 `manifest.json`。清单保存素材校验值、实际分区、内容摘要和验证基准摘要。

解压后使用 `data.yaml` 的绝对路径启动本地已安装的 Ultralytics：

```bash
yolo detect train data=/absolute/path/to/dataset/data.yaml model=yolo11n.pt
```

训练集和验证集已经分开。验证摘要不同的版本代表不同评估基准，分数不能直接作为新旧模型提升的证据。数据包不含独立测试集。

## 失败、取消与删除

构建失败后可重试同一快照；已经复制的原图会被复用，不会读取后续的新标注。原图变化或标注需要修正时，应创建新版本。

点击「取消构建」后，后台会在图片处理边界退出。旧构建仍在退出时，重试和删除会提示稍后操作。没有后续版本引用的终态版本可以删除；被引用或仍在运行的版本不能删除。删除会移除该版本冻结的图片和训练包。项目包含数据版本时，需先处理这些版本才能删除项目。

训练包长期保存在独立训练桶；下载链接有效期为 10 分钟，过期后重新点击下载。版本列表与快照不随后台任务历史清理而消失。

## 创建训练实验

管理员启用独立训练执行器后，在「训练实验」点击「新建实验」，进入独立的配置页面。按「数据与模型」「配置参数」「核对并开始」三步完成配置：填写名称，明确选择已就绪数据版本、训练器和基础权重，再设置参数。较早的就绪数据可通过「加载更早的数据版本」继续选择。

参数页默认展示常用项，可切换「全部可编辑参数」，按中文名称、原生键或别名搜索，或只看已修改项。每项显示默认值、约束和来源，支持单项或整组重置；区间、可选值与布尔开关使用对应控件，学习率可输入科学记数法。切换训练器后需明确选择基础权重，并核对保留与移除的已修改参数。

在最后一步点击「检查训练配置」，逐项核对服务端返回的最终生效值、依赖调整和当前不生效项，再点击「开始训练」。同时可查看冻结数据、类别、权重、镜像与配置摘要。修改任何输入或受控目录发生变化后，都需重新检查。

页面按当前账号和项目保存本地草稿，刷新后会重新核验数据、目录与权限。创建响应中断时，会锁定原请求并提供「重试并确认创建」，重试沿用相同请求身份。也可返回实验列表检查结果；只有明确放弃尚未确认的请求后才能继续编辑，重新提交可能产生另一个实验。

「导入 YAML」支持当前训练器的可编辑参数片段，或从本页导出的配置文件。文件上限 64 KiB，不接受多文档、重复键、标签、锚点、引用和平台管理参数。导入前会列出差异与错误；应用时替换全部参数覆盖，省略的已修改项恢复默认值，有错误时整批拒绝。导入不会创建实验。「导出 YAML」保留参数覆盖及训练器、基础权重、参数定义与镜像身份，便于复用；不包含训练包路径或下载凭据。

展开「完整参数目录」可按中文名称、原生键或别名搜索，并按分组和支持状态筛选。Ultralytics 检测目录覆盖 113 个原生字段，LibreYOLO YOLO9 检测覆盖 92 个；目录同时保留其他任务、平台管理和未验证字段，避免把上游存在的参数误当成可用能力。设备、数据路径、下载脚本、回调和续训由平台管理。

扩展配置会固定参数定义、用户输入、有效默认值及其来源。优化器、增强和预热存在依赖：例如 Adam 不使用 SGD 动量预热，关闭 EMA 后不能设置 EMA 衰减。短训练会调整默认预热和末尾关闭增强的轮数，显式提交无效组合会被拒绝。原生框架开始训练前再次核验实际配置；扩展实验的产物包含 `native-config.json`，可查看实际值与验证结果。原六参数实验继续沿用原有配置与续训方式。

实验固定数据包、类别顺序、验证集、基础权重和运行环境。GPU 正忙或执行器离线时，实验保持排队。训练使用指定的一张 GPU，同一物理资源一次执行一个实验。显存不足会报告失败，不会自动改小批大小或图片尺寸。

### 项目配方与实验克隆

在参数页点击「保存为配方」，填写名称和说明，可新建项目配方或为已有配方创建新修订。每个修订保存完整生效配置、参数定义、原始基础权重和来源，历史修订不会被覆盖。发生并发修改时，编辑内容保留；核对最新修订后，再明确选择以它为基准提交。

展开「项目训练配方」，选择当前或历史修订，核对完整生效参数差异后点击「确认采用配置」。取消不会改变草稿。采用后保留当前名称与已经明确选择的数据，并要求重新预检；配方本身不指定数据版本。继续修改参数时会标记「已修改参数」，来源仍可追溯。目录、权重或参数定义变化时会阻止直接套用，需要明确解除来源并迁移，或保存一份与当前目录兼容的新修订。

完整配置实验的「训练配置」提供「使用原始基础权重新建草稿」。克隆使用该实验原先选择的基础权重，数据版本仍需手动选择；不会继承续训检查点、请求身份、自动触发或执行租约。加载来源时编辑草稿，会丢弃迟到的核对结果，可点击「重新核对克隆来源」再核对；也可取消克隆意图。成功实验还可直接保存为配方。旧六参数实验缺少完整默认值记录，不能声称完整克隆；请在参数工作区明确迁移后另存。

配方出现新修订时，当前草稿和策略只显示可更新提示，需重新核对才能采用。归档停止新采用和创建修订，保留历史读取、已排队实验和已采用策略。原实验删除后，保存的配方快照与当时来源仍保留；未保存配方的克隆来源失效时，草稿保持不变，可明确解除来源再继续。

选择实验后，详情显示训练阶段、实际轮次与执行耗时。「指标曲线」分别展示验证表现和损失变化，训练时每 3 秒增量刷新；可切换各次执行记录，续训曲线不会与前一次混合。逐轮指标表保留可查询的数值，缺失或不可用指标显示为空，不会补成零。

「产物与记录」按执行次数下载权重、完整续训检查点、日志、配置和产物清单；「训练配置」查看本次冻结的数据与参数。产物通过大小与 SHA-256 校验后才可下载；上传中断会继续上传已完成结果，不会重新训练。

「停止训练」会先请求退出。看到「已取消」才表示训练进程已停止。失败或取消后，若已有未完成总轮数的完整检查点，可点击「从检查点续训」；续训继续使用原配置并新增执行记录。执行器失联时保留 GPU 租约，确认旧进程退出后才能恢复资源。没有完整检查点时需创建新实验。

新生成的 Ultralytics 检查点会一并保留历史最佳权重，续训期间没有更佳指标也能完成最终评估。旧检查点若缺少这一恢复凭据，仍按原配置尝试恢复；无法取得历史最佳时会明确失败，不会将最后一轮权重冒充最佳。扩展配置实验要求完整恢复凭据。续训保留最佳模型选择，但不承诺与不中断训练逐位一致。

最近轮次的曲线不是最终最佳权重的评估结果，最终结果见下载的评估指标文件。指标按训练框架语义显示，并合并重复别名。比较实验时必须核对框架、评估口径与验证摘要；不同验证集的分数不能作为模型提升依据。被实验引用的数据版本不能删除，需先处理对应实验。

训练器目录可提供 Ultralytics 与 LibreYOLO 图片检测。LibreYOLO 使用原生训练、完整检查点和最终权重评估；下载权重可由原生 LibreYOLO 加载。其指标报告明确区分 mAP 与 AR100，原生 `precision`／`recall` 别名不代表常规精确率／召回率；暂不提供分类别指标。续训保留历史最佳权重，但不承诺与不中断训练逐位一致。

LibreYOLO 当前支持训练、续训和产物下载，尚未开放平台模型回流。已有 Ultralytics 模型仍按下述流程注册、试用和发布。

## 注册模型与回流

切换到「模型与发布」，在「模型版本与回流」填写名称，选择成功实验及执行尝试，为每个原生输出类别明确选择当前项目的矩形框类别，再点击「注册候选模型」。模型保存权重摘要、类别顺序、绑定、实验、数据版本与评估来源；注册后这些信息固定，被模型引用的实验不能删除。

选择已启用且配置了认证的 YOLO 实例，点击「加载检查与样本试用」。平台校验权重后安装到该实例，检查原生任务和类别，并在一张固定验证图片上推理。页面展示试用图片、预测框和耗时；负责人检查误检、漏检及人工修正成本，勾选确认后才能发布。训练完成或试用成功都不代表精度已经提升。

候选对比要求相同的验证摘要、类别、绑定、框架及评估配置。页面只展示验证集中实际参与评估的分类别结果；不满足条件的候选分别展示，不能直接比较分数。

发布后，在当前发布下选择待标注图片，设置置信度与追加／覆盖方式，点击「使用当前发布预标注」。每个任务固定创建时的模型和类别绑定，并保留权重、实验、数据版本与发布来源。后来发布其他模型不会改变已排队任务；网络重试沿用原任务身份。结果仍需在工作台接受、修正、提交并审核，之后才能进入下一训练数据版本。

工作台按自己的置信度阈值筛选候选。若模型已返回结果但列表为空，可在「当前题 AI → 高级配置 → 候选筛选与批量采纳」降低显示阈值，再审阅候选。点击对象行「更多操作」可固定展开采纳、改类别等操作，触屏也可使用。

当前受控模型支持单阶段整图矩形框检测。视频、交互提示、多阶段、裁剪和二次推理不在该入口范围。任务只会进入完成该版本部署检查的确切实例；实例不可用时任务报错，不会换用其他权重。重新点击加载检查可恢复该实例丢失或损坏的副本。

发布历史可回退到此前模型与实例组合，也可清除当前发布。回退先验证旧部署可用，再更新项目选择；已有任务和历史结果保留原版本。其他负责人同时发布时，页面会要求刷新，避免覆盖对方的更新。

## 自动训练策略

自动训练默认关闭。切换到「自动训练」，在「自动训练策略」选择初始划分数据、受控训练器、基础权重和训练参数，并明确填写变化样本门槛、检查间隔与冷却时间，勾选启用后保存。页面配置覆盖整个项目；只使用已审核合格的图片。

编辑策略时，可从项目配方库核对并采用具体修订。采用的参数保持只读；需要改参数时，先另存配方修订，或明确解除策略配方。只改门槛、间隔或冷却会保留完整高级配置与固定修订，归档该配方也不影响这些编辑。最后点击「保存自动策略」才产生新的策略修订，并取消旧修订尚未开始的候选和排队实验；已经开始的实验继续。

首轮统计当前合格训练样本。之后以最近成功的自动训练数据为基线，统计训练分区中新出现或标签修正的图片内容。重复的相同图片合并，同场景与重复内容先统一分区，再去重；验证分区变化形成新评估基准，不增加训练变化计数。达到门槛且冷却结束后，后台冻结数据并排入一个自动实验。训练期间的新变化留待后续检查。

「立即检查与同步」可立即检查数据或更新当前实验的触发记录。定期检查需要管理员运行 Celery beat 与 default/export worker，训练仍由独立执行器完成。触发记录显示数据版本、实验、变化数量和结果。

失败或取消不会推进成功基线。同一策略版本不会反复启动相同失败训练内容；仅修改验证集也不会绕过这一限制。处理原因后，编辑并保存策略可明确发起新一轮检查。负责人失权、API Key 失效、项目停用或训练目录变化会停止后续自动触发，页面说明原因。

关闭策略取消尚未启动的自动实验；已经开始的实验可继续，或在训练实验中显式停止。已有模型发布不变，训练成功后仍需人工注册、试用和发布。删除策略与记录前，需要关闭策略并移除其引用的实验；被策略或触发记录引用的数据不能直接删除。
