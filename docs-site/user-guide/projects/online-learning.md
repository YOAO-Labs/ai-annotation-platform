# 在线学习与模型训练

项目负责人和超级管理员从侧栏「训练队列」查看训练仓库与项目，进入项目后将图片矩形框或合格多边形实例标注生成固定的数据版本并创建训练实验。项目卡片菜单中的「在线学习」也可进入同一项目训练页。

本地开发通过局域网 HTTP 地址访问时，也可打开训练页面、保存数据版本和配置实验。复制功能仍受浏览器剪贴板权限限制，失败时可检查权限或改用 HTTPS。

## 查看仓库与项目

界面中的权重、配置、数据快照等哈希以复制图标呈现，与字段名或对象名称同行显示。悬浮或键盘聚焦时提示“复制哈希”，点击复制完整原值；实验、模型、数据版本等内部 ID 使用“复制 ID”。名称、任务编号、版本序号和指标仍直接显示。复制成功会提示“已复制”，失败时会提示检查浏览器剪贴板权限。

仓库资源栏显示节点名称，并提供完整 GPU 资源 ID 的同行复制操作。新建实验摘要显示初始化模型名称；来源尚未核验时显示“所选候选模型”，仍可复制所选模型的完整 ID。

训练数据预检的问题按不同任务显示“任务 N”，同一任务的多条问题复用序号。未识别的历史数据版本显示“记录 N”，即使版本重名也能区分；记录序号按当前分页位置计算，列表变化后可复制完整 ID 核对具体版本。

主动学习与样本评估的就绪部署选项显示后端名称、部署序号及检查或创建日期。相同选项集合只改变返回顺序时，序号保持一致；选定后可复制完整部署 ID 核对具体目标。序号用于当前选项集合，不替代持久身份。

「开始训练」以当前账号可管理的项目为主区，桌面端右侧展示已配置的 Ultralytics、LibreYOLO 仓库及基础模型能力。点击「进入项目」，在项目的「训练实验」中选择训练器并新建实验。没有就绪数据的项目可先点击「准备数据」。项目名称或编号搜索无结果时，可直接清除搜索。项目类别未配置或媒体类型不支持时，会显示具体原因。结构配置通过不代表样本已经合格，仍需数据预检。

「队列与历史」集中查看管理范围内的实验，上方汇总执行、排队、完成和失败数量；列表对齐展示项目、训练器、任务类型、状态、训练轮次和创建时间，排队实验显示调度状态。可按进行中、已结束、异常和训练器筛选，筛选无结果时可重置；视图与筛选保存在 URL，刷新或返回后可恢复。记录每 3 秒自动更新，也可手动刷新。点击实验进入项目详情；失联与停止中的实验仍可能占用 GPU。

「训练仓库」展示实际执行器、最近心跳、基础模型、参数能力与模型回流能力；展开各仓库的「技术信息」可查看镜像摘要和基础权重校验值。仓库代表训练框架配置，多个框架可共用一个容器和同一张 GPU，实验依次运行。页面支持明暗主题，窄屏下列表按行展示，项目区与仓库区上下排列。

项目训练页分为「训练实验」「训练数据」「模型与发布」「自动训练」四个标签页。标签、列表筛选和页码保存在 URL，刷新或返回时可恢复对应视图。

「训练实验」首页用表格展示名称、状态、任务、框架、基础权重、训练进度和创建时间。可搜索实验名称或基础权重，按状态、任务、框架及创建日期筛选全部记录，再分页显示。点击实验名称进入独立详情页，默认展示指标曲线；资源与耗时、产物、训练配置和实时日志分别查看。后台每 3 秒更新状态时保留表格，不重复显示加载占位。

「训练数据」先选任务，表格展示各版本的状态、样本数、类别数、训练包大小和创建时间，可按名称、状态及创建日期筛选。点击版本名称进入独立详情页，查看摘要、分布、冻结样本与版本差异。两类详情都像实验比较一样拥有独立地址，支持浏览器新标签页打开；返回列表保留筛选和页码。创建日期范围按 UTC 日界筛选，结束日期包含整天。

四个标签页的同级标题、说明与顶部操作控件采用一致的字号和间距，窄屏下操作栏自动换行。

点击「准备新版本」打开居中的配置面板。「模型与发布」先显示当前发布状态，再查看候选模型或填写注册信息。「自动训练」按数据与训练模板、触发规则、训练参数分组，策略修订与检查条件集中显示。

## 创建版本

本地开发试跑可按 [DEV.md 的 COCO8 在线训练夹具说明](https://github.com/yyq19990828/ai-annotation-platform/blob/main/DEV.md#coco8-在线训练夹具)
生成「COCO8 在线训练（dev）」项目。该项目预置 8 张已审核图片和一个可直接选择的初始训练数据版本，
保留原始 4 张训练图 / 4 张验证图划分。训练实验和自动策略仍需负责人明确创建或启用；此小样本仅用于验证流程。
初始版本构建失败、取消或进程中断后可重跑夹具命令，恢复构建同一冻结快照；上次构建仍在执行或清理时会提示稍后重试。

先切换到项目的「训练数据」，选择检测或分割任务，再点击「准备新版本」。数据集由当前项目派生，版本冻结项目标注与所选素材；此处不是另一个上传原图或复制标注的入口。

1. 在居中面板中核对训练任务、版本名称并选择项目或批次范围。名称会预填当前本地时间，例如 `2026-0909-1125`，可继续补充或修改。检测使用矩形框类别，分割使用区域类别；页面会列出本次工具与类别范围。
2. 默认使用「已审核数据」。没有审核流程时，选择「负责人确认」，逐项选中本轮已经检查的任务。
3. 空标注需要本轮审核确认「无目标」，或在负责人确认模式下逐项勾选负样本。未标注图片不会自动成为负样本。损坏、模糊或不可用图片被排除。
4. 保持默认验证集比例 20% 和随机种子 42，或填写适合本项目的值。后续迭代可分页选择同任务、已就绪且数据契约兼容的父版本，继承历史分区；不必选择最近一版。
5. 点击「检查训练数据」，核对正样本、负样本、排除原因和类别数。数据或选择条件变化后需要重新预检。
6. 点击「创建数据版本」。页面显示后台进度，刷新后仍可查看。就绪后点击「下载训练包」。

每个版本最多包含 20,000 张图片，总素材最多 20 GiB，单图最多 256 MiB。先选择「图片目标检测」或「图片实例分割」，分别使用项目已启用的矩形框或区域类别。其他工具的标注会排除并计数；所选工具内的未知类别、非法坐标和无法读取的图片会阻止构建。至少需要两组互不重复的图片，才能分开训练和验证；父版本须与当前训练任务一致。

一个项目可以同时拥有矩形框、多边形等标注，并分别创建多个单任务版本。预检显示所选任务的对象数和其他工具的排除数；只有其他任务标注的图片不会自动算作当前任务的负样本。切换任务后列表、父版本及比较基线按任务重新查询，不混用筛选和页码；各任务的版本表单和未确认请求独立保留。关闭面板后再次打开可继续该任务的草稿。

创建响应中断或服务暂时出错时，面板保留原创建请求并锁定编辑与重新检查；刷新页面、离开项目再返回也能恢复。点击「确认原创建请求」会原样重试，即使关闭期间源标注发生变化也不会替换请求内容。只有服务端明确成功或拒绝后才解除锁定；网络中断、限流和临时锁繁忙不会丢弃原请求。浏览器无法保存请求时不会发送创建操作，会显示存储错误。

未确认请求按账号、登录会话、项目和任务隔离。同一登录期间刷新或自动更新凭据仍可恢复；更换账号或重新登录不会自动沿用旧会话请求。

检测与分割各有独立版本序号，例如各自的 `V1`。类别、批次或标注范围变化属于同一任务数据集的版本演进，不会自动另建数据集。序号与可编辑时间戳名称分别显示；失败、取消或删除可能留下缺号，不表示数据丢失。旧版本尚未关联序号时会明确显示待关联，不会更改其下载包或已有训练引用。无法识别契约的历史记录显示独立诊断数量和列表，需由管理员核对，不自动归入检测。

当前训练抽取只支持图片项目。视频导出会保留原项目采样与协作参数、原始视频身份及绝对源帧号，供后续按原项目参数派生图片数据集使用。

实例分割接受每个实例一个简单多边形，可包含凹形和相互重叠的独立实例；可省略闭合点，也可精确重复首点闭合。带孔、多部件、栅格掩码、自相交、自接触、重复顶点、零面积以及转换为原生 float32 后退化或重复的实例会被拒绝。单实例最多 512 个顶点，单图最多 300 个实例、8,192 个顶点。平台保留顶点、类别、来源标注 ID 与版本，不将不支持的几何近似成可训练标签，也不将它们视为负样本。

## 版本和数据划分

创建时冻结类别、标注内容、范围和原图身份；后台校验并复制原图。后续编辑或删除原任务不会改变已就绪版本。原图在复制前发生变化时，构建失败，需要重新创建版本。

重复图片和同一场景归为一组，不能分散到训练集与验证集。相同图片存在冲突标注时构建失败。父版本及其祖先的任务、图片内容和场景分区会持续保留；历史样本暂时移出再加入也不会重新分配。若新的分组合并了历史上的不同分区，需要调整数据范围，不能混用。

## 查看冻结数据与比较版本

首次进入「训练数据」显示当前任务的版本表格，不自动打开详情。点击版本名称进入该版本的独立详情页，可切换「概览与类别」「冻结样本」「版本比较」。列表的行内操作和详情页操作均作用于对应版本，可下载、重试、取消构建或删除。所选任务、版本、洞察视图、基线和样本筛选保存在 URL，刷新或返回后可恢复；旧的版本详情链接仍可使用。构建完成前保留进度与错误提示，后台刷新不插入加载占位。

概览以实际训练包成员为准，显示图片数、实例数、唯一内容与重复图片项，并区分冻结定义的类别数与已知标注中出现的类别数。训练／验证环形图与类别堆叠柱优先展示，训练使用蓝色、验证使用绿色，未知划分单独显示。环形图以图片成员为单位，重复图片仍是多个训练成员。类别横向图可切换图片和实例频次、全部／训练／验证划分；悬停或键盘聚焦查看分区数量，点击类别或分区进入对应冻结样本列表。类别图明确表示当前页前十类；搜索和分页保留在图表旁，完整类别明细默认收起，包含未使用类别。一张图片可含多个实例，图表会说明分区与计量单位。冻结准备记录、存储证据和更多尺寸／面积明细可在下方展开。

检测还提供图片宽高二维分布、归一化框中心热力图、框宽高热力图和每图目标数分布。各图使用随明暗主题变化的专用配色；热力图可悬停查看坐标区间、数量和占比，点击／触控固定格子，方向键移动、Enter 固定、Escape 清除。可切换线性色阶或增强稀疏区域，色阶变化不改变计数。目标数量柱可悬停、聚焦或点击查看分组占比；这些几何与密度交互用于检查统计，不会生成不存在的样本筛选。图片尺寸以可测图片成员计数，框图以已知有效实例计数，每图目标数排除无法确认标注的成员；各图单独说明已计量与未知数量。每图目标数不是单位面积的物理密度。尺寸与框／多边形面积用于了解分布；缺类、样本少或分布偏斜是可核对事实，不会自动阻止训练，也不构成通用质量评分。分割继续使用其自身的多边形统计与预览，不被当成检测框。

「冻结样本」先在服务端筛选，再按每页 25 项显示。可按类别、分区、有目标、空标注、排除记录或变化类别筛选；类别和比较基线支持继续翻页查找。点击「预览冻结样本」，查看经字节校验的冻结图片及训练包对应的框或多边形；实例很多时按页查看并可关闭叠加。多边形同时显示顶点数量、面积与来源标注版本。被移除内容的预览读取比较基线。无法读取或摘要不匹配时会明确报错，不会借用当前原图或当前标注。

「版本比较」表示基线到当前版本的方向，按唯一图片内容列出新增、移除、标注修正、分区变化、重复次数变化、来源工作项 ID 变化和祖先内容重新纳入；类别可重叠，列表则展示实际图片项。类别重排与标注修正分开报告；名称增减不能单凭快照判断为重命名。验证基准分别显示去重后的内容／标签身份和包含重复次数、有序类别的评估身份；重复次数也会改变评估权重。基准相同仍需核对训练器与评估条件，不能据此直接排名模型。

比较基线须同项目、同任务且媒体／几何／桥接契约兼容，可跨页选择；选择基线不改变父版本或数据。差异摘要的计量单位为唯一图片内容，前后成员数另外显示，重叠变化不能相加成一个总数。「训练语义未变化」只说明图片与原生训练标签未变化，不表示来源信息完全相同。

从变化内容打开前后冻结样本对照，分别查看标记为基线／当前版本的图片、类别与框。相同内容有多个成员时可分别选择并核对重复次数；新增或移除内容的一侧没有已知匹配成员时会说明原因。若该侧存在缺少内容摘要的成员，只能确认已知内容集合不同，不能证明图片实际不存在，差异卡片会提示待核实。两侧使用各自的类别编码，查看基线移除项不会沿用当前版本的类别索引。标签数量超过一页时会说明当前加载范围。此处不推断每个真实目标的移动、改类或追踪关系。

新版本保留创建时的准备与排除记录。旧版本没有记录时显示未知，不会用当前任务状态补算。元数据缺失时只统计可确认项；未保留的标注不能视为空标注。媒体读取记录显示最近检查时间、已校验、不可用和尚未读取数量，只反映读取时刻；每次预览重新检查。洞察暂不可用不改变版本就绪状态，训练包下载仍独立可用。

未知标注不当成负样本或零目标；若类别分布存在未知成员，零已知频次不能证明整个版本没有该类。缺预览或分析暂不可用也不阻止使用仍已资格的冻结版本训练。分类、关键点、旋转框及视频／点云等新来源尚未开放同样的训练与比较路径，页面会说明具体能力边界。

相同内容缺少分区记录时，不能确认训练语义未变化，也不能推断分区发生变化；此类内容列入「训练语义变化无法确认」，已确认的标注或重复次数变化仍可同时列出。

## 下载与离线训练

ZIP 包含 `images/train`、`images/val`、对应的 `labels`、`data.yaml`、`classes.json` 和 `manifest.json`。清单保存素材校验值、实际分区、内容摘要和验证基准摘要。

解压后使用 `data.yaml` 的绝对路径启动本地已安装的 Ultralytics：

```bash
yolo detect train data=/absolute/path/to/dataset/data.yaml model=yolo11n.pt
```

训练集和验证集已经分开。验证摘要不同的版本代表不同评估基准，分数不能直接作为新旧模型提升的证据。数据包不含独立测试集。

## 失败、取消与删除

构建失败后可重试同一快照；已经复制的原图会被复用，不会读取后续的新标注。原图变化或标注需要修正时，应创建新版本。

点击「取消构建」后，后台会在图片处理边界退出。旧构建仍在退出时，重试和删除会提示稍后操作。没有后续版本引用的终态版本可以删除；被引用或仍在运行的版本不能删除。删除会移除该版本冻结的图片和训练包。项目包含数据版本时，需先处理这些版本才能删除项目。

训练包长期保存在独立训练桶；下载链接有效期为 10 分钟，过期后重新点击下载。版本列表与快照不随后台任务历史清理而消失。

## 创建训练实验

管理员启用独立训练执行器后，在「训练实验」点击「新建实验」，打开居中的配置面板，项目实验列表保留在背景。按「数据与模型」「配置参数」「核对并开始」三步完成配置，步骤条在滚动时保持置顶：填写名称，明确选择已就绪数据版本、训练器和基础权重，再设置参数。未选择数据或基础权重时显示灰色占位提示，提示不作为下拉选项；较早的就绪数据可通过「加载更早的数据版本」继续选择。关闭面板后保留当前账号与项目的本地草稿，再次打开可继续编辑；创建链接也可直接访问或刷新。

也可在就绪数据详情点击「使用此版本新建实验」。系统先核对精确冻结版本与兼容训练器／基础权重，展示确认面板，只有点击「确认采用数据版本」才更新草稿。兼容的当前模型与参数会保留；需要换模型时会明确说明采用受控默认参数并移除原参数覆盖、配方来源及项目权重初始化。取消保持原草稿。已有尚未确认的实验或参数搜索请求时不能替换数据，关闭面板也不丢弃原请求身份；采用后仍须检查配置并提交，后续新数据版本不会自动替换此选择。关闭实验面板可返回原数据任务和版本。

图片实例分割目前使用受控 Ultralytics `yolo11n-seg` 基础权重，数据任务、基础权重与参数定义须一致。可创建普通实验、保存配方、克隆、停止、断点续训并下载原生最佳权重；自动策略、参数搜索、项目候选初始化、原生增强预览、候选注册和逐样本推理评估尚未开放分割资格。页面会说明原因，已有选择不会被静默换成检测配置。

分割固定独立实例掩码、`mask_ratio=1`，关闭 Copy/Paste、Mosaic、MixUp、CutMix、仿射／透视和多尺度；当前可配置水平翻转及颜色增强。矢量顶点完整保留不代表缩放后的像素覆盖不变，细小目标仍受训练分辨率影响。报告分别显示框和掩码的精确率、召回率、mAP 与分类别结果；原生最佳权重选择分数是二者 mAP50–95 之和，可大于一，不能当作百分比或单一掩码准确率。版本比较只接受相同训练任务，模型结果还须满足完整评估身份兼容条件。

参数页默认展示常用项，可切换「全部可编辑参数」，按中文名称、原生键或别名搜索，或只看已修改项。每项显示默认值、约束和来源，支持单项重置，也可通过章节标题栏右侧的「重置本组」恢复整组默认值，操作不会改变章节的展开状态；没有已修改项时重置按钮禁用，点击该区域也不会展开或收起章节。区间、可选值与布尔开关使用对应控件，学习率可输入科学记数法。切换训练器后需明确选择基础权重，并核对保留与移除的已修改参数。

### 从项目模型初始化权重

在「数据与模型」的「初始化权重」中选择「预训练基础权重」或同项目保留的候选模型。预训练基础权重使用上方所选基础模型，由管理员预先配置并校验，无需选择本地文件夹。候选可分页查找，已归档候选也可选择；无需先部署或发布。当前支持 Ultralytics YOLO11 图片检测，目标基础模型规格、原生类别及顺序须与来源完全一致，不提供类别头重映射或任意检查点上传。

页面显示来源候选、训练数据、验证摘要、权重 SHA256 与大小。这里的资格检查只读取固定身份和对象元信息；「检查训练配置」会完整验证权重与评估对象。核对页显示实际固定的模型、实验和执行尝试。来源失效、规格不匹配或对象损坏时保留当前选择并显示原因，需要明确重新选择后再检查。

项目权重仅用于初始化：新实验从第 0 轮开始，优化器、调度器、缩放器、EMA 和最佳成绩均重新创建。后续停止或中断时，断点续训使用本实验自己的完整检查点，不会重新加载父模型。改变初始化来源会清除旧检查结果并轮换创建请求；尚未确认的创建请求保持原内容，刷新后仍可原样重试。模型谱系提供独立的「初始化权重来源」关系。

包含项目权重的完整 YAML 使用格式 2，保存模型版本与来源摘要，不保存下载 URL。导入时展示来源变化并重新校验同项目权限；旧格式 1 或纯参数片段只替换参数，保留当前明确选择的初始化权重。

### 查看原生增强预览

Ultralytics YOLO11 图片检测可在「配置参数」下方点击「生成原生预览」。选择独立的预览种子、训练轮次和 1–4 张输出；「更换预览种子」只改变预览选择，再生成即可查看另一组随机结果。种子和轮次不会写入训练配置、配方或实验请求。选定的轮次遵循关闭 Mosaic 的尾段设置，矩形批训练也遵循原生增强依赖。

完成后选择输出图片及其实际使用的原始来源，核对类别颜色、完整变换框和坐标。来源标出重复取用次数；读取但最终跳过的混合分支不算已使用来源。裁剪和过滤次数累计原生流水线中的操作，包含中间分支，不能当作唯一目标数或原图与结果框数之差。「实际参数与原生步骤」可核对精确参数、来源池和操作记录。预览只是当前种子的随机样本，未来训练批次可能不同。

预览只读取冻结训练分区中满足上限的最多 16 张图片：单图不超过 8 MiB、1600 万像素和 256 个框，来源池不超过 64 MiB、3200 万像素和 4096 个框。超限或未保留完整标签的图片会被跳过；没有可用图片时明确报错。输出最多每边 2560 像素、4096 个框。

预览使用单独的 CPU 槽，可能排队，也会与训练共享主机的 CPU 和内存。可点击「取消预览」；失联时保留资源直到确认进程退出。参数、数据、目录或登录会话改变后，旧结果立即移除。预览失败、执行器离线或 LibreYOLO 暂不支持时，仍可继续配置、检查并开始训练。

执行器升级时会自动核对上次请求：没有任务的旧请求会被清除，再由当前执行器重新上报预览能力；已有任务仍按原租约恢复。能力恢复后刷新页面，即可重新生成预览。

结果保留 24 小时，过期后需要重新生成。冻结数据在预览清理前仍受引用保护；删除预览的 API 可立即隐藏结果，后台等上传授权到期后清理。预览状态与图片不会在刷新后恢复，训练草稿仍按原规则恢复。

项目权重选择不参与增强预览的模型加载。预览仅验证数据变换和受控模型结构，不能代替训练初始化资格检查；改变初始化来源也会移除旧预览。

在最后一步点击「检查训练配置」，逐项核对服务端返回的最终生效值、依赖调整和当前不生效项，再点击「开始训练」。同时可查看冻结数据、类别、权重、镜像与配置摘要。修改任何输入或受控目录发生变化后，都需重新检查。

页面按当前账号和项目保存本地草稿，刷新后会重新核验数据、目录与权限。创建响应中断时，会锁定原请求并提供「重试并确认创建」，重试沿用相同请求身份。也可返回实验列表检查结果；只有明确放弃尚未确认的请求后才能继续编辑，重新提交可能产生另一个实验。

「导入 YAML」支持当前训练器的可编辑参数片段，或从本页导出的配置文件。文件上限 64 KiB，不接受多文档、重复键、标签、锚点、引用和平台管理参数。导入前会列出差异与错误；应用时替换全部参数覆盖，省略的已修改项恢复默认值，有错误时整批拒绝。导入不会创建实验。「导出 YAML」保留参数覆盖及训练器、基础权重、参数定义与镜像身份，便于复用；不包含训练包路径或下载凭据。

展开「完整参数目录」可按中文名称、原生键或别名搜索，并按分组和支持状态筛选。Ultralytics 检测目录覆盖 113 个原生字段，LibreYOLO YOLO9 检测覆盖 92 个；目录同时保留其他任务、平台管理和未验证字段，避免把上游存在的参数误当成可用能力。设备、数据路径、下载脚本、回调和续训由平台管理。

扩展配置会固定参数定义、用户输入、有效默认值及其来源。优化器、增强和预热存在依赖：例如 Adam 不使用 SGD 动量预热，关闭 EMA 后不能设置 EMA 衰减。短训练会调整默认预热和末尾关闭增强的轮数，显式提交无效组合会被拒绝。原生框架开始训练前再次核验实际配置；扩展实验的产物包含 `native-config.json`，可查看实际值与验证结果。原六参数实验继续沿用原有配置与续训方式。

实验固定数据包、类别顺序、验证集、基础权重和运行环境。GPU 正忙或执行器离线时，实验保持排队。训练使用指定的一张 GPU，同一物理资源一次执行一个实验。显存不足会报告失败，不会自动改小批大小或图片尺寸。

### 项目配方与实验克隆

在参数页点击「保存为配方」，填写名称和说明，可新建项目配方或为已有配方创建新修订。每个修订保存完整生效配置、参数定义、原始基础权重、初始化权重和来源，历史修订不会被覆盖。发生并发修改时，编辑内容保留；核对最新修订后，再明确选择以它为基准提交。

展开「项目训练配方」，选择当前或历史修订，核对完整生效参数差异后点击「确认采用配置」。取消不会改变草稿。采用后保留当前名称与已经明确选择的数据，并要求重新预检；配方本身不指定数据版本。继续修改参数时会标记「已修改参数」，来源仍可追溯。目录、权重或参数定义变化时会阻止直接套用，需要明确解除来源并迁移，或保存一份与当前目录兼容的新修订。

完整配置实验的「训练配置」提供「使用原配置初始化权重新建草稿」。克隆保留该实验原先选择的初始化权重，使用项目模型时仍固定原模型，不会自动选择被克隆实验的新产物。数据版本仍需手动选择；不会继承续训检查点、请求身份、自动触发或执行租约。加载来源时编辑草稿，会丢弃迟到的核对结果，可点击「重新核对克隆来源」再核对；也可取消克隆意图。成功实验还可直接保存为配方。旧六参数实验缺少完整默认值记录，不能声称完整克隆；请在参数工作区明确迁移后另存。

配方与自动策略保留所选初始化权重，解除配置来源不会清除权重选择。配方出现新修订时，当前草稿和策略只显示可更新提示，需重新核对才能采用。归档停止新采用和创建修订，保留历史读取、已排队实验和已采用策略。原实验删除后，保存的配方快照与当时来源仍保留；未保存配方的克隆来源失效时，草稿保持不变，可明确解除来源再继续。

选择实验后，详情显示训练阶段、实际轮次与执行耗时。「指标曲线」分别展示验证表现和损失变化，训练时每 3 秒增量刷新；可切换各次执行记录，续训曲线不会与前一次混合。逐轮指标表保留可查询的数值，缺失或不可用指标显示为空，不会补成零。

「资源与耗时」中的所选执行资源卡片约每 5 秒刷新，显示训练进程组的 CPU 核数、RSS 总和、原生批次吞吐，以及整张 GPU 的利用率和显存。整卡数值可能包含其他进程；PyTorch 已分配／保留显存来自训练子进程分配器，不能当作全部进程显存。无法确认归属或读取失败时显示不可用，真实零值仍显示为零。可展开近期资源趋势；峰值只涵盖实际收到的采样。

执行耗时持续更新，已结束的历史记录保持固定。观测阶段与执行状态分别显示，不会从低利用率推断等待数据。至少收到 3 个可比较的完整训练周期后，才估算训练剩余时间范围；首个预热／恢复周期不计入。尚未观测过的增强尾段、过期采样、停止或失联会暂停估算。评估和保存耗时保持未知，提前停止也不会被当作保证完成时间。

「实时日志」显示已脱敏的近期内容，可加载更早日志或关闭「跟随最新日志」继续阅读。点击「复制当前日志」可原样复制当前已加载的全部日志块；需要完整历史时下载日志产物。实验、评估、数据版本和模型发布的错误信息旁均提供复制入口，保留完整原文和换行。连接中断后保留已显示内容并继续重连；保留窗口造成的缺口会明确提示。每次执行最多保留 720 条近期采样与 512 个日志块，原始观测在 7 天后分批清理；历史摘要和已发布产物继续保留。切换执行、项目或登录会话后不会混入迟到结果。

「产物与记录」按执行次数下载权重、完整续训检查点、脱敏日志、配置、资源与阶段观测摘要和产物清单；「训练配置」查看本次冻结的数据与参数。产物通过大小与 SHA-256 校验后才可下载。日志下载返回再次脱敏的副本，原始产物与摘要不改写；超出 8 MiB 或校验失败的历史日志明确不可用。URL、凭据和主机路径在新日志保存前脱敏，超长行整体省略。上传中断会继续上传已完成结果，无需重新训练。

「停止训练」会先请求退出。看到「已取消」才表示训练进程已停止。失败或取消后，页面核对当前执行已释放资源、正轮次的未完成检查点、冻结配置与已知兼容环境，才提供「从检查点续训」。兼容执行器离线时可以排队；历史执行的检查点不会替代当前执行。续训沿用原配置并新增记录，当前进度重新开始记录；没有合格检查点时需创建新实验。

显存不足依据原生异常类型显示说明，信号终止不会被推断成显存不足。完整配置实验可使用原始基础权重新建草稿，明确检查批大小 `batch` 与尺寸 `imgsz`；不会自动改参数、选数据或采用检查点。旧六参数实验需在配置工作区明确迁移。执行器失联时保留 GPU 租约，等待确认旧进程退出；遥测中断本身不会释放资源。

训练已经退出后，产物发布遇到永久性校验拒绝会回报失败并显示原因，避免一直占着队列重试。临时网络、存储或锁繁忙会继续上传；完成响应丢失时确认原结果，不会重新训练。

新生成的 Ultralytics 检查点会一并保留历史最佳权重，续训期间没有更佳指标也能完成最终评估。旧检查点若缺少这一恢复凭据，仍按原配置尝试恢复；无法取得历史最佳时会明确失败，不会将最后一轮权重冒充最佳。扩展配置实验要求完整恢复凭据。续训保留最佳模型选择，但不承诺与不中断训练逐位一致。

最近轮次的曲线不是最终最佳权重的评估结果，最终结果可在「比较实验」中查看，也可下载评估指标文件。指标按训练框架语义显示，并合并重复别名。被实验引用的数据版本不能删除，需先处理对应实验。

删除未被引用的数据版本或终态实验后，记录立即移出列表。存储暂时不可用时，后台继续清理文件，不会将已完成的删除显示为失败。

### 有预算的参数搜索

在项目「训练实验」展开「参数搜索」，点击新建入口；也可在新建训练的确认步骤选择「参数搜索」。先选择就绪数据、训练器、基础权重和完整参数，完成普通训练预检，再填写搜索设置。

1. 用 JSON 对象填写可编辑原生参数和显式候选值，例如 `{"lr0":[0.005,0.01]}`。组合按参数名排序展开，不接受重复值、未知键或当前不生效的条件参数。
2. 明确填写最多试验数、计划总轮数上限和原生计算秒数上限。最多 20 个组合，超过上限会拒绝整个计划，不会悄悄截断。计划总轮数是全部组合的目标轮数之和。
3. 选择要最大化的最终验证指标，点击「预览全部组合与预算」，核对每项参数、配置摘要和计划摘要。修改配置、网格、目标或预算后需要重新预览。
4. 点击「开始参数搜索」。页面保存本次请求，网络中断或刷新后可确认同一搜索的创建结果。

同一搜索同时只排队或执行一个试验，与手动实验和自动训练共用资源；不会为整个搜索独占 GPU。失败试验保留，不自动重试。点击「停止搜索」会阻止后续组合并请求停止当前实验，失联或取消中的实验仍需等待确认退出。

原生计算从训练子进程启动计到整个进程组确认退出，包含原生准备、训练、评估和停止宽限；所有失败与续训都累计计入时长。执行器到截止时间独立请求停止，即使搜索调度暂时离线仍有效。停止宽限可能产生超额，实际耗时完整显示。排队时间和领取至退出结算的占用时间单独展示，不算成原生计算。执行器自身重启而缺少退出计时证据时，时间显示未知，后续试验和续训暂停。

每项显示计划轮数、最新完成轮次及提前停止情况；最新轮次不是续训重复工作的总轮数。只有校验通过且目标指标可用的最终最佳权重评估才参与排名，按完整验证与评估身份分组，不跨组选择总冠军。缺失或损坏报告、失败试验不会补零，可继续打开普通实验查看日志、检查点和续训资格。续训重新检查搜索当前余额，另一子实验活动期间不能续训；停止搜索后手动续训不会恢复后续组合。

搜索历史保留冻结计划、数据与子实验引用，当前不提供删除搜索入口；受引用的实验、数据版本和项目不能删除。搜索不会自动注册、部署或发布模型。

### 比较实验

在项目的「训练实验」点击「比较实验」，从分页列表加入 2–4 个不同实验，为每项明确选择执行记录。选择、视图、曲线指标和平滑选项保存在链接中，刷新或返回后恢复；续训不会自动替换已选执行。实验已删除、无权读取或执行不存在时，各项独立提示，可移除或显式改选。

「输入差异」默认只列出变化项，包括数据与冻结验证摘要、原始基础权重、实际续训检查点、框架、运行环境及生效参数与来源。取消「仅显示变化项」可查看全部输入。历史值按保存时的定义显示；旧六参数实验没有保存的原生默认值保持未知。

「指标结果」分为两张表：**Best · 最佳权重最终评估**读取所选成功执行的已发布最佳权重报告，无须先注册模型；**Last · 最近一轮上报指标**读取所选执行最新轮次的原始指标，表头显示对应轮次。Last 不会使用 Best 或其他执行的数值补齐，训练完成后展示最后一轮；续训的 Best 可保留前一次执行的历史最佳权重。

两张表分别以同口径下每行的最大有效值作为最优基线，高亮最优单元格，并列时同时标记。其他实验以绿色显示「较最优 -X.X 个百分点」，这是数值与最优值之差，不是相对百分比；较小差距保留必要的小数位，避免显示为负零。至少两个有效且兼容的结果才参与排名，缺失值显示为「—」。只有冻结验证基准、类别顺序及覆盖、评估器版本与源码、实际选项和指标语义全部兼容时，才计算 Best 差距；Last 还须满足轮次评估参数兼容。不同口径按组计算，不选跨组最优值，旧报告或身份不足的结果仅并列展示。LibreYOLO 在没有预测结果时可能未执行 COCO backend；零指标仍然有效保存，但评估身份标记为不足。这里使用冻结原生类别空间；模型的项目类别绑定仍需在「模型与发布」核对。

最新上报轮次来自该执行的事件，与最终最佳权重结果分别展示。墙钟耗时包含准备、评估和上传，不代表 GPU 计算时间。未记录的最佳轮次和停止原因显示为未知，不将提前完成推断为耐心早停。

「训练曲线」仅叠加评估身份及轮次参数兼容的实验，其余分开绘制，损失保留框架口径。原始零值保留，缺失、不可用哨兵和轮次间断断线。平滑为当前点权重 0.4 的指数平滑，只影响绘图；原始轮次表和最终结果始终保留原值。分类别结果按原生索引分页，不存在的类别结果不会补成零。

训练器目录可提供 Ultralytics 与 LibreYOLO 图片检测。LibreYOLO 使用原生训练、完整检查点和最终权重评估；下载权重可由原生 LibreYOLO 加载。其指标报告明确区分 mAP 与 AR100，原生 `precision`／`recall` 别名不代表常规精确率／召回率；暂不提供分类别指标。续训保留历史最佳权重，但不承诺与不中断训练逐位一致。

LibreYOLO YOLO9 t/s/m/c 的原生检测最佳权重也可按下述流程注册、试用、人工发布与回滚。推理使用已验证的 CPU 运行时；规格 E、其他模型家族、任务与量化格式尚未开放。页面以服务端对冻结实验的资格检查为准；未通过检查的实验仍保留原生产物下载。

## 注册模型与回流

切换到「模型与发布」，在「模型版本与回流」先选择来源训练实验，再核对模型名称及执行尝试。名称会预填当前本地时间，例如 `2026-0909-1125`，可继续补充或修改。为每个原生输出类别明确选择当前项目的矩形框类别，再点击「注册候选模型」。模型保存权重摘要、类别顺序、绑定、实验、数据版本与评估来源；注册后这些信息固定，被模型引用的实验不能删除。

选择已启用且配置了认证的 YOLO 实例，点击「加载检查与样本试用」。平台校验权重后安装到该实例，检查原生任务和类别，并在一张固定验证图片上推理。页面展示试用图片、预测框和耗时；负责人检查误检、漏检及人工修正成本，勾选确认后才能发布。训练完成或试用成功都不代表精度已经提升。

候选对比要求相同的验证摘要、类别、绑定、框架及评估配置。页面只展示原生报告实际提供的指标；LibreYOLO 暂无分类别结果，不将其原生 precision／recall 别名当作常规精确率／召回率。不同框架候选分别展示，不能直接比较分数。

发布后，在当前发布下选择待标注图片，设置置信度与追加／覆盖方式，点击「使用当前发布预标注」。每个任务固定创建时的模型和类别绑定，并保留权重、实验、数据版本与发布来源。后来发布其他模型不会改变已排队任务；网络重试沿用原任务身份。结果仍需在工作台接受、修正、提交并审核，之后才能进入下一训练数据版本。

工作台按自己的置信度阈值筛选候选。若模型已返回结果但列表为空，可在「当前题 AI → 高级配置 → 候选筛选与批量采纳」降低显示阈值，再审阅候选。点击对象行「更多操作」可固定展开采纳、改类别等操作，触屏也可使用。

当前受控模型支持单阶段整图矩形框检测。视频、交互提示、多阶段、裁剪和二次推理不在该入口范围。任务只会进入完成该版本部署检查的确切实例；实例不可用时任务报错，不会换用其他权重。重新点击加载检查可恢复该实例丢失或损坏的副本。

发布历史可回退到此前模型与实例组合，也可清除当前发布。回退先验证旧部署可用，再更新项目选择；已有任务和历史结果保留原版本。其他负责人同时发布时，页面会要求刷新，避免覆盖对方的更新。

## 模型谱系与候选决策

在「模型与发布」的候选行或详情点击「谱系与决策」。先查看权重和冻结来源摘要，再沿「直接来源」进入准确的实验、执行尝试和数据版本；「关联记录」一次加载一类后续记录，每页最多 20 条。「打开原有详情」进入现有页面，其返回链接保留谱系位置。原候选列表的归档范围、页码和所选模型也会保留，刷新后可以继续查看。

配置克隆表示沿用配置，断点续训表示恢复对应检查点；两者不会混为同一来源。部署页面显示最近一次加载与试用检查，发布页面显示当时保存的冻结身份。历史记录缺失、不一致或无权访问时显示来源缺口，不会改用最新尝试。路径再次经过同一节点时会提示可能存在历史循环。

在候选谱系页填写「决策依据」，选择「保留研究」「不予发布」「归档候选」或「恢复默认显示」，然后点击「追加决策」。每次说明独立保留作者、时间与序号；后续处置不会覆盖旧说明。该操作不部署或发布模型，也不改变当前项目选择及发布代次。

默认候选列表隐藏已归档模型，但当前发布仍保留并标明归档。可切换为包含归档或仅已归档；已有模型详情、部署和历史证据继续可用。归档不删除权重，也不解除数据与实验的来源保护。

「可归属的预测记录」按需统计匹配完整冻结候选身份的现存记录，最多读取 1,000 条并明确上限。旧格式、已删除和无法核对的记录不在范围内；候选身份不完整时显示无法计数，零也不表示从未使用。该计数不是累计调用量或模型质量评分。

## 逐样本评估与误差复查

在「模型与发布」点击「逐样本评估与误差复查」，进入独立评估历史。新建时选择已注册模型、就绪部署和冻结数据版本，再逐项选择该版本的验证成员，最多 32 个；跨页选择会保留，切换数据版本会清空选择。只有权重、类别绑定及实际推理环境通过核对的 Ultralytics 图片检测部署可以开始，LibreYOLO 的原生试用与人工发布继续可用，但尚未通过这套共享评估资格。

默认用途是「验证集，用于模型选择」。若声明独立测试，须明确确认这些成员未用于候选训练或模型选择；系统还会拒绝与该候选训练或验证图片 SHA 重叠的成员。平台不会自动生成测试集或用测试结果调整参数。

开始前明确设置预测置信度、匹配 IoU 和独立的 NMS IoU。评估固定候选权重、数据成员与真值、类别、预处理、运行环境和这些阈值。相同内容的不同冻结成员分别计数。原图需不超过 16 MiB、解码后不超过 1,600 万像素，单图真值最多 200 个、总计最多 2,000 个；超出支持范围会给出原因。

报告将达到置信度阈值的预测按置信度排序，与未使用的同类真值进行一对一匹配，包含阈值等号；重复预测计为误检。主指标是 TP、FP、FN、精确率、召回率和 F1，不是 AP/mAP。分母为零时显示不可用。类别混淆与定位偏差解释已有的 FP/FN，不重复增加主计数；样本失败或未完成时不提供整体指标。

结果页按类别、误差类型和证据置信度筛选，再分页显示成员。筛选不会重新匹配；漏检 FN 没有置信度，因此漏检筛选忽略置信度范围。图中实线表示冻结真值，虚线表示预测，两层可以单独隐藏；下方保留完整坐标、置信度、匹配和诊断。链接保存执行尝试、筛选、分页与所选成员，刷新或返回可以恢复。恢复产生新尝试，旧报告仍可明确选择查看。

「请求停止」先保存意图，只有后端确认原生请求结束后才显示已取消。执行失联不等同于已停止；「恢复未完成成员」先核对原请求的收据与执行锁，保留已验证成员。未完成推理的恢复窗口为创建后 24 小时，过期或已取消需新建评估；完成报告不会因此过期。

比较时明确选择第二个评估。只有冻结基准及重复次数、类别、用途、匹配设置、预处理和推理环境全部兼容，且双方均有完整成功报告时，才显示「第二减当前」差值。失败或不兼容候选仍独立展示；不会自动排名。比较使用各评估的当前尝试，查看旧尝试时需先显式切换。选择具体成员后，可直接查看另一候选对应的同一冻结成员。

「核对当前标注任务」会重新核对当前图片内容、标签与权限。若内容变化、标签类型不受支持或无法完全核对，先显示说明，再由你决定是否打开当前任务。工作台显示当前内容，返回链接保留历史评估位置；修改、提交和复核继续走正常标注流程，不会修改冻结真值或历史报告。源任务删除或不可访问时不会打开其他任务。删除终态评估会清理其历史和报告，被保留评估引用的数据版本、模型部署与项目需先解除引用。

## 主动学习人工选样

在「模型与发布」点击「主动学习人工选样」。每轮由负责人显式发起，不会持续自动占用 GPU。

1. 新建轮次，选择同项目已通过共享评估资格的 Ultralytics 模型及就绪部署，填写名称、随机种子、每组数量、推理派发上限和人工审核任务上限。
2. 明确选择 2–32 张未分派的待处理图片。任务须没有标注、草稿、编辑锁及提交／审核历史；仅支持未入批次或未分派的默认批次。单图最多 16 MiB、1600 万像素，总原图最多 128 MiB。
3. 点击「核验并预览」。系统核对实际图片 SHA256、模型与推理环境，按相同内容和场景合并来源，排除保留的训练、验证及独立测试成员。历史版本缺少完整清单时会拒绝选样，需先完成构建或按原流程删除可删除的未使用版本。
4. 核对预览后创建轮次。每组 1–16 张，去重／排除后至少需要两组数量之和的独立候选。推理上限最多 96，至少覆盖全部独立候选；人工审核上限最多 32，至少覆盖两组计划。修改候选、模型或预算后须重新预览。

结果分为「主动建议」与「随机对照」。两组候选在评分前随机分开，控制组不读取分数来决定顺序；每组保留相同计划数量。主动组将四分之一的名额向上取整用于随机探索，其余优先选择低置信度或不同类别重叠的图片。每组数量为一时，主动组也完全随机探索。没有检测框表示缺少信号，会使用明确标记的随机补位，不能解释为确定背景。达到 100 个检测框时会提示输出可能截断。这些分数是检测启发式，不能跨模型比较或解释为正确率。

选择计划内候选子集，填写批次名称，点击「接纳并创建人工批次」；也可以拒绝候选。接纳前重新核对整个内容／场景组的媒体、任务资格、分派、编辑锁及当前历史成员。任何变化都会阻止接纳，须重新选样。每个候选在本轮只能决策一次，累计接纳受人工审核预算限制。批次链接进入正常批次管理，后续分派、Workbench 标注、提交与审核与普通任务相同；选样框不会写入标注真值，也不会改变项目发布。

推理预算按每次实际派发预扣，失败或超时不退还。失联不表示停止；恢复先核对同一请求的收据并复用已成功证据，保持原模型、请求与创建后 24 小时的到期时间。取消等待所有已保存请求确认完成或封存，无法确认时继续显示「正在确认停止」。已取消、封存、过期或用完预算的轮次不能通过更换请求逃逸限制，可显式新建下一轮。创建或决策回执中断时，页面保存原请求供原样重试，刷新仍可继续确认。

普通审核后点击「记录当前人工反馈快照」。两组分别显示实际接纳／计划、已审核任务、保留驳回记录，以及按人和作业类型去除重叠的已记录会话时间。会话时间仅反映部分记录，不证明完整工时；未完整采集的纠正次数保持未知。可选填写两份后续逐样本评估及精确执行尝试，完整且口径兼容时显示第二减第一的指标变化；部分报告、不同口径或没有评估时保持不可比较。部分接纳、不同审核量或缺少完整工时不能证明效率收益。

轮次、图片、决策和反馈长期保留，当前没有轮次删除入口。被保留历史引用的任务、素材、数据版本、评估、模型部署和项目不能直接删除；普通批次删除仍保留其历史名称及决策。后续编辑不会改写已记录的反馈快照。

## 自动训练策略

自动训练默认关闭。切换到「自动训练」，在「自动训练策略」选择初始划分数据、受控训练器、基础权重和训练参数，并明确填写变化样本门槛、检查间隔与冷却时间，勾选启用后保存。页面配置覆盖整个项目；只使用已审核合格的图片。

初始划分数据必须是已就绪且支持自动训练的图片检测版本。历史视频版本或未注明媒体类型的版本不能作为父版本，保存时会直接说明原因。

编辑策略时，可从项目配方库核对并采用具体修订。采用的参数保持只读；需要改参数时，先另存配方修订，或明确解除策略配方。只改门槛、间隔或冷却会保留完整高级配置与固定修订，归档该配方也不影响这些编辑。最后点击「保存自动策略」才产生新的策略修订，并取消旧修订尚未开始的候选和排队实验；已经开始的实验继续。

首轮统计当前合格训练样本。之后以最近成功的自动训练数据为基线，统计训练分区中新出现或标签修正的图片内容。重复的相同图片合并，同场景与重复内容先统一分区，再去重；验证分区变化形成新评估基准，不增加训练变化计数。达到门槛且冷却结束后，后台冻结数据并排入一个自动实验。训练期间的新变化留待后续检查。

「立即检查与同步」可立即检查数据或更新当前实验的触发记录。定期检查需要管理员运行 Celery beat 与 default/export worker，训练仍由独立执行器完成。环境更新后，管理员需同步训练配置，确保手动检查与定期检查使用相同训练目录。触发记录显示数据版本、实验、变化数量和结果。

失败或取消不会推进成功基线。同一策略版本不会反复启动相同失败训练内容；仅修改验证集也不会绕过这一限制。处理原因后，编辑并保存策略可明确发起新一轮检查。负责人失权、API Key 失效、项目停用或训练目录变化会停止后续自动触发，页面说明原因。

关闭策略取消尚未启动的自动实验；已经开始的实验可继续，或在训练实验中显式停止。已有模型发布不变，训练成功后仍需人工注册、试用和发布。删除策略与记录前，需要关闭策略并移除其引用的实验；被策略或触发记录引用的数据不能直接删除。
