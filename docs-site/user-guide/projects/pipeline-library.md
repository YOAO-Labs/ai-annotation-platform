# 全局编排库

> 适用角色：项目管理员 / 超级管理员

<!-- TODO IMAGE_CHECKLIST: images/pipeline-library/apply-to-project.png — 从库套用到项目 copy-on-write [manual] -->

AI 预标编排将多个模型阶段连接起来，例如先检测车辆，再为检出框补充属性。**全局编排库**用于保存可命名、可复用、带可见范围的编排模板；在 `/ai-pre/pipelines` 从全局模型服务和模型中选择阶段，再在项目中套用。

编排的阶段结构与项目里「批跑预标设置」相同；编排库只负责保存、共享和套用，不直接运行预标。搭建操作见 [AI 预标注](./ai-preannotate)。

## 三档作用域

每条编排有一个作用域，决定谁能看到、谁能用：

| 作用域   | 语义                                      | 谁能创建          | 谁能看到                   |
| -------- | ----------------------------------------- | ----------------- | -------------------------- |
| **私有** | 项目私有，即「项目当前 / 默认编排」的载体 | 项目管理员 / 超管 | 仅创建者本人（超管全可见） |
| **组织** | 组织内共享                                | 该组织成员 / 超管 | 该组织成员（超管全可见）   |
| **公开** | 平台公共模板                              | **仅超级管理员**  | 所有人                     |

看不到的编排一律按不存在处理（不泄露「有这条但你无权」）。

包含 `trained:<版本ID>` 或「项目当前发布」的管线只能保存在所属项目的私有范围。组织／公共模板继续使用通用内置模型；跨项目复制私有模型管线时，须先明确替换模型，不能把原项目的私有权重引用带给其他项目。

## 在编排库里建模板

`/ai-pre/pipelines` 页（标题「编排库」）专门维护**公共 / 组织**命名模板：

<DocsVideo
  src="/media/pipeline/template-create.mp4"
  poster="/media/pipeline/template-create-poster.webp"
  alt="配置 YOLO 车辆检测与车辆属性分类两阶段 DAG，选择车辆类别和车型、颜色写回键，再保存为公共编排模板"
  caption="公共模板只定义可复用编排；套用项目与实际运行分别在项目内完成。"
/>

1. 在画布的输入节点选择数据类型：图像使用几何模型；视频选择**整段序列**时源阶段只列追踪模型，生成跨帧轨迹；选择**逐帧**时源阶段使用图像几何模型，生成不跨帧关联的单帧结果。
2. 选择源模型并按需添加下游阶段。下游需要能接收裁剪图或框提示的非交互、非组合模型；服务处于错误状态时对应模型不可选。检查阶段警示、写回属性键冲突及项目中的服务可用性。
3. 给编排起名（如 `detect → 车辆属性`），选择可见范围并保存。

保存后编排出现在页面下方的「命名编排库（公共 / 组织）」列表里，每条显示 `作用域 · N 阶段 · 已套用 N 次`——套用热度让「哪条模板最常用」可见，便于沉淀策展。点列表条目可把它回填到画布继续编辑、另存为新条；删除仅所有者 / 超管可做。

::: warning 组织编排限制
页面尚不能选择组织，直接选择「组织」保存会被拒绝；通过 API 创建时需指定 `organization_id`。
:::

> **私有（项目默认）编排不在这页建。** 它是项目自己的「当前编排」，在项目详情页「批跑预标设置」里点**保存为项目编排**产生（一项目一条默认，可另存多条私有备选切换）。见 [AI 预标注 · 保存为项目编排](./ai-preannotate)。

## 套用到项目（copy-on-write）

在**项目详情页**从库里选一条模板套用到当前项目。套用是**深拷贝快照，不是活引用**：

<DocsVideo
  src="/media/pipeline/apply-project.mp4"
  poster="/media/pipeline/apply-project-poster.webp"
  alt="在 AI 预标项目详情中选择公共两阶段编排并套用为默认，再进入图片工作台运行项目编排并查看带车型和颜色的车辆候选"
  caption="套用生成项目私有默认副本；工作台随后按这条两阶段编排执行真实车辆检测与属性分类。"
/>

- 系统把模板阶段拷成该项目名下一条新的**私有**副本；可勾选同时置为项目默认编排。
- 源模板的「已套用次数」+1。
- **套用即解耦**：之后项目改这条副本不会回灌源模板；源模板日后改动也不会追灌已套用的项目。全局 / 组织模板是「出厂样板」，项目拿到的是自己可改的一份。

套用前会校验编排引用的每个模型服务**已在当前项目启用**；有未启用的会拒绝并列出待启用的服务（先去 [启用模型服务](./ml-backends) 里开启）。

## 权限速查

- **创建**：项目管理员 / 超管；`公开` 档仅超管；`组织` 档须创建者属于该组织。
- **可见**：超管全可见；`公开` 人人可见、`私有` 仅本人、`组织` 仅该组织成员。
- **编辑 / 删除**：超管、创建者本人、或组织编排的同组织成员。

架构与数据模型细节见 [ADR-0046](../../dev/adr/archive/0046-project-pipeline-library-and-scopes)。
