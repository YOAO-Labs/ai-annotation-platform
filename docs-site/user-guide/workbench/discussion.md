# 评论与问题

面向标注员与审核员的任务协作沟通指南。工作台支持针对单条任务、具体标注对象或特定视频帧发起讨论、标记问题图钉与追踪处理进展。

工作台的「讨论」面板由「评论」、「问题」与「历史」三个选项卡组成：评论用于日常交流与答疑，问题用于记录必须返修或确认的阻塞事项，历史用于回溯所有编辑记录。面板支持按阅读范围、问题状态进行快速筛选（详见 [筛选操作说明](/user-guide/reference/filtering)）。

「评论」右上角显示本任务全部评论总数，使用中性色；「问题」右上角显示本任务未解决问题总数，使用红色。零条时隐藏角标，1–9 条显示数字，超过 9 条显示 `9+`，悬停可查看准确数量。这些数量不代表未读消息，也不随阅读筛选改变；加载中显示省略号，失败显示问号。

Data Manager 任务列表的「未解决问题」「评论」两列使用与此处相同的统计口径：未解决问题是有效、开放的问题主题（根记录），评论是任务留言与标注评论的完整总数，不含问题回复和镜像记录。详见[数据浏览](../projects/data-manager.md)。

## 不选标注也能留言

首次进入任务且没有选中标注时，评论区默认显示「本任务全部讨论」，发送目标是「当前任务」。直接输入文字即可发送，不需要先创建标注。未采纳的 AI 候选、临时图形和多选状态都不会成为标注评论的目标。

阅读范围与发送目标互不影响：

| 控件     | 可选内容                             | 切换后的变化                         |
| -------- | ------------------------------------ | ------------------------------------ |
| 阅读范围 | 本任务全部讨论、仅任务留言、当前标注 | 只改变列表，不搬动草稿               |
| 发送目标 | 当前任务、任务中已载入的正式标注     | 保存原目标草稿，恢复新目标自己的草稿 |

选中一个已保存标注后，发送目标自动跟随它；切到另一标注时，保存原目标草稿并恢复新目标自己的草稿。下拉列表逐个列出已载入的正式标注，以类别和短 ID 区分同类别实例，也可手动回退到「当前任务」。手选目标在切换页签或重新打开面板后保留，直到画布选择改变。取消选择时，发送目标自动回到「当前任务」；原标注草稿保留，重新选中该标注即可继续编辑，不会把草稿内容搬到任务留言。发送前可核对目标标签。目标标注已删除或不可访问时，该草稿会暂停发送，并提示返回任务留言，不会自动转换成任务评论。

「当前标注」阅读范围随选中的正式标注变化；取消选择或改为多选后，会回到任务范围并显示原因。其他阅读范围不会因画布选择改变。

图片任务留言支持文字、绘图或两者一起发送，不需要选中标注；视频和点云任务留言支持文字。所有类型的任务留言和标注评论都可输入 `@` 选择项目成员，候选列表还包含项目负责人（标注为「项目负责人」）和平台超级管理员（标注为「超级管理员」，即使未加入成员表也可被提及），发送后保留提及并通知仍有任务权限的成员。候选浮层靠近窗口底部时会向上展开，避免内容超出视口。任务留言不提供附件上传；标注评论保留附件、绘图和视频位置能力。Enter 发送，Shift+Enter 换行；按 Enter 确认选中的 `@` 候选只插入提及，需再次按 Enter 才发送；中文输入法选词时按 Enter 不会发送。

「弹窗批注」和「在题图上绘制」用于给评论附加圈点说明，例如指出边界偏差，不修改标注图形。图片任务的「当前任务」目标支持两个入口，可以在未选中任何标注时说明漏标区域或整体问题。图片标注评论也支持两个入口；题图直接绘制要求发送目标与当前选中的标注一致，手动选择另一标注作为目标时可先使用弹窗。视频标注评论沿用弹窗批注。绘图完成后仍需点击「发送」才会提交评论。

## 画布上的评论提示

图片和视频画布中，有评论的已保存标注显示中性色评论气泡，框、多边形和像素 Mask 都可使用；同类别的不同标注分别计数。1–9 条显示数字，更多显示 `9+`，悬停可查看准确数量。这是现有评论总数，包含已解决评论，不代表未读消息。

视频单帧标注的气泡只显示在所属帧；轨迹气泡跟随当前帧可见的对象，数量为该轨迹的全部评论数。对象隐藏、处于离场区间或属于未加载的协作分段时不显示；拖拽期间暂时隐藏，结束后恢复。旧评论没有帧位置时，仍可打开对象讨论，不会推测原评论发生在哪一帧。

点击气泡会选中对应标注、打开讨论面板并切到「评论 → 当前标注」；待处理的视频绘制和 Mask 编辑仍需先完成原有确认。气泡大小不随缩放改变，隐藏标注时一起隐藏，单独隐藏类别标签不会隐藏气泡。新增或删除评论后数量刷新，重新聚焦页面也会刷新。

可在「工作台设置 → 标注显示」关闭「标注评论提示」。此开关按账号保存，默认开启；关闭后仍能在讨论面板阅读和发送评论。

## 阅读与继续加载

全部讨论按时间从新到旧排列，包含任务留言和本任务的标注评论，不包含问题回复、产品 BUG 或任务退回记录。每条评论显示来源；点击可用的标注来源标签可选中对应对象。历史对象已不可定位时，仍可阅读保留下来的评论。

列表底部的继续加载入口用于读取更早内容。加载失败会显示重试，不会把失败当作空列表。附件按评论原来所属的标注下载，与当前选中对象无关；旧任务留言中没有受支持下载方式的附件会显示不可用。

编辑、状态和删除操作按当前权限显示。操作失败会保留内容并提示原因；如果发送请求失败，请核对后手动重试，系统不会自动重复发送。

提交时会重新核对当前账号、项目权限及任务归属，并刷新要修改的记录。项目转移、成员职责或任务分派变化后，较早打开的面板不再代表写入许可；资源繁忙会明确返回冲突，不会等待后再用旧内容覆盖。确认当前目标和权限后可手动重试，不能通过重复点击强行提交。

## 上传和下载附件

选中已保存标注作为发送目标后，可通过「附件」选择任意类型的文件，每个文件最多 20 MiB，也支持空文件。文件逐个上传，每次成功都会立即加入原目标草稿；后续文件失败不会移除已经上传的附件。上传完成后仍需点击「发送」，也可只发送附件。

下载会验证当前登录权限及完整文件内容。附件保留期限从上传时起固定为 90 天，重新打开或阅读评论不会延长。已过期的附件需要联系原上传者重新上传并发送评论；历史附件无法核验时也会提示重新上传，不会自动从其他位置寻找文件。临时网络错误可在原附件按钮重试。切换任务或离开工作台会取消尚未完成的下载。

## 草稿保留到什么时候

同一浏览器标签页、同一次登录期间，文字及已附加的内容按用户、项目、任务和目标分别保留。切换评论／问题／历史，隐藏、浮动或重新停靠面板，任务 A → B → A，以及离开工作台后通过站内导航或浏览器后退返回，都可恢复原目标草稿。

发送和上传也绑定原目标。请求较晚完成时，不会清空另一个任务的输入，也不会把附件挂到当前选中的标注上。发送失败后保留草稿；已有请求正在发送时，同一目标不能重复提交，其他目标仍可编辑。

文字草稿不承诺在刷新、关闭标签页或重新登录后恢复。有未发送内容时，浏览器会在支持的情况下提示离开风险；退出登录或切换账号会清除当前会话的讨论草稿。

弹窗中的笔触会随绘制保存到打开时的任务或标注草稿。关闭弹窗、切换页签或离开工作台后，同一登录会话内仍可重新打开继续绘制；「保存批注」把绘图留在输入区，点击「发送」才会提交评论。弹窗绘图与题图直接绘制不能同时进行。

在题图上直接绘制的活动批注另有五分钟的本标签页恢复记录，按用户、项目、任务和发送目标隔离。切任务或离开工作台前，笔触同时保存在会话草稿中，因此同一登录会话内离开超过五分钟再返回，仍可继续绘制。五分钟限制只作用于刷新后的恢复记录；它不保存文字或弹窗绘图草稿，也不会把没有用户归属的旧记录导入其他账号。

## 新建与筛选问题

在「问题」页选择新建任务问题，可记录不绑定画布位置的事项。图片和视频的任务问题表单都不要求坐标。需要具体位置时，选择「在画布选点」，再点击实际问题位置；视频会先确认源帧，保存位置、帧号及已有视图上下文。

在图片或视频中选中一个已保存标注后落点，问题会默认关联该对象，表单显示关联对象的类别和短 ID。可在提交前取消关联，已确认的画布位置仍保留。表单打开后再改变选择不会替换已经捕获的对象。列表和详情会保留对象标识；对象后来不可用时，仍可阅读问题并定位原画布位置。

图片和视频图钉使用相同的尺寸和颜色规则，大小不随画布缩放改变，状态符号保持在圆心。未解决问题按严重度显示：提示为蓝色、警告为黄色、阻断为红色；已解决为绿色，搁置为灰色。选中时强调外圈。普通讨论问题的「阻断」表示严重度，不会自动阻止任务提交；Mask 质检的审核阻断继续按项目配置执行。

问题默认显示「未解决」，可切换「全部」「已解决」「搁置」。筛选由服务端执行，较早的问题不会因为不在第一页而被漏掉。视频保留整个项目范围和跨任务定位；图片与点云仍使用当前任务范围。

「问题」页签和画布入口显示当前任务的未解决总数，不是列表当前加载条数。数量请求进行中显示加载状态，失败显示未知和重试入口，不把失败写成 0。画布图钉逐页加载，已有图钉会保留；加载未完成或失败时会显示覆盖状态，全部加载完成后提示才消失。

问题状态包括未解决、已解决和搁置。可用操作取决于当前任务权限；审核员可处理状态，并不因此获得修改他人正文或删除问题的权限。位置与视频源帧的说明见[视频任务审核](../review/#在视频画面标记问题)。

## 打开问题与回复

点击问题标题打开详情，阅读正文、状态和回复，不会移动画布。带位置的问题另有「定位」按钮；定位时会选中仍可用的关联对象，并保留已有编辑确认。任务问题没有伪造的画布位置。点击图钉可直接打开对应详情，即使它不在当前加载页或不符合列表筛选，也不需要改变筛选。

回复按时间从早到晚显示，较长的对话可用「加载更早回复」继续阅读。加载失败时，已读回复仍会保留，可重试继续加载。历史嵌套回复保留上级信息，新回复统一发到当前问题。回复只支持文字，草稿沿用评论区的会话保留规则；发送失败保留内容，切换问题不会把迟到响应写进另一个回复框。

切换任务或离开工作台后，再打开「问题」页不会自动恢复上一个任务的详情；原问题的回复草稿仍按目标保留。

有权限时可解决、重新打开或搁置问题。解决后详情仍保持打开，不会因为该问题离开「未解决」列表而消失；「返回问题列表」回到原筛选和阅读位置。删除需要确认，问题已删除或权限变化时会显示不可用状态。

## 连续处理未解决问题

详情中的「上一条」「下一条」按当前范围从新到旧查找未解决问题，遇到分页边界会继续加载，首尾不会循环。刚解决或搁置的问题保留原来的排序位置：「下一条」继续找较早的未解决项，「上一条」找较新的未解决项。

顺序切换只打开详情，核对画布时再点击「定位」。目标不在当前范围时，先明确切换范围；查找过程中可取消，加载失败可重试。输入评论或回复时，Enter 不会同时提交画布中的多边形草稿。

## 从通知返回讨论

问题收到回复时，仍有任务权限的原作者会收到通知；问题状态变化时，原作者和参与回复的人会收到通知。任务留言和标注评论中的 @ 提及会通知被提及的人。操作人不会收到自己的通知，同一事件不会重复通知同一个人。

点击通知会先核对当前权限，再打开对应的标注或审核工作台。问题通知打开详情，回复通知突出显示指定回复；任务留言提及通知打开任务评论并突出显示原留言；原标注评论通知切换到该标注的阅读范围并突出显示原评论。若同时选中画布中另一条已载入标注，发送目标会按选中规则跟随，并保留原目标草稿；只阅读未载入标注的评论不会改变发送目标。内容较早时会继续加载，查找过程中可以取消，网络失败可重试。目标已删除或不可访问时显示原因，不会改为打开另一条任务。

跳转涉及未完成的视频绘制或 Mask 编辑时，仍需先处理原有确认。选择继续编辑会保留原任务和草稿。协作视频的评论若属于当前画布未载入的分段，面板会打开原评论并显示说明，不会自动认领或释放分段。

通知的已读状态只属于通知中心，不表示整个问题线程已读。可在[通知偏好](../reference/settings#通知偏好)分别关闭问题回复、问题状态、任务留言提及和标注评论提及；已有通知保留。问题回复仍不提供 @ 提及，邮件提醒也未开放。

工作台的软件问题可从顶栏「报告 Bug / 提交反馈」入口提交，与任务讨论中的问题记录分开。

## 历史与布局

「历史」显示当前任务或标注的审计范围，只用于阅读，不是另一份可编辑评论。用方向键、Home、End 可在讨论页签之间移动，输入区保留独立焦点。列表随面板高度伸缩，输入区固定在底部；更多布局方式见[布局偏好与浮窗](./#布局偏好与浮窗)。
