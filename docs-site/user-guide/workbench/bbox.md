# Bbox 标注

矩形框（轴对齐 Bounding Box）是最基础的高频目标检测工具，适合标注与图像坐标轴对齐的物体。

> 快捷键速查：`B` 激活矩形工具 ｜ `Alt + 拖拽` 从中心画框 ｜ `Shift + 单击` 多选 ｜ `Ctrl + A` 全选当前帧框体

1. **激活工具**：按 `B` 键或点击左侧工具栏的矩形图标。
2. **绘制框体**：在画布上按下鼠标左键 → 沿对角线拖动 → 松开鼠标，生成矩形框。
3. **选择类别**：在框旁弹出的类别浮层中选择目标类别；若项目配置了必填属性，补齐后按 `Enter` 保存。

::: tip 连续创建技巧
若同类目标较多，可在类别面板开启 **「图片连续创建」**：选定类别后连续拉框，无需每次重新点选分类。
:::

## 绘制与编辑手势

| 交互目标         | 鼠标 / 快捷键手势            | 行为说明                                 |
| :--------------- | :--------------------------- | :--------------------------------------- |
| **角点画框**     | 直接按下拖动（默认）         | 以落点为左上/右下角拉伸矩形              |
| **中心画框**     | 按住 `Alt` + 拖动            | 以按下点为矩形中心，向四周等距扩展       |
| **缩放已有框**   | 选中框后拖动 8 个控制手柄    | 拖角保持宽高比微调，拖边单向伸缩         |
| **中心等比缩放** | 选中手柄后按住 `Alt` 拖动    | 围绕原中心对称缩放                       |
| **移动位置**     | 单击框体内部拖动             | 平移目标框                               |
| **批量选中**     | `Shift + 单击` 或 `Ctrl + A` | 多选后在右侧属性面板批量改类别或批量删除 |

## 常见错误与防护机制

| 异常现象         | 系统行为与原因                                      | 推荐解决办法                                        |
| :--------------- | :-------------------------------------------------- | :-------------------------------------------------- |
| **画框无法保存** | 归一化宽或高小于 0.5%（`w < 0.005` 或 `h < 0.005`） | 目标过小，请按 `Ctrl + 滚轮` 放大视图后重新精细绘制 |
| **框体贴近边缘** | 角点创建会自动裁切在图像边界内                      | 中心创建会自动同步限制两侧半径，中心保持原位        |
| **无法提交任务** | 存在未指定类别的空白框，或必填属性缺失              | 点击未填框体，补全分类属性后再次提交                |

## IoU 与 AI 去重高亮

当工作台中的 AI 候选框与已有人工框的重合度（IoU）超过阈值（默认 0.7）时，系统会自动标记为「已被覆盖」并以半透明样式展示。点击「全部采纳」时会自动跳过这些冗余候选，避免重复落库。

> 注意：此处的 IoU 仅作为候选高亮与去重工具，不作为审核员质检的评分指标。
