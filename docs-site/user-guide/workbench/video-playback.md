# 视频播放、帧导航与采样

视频任务的画布是一个视频播放器，时间轴悬浮在画布底部。本页讲**怎么在视频里移动**——播放、逐帧、帧采样软网格与章节导航。矩形框与轨迹的标注见 [视频追踪标注](./video-track)。

## 播放与逐帧

服务端会按系统设置预热后续视频块。超级管理员可在「设置 → 系统设置 → 视频体验」调整向后预热块数，设为 0 可关闭额外预热；修改只影响新的预热决策，已经排队的任务继续执行。此设置不改变现有视频分块、采样网格或标注，当前块仍按需加载。

### 通用键（无论是否选中轨迹）

| 操作                      | 说明                                                                     |
| ------------------------- | ------------------------------------------------------------------------ |
| `Space`                   | 播放 / 暂停；按住并拖拽画布时平移视图                                    |
| `J` / `K` / `L`           | 反向播放或减速 / 暂停 / 正向播放或加速                                   |
| `←` / `→`                 | 上一帧 / 下一帧（开启采样时按网格跳）                                    |
| `Shift + ←` / `Shift + →` | 开启采样时源帧 ±1 微调                                                   |
| `Ctrl + M`                | 当前帧添加 / 移除书签                                                    |
| `Ctrl + [` / `Ctrl + ]`   | 跳转历史后退 / 前进                                                      |
| `Alt + L`                 | 清除循环区间                                                             |
| `Tab` / `Shift + Tab`     | 下一个 / 上一个轨迹（循环切换）                                          |
| `V` / `B` / `T`           | 切换选择 / 矩形框 / 轨迹工具                                             |
| `Esc`                     | 取消当前草稿 / 选中                                                      |
| `1-9`、`0`                | 有选中对象时改该对象类别；无选中时切换默认类别（按项目类别顺序取前十个） |
| 时间轴拖动                | 直接跳到指定帧                                                           |

### 选中轨迹时生效的键

| 操作                                 | 说明                                   |
| ------------------------------------ | -------------------------------------- |
| `,` / `.`                            | 跳上 / 下关键帧                        |
| `Home` / `End`                       | 跳首 / 末关键帧                        |
| `O`                                  | 标记 / 恢复当前帧消失                  |
| `Q` / `Slash`                        | 标记 / 恢复当前帧遮挡                  |
| `H`                                  | 隐藏 / 显示轨迹                        |
| `L`                                  | 锁定 / 解锁轨迹                        |
| `Ctrl + B`                           | 打开 AI 追踪                           |
| `Delete` / `Backspace`               | 删除当前帧关键帧；选中单帧框时删除该框 |
| `Ctrl + Delete` / `Ctrl + Backspace` | 删除整条选中轨迹                       |

播放时画布只读，暂停后才能编辑，避免拖框和播放状态互相抢焦点。时间轴会在鼠标进入画布时显示；选中框体时，框体和 resize 控制点会优先响应，拖拽时自动隐藏时间轴。

启用精确帧后，首次打开视频或切换任务时会自动准备当前帧；帧时间表和视频数据就绪后继续显示，无需刷新或手动切换到其他帧。

平移视图不需要切换工具：右键拖拽或按住 `Space` 后拖拽画布即可平移，Ctrl/Meta+滚轮以光标为锚点缩放。

J/K/L 播放支持 `0.25x / 0.5x / 1x / 2x / 4x` 档位。反向播放按帧步进，因此不会依赖浏览器不稳定的负速率播放。

> 轨迹关键帧导航只由 `,` / `.` 和 `Home` / `End` 承担；未选中轨迹时这些键不会退化成逐帧导航。

## 帧采样与软网格导航

<!-- TODO(v0.14.18) IMAGE_CHECKLIST: images/video-playback/sampling-config.png — 项目设置帧采样配置区（mode/target_fps/frame_step） [manual] -->

视频项目可在「项目设置」里配置**帧采样**（对应 `VideoSamplingConfig` 的 `mode` / `target_fps` / `frame_step` 三个字段），把逐帧标注约束在一张更稀疏的「网格」上，减少要标的帧数。采样有两种填法（二选一）：

- **按目标 fps**（`mode=fps`，填 `target_fps`）：例如源视频 30fps、目标 10fps，则每隔约 3 帧打一个网格点。
- **按帧间隔**（`mode=step`，填 `frame_step`）：直接填 step，例如每 5 帧一个网格点。

采样是**逻辑视图**，不会重新编码视频，也不改变已存的标注：

- **连续播放不受影响**：`Space` 播放的始终是完整原视频、原始 fps、所有帧。采样只约束「逐帧导航 + 打点」。
- **网格是绝对的**，锚定第 0 帧：step=5 → {0, 5, 10, 15, …}，所有标注员落在同一批帧上（保证一致性与导出干净）。
- **标注的帧号永远是源视频帧号**，改采样密度不会破坏旧标注。

开启采样（step>1）后键位重映射：

| 操作                      | 说明                                                                                                         |
| ------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `←` / `→`                 | 跳到比当前帧**严格小 / 大的最近网格点**（如 step=5 时 3→5、5→10）                                            |
| 暂停                      | 自动**吸附**到最近的网格帧                                                                                   |
| `Shift + ←` / `Shift + →` | **逃生口**：微调 ±1 源帧，可钻到网格之间的任意帧打**合法的 off-grid 关键帧**（应对关键事件刚好卡在网格之间） |
| `,` / `.`                 | 选中轨迹时跳上 / 下关键帧                                                                                    |

off-grid 关键帧只影响该轨迹在网格点之间的插值取值，不污染 MOT / 共识计算与导出帧号。step=1（不采样）时 `←` / `→` 回到源帧逐帧导航，`Shift + ←` / `Shift + →` 不提供额外跳转。

## 问题标记定位

画布落点创建 Issue 与「定位」按钮、时间轴问题标记共用保存的源帧。点击问题标题只打开对话，不会跳帧。进入问题落点模式会暂停且不吸附网格；只有实际源帧绘制完成后，才打开创建表单或显示定位成功。准备失败会保留锚点并提供重试。操作步骤见 [视频问题标记](../review/index#在视频画面标记问题)。

时间轴在紧凑浮层中占据主行，展开后则铺满整段视频；状态行同时显示当前时间与视频总时长。展开面板上方带稀疏的帧号刻度尺（随缩放自动重排，给长视频一个帧位参照）。长视频里帧太密时可以**横向放大**只看一段：

- **底栏最右侧的 `−` / `+` 缩放按钮**：以窗口中心为锚放大 / 缩小；放大用于长视频精细定位。「适配全部帧」与它们组成独立按钮组，紧邻收起按钮，和左侧播放 / 逐帧操作明确分区。
- **`Ctrl` / `⌘` + 滚轮**：以指针所在帧为锚点放大 / 缩小可见窗口。滚轮缩放在**整个播放组件**（底栏 / 时间轴 / 概览条）任意处都能触发，不必精确停在轨道上。不按修饰键的普通滚轮（或横向滚动）在放大后**平移**窗口。
- 放大后 seek 播放头、密度条、章节色带、关键帧点、刷选高亮**全部随可见窗口对齐**，缩放不会让它们错位。
- **概览导航条**：展开态始终显示一条代表整段视频的概览条，用高亮方块标出当前可见窗口，并叠一层全段标注密度缩影与播放头位置。未放大时，方块覆盖全宽且状态行显示「窗口：全部」；放大后显示「窗口：F{起}–{止}」，一眼看清「正看整段的哪一截、标注都在哪」。**拖方块平移、拖方块两边缩放、点空白处把窗口挪过去**。
- **双击时间轴**，或点底栏上的**「适配全部帧」**按钮，退出缩放回到整段全窗口。

需要同时看清各类时间轴信息时，点右侧的**展开**按钮把播放组件切到**分行面板**。展开 / 收起会以平滑的尺寸和淡入淡出过渡衔接；系统启用「减少动态效果」时则直接切换。标尺、进度条与标注密度始终保留；播放、逐帧、缩放、窗口概览和状态信息合并在底部单层工具栏，面板在两态下都贴近画布底部。章节、书签、问题、AI 预测密度、所选轨迹、采样网格、AI 影响范围和循环区间只在存在对应数据或正在操作时增加独立轨道，避免空行或大号控件长期遮挡画布。再点同一位置的**收起**按钮回到紧凑单轨浮层。紧凑态把状态信息放在独立一行，为主时间条保留更多宽度；时间条下方的细型全片概览会继续标出当前窗口。章节、书签、问题、密度、所选轨迹以及循环区间 / AI 影响范围的摘要标记也会保留，seek、刷选、缩放在两态下操作一致。

审阅 AI 预测时，时间轴上还有一条独立的 **AI 预测密度轨**（violet 单色，按帧桶聚合）：

- 存在预测时才显示；选中轨迹后也会和标注密度一起保留在分行面板与折叠摘要里，让预测分布保持可见。
- 密度轨旁的**「上一个 / 下一个有预测的帧」**导航按钮在预测帧集合上跳转，方便逐个核对 AI 追出的帧；没有任何预测帧时这对按钮不出现。

长视频可以通过「章节」侧栏（位于轨迹侧栏下方）划分场景：

- 项目负责人 / 超级管理员可以新建、编辑、删除章节。
- 表单支持「使用当前帧」按钮一键填入起止帧。
- 除表单外，还能在时间轴上**刷选建章节**：点章节侧栏的**「圈选」**进入圈选态，再在时间轴上拖出一段，填写标题后创建章节。
- 时间轴上方有彩色色带，点击跳到章节起点；色带段**可拖边界改起止**——拖动某段的左 / 右缘调整范围，松手后自动保存。
- 章节色带与侧栏章节行**双向 hover 联动**：悬停任一侧，另一侧对应项高亮，便于长列表里对位。
- `PageDown` / `PageUp` 在章节之间跳转（如果当前帧在某章节内部，`PageUp` 先回到该章节起点）。

章节是纯展示语义，不影响 `video_segments`（协作分片）的 claim/lock。
