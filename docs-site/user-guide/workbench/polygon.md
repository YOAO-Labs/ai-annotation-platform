# Polygon 标注

沿目标边界绘制并保存一个 `region` 多边形。图片和视频工作台都支持逐点绘制；图片工作台还支持沿光标自动落点。

开始前，打开可编辑的图片或视频任务，并确认项目已配置区域标注类别。

## 操作

1. 按 `P` 切到多边形工具
2. 沿目标边界依次单击落点，每点会生成一个顶点
3. 双击 / 按 `Enter` 闭合多边形
4. 在多边形旁弹出的类别浮层中选择 `region` 类别

图片与视频在落点过程中会按已有顶点和当前光标实时预览闭合轮廓及内部填充，无需先完成多边形。填充透明度跟随工作台设置中的「填充透明度」，设为 0 时仅显示轮廓；预览不会自动保存。

完成类别选择后，先确认当前对象已经保存，再开始下一个对象；保存失败时按工作台提示重试，保留当前草稿。

## 编辑

### 调整已有对象

<!-- TODO IMAGE_CHECKLIST: images/polygon/vertex-insert-alt.png — 按住 Alt 悬停边上光标变「+」的瞬间 -->

- 选中已有多边形，鼠标悬停在**边**上 → 出现「+」图标，按住 `Alt` 后单击边插入新顶点
- 拖动顶点 → 修改形状
- `Shift + 单击顶点` → 删除该顶点（多边形 ≤ 3 个顶点时拒绝删除）
- 绘制 polygon / polyline 或拖动 polygon 顶点时，会在 8px 屏幕距离内吸附到可见 polygon / multi_polygon 的顶点或边界；按住 `Alt` 可临时关闭吸附

## 高级操作

### 图片连续创建与自动落点

开启[图片连续创建](./#图片连续创建)并选定区域类别后，完成多边形即可继续同类下一对象；缺必填属性时先补齐字段。Esc 先取消当前点集或待保存草稿，再按一次退出连续模式。

图片工作台还支持按住 `Shift` 和鼠标左键沿边界拖动，按累计约 **8 CSS px** 自动落点。缩放画布后仍按屏幕距离采样，快速拖动会补齐相邻输入之间的点；松开鼠标或 Shift 时保留终点，随后可继续单击补点或再次拖动。自动落点沿用已有吸附规则，`Alt` 临时关闭吸附；它不会自动寻找图像边缘。

::: warning 草稿保护与点数预算

草稿达到 **20,000 点** 时自动落点暂停，画布显示提示并保留全部已有点。可用 `Backspace` 撤销最后一点、`Esc` 取消草稿，或按 `Enter` 进入原有闭合和保存流程；达到预算不会自动保存。按住 Space 平移不会添加点，切换任务或工具会取消未完成的草稿。

:::

### 沿已有边界追踪（图片）

在多边形工具中点击画布左上角的 **沿已有边界**，依次点击已保存多边形的起点和终点。两点必须在同一个来源的边界上，8 屏幕像素内优先吸附到顶点，其次吸附到边。

画布预览 **顺时针 / 逆时针** 两条可选路径，默认选择屏幕长度较短的一条。切换方向后点击 **确认追加**，或在画布中按 `Enter`，将所选路径一次追加到当前草稿；草稿末点与路径起点重合时只保留一份。之后仍可单击补点、Shift 拖动或用 `Backspace` 逐点撤销，再按 `Enter` 闭合并保存。

追踪期间 `Esc` 只取消预览，保留已有草稿；`Backspace` 先退出预览再撤销草稿的最后一点。平移和缩放可继续使用，切换任务、工具或进入只读状态会结束预览。来源对象不会被追踪操作修改。

仅支持已保存的简单单外环 Polygon。带孔、多外环、自相交和退化边界会显示不支持原因，起止点不能重合。确认前会核验来源是否仍为选择时的版本；来源修改、隐藏或删除后必须重新选择。网络核验失败时保留预览，可重试，不向草稿追加未经确认的路径。

### 合并与裁切重叠区

- 多选同类别 polygon / multi_polygon 后，可在浮条或右键菜单点「合并」生成一个新的 polygon / multi_polygon；原标注会被删除，整次操作可一次撤销
- 不同类别、锁定标注或非 polygon 几何不会合并；属性完全相同时保留，不一致时新标注属性为空
- 多选 ≥ 2 个 polygon / multi_polygon 后，在**右键的那个**多边形上点右键菜单「裁切重叠区」，会从它身上减去其余选中多边形的重叠区域（布尔差集）：被裁的框作基准、几何就地更新（可裁出孔洞），其余框原样保留。常用于遮挡场景（前景物体压在背景上时，让背景多边形不再覆盖前景），不要求同类别；若重叠区覆盖整个基准则裁切失败并提示

## 切割为两个对象

1. 切换到选择工具，在已保存的多边形上点右键，选择「切割多边形」。对象必须未锁定、没有活动子对象，且只有一条不含孔洞的外环。
2. 从对象外或边界开始，逐点画一条穿过对象的切线，在对象外或边界结束。可以使用折线，最多 256 点；靠近来源边界时吸附，按住 `Alt` 可临时关闭。`Backspace` 撤回一点，`Esc` 取消切割。
3. 按 `Enter` 或「预览切割」查看两块区域和面积比例。可修改切线或取消；只有「确认切割」或预览后的 `Enter` 才保存。
4. 面积较大的区域保留原对象 ID，另一块成为同类别的新对象，保留业务属性及原父对象关系。切线不会擦除任何区域。相切、沿边重合、多次进出、自交或空结果会显示原因并保留切线。

切割需要在线提交。提交失败时预览保留，「重试切割」可安全重试同一次操作。一次 `Ctrl+Z` 恢复原形状，一次 `Ctrl+Shift+Z` 恢复相同的两个对象。任一结果被再次编辑、锁定或添加子对象后，撤销/重做会整批拒绝，历史位置保留。

服务端允许在原切割后的 30 天内恢复，重做不延长期限；页面仍使用当前任务的会话历史，刷新后的历史恢复窗口为 5 分钟。取消预览后刷新不会产生新对象。

## 绘制快捷键

| 操作                     | 快捷键                                           |
| ------------------------ | ------------------------------------------------ |
| 撤销最后一个落点         | `Backspace`                                      |
| 沿光标自动落点（图片）   | `Shift + 左键拖动`                               |
| 取消当前草稿             | `Esc`                                            |
| 闭合多边形（≥ 3 个顶点） | `Enter` 或双击                                   |
| 自动闭合                 | 单击第一个顶点（首点高亮时出现「单击闭合」提示） |

## 性能提示

- 渲染层 LOD（Douglas-Peucker 简化）：未选中态下顶点数超过 **60** 时，画布渲染会按当前视口缩放级别自动简化；编辑态和选中态始终使用完整顶点，保证拖拽手感。
- 自动落点采用 20,000 点的交互预算；顶点过多仍会增加序列化和 API 传输开销，建议只沿需要保留的轮廓绘制。
- 极复杂边界可能超过切割校验预算；此时保留来源和切线并提示，可减少不必要的切线点或先简化来源。
