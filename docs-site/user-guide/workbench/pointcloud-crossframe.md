# 点云与序列跨帧标注

scene 模式的项目里，同一物体会在一段录像里连续出现多帧。跨帧能力让你不必每帧从零画框，并能叠加邻帧参考检查时序连续性。本功能同时适用于 **3D 点云框**和 **2D 图像序列框**（bbox / polygon / rotated_bbox / polyline / keypoint 等）。scene 与 `frame_index` 的概念见 [Scene + frame_index 跨 task 帧序列地基](/dev/concepts/scene-and-frame-index)。

上面的流程使用真实 nuScenes ego 位姿，将已复核的 3D 框从第 0 帧延续到第 1、2 帧，在第 1 帧修正中心位置，再返回第 1 帧叠加同轨迹的前后参考。它不是 AI 追踪；`track_id` 保持目标身份，ego 位姿补偿车辆运动，标注员继续核对几何。对齐后参考框可能与当前框重合，不能据此判断邻帧缺失，也不应人为挪开框体制造分离效果。

## 沿对象轨迹连续检查

在 3D 工作台选中带 `track_id` 的框，再点击 Scene 时间轴的「播放」，可沿该对象连续检查。播放会记住本次跟随的轨迹：没有已物化成员的帧不显示虚构框，后续帧存在同轨迹成员时恢复选择。暂停或离开 Scene 后清理本次临时跟随意图。

展开时间轴后可对照对象存在区间、关键帧 / 派生 / 采样成员与质检问题。连续播放期间为只读预览，跨帧任务中心仍可查看作业；传播、插值和其他修改需先暂停，等待当前帧获得编辑权限。浏览速率、缺帧跳过及键盘定位见[点云工作台](/user-guide/workbench/pointcloud-view)。

跨帧任务中心使用半透明遮罩，不模糊背后的点云，以降低软件渲染环境的开销。批量传播与轨迹生命周期共用此弹窗，仍可按 `Esc` 或点击遮罩关闭。

延续和插值要求源帧与目标帧都可编辑；已完成任务需先重新打开，审核中的修改仍按审核微调权限处理。只读源帧可以查看，不可借可编辑目标帧修改其轨迹身份。

系统会在实际写入前重新核对任务状态、当前分派、编辑占用和审核证据。等待期间条件变化、不再允许修改时，本次操作会被拒绝；源框已更新时使用当前有效内容，已删除时停止传播。插值仍会跳过已有同轨迹框的中间帧。

批量作业提交时若提示后台暂时不可用，可先在跨帧任务中心查看当前状态：已经开始或完成的作业会保留实际进度。已完成、失败或取消的作业不会因迟到的后台消息继续修改标注。

## 跨帧目标延续

<!-- TODO(v0.14.18) IMAGE_CHECKLIST: images/pointcloud-crossframe/crossframe-propagate-toast.png — 按 Alt+→ 跳帧自动选中新框 + toast [manual] -->

同一物体在一段录像里连续出现多帧时，不必每帧从零画框：

- **`Alt+→`**（主键，2D 与 3D 通用）：把当前选中的标注延续到**同 scene 的下一帧** task —— 系统在下一帧新建一个几何相同的框（与源框共享 `track_id`，表示"同一物体"），自动跳到下一帧工作台并选中这个新框，你只需微调位置即可继续 `Alt+→`。
- **`Alt+←`**：同理延续到上一帧。
- **`Shift+→` / `Shift+←`**（3D 补充键）：3D 点云舞台额外支持 Shift+方向键触发同一跨帧延续。2D 舞台中 `Shift+方向` 已用于 10px 平移，故 2D 只能用 `Alt+方向`。
- 已到 scene 末帧再按 `Alt+→`、首帧再按 `Alt+←`，提示"已是该 scene 最后 / 首帧"，**不会**误跳到别的 scene。
- 仅在选中了一个标注时生效，且该标注的几何类型须属于可跨帧复制的类型（`bbox / polygon / multi_polygon / rotated_bbox / polyline / keypoint / box_3d`）；未选中或选中点云分割（`point_mask_3d`）会有相应提示。
- **运动补偿（v0.15.1，仅 `box_3d`）**：scene 有逐帧 ego 轨迹时（nuScenes 导入数据自动有），延续不再是"原样复制"——系统按车体位姿变化反算目标帧坐标，**静止物的框在下一帧自动套住目标**，无需手动追平车辆前进带来的偏移。scene 无轨迹（如 SUSTechPOINTS 示例数据）时自动退回原样复制，并轻提示一次"未做运动补偿"。

> 跨帧延续不是破坏性操作：新框只是源框的副本，调坏了可直接删除或撤销。

## 批量延续与区间插值（v0.15.1，仅 3D 点云）

长 scene 里逐个目标、逐帧延续太累，3D 工作台提供两个加速入口（工具条「跨帧工具」展开）：

- **批量延续**（`Ctrl+Shift+→` / `Ctrl+Shift+←` 或面板按钮）：把**当前帧全部 3D 框**一次运动补偿延续到邻帧，各自延续自己的跨帧链；toast 报"N 个目标已延续到帧 M"。
- **区间插值填充**：只标首尾两帧，中间帧自动生成。工作流：
  1. 在起点帧画好框，面板里填**目标帧号**，点「**延续到帧**」——框被运动补偿延续到区间终点帧（同时建好跨帧链）；
  2. 在终点帧把框微调到准确位置；
  3. 回到起点帧选中该框，点「**插值填充**」——中间每一帧自动生成插值框（世界系线性插值位置 + 球面插值朝向 + 线性插值尺寸），完成后跳到首个插值帧逐帧抽查。
- 插值生成的框 `source` 标记为 `interpolated`（区别于手工 `manual`），便于审核侧按来源过滤或批量清理；对已有该物体框的中间帧自动跳过，重复触发不会生成重复框。
- 目标帧反查范围为当前帧 ±20 帧；更长区间分两段操作即可。
- 匀速直线假设下插值最准；目标急转弯/加减速的帧需要人工微调（这正是"跳首帧逐帧抽查"的意义）。

## 邻帧参考叠加（仅 3D 点云）

<!-- TODO(v0.14.18) IMAGE_CHECKLIST: images/pointcloud-crossframe/overlay-k3-triview.png — K=3 时主视图 + 三视图半透明虚线参考框 [manual] -->

工具条「邻帧框叠加」用独立开关控制是否显示同 `track_id` 历史 / 未来框作时序参考：

- 开关控制是否显示参考框；帧数档位 **1 / 3 / 5 / 7** 控制前后各显示几帧。
- 参考框为**半透明虚线、不可选不可拖**，只读参考，方便判断时序连续性（这一帧的位置和上一帧是否对得上）。
- **叠加范围（v0.15.17）**：工具条上的「对象 / 全部」切换控制叠什么。
  - **对象**（默认）：选中某个有跨帧链（`track_id`）的框时，只叠该物体前后各 K 帧的框。需先选中一个对象。
  - **全部**：不选任何对象也叠加邻帧的**全部**框，用于整体时序感知（代价是渲染量更大）。此模式下若选中了某对象，其轨迹框正常显示、其余框弱化（更淡），便于聚焦当前目标。
- **ego 对齐（v0.15.1）**：scene 有 ego 轨迹时，邻帧参考框会先变换到当前帧车体坐标系再叠加——静止物的历史/未来框与当前帧重合，而不是沿车辆运动方向拖出一串影子；偏离重合位置的部分就是目标自身的真实运动。
- **无轨迹提示（v0.15.17）**：scene 无 ego 轨迹（如 SUSTechPOINTS 示例数据）时，邻帧框维持原样叠加（不做运动对齐），工具条常驻 badge「无 ego 轨迹·未对齐」提示这一点——这是数据没有轨迹，不是故障。
- 开关、帧数与范围都保存到个人工作台设置，刷新、换任务或换设备登录同一账号后保持。

## 邻帧点云叠加（v0.15.18，仅 3D 点云）

上面叠的是**框**;邻帧点云叠加叠的是**点云本身**。在 `设置 › 点云 › 邻帧点云叠加` 打开后，系统把前后帧的点云用车体位姿对齐到当前帧一起渲染：

- **为什么要对齐**：车端采集时车在动，邻帧的静止背景（墙 / 路 / 楼）相对车体也在平移。直接叠会错位成一团乱影；用 ego 轨迹做运动补偿后，**静止背景重合 → 点变密**（远处稀疏、小目标更好标），**动态目标（其他车 / 行人）留下沿运动方向的拖影**（能看出目标轨迹趋势，也是一种噪声）。
- 邻帧点用**前/后帧分色（过去冷蓝 / 未来暖橙）+ 按帧距淡出（近帧实、远帧淡）+ 低透明 + 略小点**，与当前帧点（高度色带 / 相机上色）一眼可分；动态目标的拖影因此读起来是「运动方向」而非乱噪。
- 邻帧点云有**独立帧数设置**，可选前后各 **1 / 2 / 3** 帧（点云比框重得多），且邻帧点云会**强制下采样**;切帧 / 关开关即时释放，避免卡顿和内存堆积。
- **需 ego 轨迹**：无 ego 轨迹的 scene 不叠点云（直接叠会乱），这是数据没有轨迹，不是故障。
- 标动态目标、想看清当前帧时可随时关掉——邻帧点云只是观察辅助，不影响标注落点。

### 动态点处理（v0.15.22 剔除 / v0.15.23 逐目标对齐）

`设置 › 点云 › 邻帧动态点` 三档控制邻帧点云如何处理动态目标：

- **保留（拖影）**（默认）：邻帧点全叠，动态目标留沿运动方向的拖影（= v0.15.18 行为）。
- **剔除动态点**（v0.15.22）：把对齐到当前帧后**落在已标注框内**的邻帧点剔除，只叠静止背景——动态目标拖影随之消失，远处静止结构仍加密。状态栏显示本帧剔除了多少点。
- **逐目标对齐**（v0.15.23）：不丢弃动态点，而是把它**搬到当前帧位置**一起渲染——按该目标在邻帧框与当前帧框之间的位姿变化（`T = 当前框位姿 · 邻帧框位姿⁻¹`）逐目标补偿。静止背景照旧 ego 加密，**动态目标也对齐加密、无拖影**，相当于用已有 track 数据做轻量 scene flow。状态栏显示本帧搬运了多少点。

> **仅对已标注且跨帧成链的目标有效**：剔除与对齐都靠「点是否落在框内 + `track_id` 配对」判定，所以**未画框 / 未 propagate 的动态物**仍会留拖影（对齐模式下默认按剔除处理，不冒新拖影）。想叠得最干净，先把动态目标标出来并 propagate / 插值成跨帧 track，再开「逐目标对齐」效果最佳。对齐依赖邻帧框位姿的准确度——track 不准则搬运后会错位。
