# 点云视图与上色

面向标注员与审核员的 3D 激光雷达点云场景浏览指南。涵盖 Three.js 视角漫游导航、多相机 RGB 环视投影以及强度/高度上色模式。

3D 点云项目（`data_type=lidar`）进入 Three.js 3D 舞台后，主 3D 视图显示点云，相机可按物理朝向悬浮在四周，也可整组收进一个停靠图库。本页讲**怎么看点云**——视角导航、相机面板与上色 / 深度；绘制和编辑 3D 框见 [3D 立体框标注](./3d-box)。质量面板支持按严重级别与规则原位筛选（详见 [筛选操作说明](/user-guide/reference/filtering)）。

![nuScenes 激光雷达与六相机环视任务工作台](../images/workbench/pointcloud-real-scene.png)

示例画面使用 nuScenes / Motional 的六相机公开样例，经 OpenMMLab MMDetection3D
版本固定的演示资产接入；仅用于非商业文档演示，并按
[nuScenes 使用条款](https://www.nuscenes.org/terms-of-use)保留署名。

## 原件读取

点云与每路相机分别核验当前任务下的内容，读取失败会保留可用的其他相机信息。相机面板、放大图、点云上色和邻帧预取使用同一内容身份；不会因旧签名地址仍有效而读取已变化的原件。普通切帧保留已就绪画面至新帧可用，退出或更换登录会话则释放旧资源。

单个完整原件最多512MiB。缺失、内容不符、未核实的历史原件或超限文件会明确报错；解决来源或权限问题后重试。原生视频播放仍使用独立链路。

取消邻帧预取后，旧结果不再进入当前画面；已经开始的传输结束后才释放读取名额，避免旧读取尚未结束就启动替代请求。当前帧优先于尚未开始的预取；退出或更换登录会话仍立即中止旧请求。

## 视图导航

  poster="/media/pointcloud/orbit-poster.webp"

/>

- 主 3D 视图可旋转 / 平移 / 缩放查看点云。
- 左上角的单行视角工具栏提供「俯视」和重置图标。重置图标的提示为「重置视角」，回到默认斜视（跟随车头朝向）；「俯视」切到正上方鸟瞰（BEV），便于框选地面 footprint。
- 顶部“布局”菜单的「恢复相机排列」按当前模式恢复相机排列，不改变主视角，也不切换悬浮或停靠模式。
- 同一菜单中的「框体精修」显示三视图并隐藏相机；「传感器融合」显示相机、沿用上次呈现模式并隐藏三视图；「点级分割」隐藏三视图和相机。这些工作方式保留主画布及其他工作台面板的位置，不切换当前标注工具，可用切换后的撤销提示恢复上一次布局。
- 工作台设置窗口的「画布与视角」分类可调整点大小、点选模式、相机上色、深度提示、地面网格、坐标轴、相机灵敏度和 3D 视角持久化；设置窗口与视角工具栏读写同一份偏好。
- 开启「持久化 3D 视角」后，平台会记住主 3D 视图的相机位置、目标点、up 向量和当前 orbit / BEV 模式；再次打开点云任务时会在点云加载完成后恢复该视角。
- 在同一 scene 的相邻帧之间切换时，主 3D 视图会保留当前相机位置、目标点、up 向量和 orbit / BEV 模式，无需开启持久化。切换到不同 scene 时，开启持久化则恢复账号视角，未开启则使用新场景的默认取景
- Scene 时间轴会预解析相邻帧点云并预解码相机图。普通切帧时，画布保留当前已就绪点云并显示加载状态，等目标 geometry 完整就绪后一次替换，不会出现中间空白；高速连续点选只处理首帧和停手时的最终帧，过期下载、解码与相机预取会被取消。新点云到位后先显示高度色，相机资源准备好后至多切换一次 RGB，不会为了等待上色隐藏画布。
- 相机浮层或停靠图库中的放大按钮打开相机编辑大图，点关闭按钮或按 `Esc` 可收起。

三视图的停靠、浮动、标签合并和隐藏操作始终作用于同一个面板，选中的 3D 框和主画布不会因布局变化而重建。相机则按整组切换：悬浮模式按物理朝向排列六路相机，停靠模式收进「相机视图」图库；隐藏后可从顶部「布局」菜单恢复。面板恢复后使用 Scene 时间轴的「下一帧」或帧号输入切换任务，可同时核对点云、投影图和相机角色。

## 跨帧传播任务

Scene 时间轴默认以紧凑播放条显示。上一帧 / 下一帧会跳过明确缺失或不可访问的帧；帧号输入使用数据中的实际编号（例如 `F105 · 6/39` 表示第 6 个逻辑帧），输入后按 Enter 精确定位，目标不可访问时留在原帧。底部全段位置条可点击，拖动时先预览候选帧号，松手后才切帧。

展开后，帧标尺、任务状态、当前窗口标注数量、已选对象和质检问题分行显示。圆点表示对象关键帧，菱形表示派生成员，空心圆表示采样成员；存在区间有浅色带，空白不代表对象缺席。未加载摘要显示等待标记，不会被当成零标注。缩放提供 24 / 40 / 64 / 80px 四档，「定位当前帧」回到正在查看的位置。手工横向浏览和同 Scene 切帧会保留窗口；展开与缩放偏好只在本次工作台会话内保留。画布高度不足时临时收起，恢复空间后恢复展开。

「播放」以 **1 / 2 / 4 帧/秒**进行只读逐帧预览，默认 2 帧/秒。这是最高浏览速率：每帧点云和标注就绪后停留相应时长，慢加载会降低实际速率，不跳帧追赶。播放前必须完成保存、表单输入、拖动或绘制草稿；播放期间可旋转和缩放视角，写操作暂停且不逐帧申请编辑锁。暂停后等待当前帧重新取得编辑锁再编辑。点击编辑区域或使用编辑快捷键会先暂停，本次输入不同时修改标注。

帧加载出错或等待超过 15 秒时暂停并提供重试；重试不会自动续播。到末帧停止，再次播放从首个可访问帧开始。切换任务队列、离开 Scene、隐藏画布或浏览器进入后台都会暂停。时间轴自身或帧轨道获得焦点时，Space 播放 / 暂停、左右键前后帧、Home / End 首尾定位；帧号输入保留正常编辑键。

Scene 时间轴的「跨帧任务」会打开当前 Scene 的 3D 跨帧任务中心。「批量传播」页签要求明确选择「已选框」或「当前帧全部框」、向前 / 向后方向和结束帧；单个任务最多处理 100 个逻辑帧和 500 个源框。

- 目标帧已有同一 `track_id` 的 3D 框时会跳过，不覆盖既有框。
- 任务在后台逐帧提交；关闭弹窗或刷新页面不会中断，重新打开后会恢复进度。
- 取消会保留已完成帧，只停止后续帧。失败或源框已过期的帧可用「重试失败帧」建立新任务。
- 传播期间修改或删除源框时，后续帧会标记为已过期并停止写入，防止用旧几何覆盖新真值。

## 质量问题筛选

从 Scene 时间轴打开「3D 质量检查」，可按状态、严重级别和规则组合筛选，包括投影残差。存在 Scene 时读取当前 Scene 的问题，否则读取当前任务；读取范围与扫描权限分别判断。

严重级别计数标注为“已加载”，右侧总数来自服务端完整匹配集合。筛选只改变问题列表，不会自动扫描、修改框或轨迹。时间轴继续显示当前 Scene 的未处理问题标记；切换任务或 Scene 后会退出旧问题详情与运行状态。

## 轨迹生命周期

在当前帧选中具有跨帧轨迹的 3D 框后，打开「跨帧任务」并切到「轨迹生命周期」页签。面板会显示轨迹 revision、存在区间，以及人工关键帧、派生成员和兼容样本的数量。

- 「拆分」以当前帧为边界：当前帧及之前保留原身份，之后的区间和成员迁移到新轨迹。
- 「合并」会列出同一 Scene 中类别相同、帧不冲突且当前用户可以完整编辑的候选。当前选中轨迹始终保留；平台不会覆盖同帧成员。
- 「标记缺席」从当前帧起移出存在区间并停用相应成员；对象之后仍可用同一身份恢复。
- 「恢复出现」从当前所选框复制几何，在指定缺席帧建立新的人工关键帧，不会自动猜成新对象。
- 「终止轨迹」保留当前帧，关闭后续存在区间并停用未来成员；它不会删除轨迹历史。
- 所有操作都必须先点「预览影响」，核对区间变化、受影响帧和成员角色，再显式确认。涉及人工关键帧或兼容样本时还需额外确认。
- 如果预览后任何成员被修改、轨迹成员锁定、某一帧进入只读状态或权限变化，确认会被拒绝并要求重新预览，不会只改一部分帧。
- 已提交操作会出现在面板历史中。只要相关轨迹和成员之后没有变化，就可以撤销并精确恢复原区间与成员状态；已有后续修改时会拒绝撤销，避免覆盖新真值。
- 单次轨迹修正最多处理 5000 个活跃成员；更长的轨迹需要先缩小数据范围或由管理员拆分 Scene。

> 框选目标时建议先切「俯视」鸟瞰视角更顺手，但斜视下也能选对（框选屏幕里的真实点，与视角无关）。详见 [3D 立体框标注 · 操作](./3d-box#操作)。

## 相机面板

相机以整组为单位切换呈现方式，不支持部分停靠、部分悬浮：

- **悬浮显示**：每路图像按物理朝向贴在主视图四周。标题条可逐路拖动避让；第一次从默认位置拖动时先锁定当前位置，双击标题条或点「归位」回到默认锚点。中等窄屏默认折叠为小标签，手动展开 / 收起状态优先；折叠标签也提供布局菜单。
- **全部相机停靠**：从任一路相机的布局菜单或顶部“布局”菜单选择该动作，所有相机收进一个“相机视图”组件。窄列纵向滚动，拉宽后自动变为网格；每张图带名称和朝向，等比显示，投影随尺寸同步。组件可在停靠区间移动、上下分割或与其他面板组成标签。
- **切回悬浮**：点相机视图标题栏的「悬浮显示」，恢复每路相机记住的位置和折叠态；再次停靠时恢复图库的位置和列宽。标题栏 × 只隐藏相机视图，保留模式，可从“布局”菜单找回。
- **恢复排列**：顶部“布局”菜单的「恢复相机排列」在悬浮模式恢复各路默认贴边位置，在停靠模式回到默认朝向顺序及滚动起点，不移动其他面板。

相机图像缺少标定时仍可查看，但不显示投影线框。当前帧缺图或加载失败时显示对应提示；加载新帧期间不会用上一帧图像代替。放大任一路相机后继续使用现有的种框、标定及人工 2D 成员编辑功能，`Esc` 关闭大图。3D 框的实时投影与双向选中见 [点云跨模态联动](./pointcloud-projection)。

### 相机 RGB 上色

<!-- TODO(v0.14.18) IMAGE_CHECKLIST: images/workbench/pointcloud-rgb-colorize.png — 相机上色前后对比 [manual] -->

设置「相机上色」（默认关）：逐点投影到各标定相机像面采样像素 RGB，主视图和三视图一致跟随；无标定的点回退高度色带。开启后自动按 z-test 剔除被前景遮挡的背景点（容差 10cm），避免背景墙面被前景车辆“染色”。常规渲染路径在持久 worker 中完成颜色与深度计算；实验渲染路径会缓存解码后的相机图和相邻帧遮挡深度，并由 GPU 直接采样纹理，不读取 Canvas 像素。

上色结果可通过「上色对比度」「上色亮度」「上色 Gamma」继续微调。这些字段存入账号级工作台设置，跨浏览器同步；调整色彩时只重映射已经采样出的 RGB，不会重复加载点云。

### WebGPU 实验渲染器

工作台设置的「实验」分组提供 WebGPU 点云渲染器开关。它默认关闭，切换后需要刷新或重新打开 3D 任务；状态栏会显示实际使用的 `WebGPU`、`WebGL2 fallback` 或 `Legacy WebGL2`，不能只凭浏览器支持标记判断是否真的启用了 WebGPU。

`WebGL2 fallback` 表示当前访问页面的浏览器没有提供可用 WebGPU adapter，并不表示部署服务器没有显卡。尤其是 Linux + NVIDIA 的支持还会受 Chrome 版本、Wayland / X11 会话、Vulkan 与浏览器 GPU 策略影响；应以浏览器的 GPU 状态为准。

该开关用于在同一套真实任务上对比切帧、选框和三视图性能。初始化失败或运行时设备丢失会自动回到 Legacy，不影响当前标注数据。在真实 nuScenes A/B 和多设备验证确认有效前，它不会成为默认功能。

无论使用哪个实际 backend，主透视视图与三个精修视图都由同一块渲染画布驱动，三视图放到侧栏也可查看底图。静止且没有加载、相机或标注变化时，渲染器会停止提交；移动主视角、调整框体、缩放或移动三视图面板会按需唤醒对应视图。隐藏面板或切换到其他标签时暂停该视图绘制。状态栏只显示这一个 renderer 的真实 backend，因此主视图与三视图不会出现不同的 fallback 状态。

## 点云点选（PointMask）

启用 `point_mask_3d` 工具单位后，按 `P` 切到分割工具，左上视角工具栏显示“选点”下拉。在主 3D 视图用矩形、套索或多边形选取目标点集，闭合后选区内可见点自动聚合为一条 `point_mask_3d` 标注。详细操作见 [3D 立体框标注 · 点云分割](./3d-box#点云分割)。
