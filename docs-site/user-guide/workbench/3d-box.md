# 3D 立体框标注

<!-- TODO(v0.14.18) IMAGE_CHECKLIST: images/3d-box/workbench-overview.png — 3D 工作台全局（主视图 + 相机面板 + PSR 面板 + 自动贴合按钮组） [manual] -->

3D 点云项目（`data_type=lidar`）启用 `lidar_box_3d` 或 `point_mask_3d` 工具单位后，工作台进入 Three.js 3D 舞台：主 3D 视图旋转 / 平移 / 缩放查看点云，三视图精修面板可整体停靠、组成标签或浮动，相机可按朝向悬浮或整组停靠。本页讲 **3D 框的绘制、编辑、属性、批量操作、点云分割、测量与自动贴合**。相关页：

- 视角导航、相机面板与上色 / 深度 → [点云视图与上色](./pointcloud-view)
- 3D↔2D 投影联动 → [点云跨模态联动](./pointcloud-projection)
- 跨帧目标延续与邻帧框叠加 → [点云跨帧标注](./pointcloud-crossframe)

面板布局的完整操作（包含三视图整体停靠 / 浮动 / 隐藏恢复、相机整组切换和相邻帧核对）见[点云视图与上色](./pointcloud-view#面板布局与切帧)。

## 操作

1. 在左侧类别面板选择本轮要创建的类别，也可用 `1-9`、`0` 切换前十类。
2. 按 `B` 进入「连续建框」。底部状态条会显示当前类别、下一次手势和 `V/Esc` 退出提示。两种画框方式：
   - **拖框选（推荐）**：在主 3D 视图按住拖出一个**罩住目标**的矩形 → 松手即选中矩形内的真实点云、以其包围盒建框并自动选中(框底贴地、高度到目标顶)。框选屏幕里的真实点,与视角、目标高度无关、无视差;建议先点控件浮条「俯视」切鸟瞰视角框选更顺手,但斜视下也能选对。斜置物体建好后可按工具栏「朝向⚗」旋正。
   - **点击放置**：原地单击（不拖动）→ 落一个默认尺寸框并自动选中（向后兼容旧行为）。默认尺寸可由项目管理员在「项目设置 → 工作台规范」中统一指定；未指定时为 `4.0 / 1.8 / 1.6` 米。
3. 保存成功后新框保持选中，类别与建框工具继续待命；直接点击或拖框即可创建下一个对象，不必重复按 `B`。保存期间工作台会短暂阻止下一次创建，避免产生重复对象。
4. 框内无点、无法放置或保存失败时，状态条会说明原因并保持待命；调整范围后直接重试。完成本轮连续创建后按 `V` 或 `Esc` 回到选择工具。

## 编辑已有 3D 框

- 单击主视图框 → 选中（出现 gizmo 和 PSR 数值面板，已打开的三视图精修同步显示该框）
- 在选择工具下双击主视图中可见的 3D 框 → 单选该框并将主相机聚焦到框体。聚焦保留当前观察方向、up 向量和 orbit / BEV 模式，不改标注几何；锁定或只读任务也可用于查看。双击空白处不会清空原有选中
- 按 `W` / `E` / `R` 切 gizmo 模式：平移 / 绕 Z 轴旋转 / 缩放
<!-- TODO(v0.14.18) IMAGE_CHECKLIST: images/3d-box/psr-panel.png — PSR 面板近景，标注红框：l/w/h 尺寸字段 [manual] -->
- PSR 数值面板：直接输入中心 `cx/cy/cz`、尺寸 `l/w/h`（长宽高，米）、朝向 `yaw/pitch/roll`（°）；「朝向归零」一键复位三轴。开启工作台桌宠时，面板会由桌宠托住，拖动面板标题或桌宠都会整体移动；关闭桌宠后，面板回到可独立拖动的画布右上角
- 三正交视图（俯 / 侧 / 正）：从顶部“布局”菜单打开“三视图精修”，或选择“框体精修”工作方式。三张视图上下排列、均分可用高度，作为一个面板整体拖动，可放到画布之外的停靠列、组成标签或变为浮窗。停靠时拖动分隔条，浮动时拖动边缘调整尺寸；标题栏 × 隐藏面板，之后可从“布局”菜单找回，位置随账号保存。没有选中框时显示选择提示，面板不会消失。视图内部拖边 / 拖角改尺寸、拖方向线转三轴朝向；主视图 gizmo / 数值面板 / 相机投影四方实时同步，松手只提交一次。鼠标滚轮或触控板可离散缩放当前正交视图，比例显示在标题中；聚焦某个视图后可用 `+` / `=`、`-`、`0` 放大、缩小和复位。缩放在当前会话中按标注和俯 / 侧 / 正视图分别记忆，不会修改框体或账号偏好
- 放大带标定的相机面板后，选择工具下单选且未锁定的 3D 框会显示中心手柄。拖动手柄可直接在图像中微调框中心，主视图、三正交视图和其他相机投影会实时同步；松手只保存一次，按 `Esc` 或拖出画布可取消。一次拖动保持相机深度、尺寸和旋转不变，深度仍通过主视图、三正交视图或 PSR 数值面板调整
- 按 `V` / `Esc` 回选择工具并退出连续建框，`Backspace` / `Delete` 删除选中框

## Scene 时间轴

属于多帧 Scene 的点云任务会在工作台底部显示只读时间轴。它不会遮住主视图，也不会自动改动标注。

- 每一列对应一个 Scene 帧，数字是 `frame_index`；柱高表示该帧活跃 3D 框与点云分割的数量
- 品牌色列是当前帧；虚线弱化列表示帧缺失，不可访问的帧会禁用且不展示任务或标注数量
- 选中带 `track_id` 的 3D 标注后，底部短横会标出同一对象在哪些帧出现，标题栏同时显示「当前对象轨迹」
- 点击可用帧会服从工作台现有的未保存保护后切换任务；目标帧存在同一对象时会自动恢复选择
- 点击左侧箭头可折叠或展开时间轴。横向滚动只改变观察范围，不会切换当前任务

没有 Scene、当前任务缺少帧序号，或 Scene 只有一个有效帧时，时间轴不会显示。时间轴按当前可视窗口取数并虚拟化渲染，长 Scene 不会为每一帧单独加载完整标注。

## 3D 质量检查

项目所有者、超级管理员和审核员会在 Scene 时间轴看到「3D 质检」入口。项目所有者可扫描当前 Scene，包含逐框与完整轨迹规则；审核员扫描当前可访问任务时只运行逐框规则，不会用局部轨迹成员误报整轨问题，也不会读取不可见批次。

- 扫描只产生问题和证据，不会自动改框、补帧、删除轨迹或改写存在区间
- 时间轴帧右上角的色点表示该帧最高严重度；打开面板可按待处理、已过期或全部查看
- 点「定位」会切到对应帧并选中框；穿地/悬浮问题同时显示质检地面，时序跳变会打开邻帧参考层
- 处置会显式记录「确认问题」、「误报」、「接受例外」或「不确定」；后三者必须填写判定依据，「讨论」会将评论持久锚定到当前 3D 问题
- 标注版本、轨迹 revision、点云内容或规则配置变化后，旧问题会标为「已过期」；请重新扫描，不要继续处置旧证据
- 同一 SceneTrack 保存了相机人工 2D 成员时，质检还会比较人工框与当前 3D 投影：IoU 过低或边缘偏差过大会生成投影残差问题，并直接定位到对应相机。2D / 3D 任一成员或标定变化后，旧证据会自动过期。

当点云文件无法解析、局部地面样本不足或当前范围不具备完整轨迹时，检查会在运行摘要记录跳过原因，而不是制造一条伪问题；局部跳过也不会把其它既有问题误标为过期。

「规则治理」分页会把已有人工判定冻结为可追溯评估，按规则和类别显示观察误报率。项目负责人可以在全局或某个类别下放宽可重放阈值，生成候选评估；只有可判定样本数、误报率和已确认问题保留率同时达标时才能晋级。“保留率”只表示候选仍命中多少已确认问题，不是召回率；绝对召回率需要独立 Ground Truth。

## 属性、批量与撤销

如果项目在 `lidar_box_3d` 工具单位下配置了属性 schema，选中 3D 框后，选中信息栏会在 PSR 数值区下方显示「属性」。常见字段包括遮挡、截断、可见度，也可以是项目自定义的文本、数字、布尔、单选、多选或范围字段。属性会保存到标注的 `attributes`，刷新任务后仍会保留。没有配置 schema，或当前类别没有可见字段时，属性区不会显示。

多选只作用于 3D 框：

- `Shift + 点击`主视图框或相机投影框可叠加 / 取消选择多个框
- 多选后，类别下拉会批量修改全部已选框
- `Delete` / `Backspace` 会删除全部已选且未锁定的框
- 多选时 PSR 数值、gizmo、三正交视图和自动贴合不可编辑；需要改几何时先回到单选

可逆操作与复制：

- `Ctrl + Z` / `Cmd + Z` 撤销，`Ctrl + Y` 或 `Ctrl + Shift + Z` 重做
- 放置、删除、改 PSR、改类别、改属性都会进入撤销栈
- `Ctrl + C` / `Cmd + C` 复制当前 3D 框，`Ctrl + V` / `Cmd + V` 在世界坐标中偏移粘贴同类同属性的新框
- `Ctrl + D` / `Cmd + D` 直接复制并偏移生成一个新框
- 焦点在 PSR 数值框或属性输入框里时，这些快捷键让给输入框本身，不会触发框级操作

3D 框顶部有一枚 **billboard 文字标签**——它始终朝向相机，随视角旋转保持正对，方便在任意角度读出类别 / 轨迹号 / 属性。显示哪些字段由工作台设置里统一的**「标签内容」**决定：点云框复用其中的**「轨迹」段**（`类别名` 恒显，另可勾选 `轨迹号 / 状态 / 属性`），与视频轨迹框同一套配置，调一处两端同步。见[工作台设置 · 标签内容](./settings#补充说明)。

## 点云分割

点云项目启用 `point_mask_3d` 工具单位后,主视图工具栏会出现分割工具。

1. 按 `P` 切到分割工具
2. 在左上视角工具栏的“选点”下拉中选择矩形、套索或多边形
3. 在主 3D 视图拖出矩形 / 套索,或逐点点击多边形后双击、按 Enter 闭合
4. 松手或闭合后,选区内的可见点会落为一条 `point_mask_3d` 标注

分割标注存储的是点云原始点索引 `point_indices`,并记录 `convention_at_create`、抽稀步长和源点数量。再次从右侧标注列表选中该分割时,主 3D 视图会高亮所属点。选中已有分割后再次按 `P` 圈选可加点,按住 Alt 圈选可减点;分割信息栏可改类别、查看点数或删除分割。开启工作台桌宠时，该信息栏同样会与桌宠合并联动。

## 点云测量

按 `M` 切到测量工具，然后在主点云中依次单击两个或更多真实点。右上测量面板会实时显示路径的三维总长、水平总长和首尾高差，单位均为米；高差为“最后一点高度减第一点高度”，因此会保留正负号。

- 按 `Enter` 或点“完成当前”保存本次测量，工具会保持激活，可继续创建下一条
- 草稿存在时按 `Esc` 只取消草稿；草稿为空时按 `Esc` 退出测量，`V` 始终直接退出
- 已完成的测量可以隐藏、重新显示、单独删除或全部清除
- 点击未命中点云时不会在地面或自由空间生成锚点；请放大或调整视角后重试
- 测量是当前任务的临时辅助层，只在本次页面会话中保留；切换任务会清空，也不会进入标注、撤销历史或导出结果

测量不修改项目数据，因此锁定任务、审核视图和 viewer 只读场景也可以使用。

## 自动贴合（一键吸附）

<!-- TODO(v0.14.18) IMAGE_CHECKLIST: images/3d-box/autofit-buttons.png — 贴合/收尺寸/贴地/朝向按钮组 [manual] -->

放完粗框后按 `Q` 让框自动收缩并贴地，省去逐边拖边。仅在「选中且可编辑」时显示按钮组。框内无点云时返回原状不动。

### 四种动作

| 动作              | 快捷键    | 改了什么                                                                                                                         | 保持不变               | 典型场景                               |
| ----------------- | --------- | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------- | -------------------------------------- |
| **贴合**          | `Q`       | 收尺寸 + 贴地（连击）                                                                                                            | yaw/pitch/roll         | 标常规车辆 — 一键到位                  |
| **收尺寸**        | `Shift+Q` | size 收到「框内点云 AABB + 5cm padding」；**中心同步对齐到框内点 AABB 中心**（点云分布对称时中心不动，不对称时会沿主体方向微漂） | 朝向                   | 已经手动调好 z 高度（卡车顶 / 屋顶物） |
| **贴地**          | `Alt+Q`   | cz 下移让框下沿对齐框内最低点                                                                                                    | cx/cy、尺寸、朝向      | 框尺寸已经合适但浮在空中 / 沉地下      |
| **朝向⚗**（实验） | 仅按钮    | yaw 转到框内点云 XY 主轴方向                                                                                                     | 中心、尺寸、pitch/roll | 框已经包住车体但角度偏斜               |

### 典型流程

**新框初标**：

1. 按 `B` 放置默认尺寸框（优先落到鼠标点的点云上，没点云则落地面）
   - **点击位置最好沿车体侧面 / 轮胎区域**：落点 z 接近地面 → 默认尺寸的框正好包住车体 → `Q` 能找到框内点云。
   - **避免点击车顶**：落点 z 在车顶高度 → 默认尺寸的框整个落在车体之上 → `Q` 找不到框内点云会无操作；这时要先用 gizmo 把框往下拖到把车包住，再按 `Q`。
2. 用主视图 gizmo / PSR 数值面板把框中心粗略移到车体中央（如果第 1 步已经命中车体侧面点云，可以跳过）
3. 按 `Q` 一键贴合 → 框收紧 + 框底贴地
4. 如朝向不对，工具栏按「朝向⚗」 → 若 PCA 推错（稀疏点云时主轴可能反转 180°），按 `E` 切 gizmo 转 180° 修正

**修已有框**：

- 框包住车但松散 → `Shift+Q` 单独收尺寸（中心会对齐到框内点 AABB 中心，点云对称时中心基本不动，不对称时会微漂）
- 框尺寸合适但 z 高度偏了（漂浮 / 埋地）→ `Alt+Q` 单独贴地
- 标卡车顶 / 屋顶等离地物体：**不要按 `Q`**，否则会把框拉到地面；改用 `Shift+Q` 只收尺寸

### 预期结果

- **框内点云充足**（≥ 20 个点）：贴合 / 收尺寸 / 贴地三种动作可信；`朝向⚗` 也会尝试 PCA 推算。
- **框内点云稀疏**（< 20 个点）：`朝向⚗` 自动放弃不动（`FIT_YAW_MIN_POINTS = 20`，来自 `autofit.ts`）；贴合 / 收尺寸 / 贴地仍会跑，但精度受限（点少时 AABB 可能不稳定）。
- **框内极少点**（< 3 个点）：收尺寸返回原 PSR 不动。
- **框内空**：所有动作返回原 PSR 不动（不会缩成零体积）。

### 不做（留后续版本）

- 跨帧轨迹的车头朝向先验（解决稀疏点 PCA 反转 180°）
- 多帧批量贴合
- 类别专属 padding（car / pedestrian / cyclist 分别给）

## 导出几何 JSON 结构

### box_3d

```json
{
  "type": "box_3d",
  "center": [cx, cy, cz],
  "size":   [l, w, h],
  "rotation": [roll, pitch, yaw]
}
```

三个数组均为长度 3 的浮点数列表，单位米（center / size）或弧度（rotation）。UI PSR 面板显示的 `l/w/h` 对应 `size[0]/size[1]/size[2]`，`yaw/pitch/roll` 对应 `rotation[2]/rotation[1]/rotation[0]`（弧度转°显示）。坐标系约定见 [LiDAR 坐标轴约定](../datasets/lidar-axis-convention)。

### point_mask_3d

```json
{
  "type": "point_mask_3d",
  "point_indices": [0, 42, 1337, ...]
}
```

`point_indices` 为点云原始点的整数索引列表，单条分割最多 **600 000** 个点（`max_length=600_000`，定义于 `apps/api/app/schemas/_jsonb_types.py`）。

## 注意

- `B` 仅在项目已为 `lidar_box_3d` 工具单位配置类别时生效，否则按键无效
- 缩放（`R`）翻转出的负尺寸自动取绝对值兜底
- 锁定 / viewer 角色任务只读：不放置框、不挂 gizmo、PSR 面板禁用，仅可选中查看数值
