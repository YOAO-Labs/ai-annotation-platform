# 工作台设置

工作台设置按用途统一组织，图片、视频和点云共享同一个面板，不随当前任务隐藏其他类型的设置。有两个入口：

| 入口               | 路径                              | 适用场景                       |
| ------------------ | --------------------------------- | ------------------------------ |
| **工作台设置窗口** | 工作台右上角「工作台设置」齿轮    | 在悬浮窗口中调整全部工作台偏好 |
| **个人设置页**     | 顶部头像菜单 → 设置 →「标注偏好」 | 浏览/调整全部分类的字段        |

工作台顶栏另有通知铃铛与未读角标，从通知进入目标前会先完成视频 / Mask 离开检查；详见[通知中心](../reference/notifications)。

搜索「通知」或「通知偏好」可查看全部通知设置项，搜索「退回」等具体类型词则只显示匹配项。连续修改不同类型时，每行独立保存；失败行恢复上次确认的值并提供重试，其他行仍可正常保存。

账号偏好在两个入口共用：工作台设置提交后约 300ms 防抖保存，个人设置页直接保存。保存成功后可在同一账号的其他设备读取。
面板的位置、标签、浮窗、隐藏与布局预设由工作台顶部“布局”菜单管理，操作方式见[布局偏好与浮窗](./#布局偏好与浮窗)。

## 通知

「通知」分类内嵌[通知偏好](../reference/settings#通知偏好)面板：按类型设置「接收通知」与「弹出提示」。设置随账号同步，适用于主界面及所有标注、审核工作台，与个人设置页「通知偏好」是同一份配置，一处修改两处生效。

该分类有自己独立的加载与重试状态：通知偏好加载失败不影响其它分类的设置，画布/渲染偏好加载失败也不影响通知面板。修改自动保存，保存失败时该行恢复上次保存值并支持重试。通知标签与说明也参与设置窗口顶部的全局搜索。

### 保存范围与失败处理

- **账号偏好**：常规设置（包括工作台桌宠）和二次推理面板显隐保存到账号；布局中的部分状态另有浏览器缓存，用于首帧恢复。
- **二次推理面板**开关控制整个入口是否显示；面板内的“收起”只返回胶囊，不更改账号偏好。
- **本机实验特性**：只写入当前浏览器，不跨设备同步；需要刷新才能生效的项会单独标注。
- **会话设置**：隐藏孤儿标注只影响当前工作台会话，不保存到账号。

首次读取失败时，设置窗口显示重试入口，成功读取前不能编辑，以免用默认值覆盖原有偏好。已有成功数据时，后台刷新失败不会清除当前设置。

窗口内的设置提交后先在当前工作台生效，再写入服务器；关闭窗口不取消待保存的修改。保存失败会提示“未同步”，当前工作台保留修改，再次调整会重试保存。离开工作台路由时会立即尝试提交待保存值；若该次提交失败，提示返回检查并重新设置。这里没有离线保存队列，失败后刷新或离开页面可能丢失尚未同步的修改。

## 窗口布局与操作

设置以居中悬浮窗口打开，桌面左侧提供搜索和分类，右侧按用途分组展示字段说明与控件。窄屏时铺满屏幕，分类改为顶部横向导航，内容独立滚动。

- **布局预设**：在「界面布局」选择可视化预设，或在「我的预设」保存、应用与删除自己的命名布局；「面板与高级布局」提供面板找回、点云专用布局及重置。顶部「布局」只保留标准、专注／恢复与更多布局设置。
- **滑动预览**：按住滑动条时，设置窗口和遮罩透明，仅保留当前设置行；调整实时作用于工作台，松手、取消拖动或移出焦点后恢复窗口。背景仍禁止误操作。
- **分类**：固定显示下表七类，不按当前任务过滤。个人设置页的「标注偏好」沿用同一分类，但只显示账号偏好，不包含本机实验、会话设置与通知偏好；通知偏好在设置页侧栏单独成项。
- **搜索**：搜索全部设置的名称、说明、选项、用途分类和适用类型；匹配子设置时一并显示其父开关。关闭窗口后清空搜索。
- **关闭**：点击窗口外的遮罩、右上角关闭按钮、左侧「返回工作台」，或按 Esc。关闭前会提交正在编辑的文本；中文输入法组合期间 Esc 用于输入法，不关闭窗口。从窗口内部拖动滑块到外部松手也不会关闭。
- **键盘与画布**：Tab 焦点保持在窗口中，分类可用方向键切换。窗口打开时，背景画布的快捷键、缩放、选择与绘制暂停响应；关闭后焦点回到打开入口。
- **视频**：打开设置会暂停播放并停留在当前画面，关闭后保持暂停，可手动继续播放。

### 七类用途

| 分类       | 内容                                                      |
| ---------- | --------------------------------------------------------- |
| 界面布局   | 可视化布局预设、面板操作、左右边栏宽度、工作台桌宠        |
| 标注显示   | 标签、线条、填充、标注评论提示、邻帧参考框                |
| 编辑与辅助 | 删除确认、类别与审核行为、图片绘制、AI 辅助、隐藏孤儿标注 |
| 画布与视角 | 图片与视频画布、点云显示、相机上色、视角及邻帧点云        |
| 播放与轨迹 | 视频播放速率、步进帧数、轨迹续写                          |
| 性能与实验 | 性能档位、采样率、当前浏览器的实验特性                    |
| 通知       | 按类型设置接收与弹出提示，与个人设置页「通知偏好」共用    |

可以在图片任务中修改视频或点云偏好，保存后在对应任务中使用。图片与视频的「自动适应大小」仍是两个独立值，分别列在「图片画布」「视频画布」中；统一入口不会合并它们。项目锁定项继续以当前项目配置为准。

### 补充说明

- **边栏宽度**:左 / 右侧可见列宽度按工作台宽度的 10%–35% 调整，多列分别调整，受面板最小尺寸限制；隐藏侧栏及专注画布时不调整。可直接拖动分隔条精调，或在设置中重置偏好为 15%。
- **布局宽度**：各预设的左右侧栏及新建停靠列默认宽度均为工作区的 15%，可拖动分隔条继续调整；选择预设会按示意图恢复完整排列，专注画布退出时恢复原布局。设置中「面板与高级布局」的「重置为标准布局」恢复标准布局。当前题 AI、视频追踪、三视图及相机停靠组件都随布局保存。标题栏 × 隐藏当前面板，可从设置中的面板列表找回。
- **点云辅助面板**：三视图整体移动，相机整组选择悬浮或停靠；相机浮层的位置和折叠态、停靠图库的位置分别记忆。旧三视图绝对坐标不再驱动停靠面板。
- **标注视觉(通用,图片 / 视频共用;标签内容含点云)**:标签字号、线宽、填充透明度、选中填充透明度,以及标签显隐与标签内容,都在「标注显示」分类里,一套值同时作用于图片与视频画布,调一处两端实时同步;其中「标签内容」的「轨迹」段还会驱动点云 3D 框的 billboard 标签(见下)。
  - **标签显隐**:`始终显示` / `仅选中时`(只给当前选中对象显示标签)/ `不显示`。
  - **标签内容**:按标注类型分段控制,顶部切换 `单帧 / 轨迹 / AI预测`,下方按段勾选字段;`类别名` 三段恒显(标「必选」)。单帧(图片手工框)可选 `分组号 / 属性`;轨迹(视频 track 框)可选 `轨迹号 / 状态(插值·遮挡) / 属性`;AI预测(图片预测框)可选 `来源(✦模型/导入)/ 置信度 / 分组号 / 属性`。不同类型只列对它有意义的字段——例如置信度仅 AI 框才有。**点云 3D 框**的顶部 billboard 悬浮标签(始终朝向相机)复用「轨迹」段配置——同一套勾选同时决定视频轨迹框和点云 3D 框显示哪些字段。
  - **线宽**:选中对象在所设线宽基础上自动加粗 0.5。
  - **填充透明度**:只作用于可闭合标注(框 / 多边形 / 旋转框);折线和关键点无填充。
- **标注评论提示**：默认开启，在图片和视频画布的已保存标注旁显示评论数量，点击打开该标注讨论；视频单帧标注仅在所属帧显示，轨迹跟随当前可见位置。按账号保存，关闭只隐藏气泡，不影响评论。详见[评论与问题](./discussion#画布上的评论提示)。
- **SAM 输出形态**:SAM 文本 / Exemplar 输出形态不在设置页中展示,但会按账号记住用户上次显式选择;无个人记忆时按项目 `type_key` 智能默认。
- **WebCodecs 精确解码**:默认开启的本机能力开关,写入浏览器 localStorage,刷新后生效;可从任何任务的「性能与实验」分类调整，作用于视频任务。暂停、逐帧与稳定 seek 优先使用浏览器原生精确解码(按帧命中目标,B 帧素材不串帧),解出的位图统一用于画布底图与当前帧抓帧;连续播放仍由浏览器播放器负责。浏览器不支持目标 codec、chunk 尚未就绪或解码失败时自动回退到原生 `<video>` 路径,不阻断标注；遇到客户端兼容问题可在此显式关闭。
- **性能档位(视频)**:影响视频帧预览缓存、WebCodecs 精确帧的内存预算与缩略图预取窗口。三档按内存字节而非对象数量控制已解码位图与 chunk 字节缓存:轻量档 bitmap 96 MiB / chunk 32 MiB 且不预取,标准档 256 / 96 MiB 并在暂停态沿导航方向同 GOP 预取 2 帧,激进档 512 / 192 MiB 预取 4 帧;标准档等同旧默认行为,激进档适合长视频快速浏览。
- **性能档位(点云)**:控制点云加载时的抽稀上限——标准档 500,000 点、轻量档 250,000、激进档 1,000,000,切换后下次加载点云时生效。
- **点云主视图视角动作**：左上单行工具栏的重置图标恢复默认斜视，「俯视」切换 BEV。三种 3D 工作方式及「恢复相机排列」位于顶部“布局”菜单；恢复排列只调整当前模式下的相机排列，不重置主视角或其他面板。

## 工作台桌宠

在「界面布局」中开启工作台桌宠后，可以拖动像素小人调整位置。上方提示的内容、长度和显隐变化不会改变小人的位置。

图片和视频标注的信息卡收起时，桌宠上方显示简化信息，点击即可展开详情。详情展开后简化气泡隐藏，收起后恢复；点云详情遵循同样规则。拖动桌宠或详情面板标题时，两者一起移动。关闭桌宠后，选中信息恢复为独立浮层。

## 项目锁定

项目管理员可以在项目设置中统一指定部分工作台规范:图像平滑、CSS 滤镜、控制点大小、网格吸附、3D 新框默认尺寸、关键帧复制是否覆盖目标关键帧、AI 追踪默认模型。被项目锁定的字段在工作台窗口中显示「项目锁定」徽章并禁用，以项目配置为准。个人设置页没有当前项目上下文，仍可编辑账号基础值；这些修改不会覆盖项目规范。

## 常见问题

- **改了没反应?** 窗口中的改动对画布实时生效;若字段带「项目锁定」徽章,说明项目配置优先,个人值不生效。
- **换设备后设置丢了?** 先确认该项属于账号偏好且保存没有报错；本机实验特性和会话设置不会跨设备同步。布局中的部分状态有浏览器缓存加速首帧，首次成功读取后以服务端数据为准。
- **可停靠布局**：布局按标注或审核模式、图片或视频或点云分别保存，切换工作类型时会恢复对应布局；本地缓存加速首帧，初次联网读取以服务端为准。
