# 点云跨模态联动

3D 框经各相机标定**实时**投影到相机图像上，悬浮相机和停靠图库都支持对照图像确认 / 校正 3D 框与双向选中联动。相机面板本身的显示与上色见 [点云视图与上色](./pointcloud-view)。

## 前提：标定文件

相机投影与锚点推导依赖数据集上传时提供的**标定 JSON**（每个相机一份），须包含：

- `extrinsic`：4×4 world→camera 变换矩阵（行主序，长度 16）；锚点外参兜底分支用前 3 行提取光轴向量。
- `intrinsic`：相机内参（焦距 + 主点）。
- `rect`（可选）：校正矩阵。

schema 详情见 [点云 / 多模态数据集导入格式 · 标定 JSON schema](../datasets/import-formats#标定-json-schema)。没有标定文件时，相机面板仍显示图像，但无投影线框。

## 查看与追加标定 revision

放大有标定的相机后，左上角的“标定 · Rn”入口会打开标定管理面板。面板显示当前 revision、内参、外参、可选矫正矩阵以及完整历史。当前和历史标定的哈希使用复制图标，悬浮或键盘聚焦时提示“复制哈希”，点击复制完整值；revision、时间和当前状态直接显示。任务可见用户都能查看，只有项目所有者和超级管理员可以修改；如果同一相机数据被多个项目共享，则只有超级管理员可以修改。
打开标定面板时，相机放大浮层会暂时隐藏；关闭面板后恢复原相机视图。

修改时：

1. 点“编辑当前标定”，核对格式化 JSON 中的 `intrinsic`、`extrinsic` 和可选 `rect`。
2. 面板会在提交前标明基于哪个 revision，以及改变了哪些矩阵。无变化草稿不会发起保存。
3. 点“追加 revision”保存。系统只追加新快照，不覆盖或删除历史。
4. 如需恢复某个旧值，在历史中点“加载为草稿”，复核后再追加一个新 revision。

如果他人在面板打开期间已更新标定，服务端会拒绝覆盖。当前草稿会保留，面板同时刷新最新 revision，需要重新比对后再提交。标定更新不会改写已有人工 2D 框，这些关系会进入“标定已变更”待复核状态。

## 3D→2D 投影

选中（或悬停）3D 框时，可见相机面板实时重绘投影线框（类别色）。可见角点最多的相机显示「· 正对」，用于快速定位主确认视角；图库仍保持朝向顺序，不因选框重排。拉宽或缩窄图库时，图像和投影按同一比例缩放；隐藏或切换标签后暂停覆盖层绘制，重新显示时使用当前帧与选中状态。

## 2D→3D 反选与命中测试

<!-- TODO(v0.14.18) IMAGE_CHECKLIST: images/workbench-pointcloud-projection/click-to-select-3d.png — 点击投影框联动主视图高亮 [manual] -->

单击相机面板里的投影区域时，系统在画布坐标系做逐框扫描：

- 命中规则：鼠标落点 `(x, y)` 落在某框轴对齐包围盒 `[x0, x1] × [y0, y1]` 内则命中。
- 多框重叠时，选**面积最小**的框（前景 / 近处框面积通常较小，优先选中）。
- 命中后调用 `onSelectBox`，选中对应 3D 框；`Shift+点击` 支持多选叠加。

## 持久化相机 2D 成员

相机里的线框投影只是随 3D 框和当前标定实时计算的参考。如果图像上的真实边界与投影不一致，可以把每个相机的人工 bbox 作为同一 SceneTrack 的独立真值保存：

1. 单选一个 3D 框并放大目标相机。
2. 在底部「多相机 2D 成员」工具条点「创建 2D 框」，拖出矩形后松手保存。
3. 已有成员可进入「编辑 2D 框」，拖动框内移动，拖八向手柄缩放；也可设置可见、遮挡、截断或未知。
4. 工具条会显示人工框与当前 3D 投影的 IoU 和最大边缘像素差。刷新或切帧后人工框仍会保留。

人工 2D 框和 3D 框共享对象身份与类别，但它们都是人工真值；修改 3D 框不会自动覆盖人工 2D 框。标定发生变化时，人工框以警示虚线显示「标定已变更」，可核对后点「重新确认」建立与当前标定的关系。一次拖动只在松手时保存，服务端检测到框、轨迹或标定版本冲突时会拒绝覆盖并重新读取最新值。

远处 / 稀疏 / 遮挡目标在点云主视图里点太少、难直接框，但在相机图上一眼可见。**种框**让你在相机图上拖一个 2D 矩形，系统反算视锥、选出锥内点云、自动拟合出一个 3D 框：

1. 点相机浮层或停靠图库中的放大按钮，打开该相机的大图编辑层（种框只在放大视图里启用——大画布画得准、单相机无歧义）。
2. 点左上角「**种框 ⊹**」进入连续种框模式（光标变十字；按钮显示当前类别；无标定相机不显示此入口）。
3. 在目标上**拖一个 2D 矩形**框住它，松手即生成 3D 框并自动选中。保存期间相机画布会短暂阻止下一次拖框；成功后种框保持待命，可直接圈下一个目标。
4. 按 `V` 或 `Esc` 退出连续种框，再回到主视图用 gizmo、三视图或数值面板微调。

拟合逻辑:

- 视锥内的点按相机系深度取**最近簇**(默认 8m 带宽),避免把目标后面的墙 / 背景点一起拟合;前后严重重叠时**收紧矩形重试**或建框后微调。
- 拟合用点云 AABB 定位置 / 尺寸 + 主方向定朝向 + 贴地;朝向可能差 180°(车头车尾),微调时用旋转 gizmo 翻转。
- **视锥内无点云**(图上可见但无 lidar 返回,如远处反光目标):按项目默认尺寸在中央射线估计深度处放一个框 + 提示「请微调」。

> 「种框」的唯一产物仍是 3D 框：它与上面的「多相机 2D 成员」是两个互斥工具。种框矩形不落库；只有明确进入「创建 / 编辑 2D 框」后，图像 bbox 才会持久化。
>
> **依赖标定准确度**:外参 / 内参不准会让选点偏、框偏。无标定相机不开放种框。标定一般的数据靠建框后微调兜底。

## 同物体高亮

同 `track_id` 成员经选中联动一并高亮，方便对照跨帧 / 跨视角确认同一物体的所有关联框。

## 相机面板贴边

## 相机面板锚点推导

悬浮模式下，每个相机根据 **role/name 优先、外参兜底** 的规则被分配到主视图四周某个边缘位置（`top / bottom / left / right` 及四角，认不出时落 `overflow` 兜底小条）；停靠图库复用同一朝向判断提供标签和排序：

1. **名字优先**：role 或 name 包含 `front/rear/back/left/right` 及复合（`front_left` 等）时直接映射，复合规则先于简单规则匹配。
2. **外参兜底**：取 `extrinsic` 第三行前两列提取光轴水平方位角，按 45°/22.5° 边界映射到 8 方位。此分支假设 LiDAR 系为 **X=前 / Y=左 / Z=上**（KITTI / ROS REP-103 标准）。
3. **都识别不了或光轴近垂直**：落 `overflow`（底部小条，不丢相机）。

锚点容器定位说明：

- 各方位锚点容器（`camAnchorTop` 等）通过 CSS `position: absolute` 贴在主视图 canvas 四边，定位偏移均为固定 12 px（CSS 硬编码，不读取工具条高度）。
- `max-height` 受 `--top-toolbar-height` CSS 自定义属性约束（运行时由 ResizeObserver 动态写入），可避免面板高度超出可视区；左上视角工具栏保持单行，顶部相机面板仍可逐路拖动避让。
- 右侧锚点容器的 `right: 12px` 是相对于主视图 canvas 包装元素（不含右侧标注列表）的右边界，不会重复叠加右栏宽度。
