# 使用筛选

应用使用统一的漏斗图标标识可展开的筛选面板入口；状态、类型、范围等常用快捷条件直接以切换项或下拉显示，选项本身已说明含义，不再附带装饰性的图标名称前缀。搜索、排序、列设置和视图切换仍是独立操作，不会因为清除筛选而一起重置。

## 找到筛选入口

- **常用条件直接切换**：项目状态、数据集类型、模板范围、任务状态等保留在列表上方。选中项会以轻量背景和文字强调显示。
- **附加条件在按钮旁展开**：项目高级筛选、成员与邀请的附加条件、审计筛选，以及模型目录的「更多筛选」使用与按钮相连的面板。桌面端没有全页筛选遮罩；窄屏改为底部面板。
- **工作台条件留在面板内**：批次、显示范围、预测来源、讨论范围、离线操作与质检筛选不遮挡整个画布。复杂 AND/OR 条件继续在 Data Manager 工具栏下方编辑。

筛选按钮上的数字表示该入口负责的已启用条件维度，不是匹配记录数。项目状态、成员账号状态等已经单独显示的快捷条件不计入对应「附加条件」徽标。面板收起后，已应用的附加条件仍以摘要标签显示；点击标签可返回编辑，点击旁边的 × 只移除该条件。

## 区分两种生效方式

### 项目高级筛选：应用后生效

筛选面板在首次使用时按需加载；页面入口与已选条件摘要保持同步显示，后续打开复用已加载的面板。

1. 点击项目列表的 **筛选**，选择状态、数据类型、成员或创建时间。
2. 成员支持按姓名或邮箱查找；搜索选项不会清除已选成员。
3. 点击 **应用** 提交这一组条件。日期开始值晚于结束值时，需要先修正错误。
4. **重置** 只清空当前面板草稿；关闭、取消或按 Esc 不会提交草稿。重新打开时仍显示已经应用的条件。

列表下方的 **清除附加条件** 仅移除数据类型、成员和创建时间，保留状态标签、关键词及列表/卡片布局。

### 即时筛选：修改后直接更新

成员、邀请、审计、模型目录等面板会标明 **即时生效**。选择条件后直接更新列表；关闭或点击 **完成** 只是收起面板，不会撤销已经应用的条件。文本输入继续沿用所在页面的等待输入或按 Enter 查询规则。

浏览器前进、后退或打开筛选链接后，可以立即继续输入，无需等待旧条件恢复完毕；快速切换其他筛选项也不会把正在输入的关键词退回旧值。

| 操作                     | 清除或恢复的范围                                                      |
| ------------------------ | --------------------------------------------------------------------- |
| 成员「清除附加条件」     | 项目、角色、数据组；保留账号状态和搜索                                |
| 邀请「恢复默认范围」     | 恢复「我邀请的」，移除项目与角色；保留邀请状态和搜索                  |
| 审计「清除追溯」         | 动作、对象类型、对象 ID、操作人、详情条件；保留事件范围与独立概览月份 |
| 模型目录「清除条件」     | 所有目录筛选维度；保留搜索及分组方式                                  |
| Data Manager「清除条件」 | 结构化和快捷条件；保留独立关键词、排序和显示列                        |

审计详情键存在时，空的详情键值也是有效条件，摘要中显示为「空字符串」。Data Manager 的未完成或无效条件会显示错误，不能仅因为关闭编辑器而把条件当作未设置。

## 工作台范围不会变成数据操作

调整列表筛选本身不会采纳、删除或修改标注，也不会重置编辑历史。仍需区分：

- **帧范围**只决定当前显示哪些候选或轨迹。
- **预测来源、置信度阈值**还影响已有的批量采纳候选范围。批量采纳按钮继续说明「当前任务已加载候选」，视频中可能包括其他帧。
- **评论阅读范围**与发送目标分别选择，不会移动留言草稿。
- **离线操作的当前题范围**在没有当前任务时不会自动扩大成全部任务。
- **通知分类**只筛选已经加载的通知，不代表服务端全部通知的数量。

## 键盘操作

筛选按钮支持 Enter / Space 打开；Tab 在字段之间移动，Esc 关闭当前浮层。明确关闭或完成后，焦点回到入口。直接点击页面其他控件时，不会把焦点强行抢回筛选按钮。日期、单选、多选和搜索字段保留各自的键盘操作。
