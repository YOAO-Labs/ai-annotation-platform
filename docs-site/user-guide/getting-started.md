# 快速开始

从零开始快速上手标注平台。只需 5 步，带你完成从登录、领取任务、绘制首条标注到提交质检的完整闭环。

```mermaid
flowchart LR
    A["1. 凭证登录<br/>(角色与仪表盘)"] --> B["2. 领取任务<br/>(开工清单/队列)"]
    A --> C["3. 绘制标注<br/>(快捷键拉框选类)"]
    C --> D["4. 提交质检<br/>(自动切题)"]
    D --> E["5. 审核流转<br/>(通过或退回重做)"]
```

1. 打开平台地址，输入管理员分派的账号（邮箱）和初始密码登录。
2. 首次登录后，建议点击左下角「**设置**」修改初始密码。

平台进行会话升级后，已有登录可能需要重新认证，使用原账号和密码登录即可。若提示认证服务暂不可用，请稍后重试；这不代表密码错误，也不需要立即重置密码。

::: tip 平台角色与项目角色
本平台支持**多重角色身份**：你在平台拥有全局账号角色（员工 / 管理员），并在具体项目中担任**标注员 (Annotator)** 或 **质检员 (Reviewer)**。

- 承担标注工作的项目显示在 **「标注工作」**；
- 承担审核质检的项目显示在 **「质检工作」**。
  :::

## 2. 首页一览

登录后会进入与你的角色对应的首页。标注员可从「开工清单」或项目卡片的「打开」进入任务；先阅读项目指引，再继续下一节领取任务。

如果你是项目中的标注员，首页还会显示「**开工清单**」。清单按当前项目的真实数据更新，依次检查：阅读项目指引、打开已分派任务、完成首条标注、查看送审结果。项目没有发布指引或还没有可执行批次时，清单会直接说明缺少哪项条件；点击步骤右侧按钮可以进入对应工作台或项目设置。清单的跳过状态按账号、项目和指引版本保存，之后可以点「重新打开清单」继续查看；管理员修改指引后会生成新的版本，阅读步骤会重新出现。

打开指引后，请阅读正文并点击「确认已阅读」；展开或收起指引不会自动完成步骤。确认和跳过操作需要保存成功，失败时会显示重试入口。打开任务依据自己的工作台访问记录，首条标注只计入自己保存的有效标注，审核结果只计入已通过或已退回的任务；送审中不算已有结果。点击「再次查看结果」会在清单中展示最近审核结论和退回理由；已经结束或归档的任务也可以查看自己的结果，无需重新进入编辑工作台。

清单下方的「**优先处理**」会把继续上次工作、退回待处理和即将到期的项目放在一起。继续工作采用最近打开时间，临近截止项目按到期先后排列。工作台记住的任务也按账号隔离，换人登录或切换标注 / 审核模式不会误打开其他人的任务。

如果首页统计、项目或批次暂时无法读取，页面会显示具体的失败区域和「重新加载」入口。已有内容刷新失败时，页面会保留上一次成功读取的内容，并在区域内提示更新失败；权限变化会单独提示联系项目管理员。

浏览器检测到网络断开时，标注、审核和 Dashboard 会显示「等待网络连接」提示。尚未读取的统计、批次或任务会在恢复连接后自动继续加载；已经显示的内容会暂时保留。任务列表底部点击「加载更多」时断网，也会提示更多任务将在恢复连接后继续读取。

需要认识首页区块和侧边栏位置时，展开界面示例；它们不是领取任务的前置步骤。

## 3. 接受第一个任务

1. 左侧导航点「标注工作」，或在项目卡片右下角点「**打开**」
2. 系统按队列分配一条未处理任务，进入「标注工作台」
3. 完成后点「提交」→ 自动加载下一条

在标注或审核页面选择批次后，任务列表会先显示首页结果；列表底部的「加载更多」可以继续读取后续任务，并保留当前批次、筛选和已选任务。加载失败时可以重试，已读取的任务仍会保留。空队列、权限不足和网络或服务失败会显示不同提示，不会把失败误显示成「暂无任务」。

## 4. 标注工作台基础操作

### 画第一个 Bbox

1. 按 `B` 切到矩形工具（工具栏高亮）
2. 在图像上按下鼠标，拖出一个矩形后松开
3. 右侧属性面板选择类别
4. 按 `E` 提交并自动加载下一题

> 提示：标注操作即时写入服务端，无需手动保存。网络断开时操作进入本地离线队列，联网后自动回放。

第一次完整体验可以按本页步骤完成登录、打开项目、标注和提交：

![从登录到提交第一条 Bbox 的完整流程](./images/getting-started/e2e.gif)

最常用 6 个快捷键（完整列表见 [标注工作台 / 界面与快捷键](./workbench/)）：

| 快捷键                          | 动作                                                              |
| ------------------------------- | ----------------------------------------------------------------- |
| `V`                             | 选择工具（点选 / 移动已有标注与预标注；默认工具，`Esc` 回退到它） |
| `B`                             | 矩形（Bbox）工具                                                  |
| `P`                             | 多边形（Polygon）工具                                             |
| `Space + drag`                  | 临时拖动画布                                                      |
| `Ctrl + Z` / `Ctrl + Shift + Z` | 撤销 / 重做                                                       |
| `E`                             | 提交质检并加载下一题                                              |

## 5. 提交后的去向

- 标注员提交 → 进入审核队列
- 审核员通过 → 任务完成，统计 +1
- 审核员回退 → 回到标注员，附带审核备注

审核员首页的「优先处理」会列出待复核任务，并给返修重提的任务标记「返修重提」。点击任务可直接打开对应项目和任务的审核工作台；批次仍在审核中但暂时没有单条入口时，可以从「审核批次」进入批次列表。
