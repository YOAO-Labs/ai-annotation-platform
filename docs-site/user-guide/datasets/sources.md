# 数据来源与增量同步

当图片已经存放在共享服务器目录（CephFS / NFS）、外部对象存储（S3）或专用只读 SFTP 中时，你无需将全量文件手工打包上传，可以在数据集的**「来源与同步」**页签登记外部数据来源，按需执行**原地引用**（零原图复制）或**托管复制**，并通过手动或周期扫描持续核对增量变化。

## 原地引用与托管复制策略

在配置数据来源时，**原图所有权策略**与**缓存策略**相互独立、分别计量，可在「来源设置」中查看服务端计算的当前生效策略：

### 原图策略

| 原图策略                          | 存储行为                                                                                                          | 适用场景与生命周期特征                                                                                                                                          |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **原地引用（`reference`，默认）** | **不复制原图字节**。平台仅保存经过完整核验的 SHA-256 摘要、尺寸与来源定位凭证。                                   | 适合大体量存量图库。标注工作台、AI 预标、后台导出与训练版本冻结在读取原图时均实时回源（或读取受控完整缓存）严格校验摘要。停用来源或位置会立即阻断新的原图读取。 |
| **托管复制（`managed_copy`）**    | 登记时从只读来源读取原图，经 SHA-256 核验后写入平台独立托管对象（支持复用同数据集内已核验且可读的相同托管内容）。 | 适合希望将外部目录分批固化进平台存储的场景。原图一旦入库即脱离外部来源独立可用，后续来源停用、注销或离线均不影响已登记样本。                                    |

### 独立缓存策略

| 缓存策略                      | 行为说明                                                                                                                           | 额度与约束                                                                                                                                                      |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **仅预览（`preview`，默认）** | 生成固定摘要派生的只读缓存预览图，原图自然离线时仍可在数据集列表中浏览缩略图（不能代替原图用于标注或训练）。                       | 独立计量；关闭缓存策略后立即停止该来源预览读取，已有缓存保留并按归属清理。                                                                                      |
| **无持久缓存（`none`）**      | 不生成持久派生预览，也不保留完整原图缓存；旧回填及金字塔入口不会为该来源独占样本生成额外缓存。                                     | 适合对平台侧衍生存储零占用的严格受控场景。                                                                                                                      |
| **按需原图（`on_demand`）**   | 首次成功读取并完整核验原图后，在平台缓存桶保留一份完整原图副本；当来源自然离线或同名文件被覆盖时，旧任务仍可凭相同摘要读取该副本。 | 受存储位置的**完整原图缓存额度**与保留时间（TTL）上限优先约束。位置默认额度为 `0`，须由超级管理员在「存储管理 → 位置详情 → 完整原图缓存」设置正额度后方可生效。 |

> **按需完整原图缓存管理**：
> 满额时优先淘汰未在读取中的旧副本；单张原图大于总额度时不淘汰其他副本，直接使用当次核验快照。超级管理员可在位置详情点击「请求清理原图缓存」，二次确认后每次提交最多 100 份副本回收（正在读取或上传的副本不强清）。保存缓存设置会递增位置修订，旧修订副本退出读取并逐步回收。

## 服务器目录原地引用

超级管理员先在**「存储管理 → 受控目录位置」**登记运维已挂载的根内相对目录，并设置使用范围为「仅指定的数据管理员」或「所有数据管理员」（支持按姓名、邮箱搜索）。随后，超级管理员或获位置授权的项目管理员可在**「数据集 → 接入服务器目录」**创建普通图片数据集，或在已有非时序图片数据集的**「来源与同步」**页签管理目录来源：

1. **创建或进入数据集**：新建时输入数据集名称创建空图片数据集；已有数据集直接打开「来源与同步」页签（尚未配置来源时新增表单自动展开）。
2. **选择受控位置与相对目录**：选择已登记且启用的存储位置，填写位置下的相对目录或通过「浏览目录」选择。根句柄由运维挂载配置，不支持输入任意宿主机绝对路径。
3. **指定扫描节点与匹配规则**：填写负责扫描的完整 Worker `hostname`（该节点必须挂载同一目录并通过探测），设置是否递归包含子目录，以及区分大小写、相对来源根匹配的 `include_globs` 和 `exclude_globs`（例如 `excluded` 排除同名子目录，`temp/*` 排除其中文件），点击「配置目录来源」。
4. **选择策略并执行只读预扫描**：选定原图策略与缓存策略后，点击「只读预扫描」。后台任务按目录检查点枚举文件，完成后可分页查看相对路径与观测字节；支持取消与断点恢复，若目录结构变化则会要求重新扫描。
5. **运行接入预检并确认登记**：点击「运行接入预检」。后台读取候选图片，核验 SHA-256、格式（支持单帧 PNG、JPEG、WebP，单张上限 64 MiB、3200 万像素）与宽高尺寸，汇总展示已索引、待核验、已核验待登记、预计新增、异常和排除数。核对无误后勾选确认并点击「确认仅登记新增」（少量图片也可在扫描条目中逐条点击「核验并登记」）。
6. **核验预览与关联项目**：进入数据集详情的样本检查器点击「核验预览」，并通过「关联项目」生成标注任务；后续新增登记也会为已关联项目自动补建任务。

### 标注、AI 预标与导出支持范围

- **工作台手工标注**：通过登录鉴权读取完整核验原图，加载完成前禁止编辑；标注员仅获得所分配任务的读图权限，不获得目录浏览权。
- **AI 预标与交互式掩码**：支持[后台图片预标](../projects/ai-preannotate)的单阶段和 geometry/ROI 多阶段执行、交互式提示、原生掩码（Mask）创建/精修与采纳、确定性批量掩码修复以及局部 SAM 重跑。每次执行、恢复、回滚与候选采纳均严格核验当前权限与固定原图摘要。
- **训练版本冻结与后台导出**：引用图片可在关联项目中冻结为独立训练数据版本（构建时按固定 Asset 与 SHA-256 保存独立训练副本），后台图片导出也会严格核验并打包原图。
- **当前限制**：引用视频/Tracker 重跑、跨任务传播、时序 Scene 及大图金字塔切片暂未接入原地引用内容，相关操作会明确拒绝。含目录来源的普通图片数据集仍可混合上传多文件、ZIP（不自动创建 Scene）或连接器复制导入。

## 外部 S3 原地引用

1. 先在[存储位置与连接器](./storage-connections)中配置允许使用的 S3 `endpoint`、桶、`base_prefix` 和只读凭据。
2. 在数据集「来源与同步 → 新增来源」中选择该 S3 位置，填写或浏览位置下的相对前缀，其余扫描、预检、确认登记及项目关联流程与服务器目录一致（API 与指定 Worker 须能访问该端点，无需挂载宿主机目录）。

**对象键与版本核验规则**：

- S3 前缀和对象键按原始字符匹配，保留空格、中文、连续斜线、反斜杠和点段，平台不会将其改写为其他键名。
- 平台优先使用对象存储返回的**不可变对象版本（Version ID）**读取原图；若服务未启用版本控制，则使用 `ETag` 条件请求并完整校验 SHA-256（绝不将 `ETag` 直接当作内容摘要）。
- 当不可变版本仍在时，最新同名对象被覆盖不会影响已登记版本；若无固定版本且源对象被替换，将拒绝旧任务读图和保存。兼容服务若不支持条件读取、返回部分原图或重定向到未授权端点，平台会直接拒绝接入。

## SFTP 原地引用

1. 先由运维配置专用只读 SFTP jail，并将精确服务器地址、账号及主机公钥登记到部署白名单（`STORAGE_SFTP_ROOTS`），连接器 Base path 固定填 `/`（整个账号可读范围即该位置的授权范围，不能用子目录代替服务端隔离）。详见[部署说明](/ops/deploy/docker-compose#只读-sftp-引用)。
2. 在数据集「来源与同步 → 新增来源」中选择符合部署资格的 SFTP 位置，浏览或填写相对目录，指定扫描 Worker，随后按相同流程扫描、预检与确认登记。
3. 文件名中的中文、空格及字面加号/百分号原样保留；父级跳转（`..`）、绝对路径、符号链接与特殊文件一律拒绝接入，单目录上限 5,000 项。更换服务器或主机公钥时须由运维先停用位置并协调节点，历史样本不会自动改指新服务器。

## 手动增量差异与预检核对

当外部目录、S3 前缀或 SFTP 目录发生文件增删改时，可在来源页再次点击**「只读预扫描」**与**「运行接入预检」**。预检会将本轮完整扫描与预检开始时已登记的来源路径逐项比对，在**「本轮增量差异」**面板中分为六类展示（支持按类型筛选与分页）：

| 差异分类                        | 含义说明                                                                          | 默认处理方式                                                                                   |
| ------------------------------- | --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **新增（Added）**               | 预检开始时尚未登记、且本轮通过完整 SHA-256 与尺寸核验的新相对路径。               | 勾选确认后点击「确认仅登记新增」批量入库并补建关联项目任务。                                   |
| **内容与观测相同（Unchanged）** | 相对路径已登记，且本轮文件身份观测与 SHA-256 摘要均未变化。                       | 保持原样本与原任务不变，无需重复登记。                                                         |
| **已变化（Changed）**           | 已登记路径的文件内容摘要改变，或摘要相同但 `mtime` / `inode` 等文件身份观测改变。 | **不会自动覆盖旧样本绑定**。需按下方「接受内容为新修订」或「重新核验并保留样本」显式处理。     |
| **本轮未见（Unseen）**          | 此前已登记的路径在本轮完整扫描中未出现（可能被移动、删除或未遍历到）。            | 保留旧样本、任务与已有标注，不自动删除；若属同来源内移动，可按下方「移动后继续原任务」重定位。 |
| **本轮排除（Excluded）**        | 此前已接纳的路径因调整扫描规则而被排除在本轮范围之外。                            | 旧样本、任务与标注保留，旧任务仍按原内容身份读取。                                             |
| **核验失败（Failed）**          | 文件损坏、超出单图预算（> 64 MiB 或 > 3200 万像素）、格式不支持或读取权限受阻。   | 在「预检与登记明细」中勾选「仅显示异常」查看原因，修复源文件后可单项重试。                     |

> **取消与恢复保障**：
> 取消或中断的预检不会提前发布残缺差异，待恢复完成后再统一核对。正式登记过程中关闭页面或点击取消均会保留已提交条目，不会撤销已登记样本。

## 周期扫描与差异核对

在数据集「来源与同步」中选择已有来源，展开**「周期计划」**，可配置 **15–10080 分钟**（默认 60 分钟）的固定间隔并启用：

- **固定间隔与显示时区**：后台按实际分钟数计算间隔（例如 `1440` 分钟固定为 24 小时，不随夏令时伸缩），可填写 IANA 显示时区（如 `Asia/Shanghai`）以本地时间展示最近检查与下次计划时间。节点繁忙或离线时顺延，不补跑错过的周期。
- **人工确认（默认策略）**：当周期预检发现任何新增、变化、未见、排除或核验失败时，计划暂停并等待管理员核对本轮差异。管理员可确认「仅登记新增」，也可勾选「已核对本轮差异」后点击「跳过本轮差异，继续周期」（不创建样本，保留差异历史）。若整轮仅有「内容与观测相同」项，则自动进入下一周期。
- **纯新增轮次自动登记（可选策略）**：在启用前若选择该策略，仅当**整轮预检完整、零错误，且只包含「新增」与「未变化」**时，系统才会沿用当前授权自动登记新增路径。只要存在任何一条变化、未见、排除或核验失败，整轮仍会停下等待人工核对，绝不先行接纳其中的部分新增。
- **暂停与权限失效保护**：点击「暂停周期扫描」仅停止后续触发，当前运行中的扫描或登记仍可完成（如需中止当前作业请在任务面板单独取消）。当启用账号的权限、凭据、来源配置或存储根身份变化时，周期计划会自动停用并提示原因，核对修复后需重新启用。

## 内容变化、同内容重核验与路径重定位

针对增量预检中识别出的「已变化」与「本轮未见」条目，平台提供三种显式受控处置动作（请先完成这些单项处置，再点击「确认仅登记新增」）：

### 接受内容为新修订

当同一相对路径的图片实际内容发生变化（前后 SHA-256 摘要不同）时：

1. 在完整预检的「本轮增量差异」列表中找到该项，点击**「接受为新修订」**。
2. 在弹窗中核对相对路径、旧样本、前后 SHA-256 摘要与候选图片预览，勾选确认后提交（每次仅处理选中的单项）。
3. **生效结果**：新样本在文件列表中显示递增的**修订号**（悬停可查看前驱样本）；已关联的普通图片项目会为新修订生成**空白任务**，而旧样本、旧任务及已有人工标注完整保留、不会自动迁移到新图上。若旧目录原图已被覆盖且无不可变 S3 版本或完整原图缓存，旧任务将拒绝读取原图，系统绝不会把新图张冠李戴配给旧标注。

### 重新核验并保留样本

当同一路径的图片按原字节重新写入、导致 `inode` 或修改时间（`mtime`）变化但 **SHA-256 摘要完全相同**时，严格读取会拦截未确认的观测变化：

1. 在完整预检的差异列表中点击该项**「重新核验并保留样本」**。
2. 核对路径、前后一致的 SHA-256 与候选图片，勾选确认。
3. **生效结果**：继续使用**原样本、原任务和原标注**，仅在账本中追加新的核验观测记录，不创建新样本或空白任务，也不重复复制托管原图。已打开且此前报错的任务刷新或点击「重读原图」即可恢复。

### 移动后继续原任务

当图片文件在同一来源内被移动到其他子目录后，重新扫描并完成预检时，旧路径会显示为「本轮未见」，新路径会显示为「新增」：

1. 在旧路径的「本轮未见」行点击**「选择移动目标」**。
2. 从系统筛选出的**相同 SHA-256 新增候选路径**中明确选择目标路径（若存在多个同内容候选，平台不会自动猜测），核对图片后勾选确认。
3. **生效结果**：原样本、原任务与已有标注保持不变，后续原图读取自动切换至新路径；该目标路径同时从待新增列表中消去，不会重复建任务。此操作仅限同一来源内部重定位，不跨来源或存储位置搬迁，也不会修改外部文件系统。

### 调整扫描范围

选择已有来源并展开**「调整扫描规则」**，可修改是否包含子目录、`include_globs` 和 `exclude_globs`（服务器目录与 SFTP 排除目录名即排除整个子树；外部 S3 按完整相对对象键匹配，如 `dir/*`）：

1. 修改规则后点击**「预览规则影响」**（若有活动扫描任务需先等待结束或取消）。预览会列出已接纳路径中哪些仍在范围、哪些将移出或重新纳入。
2. 核对列表并勾选确认后保存。保存后需重新扫描和预检，已有周期计划也需重新启用。
3. **安全边界**：移出扫描范围**不会删除**已有样本、任务或标注，旧任务仍按原内容身份读取；新一轮预检会将这些路径归入「本轮排除」。

### 扫描历史与存储位置入口

- **扫描历史与来源生命周期**：在来源页展开「扫描历史」，可分别查看最近完整扫描、当前执行任务和分页历史（每页 20 条，最新一次失败或取消不会覆盖上一次完整扫描记录）。在「来源设置」中可点击「查看停用/注销影响」：停用可恢复，注销不可恢复；两者均不删除外部原文件，但原地引用来源停用后会阻断新读取与在途未核验标注。
- **从存储位置反查来源与任务**：在「存储管理」页面的「位置关联来源与后台任务」中选择存储位置，可分页查看当前账号可见的关联来源与扫描/预检/登记任务，点击来源即可直达对应数据集并自动选中该来源。
- **冻结训练数据版本**：原地引用图片可从已关联项目创建训练数据版本，预检会展示预计复制体量，构建时按固定 Asset 与 SHA-256 保存独立训练副本；后续源文件变化、移除或来源停用均不影响已就绪的训练版本，详见[训练数据版本](../online-learning/data-versions#原地引用图片)。

## 来源原件保护责任

由于原地引用（`reference`）不在平台保存原图副本，一旦外部目录被误删或存储损坏，仅凭平台索引与缩略图无法还原原件。管理员可在数据集「来源与同步」中选择来源，查看或维护**「来源原件保护责任」**：

1. 点击「登记保护责任」或「编辑保护责任」，填写负责团队或人员名称。
2. 选择恢复方式：**外部备份恢复**、**上游重新获取**、**无恢复方案**或**尚未确认**，并可附内部恢复说明或工单编号（仅限字母、数字及 `. _ : -`，请勿填入路径、链接或密钥凭据）。
3. 已登记方案显示为「已声明」并附更新时间，存储位置的「来源诊断」面板也会同步展示该记录。登记保护责任无需来源实时在线，数据集归档、来源停用或注销后仍可按权限维护；多人并发更新时支持「载入最新记录」重新核对。

## 远端来源离线与显式备用来源

### 远端来源离线时的行为

接入[跨网络只读站点 Agent](./site-agents)或远端存储的来源会实时展示站点状态、Agent 状态与最后心跳时间。当远端网络连接中断或 Agent 离线时：

- **可继续使用的能力**：数据集列表检索、筛选、样本元数据查看以及已生成的只读缓存预览图仍可正常浏览；若已开启按需完整原图缓存且命中有效副本，在位置与来源未停用的前提下仍可核验读取；已冻结就绪的训练数据版本继续使用其独立保存的副本。
- **受阻断的操作**：无完整缓存且需要实时回源校验原图的操作（如打开标注工作台编辑、发起 AI 预标、新建训练版本冻结或执行质量检测）会明确提示来源离线，待恢复连接后点击「重读原图」或重试即可，离线绝不代表样本被删除。

### 绑定与使用显式备用来源（`reference-replicas`）

为防止单一远端站点离线阻塞标注或训练版本准备，管理员可为原地引用样本绑定**显式备用来源**：

1. 在数据集工作台打开引用图片的**「样本检查器」**（或从训练数据版本预检异常列表中点击带 `?itemId=...&prepareSource=1` 的深链直接定位到该样本的来源准备视图），展开**「备用来源」**区域。
2. 从当前账号有权管理、且**内容身份记录（SHA-256 与字节数）完全一致**的其他已登记来源中选择候选图片进行关联。
3. **设置读取优先级**：主来源默认优先级为 `100`，数字越小越优先（完整原图缓存若命中且有效仍最先读取）。管理员可随时调整备用来源优先级或解除关联。
4. **离线切换核验**：当主站点离线时，点击「核验读取原图」将按优先级顺序尝试已关联的备用来源；平台同样会完整读取并核对 SHA-256 摘要，不可读或内容不符的候选绝不会冒充原件。绑定或解除备用来源不会合并样本、任务或标注，也不会删除任何外部原图。
