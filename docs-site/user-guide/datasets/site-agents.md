# 跨网络站点与 Agent

> 适用角色：超级管理员（创建站点、签发配对码、登记位置与身份管理） / 项目管理员（获授权后接入目录来源与查看站点状态）

当远端 Linux 数据服务器位于实验室、厂区或专有子网，中心平台无法主动建立入站连接，且不便将海量原图集中搬迁到中心对象存储时，可通过 **存储管理 → 站点与 Agent**（`/storage?tab=agents`）接入只读站点 Agent。

## 适用场景与安全边界

只读站点 Agent 采用**远端主动出站（Outbound-only HTTPS）**长轮询架构，严格限制权限与物理路径暴露：

| 维度           | 安全边界与行为约束                                                                                                                 |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **网络方向**   | 远端服务器仅需主动通过 HTTPS 访问中心平台，无需开放任何入站端口、SSH 端口或公网 IP。                                               |
| **凭据隔离**   | 站点不保存平台数据库凭据、对象存储管理员密钥或全局 API Key；仅持有最长 30 天有效的专用 Agent 身份凭据（`0600` 权限）。             |
| **路径脱敏**   | 真实宿主机绝对路径仅保存在站点本地配置文件中；中心平台只接收受控根句柄（`root_handle`）、根修订（`root_revision`）与根内相对路径。 |
| **只读能力集** | 仅支持四类受控只读操作：位置探测（`probe`）、目录浏览（`browse`）、只读预扫描（`scan`）与原图核验读取（`read`）。                  |
| **禁止写删**   | 不开放远程 Shell、不提供文件写入、改名、删除或预签名上传能力，不能作为平台托管用途的新写入目标。                                   |

关于远端服务安装、系统服务托管与协议升级，参见运维指南[只读站点 Agent 部署](/ops/deploy/site-agents)；传输协议细节参见[只读站点 Agent 与传输 API](/api/guides/site-agents)。

## 创建站点与签发一次性配对码

超级管理员进入 **存储管理 → 站点与 Agent**，按以下步骤建立站点与 Agent 身份：

1. **新建站点**：点击 **新建站点**，填写站点名称（如 `shanghai-lab-01`）与可选区域（`region`）。
2. **添加 Agent 并签发配对码**：在目标站点下点击 **添加 Agent**，填写 Agent 名称及中心侧并发/带宽限制，生成一次性配对信息。
3. **保存一次性配对文件**：弹窗显示的配对 JSON 包含单次有效、**10 分钟内过期**的配对码。中心数据库仅保存配对码摘要，弹窗关闭后不再回显，请立即复制并保存为远端服务器上的私有文件（权限 `0600`）。
4. **远端完成本地配对**：运维人员在远端服务器上先运行 `--check` 检查本地配置与只读挂载，再执行 `--pairing-file` 消费配对码换取正式身份凭据：

```sh
aap-storage-agent --config /etc/aap-storage-agent/agent.json --check
aap-storage-agent --config /etc/aap-storage-agent/agent.json --pairing-file /etc/aap-storage-agent/pairing.json
```

配对成功后启动 Agent 服务，Agent 将主动长轮询中心并上报本地配置的受控根句柄（`root_handle`）、根修订与本地资源预算。

## 登记受控根位置与授权

Agent 在线并上报受控根后，超级管理员即可将其中的目录登记为平台受控存储位置：

1. 在 **站点与 Agent** 列表点击目标 Agent 的 **查看详情**，在居中弹窗核对最后心跳时间、协议版本、身份修订及已上报的受控根列表。
2. 在目标受控根行点击 **登记位置**，填写位置名称、根内相对目录（`relative_path`）、使用范围与按需完整原图缓存策略。
3. **配置并发与中心带宽预算**：中心签发的带宽预算（`bandwidth_bytes_per_second`）与 Agent 本地配置上限取较低值生效。原图分块与命令结果正文（含扫描目录清单）共用该发送预算；HTTP/TLS 头、配对和轮询控制消息不计入正文预算，进程重启后允许一个有界首片突发。
4. **授权数据管理员**：超级管理员可将位置使用权授予指定项目管理员或全部数据管理员。保存后自动跳转到位置详情页，管理员在此执行位置探测，确认远端根可达后再接入数据集。

## 扫描、预检登记与原图 Range 读取

登记为受控存储位置后，站点目录完全复用标准[数据来源与增量同步](./sources)工作流，同时具备针对跨网络传输的完整性与恢复机制：

- **只读扫描与预检登记**：在数据集页选择该 Agent 存储位置并指定中心执行 Worker，即可发起目录浏览、只读预扫描、接入预检与增量差异确认。位置相对路径与来源相对路径各自独立校验边界，防止路径逃逸。
- **完整核验与单区间 Range 读取**：Agent 读取原图时先在本地完整读取、计算 SHA-256 摘要并复核文件状态，再分块（每块最大 256 KiB，单文件上限 64 MiB）上传至中心有界暂存区。中心完整核验 SHA-256 与图片格式后才交付业务读取或写入按需完整原图缓存。已核验的 Agent 图片（扫描条目、已登记样本及任务内容接口）以及对应的同内容完整原图缓存支持单区间 `Range` 请求与强 ETag `If-Range` 校验，每次区间均切自完整核验后的同一快照。
- **断网重传与丢失授权恢复**：中心最多同时维持 4 个中继预算，原图读取优先于探测、浏览和扫描。若轮询领取响应在网络中丢失，同一耐久会话（durable session）重连后可重领同一未过期命令（单命令最长 120 秒，默认签发 45 秒，重投不延长原到期时间）。若重领时命令已过期，中心仅重投原始过期命令供 Agent 回报物理句柄已关闭，Agent 不会再次访问源文件。
- **跨站点显式备用来源**：若将另一站点的同内容目录也接入数据集，管理员可在样本检查器展开 **备用来源** 关联同内容图片并设置读取优先级（数字越小越优先，原来源默认 `100`）。主站点离线时可无缝从备用站点核验读取原图，无需搬迁文件。

## 心跳状态、离线表现与生命周期管理

列表与数据集样本页直接从数据库批量读取站点与 Agent 的连接状态及最后心跳时间，不会在打开列表时逐张探测远端文件。心跳超过 **60 秒**未更新即显示为离线。

### 站点离线时的可用范围

| 功能或操作                       | 站点离线时的表现                                                                                                 |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| **样本检索与元数据浏览**         | 正常可用。站点离线不会将已登记样本标为删除，目录结构、筛选与分页保持不变。                                       |
| **已有缩略图与完整原图缓存**     | 正常可用。已生成的只读预览和未过期的同内容完整原图缓存仍按当前项目权限核验读取。                                 |
| **已创建的冻结训练版本**         | 正常可用。冻结版本直接读取平台已保存的独立副本，不依赖外部站点在线。                                             |
| **未命中缓存的原图读取与新扫描** | 立即返回明确的站点不可用原因（离线、暂停、凭据过期、已撤销或根修订变化），连接恢复后可点击“重读原图”或重试任务。 |

### 身份生命周期操作（超级管理员）

在 Agent 详情弹窗中，超级管理员可基于当前身份修订（`expected_revision`）执行三项受控生命周期操作：

1. **暂停排空（`drain`）**：点击 **暂停派发** 后，中心停止向该 Agent 分配新任务，但允许已领取命令继续执行完毕、提交结果并释放中继资源。升级 Agent 程序或轮换凭据前必须先执行暂停排空。
2. **轮换凭据（`rotate`）**：仅当 Agent 处于已暂停（`draining`）状态，且没有任何已分配（`leased`）、已接收（`received`）或未结清关闭责任（`unsettled`）的命令时才可执行。轮换后生成新的一次性配对码，同时保留旧凭据摘要用于核对延迟到达的关闭回执。
3. **撤销身份（`revoke`）**：遇到凭据泄露或站点退役时点击 **撤销身份**。撤销立即生效，所有新任务领取与在途原图分块上传均被拒绝；旧凭据仅允许向已有命令的结果端点回报物理关闭元数据，不能再获取任何业务采纳资格。
