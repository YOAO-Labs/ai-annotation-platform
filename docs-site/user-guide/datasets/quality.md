# 图片质量检测与复核

数据集负责人或超级管理员可在数据集工作台的**「质量」**页签发起整份数据集的图片质量检测，识别解码损坏、尺寸超限与精确内容重复（SHA-256），并通过单条或固定范围批量复核记录人工处置决定与审计轨迹。

## 启动图片质量检测

在数据集详情打开**「质量」**页签，点击**「新建检测」**：

1. **固定检测范围（上限 10,000 项）**：每轮质量检测在提交时固定**整份数据集**的当前成员（单数据集最多 **10,000 个**成员）。「数据」页当前的搜索词、组合筛选、分页或个人视图**不会缩小**质量检测范围；检测提交后新上传或新登记的样本不会混入当前轮次，需另开新一轮检测。
2. **检测维度与参数设置**：
   - **原图解码核验**：实际读取并解码图片，识别文件截断、格式伪造或编码损坏；
   - **宽高范围核验**：检查实际解码后的逻辑像素宽高是否落在目标区间内（默认宽高范围均为 **64–8192 px**，可在提交前按项目要求调整）；
   - **精确内容重复（Exact Duplicates）**：按本轮完整读取计算的 **SHA-256 摘要与字节数**识别精确重复组（运行过程中随着检测推进，重复组成员数可能动态增加）。
3. **单图预算与显式「未检测（`unchecked`）」**：
   - 每张原图读取上限为 **64 MiB**，解码上限为 **3200 万像素**；
   - 尚无可信内容身份、非图片成员、暂不支持的编码格式、超出单图读取/解码预算以及原图不可读的样本，均会明确归类为**「未检测」**，并严格区分「读取失败」「内容已变化」与「图片解码损坏」——绝不会将未检测样本粉饰为通过，也不会因为列表缩略图可见就判定原图合格。
4. **原件位置与回源规则**：
   - **托管原件**：严格按该样本保存的原件位置读取；即使系统已切换数据集原件用途的新分配桶，也不会把已有样本的质量检测改指向其他位置；若历史样本位置不明确则直接拒绝检测；
   - **原地引用原件**：始终检查外部来源的实际字节，不会因为平台存在完整原图缓存命中就假定外部来源已恢复在线。
5. **取消、断点恢复与历史轮次**：运行中的质量检测可随时取消，已完成核验的样本结果予以保留；因故障或取消停止后，可点击恢复继续处理剩余未完成项。页面支持按历史轮次切换查看过往检测快照。

## 查看问题与单条人工复核

检测进行中或完成后，可在结果列表中按**问题类型**（解码损坏、尺寸超范围、精确重复、读取失败/内容变化、未检测、正常）、**复核状态**（待复核、已确认问题、已忽略）与复核原因筛选：

- **查看精确重复组**：点击某条重复样本的「重复成员数」，可在弹窗中分页查看同 SHA-256 组内的全部样本路径与核验时间。
- **单条人工复核**：点击任意样本行的**「复核详情」**，在居中弹层中核对内容摘要、尺寸、核验时间与异常详情。选择复核决定（**确认问题**、**忽略**或**恢复待复核**）并**填写原因说明**（必填）后提交。
- **证据绑定与审计**：每次复核决定都会绑定到本轮检测固定的内容身份证据，并写入审计历史。若样本后续被删除或内容修订发生变化，历史检测记录会明确标注「当前绑定已变化」，旧复核决定不会自动套用到新一轮检测或新内容上。

## 固定范围批量复核

当一轮质量检测完全停止（已完成、已取消或失败停止）后，若存在大量同类问题需要集中标记，可使用**固定范围批量复核**：

1. **选择目标范围**：
   - **手动跨页勾选**：在结果列表中跨页勾选最多 **200 个**结果；
   - **全部筛选结果**：在「批量复核」中选择「全部筛选结果」（单次最多 **10,000 项**）。
2. **填写决定并生成影响预览（10 分钟有效期）**：
   - 选择目标复核状态并填写复核原因，点击**「生成影响预览」**；
   - 预览会跨全部分页固定当时的目标成员列表、内容身份证据与当前复核修订号，汇总展示**可处理数、阻止数（如检测尚未完成的 `unchecked` 项）与历史证据数量**；
   - 预览有效期为 **10 分钟**。若期间修改了勾选范围、复核决定或原因，必须重新生成预览；预览生成后新匹配的结果不会进入原批次。
3. **按固定范围执行与并发冲突跳过**：
   - 核对无误后点击**「按固定范围执行」**；
   - 系统逐项校验目标样本的证据与复核修订号：若某成员在预览后被其他管理员单条修改了复核状态或证据发生变化，该成员会被记为**「冲突（Conflict）」并跳过**，批次继续处理其余成员（最终状态显示为「部分完成」）；
   - 即使某成员原本就处于目标复核状态，本次批量执行仍会独立保存新的复核原因、操作者、修订号与审计记录；
   - 即使历史样本已被业务删除或绑定变化，仍可针对本轮固定的旧证据完成复核记录，且该决定绝不会转移到后续同名新内容上。
4. **取消、恢复未完成项与记录留存**：
   - 批量复核执行期间支持随时取消，已成功提交的决定保留；
   - 取消或中断后可点击**「恢复未完成项」**，系统仅处理原固定名单中尚未处理的成员，已成功、已冲突和被阻止的条目不会重复执行（若需重新处理冲突项，请重新发起预览）；
   - 点击「批量复核记录」可在居中窗口分页查看每个成员的处理明细，支持深链刷新与返回；通用后台任务历史清理不会删除已落库的复核记录。

## 质量结果与训练、原件的边界

图片质量检测与人工复核遵循严格的**只读诊断与证据隔离原则**：

- **不自动删除或合并样本**：无论检测出解码损坏、尺寸超限还是精确 SHA-256 重复，系统都不会自动删除平台托管原件、不会删除外部来源文件，也不会自动合并重复样本或它们的标注任务。
- **不篡改已有标注与训练版本**：确认或忽略质量问题不会修改项目的标注数据，不会自动改变任务的训练准入资格，更不会回溯修改已经冻结发布的[训练数据版本](../online-learning/data-versions)。
- **数据集归档后只读**：数据集归档后，历史质量检测轮次与复核记录仍可完整查阅，但不再允许新建质量检测或发起新的复核委托。
