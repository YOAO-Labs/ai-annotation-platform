# 数据集 · 导入导出

本章覆盖数据从**进入平台**到**导出成果**的链路：上传或登记原图引用 → 关联项目生成任务 → 标注与审核。托管数据还可导入外部预测和导出成果；引用数据的预测、导出与训练仍按各自内容核验合同执行。

数据集管理页支持按名称检索与按数据类型快速筛选（条件即时生效并同步 URL 状态，详见 [筛选操作说明](/user-guide/reference/filtering)）。点击数据集进入独立详情；列表的筛选、位置与页码保存在 URL，返回列表后恢复。从项目向导或旧来源链接进入时直接定位目标详情。

## 归档与恢复

列表默认显示活动数据集，可用“数据集状态”切换到已归档或全部；筛选、分页和返回位置保存在链接中。归档数据集的详情深链仍可打开，样本、来源历史、项目任务、标注和关联版本继续保留。

数据集创建者或超级管理员可在详情预览归档影响，核对样本、来源、项目/任务、活动工作及已记录的冻结依赖后确认。预览有效五分钟，权限、配置、关系或生命周期变化后须重新预览；取消不会归档。统计中的冻结版本仅覆盖已保存数据集归属的样本，零计数不能证明没有历史冻结内容。

归档后不能再上传/导入、修改成员或配置、关联/解绑项目、运行来源写操作、创建质量检测/复核委托，或把归档样本加入新的训练版本。已有任务仍按当前项目权限读取与标注；已创建的冻结版本继续打包、下载和用于训练。平台不会删除或改写外部原件，个人阅读视图仍可保存。

恢复只把数据集重新设为活动，不恢复已撤销的人员/位置/项目权限、Key或同步委托。归档前的排队导入、建任务、扫描/登记、质量作业和自动同步不会因恢复而续写；需在当前权限下明确创建新一轮。旧完整观测可查看，但采纳/登记需新轮核对。取消与失败收尾仍可执行。

归档与既有删除不同。归档数据集须先明确恢复，才能使用原删除流程；解除项目关联仍按原影响确认删除对应任务/标注，不因归档引入新的隐式清理。

## 数据链路总览

```
原始数据 ──► 接入数据集 ──► 关联项目（自动建 task）──► 标注 / 审核
              │
              ├── 图像：多文件 / ZIP / 连接器
              ├── 原地引用：受控服务器目录 / S3 / 合格只读 SFTP
              ├── 点云 · 多模态：原生目录约定 / nuScenes 脚本
              └── 大批量：存储连接器（S3 / OSS / SFTP）

外部预测（AAP JSON / COCO / YOLO）──► 作为待采纳候选导入 ──► 工作台采纳
```

## 几个关键概念

- **数据集 vs 项目**：数据集是数据的容器，项目消费数据集；关联后每条数据生成一个 task。一个数据集可被多个项目关联。
- **导入即建任务**：数据集关联项目后自动建任务；条目数超过阈值（默认 2000）转后台异步建任务，建完前工作台暂时看不到，属正常现象。详见 [导入图像数据集](./import-images)。
- **scene（时序数据集）**：含 scene 的数据集才能关联 scene 模式项目（逐帧图片序列 / 逐帧点云）。如何在导入时产生 scene 见 [导入点云 / 多模态数据集格式](./import-formats)。
- **数据与预测**：数据集接入可上传/复制原图，也可只登记引用；「导入预测」向已有 task 写候选标注。引用图片可从有管理权限的关联项目冻结为训练版本，后台图片导出将核验后的原图放入包内，图片预标也使用受控快照；不能把引用标识作为对象存储路径使用。
- **外部预测 vs 平台预标**：外部预测是上传结果文件，不要求绑定 ML Backend；平台预标由项目已启用的 backend 运行。两者都先作为候选，审阅方式见[审阅 AI 候选](../ai/candidate-review)。

## 已挂载目录的观测扫描

超级管理员，以及拥有位置使用权且为数据集创建者的项目管理员，可通过[目录来源 API](/api/guides/dataset-sources)为已有数据集登记只读目录，并在指定工作节点执行手动观测扫描。任务中心报告累计扫描数和阶段；取消保留已完成目录的观测，恢复后继续处理未完成目录，目录变化会要求重新扫描。

扫描本身不会新增图片样本、修改标注或删除外部原图。随后在接入面板运行批量预检、检查影响并确认登记，也可逐条“核验并登记”。通过核验的图片逐批可用；损坏文件独立记录、分页查看和单项重试，取消保留已提交部分。原图所有权与预览缓存独立选择、分别计量。相同流程也支持外部 S3 和经部署核验的只读 SFTP。详见[服务器目录原地引用](./import-images#服务器目录原地引用)。

### 管理员图片核验

有上述来源管理权限的管理员可通过[内容核验 API](/api/guides/verified-content)对完整扫描中的匹配图片核验真实内容，取得 SHA-256、大小和尺寸；后续按该摘要读取临时快照。文件被替换、配置变化、权限收回或图片不符合预算时拒绝读取。首次核验不能证明扫描当时的字节。

独立核验 API 不创建样本；目录接入面板另行确认登记后，普通图片项目可在工作台读取严格快照并手工标注。引用图片可校验后冻结为独立训练副本；后台图片导出可生成包含原图的核验包；图片预标使用受控原图快照。已有上传和复制导入流程继续使用。

内容变化可在完整预检后[逐项接受为新修订](./import-images.md#接受内容为新修订)，新任务为空白，旧标注保留。

## 独立数据集详情

详情通过“数据”“来源与同步”“项目关联”“关联版本”组织现有操作。数据页支持服务端分页的表格与网格、文件名/来源/可用性过滤，以及可复制链接的样本检查器；不会为翻页下载全量原图。上传、扫描、维度和视频元数据补生成、Scene 信息及点云坐标系继续保留。

可用性反映**最近保存的观测**，并显示时间。“已核验（读取时复核）”不保证此刻源文件仍在线。变化待确认、完整扫描未见、仅预览、来源不可用和待核验分别显示；缩略图不构成可编辑或可训练证明。只读预览仅在当前权限和缓存策略允许时提供，主动停用、注销来源或停用位置会阻断其访问。标注及训练冻结读取仍严格校验原图。

“数据”页的文件名、来源、Scene、可用性可与“更多筛选”组合：媒体类型、文件扩展名、尺寸已知/未知和宽高范围。填写更多条件后点“应用筛选”；“清除更多条件”同时清空草稿和已应用的高级条件，保留 Scene 等主条件。扩展名按文件名后缀匹配，忽略大小写，jpg/jpeg 同组；它不保证实际编码格式。宽高以像素计，只匹配尺寸已知的样本。未知尺寸不能同时填写范围，最小值不能大于最大值。

含 Scene 的数据集可按场景筛选，范围包含同 Scene 的多模态和校准成员。Scene 选项按页加载，可按名称查找；查找与翻页只改变可选项，不改变当前样本范围。选中的 Scene 不在当前选项页时仍保留。URL 或个人视图中的 Scene 已删除或失效时显示错误，不会自动变成全部；可明确选择“全部 Scene”清除条件。切换页签再返回仍保留筛选。

常用条件可点“保存为新视图”，在居中窗口中命名。个人视图仅自己可见，每个数据集最多100个；下拉选择后恢复全部已存条件并回到第一页。修改后会显示未保存状态，可更新条件、另存、恢复原条件、重命名或删除。删除视图保留样本与当前筛选。只有视图 ID 的链接会先恢复视图再查询；视图不存在时显示错误，来源或 Scene 失效时也不会自动去掉对应条件。

个人视图保存查询条件，每次打开显示**当前匹配样本**；后续新增样本可能加入结果。要保留当时的成员、原图和标注，可点击“冻结当前筛选”，选择有管理权限的关联项目，再核对匹配任务、标注资格与预检结果并创建版本。详见[筛选冻结流程](../online-learning/data-versions.md#从数据集当前筛选创建版本)。

完整预检结束后，即使没有登记新样本，列表、检查器和状态摘要也会刷新观测。网格预览按受控并发加载，服务暂时繁忙时有限重试；切换页面或会话会取消尚未开始的读取。

“项目关联”分别显示该数据集在每个可见项目中的任务、已标注、待审核和完成数量，项目其他数据集的任务不参与计算。解除关联必须先成功取得影响预览；预览失败时可重试，不能按零影响继续提交。

解除关联会一并删除对应任务、标注、评论及其反馈镜像。已登记的评论附件保留独立清理责任，按原保存期限和删除宽限回收，不在解除关联时直接删除文件。

“关联版本”只列有训练管理权限的项目版本，详情沿用训练模块。创建时先选择关联项目，再在既有训练页面明确选择标注范围、预检并确认冻结；数据集范围由服务端限定，进入页面不会自动创建版本。质量页另提供图片检测与固定范围批量复核。

存储配置统一位于[存储管理](./storage-connections)，数据集来源页只管理扫描规则、同步和接入，不编辑共享位置的端点或凭据。

## 图片质量检测与复核

数据集负责人或超级管理员可在详情的“质量”页签新建检测。每轮在提交时固定整份数据集，最多 10000 个成员；当前搜索、分页和个人视图不会缩小检测范围。后续新增样本需要另开一轮。

- 检查原图能否解码、实际逻辑宽高是否符合范围，并按本轮完整读取的 SHA-256 与字节数识别精确重复。默认宽高各为 64–8192 px，可在提交前调整。
- 尚无可信内容身份、非图片、暂不支持的编码、超预算和不可读原图显示“未检测”。读取失败、内容变化与图片损坏分开显示；缩略图可见不代表原图检测通过。每张原图读取上限 64 MiB，解码上限 3200 万像素。
- 点击重复成员数可分页查看同组样本；“复核详情”在居中弹层显示摘要、核验时间和原因。确认、忽略或恢复待复核均须填写原因，决定记录到本轮内容证据及审计历史。
- 检测可取消，已完成的结果保留；失败或取消后可继续未完成项。历史记录可按轮次查看。运行中的结果仍在增加，重复成员数可能变化。

检测与复核不删除或合并样本，也不改变标注、训练资格或已冻结版本。旧结果不会自动应用到新一轮；样本删除或内容身份变化后，历史记录会标明当前绑定已变化。权限变化后需要重新授权，原地引用还要求对应执行节点具备受控原图读取能力。

### 固定范围批量复核

检测停止后，可勾选最多 200 个结果（支持跨页），或在“批量复核”中选择“全部筛选结果”（最多 10000 项）。填写决定与原因，点击“生成影响预览”；预览包含其他分页，固定当时的成员、内容身份和复核修订，显示可处理、阻止和历史证据数量，有效期 10 分钟。

确认无误后点“按固定范围执行”。修改范围、决定或原因需要重新预览；后续新匹配的结果不会加入原批次。检测尚未完成的成员会明确跳过；历史样本已删除或绑定变化时，仍可针对固定的旧证据复核，决定不会转移到新内容。

“批量复核记录”在居中窗口分页显示每个成员的处理结果。证据或复核修订被其他操作修改时，当前成员记为冲突，继续处理其余成员；出现冲突或阻止项时显示“部分完成”。每次成功复核独立保存原因、操作者、修订和审计，即使目标状态相同也会记录这次决定。

执行时可取消，已完成部分保留；失败或取消后可“恢复未完成项”，只处理原名单中尚未处理的成员，已成功、冲突和阻止项均不会重复执行。重新处理冲突需要重新预览。批量历史与结果链接支持返回和刷新；通用任务清理不会删除复核记录。
