# 数据集与存储

本章覆盖平台从**数据接入、存储连接与来源同步**，到**数据集工作台筛选、质量检测、关联项目标注与训练版本冻结**的完整链路。无论原图是上传到平台托管存储，还是保留在受控服务器目录、外部对象存储、只读 SFTP 或跨网络站点 Agent 中原地引用，平台都以统一的内容身份核验、权限边界和生命周期合同组织协作。

```
存储位置 / 连接器 / 站点 Agent
        │
        ▼
数据集接入（本地上传 / 连接器复制 / 原地引用与增量同步）
        │
        ├──► 数据集工作台（组合筛选 · Scene 筛选 · 个人视图 · 质量检测与批量复核）
        │
        ├──► 关联项目与批次（自动生成标注任务 · 导入外部预测 · 导出标注成果）
        │
        └──► 训练数据版本冻结（从项目或数据集当前筛选创建不可变训练快照）
```

## 从哪里进入与角色分工

平台将日常数据集协作与底层存储治理分为两个顶部入口：**「数据集」**（`/datasets`）面向数据接入、筛选、质量复核与项目联动；**「存储管理」**（`/storage`）面向存储位置、跨网络站点、九用途映射、迁移准备与容量账目。

| 角色                        | 在「数据集」（`/datasets`）可完成的工作                                                                                                                                                                                             | 在「存储管理」（`/storage`）可完成的工作                                                                                                                                                           |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **数据管理员 / 项目管理员** | 创建与管理本人负责的数据集；上传多文件或 ZIP；从已授权存储位置或连接器导入/登记来源；配置周期扫描与核对增量差异；使用数据集工作台筛选、保存个人视图、执行图片质量检测与批量复核；关联本人可管理的项目并从当前筛选冻结训练数据版本。 | 查看和使用全局或被授权的存储连接器与受控目录位置；探测被授权位置的指定扫描节点；查看本人可管理来源的关联任务与来源诊断；创建个人连接器。                                                           |
| **超级管理员**              | 拥有全部数据集的查看、接入、来源管理、质量复核、归档与恢复权限；在系统设置中调整数据导入枚举预算与同步建任务阈值。                                                                                                                  | 登记全局对象存储、受控服务器目录、合格只读 SFTP 与跨网络站点 Agent；分配位置使用人员与按需原图缓存额度；管理九用途绑定与受控切换；执行位置访问维护、平台对象盘点、增量账目对账与对象存储迁移准备。 |
| **标注员 / 审核员**         | 不直接管理数据集或目录来源；在已关联项目的标注工作台中按任务分派权限读取核验后的原图、完成标注、审阅候选预测与提交审核。                                                                                                            | 无存储管理操作入口；通过平台鉴权接口按需读取分配任务对应的媒体与个人头像。                                                                                                                         |

## 核心概念速览

- **数据集 vs 项目 / 批次 / 任务**：数据集是原始媒体的容器，可被多个项目同时关联。关联项目后，每条有效数据自动生成对应项目的标注任务（默认 ≤ 2,000 条同步创建，超出转后台异步创建）。标注进度、批次划分与候选预测均保存在项目侧，互不污染。
- **托管原件 vs 原地引用**：上传或复制导入会将原图写入平台托管存储并分配固定内容身份；原地引用（`reference`）不复制原图字节，每次标注读取、预标、导出或冻结训练版本时，均按已登记的 SHA-256 摘要与版本凭据回源（或从受控完整缓存）严格核验。不能把引用标识直接当作对象存储路径拼接访问。
- **个人动态视图 vs 冻结训练数据版本**：在数据集工作台保存的「个人视图」仅保存筛选条件，每次打开动态查询当前匹配样本；而在关联项目中创建的「训练数据版本」（或从数据集工作台点击「冻结当前筛选」）会将当时的成员、原图副本与已审核标注永久固定为不可变快照，后续数据集增删或源文件变化均不会改变已就绪的训练版本。

## 归档与恢复

数据集创建者或超级管理员可在数据集详情预览归档影响并确认归档；归档后停止新的上传、来源同步、项目关联、质量作业及新训练版本采纳，但保留全部已有样本、项目任务、标注与已冻结训练版本。需要恢复写入时可按当前权限重新设为活动状态，归档前的旧异步作业或同步计划不会自动续写。完整操作步骤、五分钟预览有效期与删除边界见[原件访问、归档与保留回收](./lifecycle-and-retention#归档与恢复)。

## 独立数据集详情

点击任意数据集即可进入独立数据集工作台（`/datasets/:id`），通过「数据」「来源与同步」「质量」「项目关联」「关联版本」五个页签集中完成服务端组合筛选、Scene 筛选、样本检查器核验、个人动态视图保存、项目标签分布统计以及从当前筛选直接冻结训练版本。详细说明见[数据集工作台与视图](./workbench)。

## 图片质量检测与复核

数据集负责人或超级管理员可在详情的「质量」页签对整份数据集发起固定范围图片质量检测，自动核验原图解码、宽高范围与精确 SHA-256 重复组，并支持单条人工复核或跨页/全筛选结果的固定范围批量复核。检测与复核决定均记录审计证据，不会自动删除原件、合并样本或篡改已冻结的训练版本。详细操作见[图片质量检测与复核](./quality)。

## 从项目取消关联数据集

项目负责人或超级管理员可以在数据集管理页或项目的数据集区域取消关联。确认前会预览将移除的任务、标注和可删除的空批次；有任务时需输入数据集名称确认。受主动学习历史、保留反馈或其他标注引用保护的来源不能强制清理，解除这些引用后再试。

取消关联只移除这个项目中的关联及由该数据集创建的项目任务和标注，不会删除数据集、数据集条目或原始上传文件。任务专属图片金字塔会在事务提交后排队清理；共享的来源预览和原始文件仍可用于其他项目。清理失败会留在后台队列中重试。

涉及尚未退役的视频执行时，取消关联返回 409，关联、任务、作业和输入保持。先取消需要停止的视频执行，等待后台退役后再重试；已完成、失败或已取消的显示状态不代表清理已经结束。旧作业没有可靠退役证明时，需要管理员先排空并修复。失败后重试继续复用本次操作的幂等键。

程序化调用可先请求 `GET /api/v1/datasets/{dataset_id}/link/{project_id}/preview-unlink`，再调用 `DELETE /api/v1/datasets/{dataset_id}/link/{project_id}`。DELETE 可附带 UUID 格式的 `Idempotency-Key`；网络结果不确定时，用同一个键重试，成功响应会回传该键。响应包含删除的任务、标注、批次数量、批次 ID 和 `soft` 标记。

## 删除素材或数据集

素材库管理员可以删除无引用的条目或整个数据集。任务主来源、相机/点云链接、标注、
轨迹、质量记录、视频章节、执行记录及主动学习历史仍在引用时，删除返回 409 并保留内容；
请先在对应项目或功能中处理引用。正在导入或仍会消费条目的后台建题也会阻止条目删除。

删除单条素材同样检查它所在场景的轨迹与质量历史；活跃视频作业和仍在保留期的输入证据也会阻止删除。删除操作不会代为解除这些引用或取消视频执行；拒绝时保留原记录和清理计划。证据按所属功能完成解除或过期后，可以重新删除。

取消视频跟踪、终止轨迹或软删除相机标注会保留相应历史，不等于解除素材引用。部分历史没有单独的解除入口，仍在引用时素材会继续保留。取消数据集与项目的关联会删除该项目的任务和标注，不能用它替代需要保留这些内容的引用处理。

删除原始素材登记不会删除原始上传文件。条目专属金字塔在提交后由后台可靠清理，
生成中的金字塔会等执行租约结束后再处理。网络结果不确定时，程序调用可用同一个
UUID `Idempotency-Key` 重试 DELETE；成功仍返回空响应。

## 连续上传与存储连接

普通文件上传先进入临时区，完成校验后才计入数据集并参与项目建题。完成请求可以重试；
已完成的上传不会再次覆盖原始文件。发现内容重复时保留已有文件；缺失或重复上传不会
删除旧的素材记录。上传仍属于原发起账号，其他账号不能接管其未完成操作。

程序上传可分别保存初始化与完成阶段的 UUID `Idempotency-Key`。初始化响应不确定时，在上传仍待完成期间复用原键取得同一条目；完成响应不确定时，用原条目和原完成键确认结果。完成成功后不要重新初始化同一次上传。读取过程中来源被替换时会提示冲突，原记录与原始文件保留。

普通创建数据集只登记目录信息，不需要向对象存储写空目录；重命名也不会移动已有文件。程序创建或更新时可保存 UUID `Idempotency-Key`，网络中断后用原请求和原键重试，读取已提交的原结果。同一键不能用于另一组修改。

旧导入路径仍可能写入零字节目录标记，扫描和文件统计会忽略它们。如果连续上传出现明显停顿，并伴随 `Failed to parse headers` 或 `MissingHeaderBodySeparatorDefect`，请让管理员核对 API 和 Celery 实际运行环境是否使用仓库锁定依赖。宿主进程同步依赖后需重启；容器内依赖更新需重建对应镜像，参见[开发部署](/ops/deploy/development)。网络和权限故障仍按各自错误排查。

## 媒体准备与任务文件权限

图片缩略图、占位预览和视频元信息由后台媒体任务准备。文件导入、项目建题和媒体准备是不同阶段；缩略图生成不会代替标注或审核，也不会把已经送审的任务回退为待标注。

历史直接任务文件的上传初始化、上传完成和项目缩略图回填只允许当前项目管理者执行；普通成员仍可读取自己有权访问的任务原图，而不是只有管理者能看图。项目外账号、移除的成员以及无权访问该任务的成员不能凭任务 ID 获取新的原图地址。

上传完成遇并发操作繁忙时会提示冲突，请刷新当前任务状态后处理，不要强制恢复上传。图片来源验证、任务状态更新和缩略图作业受理在同一事务内提交；成功回执表示作业已持久受理，不保证预览已生成。管理员可通过[任务文件 API 的回填入口](/api/guides/tasks-and-annotations#历史任务文件入口)重新检查并补充缺失预览。已签发的短期对象地址仍按原到期规则失效。

## 建题作业的恢复与取消

已接受的后台建题操作按块保存进度，重启后继续，原发起者停用或负责人转移不会自动取消。当前项目管理者可在作业列表取消，已提交任务保留；解绑后旧作业停止。若关联已成功但作业未派发，可再次关联找回同一活跃作业。导入数据集灌的是**原始文件**，「导入预测」往**已有 task** 上写候选标注；两者都先作为候选，审阅方式见[审阅 AI 候选](../ai/candidate-review)。
