# 数据集与存储

本章覆盖平台从**数据接入、存储连接与来源同步**，到**数据集工作台筛选、质量检测、关联项目标注与训练版本冻结**的完整链路。无论原图是上传到平台托管存储，还是保留在受控服务器目录、外部对象存储、只读 SFTP 或跨网络站点 Agent 中原地引用，平台都以统一的内容身份核验、权限边界和生命周期合同组织协作。

```
存储位置 / 连接器 / 站点 Agent
        │
        ▼
数据集接入（本地上传 / 连接器复制 / 原地引用与增量同步）
        │
        ├──► 数据集工作台（组合筛选 · Scene 筛选 · 个人视图 · 质量检测与批量复核）
        │
        ├──► 关联项目与批次（自动生成标注任务 · 导入外部预测 · 导出标注成果）
        │
        └──► 训练数据版本冻结（从项目或数据集当前筛选创建不可变训练快照）
```

## 从哪里进入与角色分工

平台将日常数据集协作与底层存储治理分为两个顶部入口：**「数据集」**（`/datasets`）面向数据接入、筛选、质量复核与项目联动；**「存储管理」**（`/storage`）面向存储位置、跨网络站点、九用途映射、迁移准备与容量账目。

| 角色                        | 在「数据集」（`/datasets`）可完成的工作                                                                                                                                                                                             | 在「存储管理」（`/storage`）可完成的工作                                                                                                                                                           |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **数据管理员 / 项目管理员** | 创建与管理本人负责的数据集；上传多文件或 ZIP；从已授权存储位置或连接器导入/登记来源；配置周期扫描与核对增量差异；使用数据集工作台筛选、保存个人视图、执行图片质量检测与批量复核；关联本人可管理的项目并从当前筛选冻结训练数据版本。 | 查看和使用全局或被授权的存储连接器与受控目录位置；探测被授权位置的指定扫描节点；查看本人可管理来源的关联任务与来源诊断；创建个人连接器。                                                           |
| **超级管理员**              | 拥有全部数据集的查看、接入、来源管理、质量复核、归档与恢复权限；在系统设置中调整数据导入枚举预算与同步建任务阈值。                                                                                                                  | 登记全局对象存储、受控服务器目录、合格只读 SFTP 与跨网络站点 Agent；分配位置使用人员与按需原图缓存额度；管理九用途绑定与受控切换；执行位置访问维护、平台对象盘点、增量账目对账与对象存储迁移准备。 |
| **标注员 / 审核员**         | 不直接管理数据集或目录来源；在已关联项目的标注工作台中按任务分派权限读取核验后的原图、完成标注、审阅候选预测与提交审核。                                                                                                            | 无存储管理操作入口；通过平台鉴权接口按需读取分配任务对应的媒体与个人头像。                                                                                                                         |

## 选择数据接入方式

根据文件体量、网络位置以及是否需要将原图字节复制到平台托管对象存储，可选择以下四种接入路径：

| 接入方式                                 | 是否复制原图字节                                               | 前置条件与适用规模                                                                                   | 典型场景                                                                                                 | 操作指南                                                                                                   |
| ---------------------------------------- | -------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **本地上传与桶内扫描（方式 A / B / D）** | **是**（写入平台托管对象存储）                                 | 浏览器直传单文件 ≤ 5 GiB；ZIP 整包 ≤ 200 MB（≤ 5000 文件）；或对已写入平台桶的对象执行扫描补建索引。 | 几百到数千张本地图片、分类子目录 ZIP 上传、点云与多模态（lidar + 相机）归档导入。                        | [导入图像与托管数据](./import-images)<br>[导入点云 / 多模态](./import-formats)                             |
| **连接器批量复制导入（方式 C）**         | **是**（从外部拉取并写入平台托管存储）                         | 已配置 S3 / OSS / SFTP 连接器；单次默认上限 50,000 文件 / 200 GiB（超管可调整）。                    | 数据已在云存储或 SFTP，希望将原图集中托管到平台桶内，后续脱离外部源独立使用。                            | [导入图像与托管数据](./import-images#方式-c-连接器导入大批量)<br>[存储位置与连接器](./storage-connections) |
| **受控目录 / 外部 S3 / SFTP 原地引用**   | **否**（`reference` 零原图复制；可选 `managed_copy` 托管复制） | 运维已挂载只读目录根、配置外部 S3 只读位置或只读 SFTP jail；支持按需预览缓存与按需完整原图缓存。     | 存量大图库已在共享存储（CephFS / NFS）或专有对象桶中，不希望双份占用原图空间，且需周期跟踪增量变化。     | [数据来源与增量同步](./sources)                                                                            |
| **跨网络只读站点 Agent**                 | **否**（原图留存远端站点，平台按需请求核验流）                 | 远端内网部署只读站点 Agent 并出站连接平台；注册目录绑定、签发长期凭证并保持心跳。                    | 机房或场站无公网入站端口，仅允许出站连接，需远程浏览目录、核验登记图片并在离线时配合缓存或备用来源工作。 | [跨网络站点与 Agent](./site-agents)<br>[数据来源与增量同步](./sources#远端来源离线与显式备用来源)          |

## 核心概念速览

- **数据集 vs 项目 / 批次 / 任务**：数据集是原始媒体的容器，可被多个项目同时关联。关联项目后，每条有效数据自动生成对应项目的标注任务（默认 ≤ 2,000 条同步创建，超出转后台异步创建）。标注进度、批次划分与候选预测均保存在项目侧，互不污染。
- **托管原件 vs 原地引用**：上传或复制导入会将原图写入平台托管存储并分配固定内容身份；原地引用（`reference`）不复制原图字节，每次标注读取、预标、导出或冻结训练版本时，均按已登记的 SHA-256 摘要与版本凭据回源（或从受控完整缓存）严格核验。不能把引用标识直接当作对象存储路径拼接访问。
- **个人动态视图 vs 冻结训练数据版本**：在数据集工作台保存的「个人视图」仅保存筛选条件，每次打开动态查询当前匹配样本；而在关联项目中创建的「训练数据版本」（或从数据集工作台点击「冻结当前筛选」）会将当时的成员、原图副本与已审核标注永久固定为不可变快照，后续数据集增删或源文件变化均不会改变已就绪的训练版本。

## 归档与恢复

数据集创建者或超级管理员可在数据集详情预览归档影响并确认归档；归档后停止新的上传、来源同步、项目关联、质量作业及新训练版本采纳，但保留全部已有样本、项目任务、标注与已冻结训练版本。需要恢复写入时可按当前权限重新设为活动状态，归档前的旧异步作业或同步计划不会自动续写。完整操作步骤、五分钟预览有效期与删除边界见[原件访问、归档与保留回收](./lifecycle-and-retention#归档与恢复)。

## 独立数据集详情

点击任意数据集即可进入独立数据集工作台（`/datasets/:id`），通过「数据」「来源与同步」「质量」「项目关联」「关联版本」五个页签集中完成服务端组合筛选、Scene 筛选、样本检查器核验、个人动态视图保存、项目标签分布统计以及从当前筛选直接冻结训练版本。详细说明见[数据集工作台与视图](./workbench)。

## 图片质量检测与复核

数据集负责人或超级管理员可在详情的「质量」页签对整份数据集发起固定范围图片质量检测，自动核验原图解码、宽高范围与精确 SHA-256 重复组，并支持单条人工复核或跨页/全筛选结果的固定范围批量复核。检测与复核决定均记录审计证据，不会自动删除原件、合并样本或篡改已冻结的训练版本。详细操作见[图片质量检测与复核](./quality)。
