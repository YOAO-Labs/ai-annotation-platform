# 数据集 · 导入导出

本章覆盖数据从**进入平台**到**导出成果**的完整链路：导入原始数据 → 关联项目生成任务 → 导入 / 清理外部预测 → 导出标注成果。各环节散落的入口在这里归一。

数据集管理页支持按名称检索与按数据类型快速筛选（条件即时生效并同步 URL 状态，详见 [筛选操作说明](/user-guide/reference/filtering)）。从项目向导跳转时会自动展开目标数据集，搜索过程保留已有选择。

## 数据链路总览

```
原始数据 ──► 导入数据集 ──► 关联项目（自动建 task）──► 标注 / 审核 ──► 导出成果
              │
              ├── 图像：多文件 / ZIP / 连接器
              ├── 点云 · 多模态：原生目录约定 / nuScenes 脚本
              └── 大批量：存储连接器（S3 / OSS / SFTP）

外部预测（AAP JSON / COCO / YOLO）──► 作为待采纳候选导入 ──► 工作台采纳
```

## 从项目取消关联数据集

项目负责人或超级管理员可以在数据集管理页或项目的数据集区域取消关联。确认前会预览将移除的任务、标注和可删除的空批次；有任务时需输入数据集名称确认。受主动学习历史、保留反馈或其他标注引用保护的来源不能强制清理，解除这些引用后再试。

取消关联只移除这个项目中的关联及由该数据集创建的项目任务和标注，不会删除数据集、数据集条目或原始上传文件。任务专属图片金字塔会在事务提交后排队清理；共享的来源预览和原始文件仍可用于其他项目。清理失败会留在后台队列中重试。

涉及尚未退役的视频执行时，取消关联返回 409，关联、任务、作业和输入保持。先取消需要停止的视频执行，等待后台退役后再重试；已完成、失败或已取消的显示状态不代表清理已经结束。旧作业没有可靠退役证明时，需要管理员先排空并修复。失败后重试继续复用本次操作的幂等键。

程序化调用可先请求 `GET /api/v1/datasets/{dataset_id}/link/{project_id}/preview-unlink`，再调用 `DELETE /api/v1/datasets/{dataset_id}/link/{project_id}`。DELETE 可附带 UUID 格式的 `Idempotency-Key`；网络结果不确定时，用同一个键重试，成功响应会回传该键。响应包含删除的任务、标注、批次数量、批次 ID 和 `soft` 标记。

## 删除素材或数据集

素材库管理员可以删除无引用的条目或整个数据集。任务主来源、相机/点云链接、标注、
轨迹、质量记录、视频章节、执行记录及主动学习历史仍在引用时，删除返回 409 并保留内容；
请先在对应项目或功能中处理引用。正在导入或仍会消费条目的后台建题也会阻止条目删除。

删除单条素材同样检查它所在场景的轨迹与质量历史；活跃视频作业和仍在保留期的输入证据也会阻止删除。删除操作不会代为解除这些引用或取消视频执行；拒绝时保留原记录和清理计划。证据按所属功能完成解除或过期后，可以重新删除。

取消视频跟踪、终止轨迹或软删除相机标注会保留相应历史，不等于解除素材引用。部分历史没有单独的解除入口，仍在引用时素材会继续保留。取消数据集与项目的关联会删除该项目的任务和标注，不能用它替代需要保留这些内容的引用处理。

删除原始素材登记不会删除原始上传文件。条目专属金字塔在提交后由后台可靠清理，
生成中的金字塔会等执行租约结束后再处理。网络结果不确定时，程序调用可用同一个
UUID `Idempotency-Key` 重试 DELETE；成功仍返回空响应。

## 连续上传与存储连接

普通文件上传先进入临时区，完成校验后才计入数据集并参与项目建题。完成请求可以重试；
已完成的上传不会再次覆盖原始文件。发现内容重复时保留已有文件；缺失或重复上传不会
删除旧的素材记录。上传仍属于原发起账号，其他账号不能接管其未完成操作。

程序上传可分别保存初始化与完成阶段的 UUID `Idempotency-Key`。初始化响应不确定时，在上传仍待完成期间复用原键取得同一条目；完成响应不确定时，用原条目和原完成键确认结果。完成成功后不要重新初始化同一次上传。读取过程中来源被替换时会提示冲突，原记录与原始文件保留。

普通创建数据集只登记目录信息，不需要向对象存储写空目录；重命名也不会移动已有文件。程序创建或更新时可保存 UUID `Idempotency-Key`，网络中断后用原请求和原键重试，读取已提交的原结果。同一键不能用于另一组修改。

旧导入路径仍可能写入零字节目录标记，扫描和文件统计会忽略它们。如果连续上传出现明显停顿，并伴随 `Failed to parse headers` 或 `MissingHeaderBodySeparatorDefect`，请让管理员核对 API 和 Celery 实际运行环境是否使用仓库锁定依赖。宿主进程同步依赖后需重启；容器内依赖更新需重建对应镜像，参见[开发部署](/ops/deploy/development)。网络和权限故障仍按各自错误排查。

## 媒体准备与任务文件权限

图片缩略图、占位预览和视频元信息由后台媒体任务准备。文件导入、项目建题和媒体准备是不同阶段；缩略图生成不会代替标注或审核，也不会把已经送审的任务回退为待标注。

历史直接任务文件的上传初始化、上传完成和项目缩略图回填只允许当前项目管理者执行；普通成员仍可读取自己有权访问的任务原图，而不是只有管理者能看图。项目外账号、移除的成员以及无权访问该任务的成员不能凭任务 ID 获取新的原图地址。

上传完成遇并发操作繁忙时会提示冲突，请刷新当前任务状态后处理，不要强制恢复上传。图片来源验证、任务状态更新和缩略图作业受理在同一事务内提交；成功回执表示作业已持久受理，不保证预览已生成。管理员可通过[任务文件 API 的回填入口](/api/guides/tasks-and-annotations#历史任务文件入口)重新检查并补充缺失预览。已签发的短期对象地址仍按原到期规则失效。

## 几个关键概念

- **数据集 vs 项目**：数据集是数据的容器，项目消费数据集；关联后每条数据生成一个 task。一个数据集可被多个项目关联。
- **导入即建任务**：数据集关联项目后自动建任务；条目数超过阈值（默认 2000）转后台异步建任务，建完前工作台暂时看不到，属正常现象。详见 [导入图像数据集](./import-images)。
- **后台建题恢复与取消**：已接受的后台操作按块保存进度，重启后继续，原发起者停用或负责人转移不会自动取消。当前项目管理者可在作业列表取消，已提交任务保留；解绑后旧作业停止。若关联已成功但作业未派发，可再次关联找回同一活跃作业。
- **scene（时序数据集）**：含 scene 的数据集才能关联 scene 模式项目（逐帧图片序列 / 逐帧点云）。如何在导入时产生 scene 见 [导入点云 / 多模态数据集格式](./import-formats)。
- **两条不同链路**：「导入数据集」灌的是**原始文件**；「导入预测」往**已有 task** 上写候选标注。先有数据，才谈得上导预测。
- **外部预测 vs 平台预标**：外部预测是上传结果文件，不要求绑定 ML Backend；平台预标由项目已启用的 backend 运行。两者都先作为候选，审阅方式见[审阅 AI 候选](../ai/candidate-review)。
