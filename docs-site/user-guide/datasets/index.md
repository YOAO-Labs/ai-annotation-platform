# 数据集 · 导入导出

本章覆盖数据从**进入平台**到**导出成果**的链路：上传或登记原图引用 → 关联项目生成任务 → 标注与审核。托管数据还可导入外部预测和导出成果；引用数据的后台导出等能力仍有明确限制。

数据集管理页支持按名称检索与按数据类型快速筛选（条件即时生效并同步 URL 状态，详见 [筛选操作说明](/user-guide/reference/filtering)）。点击数据集进入独立详情；列表的筛选、位置与页码保存在 URL，返回列表后恢复。从项目向导或旧来源链接进入时直接定位目标详情。

## 数据链路总览

```
原始数据 ──► 接入数据集 ──► 关联项目（自动建 task）──► 标注 / 审核
              │
              ├── 图像：多文件 / ZIP / 连接器
              ├── 原地引用：受控服务器目录 / S3 / 合格只读 SFTP
              ├── 点云 · 多模态：原生目录约定 / nuScenes 脚本
              └── 大批量：存储连接器（S3 / OSS / SFTP）

外部预测（AAP JSON / COCO / YOLO）──► 作为待采纳候选导入 ──► 工作台采纳
```

## 几个关键概念

- **数据集 vs 项目**：数据集是数据的容器，项目消费数据集；关联后每条数据生成一个 task。一个数据集可被多个项目关联。
- **导入即建任务**：数据集关联项目后自动建任务；条目数超过阈值（默认 2000）转后台异步建任务，建完前工作台暂时看不到，属正常现象。详见 [导入图像数据集](./import-images)。
- **scene（时序数据集）**：含 scene 的数据集才能关联 scene 模式项目（逐帧图片序列 / 逐帧点云）。如何在导入时产生 scene 见 [导入点云 / 多模态数据集格式](./import-formats)。
- **数据与预测**：数据集接入可上传/复制原图，也可只登记引用；「导入预测」向已有 task 写候选标注。引用图片可从有管理权限的关联项目冻结为训练版本，预标与后台导出仍待接入；不能把引用标识作为对象存储路径使用。
- **外部预测 vs 平台预标**：外部预测是上传结果文件，不要求绑定 ML Backend；平台预标由项目已启用的 backend 运行。两者都先作为候选，审阅方式见[审阅 AI 候选](../ai/candidate-review)。

## 已挂载目录的观测扫描

超级管理员，以及拥有位置使用权且为数据集创建者的项目管理员，可通过[目录来源 API](/api/guides/dataset-sources)为已有数据集登记只读目录，并在指定工作节点执行手动观测扫描。任务中心报告累计扫描数和阶段；取消保留已完成目录的观测，恢复后继续处理未完成目录，目录变化会要求重新扫描。

扫描本身不会新增图片样本、修改标注或删除外部原图。随后在接入面板运行批量预检、检查影响并确认登记，也可逐条“核验并登记”。通过核验的图片逐批可用；损坏文件独立记录、分页查看和单项重试，取消保留已提交部分。原图所有权与预览缓存独立选择、分别计量。相同流程也支持外部 S3 和经部署核验的只读 SFTP。详见[服务器目录原地引用](./import-images#服务器目录原地引用)。

### 管理员图片核验

有上述来源管理权限的管理员可通过[内容核验 API](/api/guides/verified-content)对完整扫描中的匹配图片核验真实内容，取得 SHA-256、大小和尺寸；后续按该摘要读取临时快照。文件被替换、配置变化、权限收回或图片不符合预算时拒绝读取。首次核验不能证明扫描当时的字节。

独立核验 API 不创建样本；目录接入面板另行确认登记后，普通图片项目可在工作台读取严格快照并手工标注。引用图片可校验后冻结为独立训练副本；预标与后台导出仍待适配。已有上传和复制导入流程继续使用。

内容变化可在完整预检后[逐项接受为新修订](./import-images.md#接受内容为新修订)，新任务为空白，旧标注保留。

## 独立数据集详情

详情通过“数据”“来源与同步”“项目关联”“关联版本”组织现有操作。数据页支持服务端分页的表格与网格、文件名/来源/可用性过滤，以及可复制链接的样本检查器；不会为翻页下载全量原图。上传、扫描、维度和视频元数据补生成、Scene 信息及点云坐标系继续保留。

可用性反映**最近保存的观测**，并显示时间。“已核验（读取时复核）”不保证此刻源文件仍在线。变化待确认、完整扫描未见、仅预览、来源不可用和待核验分别显示；缩略图不构成可编辑或可训练证明。只读预览仅在当前权限和缓存策略允许时提供，主动停用、注销来源或停用位置会阻断其访问。标注及训练冻结读取仍严格校验原图。

“项目关联”分别显示该数据集在每个可见项目中的任务、已标注、待审核和完成数量，项目其他数据集的任务不参与计算。解除关联必须先成功取得影响预览；预览失败时可重试，不能按零影响继续提交。

“关联版本”只列有训练管理权限的项目版本，详情沿用训练模块。创建时先选择关联项目，再在既有训练页面明确选择标注范围、预检并确认冻结；数据集范围由服务端限定，进入页面不会自动创建版本。保存视图、质量治理及全部筛选结果批处理仍待后续实现。

存储配置统一位于[存储管理](./storage-connections)，数据集来源页只管理扫描规则、同步和接入，不编辑共享位置的端点或凭据。
