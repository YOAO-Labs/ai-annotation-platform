# 存储连接器

> 适用角色：项目管理员 / 超级管理员

存储连接器让你把外部的对象存储（S3 / 阿里云 OSS / MinIO 等 S3 兼容服务）或 SFTP 服务器接入平台，之后在数据集里直接从这些来源批量导入文件，免去手动上传。

平台后端只内置两种连接器类型（`StorageKind`）：

- **`s3`**：AWS S3 及所有 S3 兼容服务，包括**阿里云 OSS、MinIO、腾讯云 COS** 等——它们都走同一个 `s3` 类型，只是填不同的 `endpoint`。
- **`sftp`**：SFTP / SSH 文件服务器。

> 界面上类型选项写作 **S3 / OSS**，对应后端的 `s3`；OSS / MinIO **没有**独立类型，统一用 `s3` 类型 + 各自的自定义 `endpoint`。

入口：左侧导航 **存储管理** → **位置**。S3/SFTP 与受控目录在同一位置入口管理；旧数据连接器链接会转到存储页。列表按名称、类型和状态展示位置。点击名称或“查看详情”，在居中弹窗查看能力、配置和关联来源；关闭后保留列表页码与返回数据集的上下文。从来源链接进入时，直接打开对应位置详情。

## 按已核验身份下载托管原件

面向集成程序的[认证原件下载接口](/api/guides/verified-content#认证通用原件下载)可先查询Task、相机关联或DatasetItem的内容身份，再下载对应完整原件。它使用原件记录保存的位置并检查全部字节，当前用途桶的调整不会改变读取目标。身份返回“可用性未检查”，不代表文件当前在线；权限撤销、内容变化或维护停止会使下载失败。

单文件最多512MiB，可保持点云、视频及其他已核验文件的原始字节；这不是原生视频的拖动播放接口。工作台现有预览和播放入口仍按各自合同运行。原地引用图片继续走原有严格图片读取，不转换成托管原件。

浏览器能查看文件而模型提示下载失败时，请管理员分别检查浏览器公共地址和模型可达的对象存储 Host。两者在签名前独立选择；不能手工改已签链接的域名。来源路径登记不负责调整容器网络，详见[部署签名契约](/ops/deploy/docker-compose#对象存储访问与签名契约)。

## 新建连接器

1. 进入 **存储管理 → 位置**，点击位置列表上方的 **新建远端连接**，在居中弹窗填写配置。
2. 填写信息：
   - **名称**：便于识别的名字，如 `aliyun-oss-prod`（必填）。
   - **类型**：`S3 / OSS` 或 `SFTP`（创建后**不可更改**）。
   - **范围**：
     - **个人（owner）**：仅你自己和超级管理员可见、可用。
     - **全局（global）**：所有用户可用，**仅超级管理员可创建**。
   - **连接参数与密钥**：按类型不同，见下面两个子节。
3. 点击 **新建连接器** 保存。

> **密钥安全**：Access/Secret key、密码、私钥、私钥口令均**加密落库**，列表、详情、任何接口都**不会回显明文**（`secret_set` 只表达「是否已配密钥」）。编辑时密钥字段**留空即保持原密钥不变**；填入新值则整体轮换。
>
> 创建（及编辑改了地址）时会先用超管配置的**主机白名单**校验目标地址，连不出去的连接器根本建不成功——详见 [主机白名单](#主机白名单超级管理员)。

### S3 / OSS / MinIO（`s3` 类型）

必填 `endpoint`、`bucket`、`access_key`、`secret_key`；可选 `region`、`base_prefix`（导入起始前缀）、是否 HTTPS（`use_ssl`）。

界面字段：**Endpoint**、**Bucket**、Region、Base prefix、**HTTPS** 复选框、**Access key**、**Secret key**。

完整配置示例（三份等价结构，差别只在 endpoint / region / 是否 HTTPS）：

```jsonc
// AWS S3
{
  "config": {
    "endpoint": "s3.ap-east-1.amazonaws.com",
    "bucket": "my-annotation-bucket",
    "region": "ap-east-1",
    "base_prefix": "raw/2026", // 可选：只看这个前缀下的对象
    "use_ssl": true, // HTTPS
  },
  "secret": { "access_key": "AKIA...", "secret_key": "********" },
}
```

```jsonc
// 阿里云 OSS（S3 兼容，填 OSS 的 region endpoint）
{
  "config": {
    "endpoint": "oss-cn-hangzhou.aliyuncs.com",
    "bucket": "annotation-oss-prod",
    "region": "oss-cn-hangzhou",
    "base_prefix": "",
    "use_ssl": true,
  },
  "secret": { "access_key": "LTAI...", "secret_key": "********" },
}
```

```jsonc
// MinIO（自建，常用明文 HTTP + 自定义端口）
{
  "config": {
    "endpoint": "minio.intranet.local:9000",
    "bucket": "datasets",
    "region": "us-east-1", // MinIO 无所谓，填默认即可
    "base_prefix": "incoming",
    "use_ssl": false, // 不勾 HTTPS
  },
  "secret": { "access_key": "minioadmin", "secret_key": "********" },
}
```

要点：

- `endpoint` 可带或不带 `http(s)://`；不带 scheme 时由 `use_ssl` 推断（勾 HTTPS → `https`，否则 `http`）。
- `base_prefix` 是连接器的「根」：之后导入填的 `source_path` 会拼在它**下面**，且不能逃出它。
- `region` 对 OSS / MinIO 通常不影响连通，留默认即可；AWS S3 建议填准以免签名/路由问题。

### SFTP（`sftp` 类型）

必填 `host`、`username`，以及一种凭据；可选 `port`（默认 **22**）、`base_path`、`auth_type`（`password` / `key`）。

界面字段：**Host**、Port（默认 22）、**Username**、Base path、**Auth**（Password / Private key）及对应凭据。

```jsonc
// 密码认证
{
  "config": {
    "host": "sftp.example.local",
    "port": 22,
    "username": "annotator",
    "base_path": "/incoming", // 可选：连接器的根目录
    "auth_type": "password",
  },
  "secret": { "password": "********" },
}
```

```jsonc
// 私钥认证（passphrase 可选）
{
  "config": {
    "host": "sftp.example.local",
    "port": 2222,
    "username": "annotator",
    "base_path": "/data/datasets",
    "auth_type": "key",
  },
  "secret": {
    "private_key": "-----BEGIN OPENSSH PRIVATE KEY-----\n...\n-----END OPENSSH PRIVATE KEY-----",
    "passphrase": "********", // 私钥无口令时省略
  },
}
```

`private_key` 把整段 PEM/OpenSSH 私钥文本贴进去（界面是多行文本框）。测试连接与实际导入使用同一解析路径，按顺序尝试 **RSA / Ed25519 / ECDSA** 三种当前支持的私钥类型。

#### SFTP 前置条件（务必先读）

连接器的“测试连接”和复制导入使用 `RejectPolicy` + 系统 **known_hosts**：

- 平台在 worker / API 进程内调 `load_system_host_keys()` 加载**服务端机器**的系统 known_hosts，并对未知主机一律 `RejectPolicy()`（直接拒绝，**不**自动接受、**不** TOFU）。
- **因此：目标 SFTP 主机的 host key 必须先出现在平台服务端的 known_hosts 里**，否则连接在握手阶段就被拒（报「Server ... not found in known_hosts」之类）。需要运维在部署平台的机器（API + Celery worker 容器/主机）上预先 `ssh-keyscan <host> >> ~/.ssh/known_hosts`，或挂载已含目标指纹的 known_hosts 文件。
- 连接测试与实际导入共享 RSA / Ed25519 / ECDSA 私钥解析和主机指纹校验。测试成功可确认连接器配置与目录读取能力；正式使用前仍建议跑一次小范围导入，验证文件范围与权限。

[SFTP 原地引用](./import-images#sftp-原地引用)使用独立的部署资格与固定主机公钥，不读取系统 known_hosts。运维须先核验整个账号命名空间的只读 jail，并配置 `STORAGE_SFTP_ROOTS`；连接 Base path 为 `/`。原地扫描的指定节点探测与连接器“测试连接”是不同检查，复制导入测试成功不代表取得持续引用资格。

## 测试连通性

连接器列表中每条都有 **测试** 按钮。点击后平台会用保存的凭据**真实建立一次连接**（出网前再次复检白名单 / SSRF）：

- **连接成功**：提示「连接成功」，并显示探测到的样本文件数（采样上限 20 条，仅用于确认能列目录，不是总文件数）。
- **连接失败**：提示原因，常见为凭据错误、地址不可达、SFTP 主机指纹不在 known_hosts、**目标不在白名单内**，或**白名单未配置**（见下）。

建议新建后先测试，再用于导入。

## 主机白名单（超级管理员）

出于安全（防 SSRF / 内网越权）考虑，连接器只能访问**白名单内**的主机。超级管理员在 **设置 → 系统设置 → 连接器主机白名单** 中管理条目；来源标记会区分部署默认和数据库覆盖，恢复部署默认只删除数据库覆盖，不修改服务器环境变量。

<!-- TODO(v0.14.18) IMAGE_CHECKLIST: images/datasets/connector-allowlist.png — 超管连接器主机白名单配置面板；标注红框：白名单条目列表 + 添加输入框 [manual] -->

白名单在**连接器创建、测试、导入**三处全部强制校验（白名单可能在建好后被超管收紧，存量连接在测试 / 导入时会复检；DNS 会先解析为真实 IP 再判定，缓解 DNS rebinding）。两类典型报错要分清：

- **白名单未配置**（一条都没有）：create / test / import 三处**全部被拦截**，提示「**未配置连接器主机白名单，请联系超级管理员先配置允许的主机**」。这是「默认拒绝」语义——超管没显式放行任何主机前，谁都连不出去。
- **目标不在白名单内**：提示「**目标不在白名单内: \<host\> → \<ip\>（需超管将其加入连接器主机白名单）**」。

白名单条目可以是：

| 形态               | 示例                           | 含义               |
| ------------------ | ------------------------------ | ------------------ |
| CIDR 网段          | `10.0.3.0/24`                  | 内网服务器整段放行 |
| 单个 IP            | `192.168.1.50`                 | 精确放行一台       |
| 精确域名           | `oss-cn-hangzhou.aliyuncs.com` | 仅该域名           |
| 后缀域名（前导点） | `.aliyuncs.com`                | 匹配其所有子域     |

**永久硬拒绝**（即使写进白名单也连不出去）的地址类别共 **5** 类，命中即拒：**loopback（回环，如 127.0.0.1）/ link-local（含云元数据 169.254.169.254）/ multicast（组播）/ unspecified（未指定 0.0.0.0）/ reserved（保留段）**。worker 在容器内，访问宿主机请走 docker 网关 IP，不要也无法靠放行 loopback 绕过。

保存时会规范化并去重条目，URL、带端口地址、路径和 `*` 通配符不能保存。保存空名单前会二次确认，因为它会阻断所有连接器目标。

若运维显式配置了部署主机 SFTP 地址，超级管理员会在数据连接器页看到 **添加部署主机**。点击后只预填 SFTP、host 和端口 22；用户名、私钥或密码、路径仍需手工填写，目标也必须单独加入白名单。应使用只能读取导入 staging 目录的专用账号，不要输入 root 或日常部署账号密码。

## 从连接器导入数据集

> 完整向导。除「新建数据集」时可走连接器导入外，已存在的数据集也能随时再次从连接器补充导入。

1. 进入 **数据集 → 数据集管理**。在某个数据集的**展开行点击「上传」**打开导入向导（新建数据集时则在向导第 1 步「选择来源」处）。
2. 把来源切到 **连接器导入** 子面板。
3. **选择连接器**：下拉列出你可见的连接器。
   - 普通**项目管理员**：可用**全局连接器 + 本人创建的个人连接器**。
   - **超级管理员**：可用**全部**连接器。
   - 没有可见连接器时下拉显示「暂无连接器」，需先去 **数据连接器** 标签建一个。
4. 填写导入参数：
   - **Source path**（`source_path`）：相对连接器 base（S3 的 `base_prefix` / SFTP 的 `base_path`）的起始目录，**留空表示根**。不能含 `..`，也不能逃出 base。
   - **递归扫描**（`recursive`，默认开）：勾选则连同子目录一起扫描。
   - **Include globs**（`include_globs`，可选）：**逗号分隔**的通配模式，留空表示全要。
5. 点击 **开始导入**。请求会落到后端 `POST /datasets/{id}/import-from-connection`，返回一个后台任务（`job_id`）。
6. 导入在后台异步执行，向导第 3 步与右上角任务铃会显示**进度**以及**成功数 / 跳过数 / 失败明细**（失败逐条带文件名与原因；跳过通常是内容已存在的幂等去重）。

真实请求体（`DatasetImportFromConnectionRequest`，前端会把逗号分隔的 globs 拆成字符串数组）：

```jsonc
// POST /api/v1/datasets/{dataset_id}/import-from-connection
{
  "connection_id": "0b6f...uuid",
  "source_path": "scene_001/frames",
  "recursive": true,
  "include_globs": ["*.jpg", "*.png"],
}
// 202 → { "job_id": "..." }
```

### Include globs 怎么写

每个模式按 `fnmatch` 匹配，对**完整相对路径**或其 **basename** 任一命中即收录（所以 `*.jpg` 这种只写扩展名的会按 basename 匹配，无需带路径前缀）：

| 模式                   | 命中示例                           | 说明                       |
| ---------------------- | ---------------------------------- | -------------------------- |
| `*.jpg,*.png`          | `a/b/img.jpg`、`cover.png`         | 按 basename 匹配扩展名     |
| `scene_*/frames/*.jpg` | `scene_001/frames/0001.jpg`        | 按完整相对路径匹配多级目录 |
| `*.pcd,*.bin`          | `lidar/0001.pcd`、`lidar/0001.bin` | 点云 / 二进制帧            |

### 导入上限

单次连接器导入按文件数与总字节限制枚举范围，**枚举超限时整体失败，不产生本次部分导入**。代码默认值为：

- 最多 **50000** 个文件（部署变量 `DATASET_IMPORT_MAX_FILES`）。
- 总体积最多 **200 GiB**，即 `214748364800` bytes（部署变量 `DATASET_IMPORT_MAX_TOTAL_BYTES`）。

实际有效值由本部署默认与超级管理员在「设置 → 系统设置 → 数据导入」保存的覆盖决定。每次导入受理时固定两项预算；修改设置只影响之后新建的导入，已经排队、运行或重试的作业继续使用原预算。恰好等于预算仍可导入。文件额度约束枚举，字节额度同时约束清单与实际读取的源字节；去重和失败已消费的字节也计入本轮预算。崩溃后重新执行的跨轮传输总量尚不提供累计保证。浏览器上传仍使用各自限额。

超限时请用 `source_path` / `include_globs` 缩小范围，避免误扫整个存储桶。

> **保留目录结构**：导入按 `source_path` **内部**的子目录层级落库（源 `dataset-A/a/img.jpg` → 数据集内 `a/img.jpg`），不会多嵌套一层。后续源里新增子文件夹时，对同一数据集再次从同来源导入即可，已存在文件按内容**自动跳过**、只补新增。

## 编辑与删除

- **编辑**：可改名称、连接参数或轮换密钥；**不填密钥则沿用原密钥**。修改参数或提交新密钥后，会先验证认证与目录列举再保存；失败保留原配置，并在弹窗中显示原因、保留当前草稿。仅改名称无需访问远程存储，也不会使已有位置探测失效。
- **多人编辑**：保存时若连接已被其他操作更新，会拒绝覆盖。请取消编辑后重新打开，核对最新配置再修改；不要直接覆盖别人的变更。
- **验证范围**：连接测试最多列举20项，反映 API 节点的认证与列举能力，不代表原图读取、Range、写入或扫描 worker 已通过验证。错误不会显示凭据或底层签名地址；超时、认证失败和目录权限不足会给出分类提示。
- **轮换安排**：平台不会自动撤销外部系统的旧密钥。运维应在新凭据验证成功、已有任务过渡完成后再撤销旧凭据。
- **删除**：移除连接器。**已经导入到数据集的文件不受影响**（文件已落入平台存储），但此后无法再用该连接器导入。

只有连接器的**创建者或超级管理员**可以编辑 / 删除；**全局连接器仅超级管理员**可管理。

## 已挂载目录的存储位置

服务器目录、CephFS 和 NFS 可由运维统一挂载为少量受控根，再由超级管理员通过[存储位置 API](/api/guides/storage-locations)登记名称、根句柄、相对目录和使用人员。例如根句柄 `ceph` 对应 `/mnt/cephfs`，位置登记 `traffic`，目录浏览选择其下 `vehicle_detection`。新建根内目录和登记已有目录无需重启容器；新增未挂载的宿主机目录仍需运维先补挂载。

超级管理员可在存储管理页登记位置、配置使用范围和人员，并探测指定节点；获位置使用权的项目管理员也可探测，并为自己创建的数据集从数据集页[接入服务器目录](./import-images#服务器目录原地引用)，扫描并逐条核验登记。存储页的桶用量统计仍仅反映平台对象存储，不代表外部目录容量。现有连接器导入仍会复制文件。管理员不能仅凭 API 节点可读就认定扫描节点可用，必须探测指定 worker；外部目录不接受平台写入或删除。

## 从数据集往返存储位置

数据集接入向导只选择已有连接；需要新建时点击管理存储位置，在存储页完成后返回原向导。平台按当前登录会话与数据集保留非秘密的文本草稿；文件选择和密钥不会持久保存，返回后需重新选择本地文件。来源页可定位到对应位置，再回到原来源与扫描上下文。

位置详情展示实际类型、启用状态、声明能力与分节点探测证据；启用不表示在线，过期证据显示待核验。来源/后台任务继续独立分页。受影响数据集数量按当前权限去重，同一数据集的多个来源只计一个；“查看数据集”打开位置筛选列表。

超级管理员可在“用途映射”查看九种业务用途，即使共用桶也逐行保留。未配置或不匹配明确提示；头像、报告附件、审计归档、导出、导入暂存、数据集原件和媒体缓存另有受控切换入口，修改配置不等于完成对象迁移。物理容量、配额、源规模和平台对象字节没有可靠测量时显示“未提供/待统计”；刷新页面不会同步扫描全部桶。视频资产失败查看与重试继续保留。

每条用途同时展示读写策略：已固定位置的对象按保存记录读取，其余入口保留既有兼容路径；头像、报告附件、审计归档、导出、导入暂存、数据集原件和媒体缓存的新写入使用当前登记绑定，其余用途使用部署目标。用途代次与位置修订分别显示，缺少字段时保持“未提供”。“已配置”只表示部署映射匹配，不代表位置在线或迁移完成；头像、报告附件、审计归档、导出、导入暂存、数据集原件和媒体缓存可按下文受控切换，标注文件和训练两个用途保持锁定。这里的托管写策略与外部来源的只读能力分别管理，不能将来源只读解释为平台无法保存文件。

## 切换审计归档的新写入位置

超级管理员在“用途映射”的审计归档行选择“切换审计归档位置”，从默认托管位置或已登记的全局 S3 位置中选择目标，先验证并预览，再于五分钟内确认。验证实际执行条件写入、完整读回和准确清理探针；验证失败或无法确认收尾时不会切换。目标、维护状态、影响数量或权限变化后需重新预览。

预览显示已分配和已发布归档数量。切换前已分配、仍在写入的归档继续完成到原位置，后续新分配才写入目标；历史月份与公开归档键不变。归档永久保留，切换不搬迁或删除旧文件。旧位置仍被归档保护，不能重定向或删除；正常密钥轮换使用当前连接凭据，仍需保留旧位置访问能力。外部目标不在现有本地九桶恢复范围内，应按部署安排独立备份。

## 切换报告附件的新上传位置

超级管理员在“用途映射”的报告附件行选择“切换报告附件位置”，从已登记的全局 S3 位置中选择目标，先验证并预览，再于五分钟内明确确认。验证会在受控前缀中实际条件写入、完整读回和准确删除；失败或收尾不明时不会切换。绑定、目标配置、维护状态或权限变化后需重新预览。

切换仅影响后续分配的上传。已保存和正在上传的附件留在原位置，报告中的逻辑附件键保持不变，下载、期限与报告权限沿用原规则；切换不会搬迁历史内容。缺少独立归属的旧附件继续显示原有不可读取结果，不按新桶猜读，也不会阻止新上传位置切换。现有头像、审计归档、导出、导入暂存、数据集原件和媒体缓存切换仍独立，标注文件和训练两用途保持锁定。

目标上的附件仍由原清理责任负责；切走后还有任意状态附件的位置不能改向或删除，密钥可按既有连接流程正常轮换。平台当前部署桶的占用盘点不包含外部目标，未覆盖提示不表示目标没有对象。

## 位置内的来源诊断

在“存储管理”打开位置的居中详情，查看“来源诊断”。每个来源分别展示原件最近观测、预览生成记录、扫描与预检 / 登记；“刷新诊断”只重新读取已保存记录，不访问原件、不扫描目录，也不生成预览。

“当前已采纳源索引规模”覆盖本位置内全部有权查看的已采纳来源文件，不随下方来源翻页变化。原地引用和复制接入均包含；同一文件跨数据集或父子来源重叠只计一次，不同文件即使内容相同仍分别计量。它是来源文件的逻辑规模，与平台对象字节分列，两个数字不能相加，也不能据此判断磁盘占用或原件实时可读。

缺少一致证据、同址内容冲突或挂载／节点无法比较时，显示已确认部分和“总量未知”，不会选择其中一个值凑成总量。已暂停或注销范围仍保留的采纳记录继续计入，业务删除后不从历史重新补回。索引观测时间与计算时间分别展示；刷新失败保留上次结果，撤权后隐藏旧统计。展开“统计口径”可查看历史修订、未采纳扫描和缓存等排除范围；不同 S3 对象版本分别计量，不承诺跨位置、硬链接或重复挂载的全局去重。

- **原件最近观测**：区分已验证、待验证、失踪、内容变化和不可读，附最近观测时间。统计的是已登记的原地引用业务样本，包含保留的历史修订；不含托管复制和未登记文件。同一路径接纳新内容后，旧样本仍在统计范围内，不会借用新内容的预览。
- **预览生成记录**：区分已有记录、生成失败、未生成或记录失效、未启用和已停用。“没有预览”不表示原件故障；已有记录也不保证预览对象此刻存在。展开数量明细可查看完整范围及观测时间区间。
- **扫描与预检**：分别显示当前活动轮次或最近轮次、完整性、时间与“配置匹配 / 历史配置”。恢复中的旧轮优先可见；最近失败不会抹掉上次完整成功。完整比较不等于登记成功，配置匹配也不代表实时可读。

点击“查看轮次”进入原数据集的来源与扫描；“任务详情”居中打开后台任务。任务保留期结束后可能只剩轮次，仍能进入历史。所有来源和任务按当前权限展示，任务历史可展开并独立翻页；返回仍保留原位置上下文。接口加载失败会提示；刷新失败时保留上次结果，需重试后再判断最新状态。

## 来源故障观测

位置的“来源诊断”内新增“来源故障观测”，可按未恢复、已恢复或全部查看，并独立翻页。每条记录显示故障类别、来源、操作、首次／最近失败时间和已接收失败观测次数；同一范围的持续失败合并，不逐次堆叠记录。点击“刷新故障观测”只查询保存的状态，不扫描目录、不读取原件，也不会重试任务。

根目录不可用与存储访问被拒绝默认由平台管理员处理，原件变化与预览失败由数据集管理员处理；尚未指定具体个人时会明确显示。任务发起者不是自动认领的负责人，来源备份责任也不等同于故障处置认领。已有任务可打开居中详情，超级管理员可查看同一故障的发生、恢复及再次发生记录。

“已恢复”只表示相同目标、操作和内容范围实际成功并通过既有核验；命中原图缓存、邻近文件读取成功或采纳不同内容都不会清除原故障。配置或内容已改变的旧范围标为历史，尚不能比对的范围标为未确认。“未恢复”是待复核观测，没有记录也不代表实时健康；首次并发失败晚到时，可能需要下一次同范围成功才能更新恢复状态。

项目管理员仅查看其可管理来源，超级管理员可查看保留的孤立来源。旧审计记录不会自动转换成当前故障状态；新状态不改变原有读取、写入或清理权限，也不自动暂停、删除、重新接受内容或向外部发送通知。

## 来源原件保护责任

在数据集的“来源与同步”选择来源，查看“来源原件保护责任”，点击“登记保护责任”或“编辑保护责任”。填写负责团队或人员名称，选择外部备份恢复、上游重新获取、无恢复方案或尚未确认；可附内部恢复说明／工单编号。编号仅用字母、数字及 `. _ : -`，不要填写路径、链接或凭据。

未填写的旧来源显示“尚未登记”；明确没有恢复方案与尚未确认分别显示。已登记方案统一标为“已声明”，并保留更新时间，不能据此认定原件已备份或已通过恢复验证。平台只保存引用时，目录丢失无法靠索引、缩略图或这份声明还原原件。

登记责任不需要来源在线，不修改扫描规则、内容修订或已有任务；停用、注销及数据集归档后仍可按原来源管理权限维护。其他人已更新时，窗口保留本次输入，点击“载入最新记录”重新核对后再保存。存储位置的来源诊断也显示同一声明；原数据集删除后，超级管理员仍可查看保留来源的责任记录。缺失原件和同名不同内容继续按严格读取规则拒绝，不会因填写声明而变成可用。

## 保存位置配置

修改受控目录的使用范围后，选择“预览使用范围变更”；调整完整原图缓存策略、额度或保留时间后，选择“预览缓存配置变更”。居中弹窗会列出本次字段差异、已保存关系和预览有效期，展开可查看完整盘点及统计范围。选择“返回修改”或按 Escape 取消，确认前不会保存。

核对后选择“确认保存位置配置”。预览有效五分钟；修改表单、切换位置或账号后需重新预览。确认时配置、权限或已盘点关系已变化，平台会拒绝旧确认并要求刷新后重预览，保留表单供核对。

保存来源位置配置会更新位置修订，依赖旧来源修订的完整原图缓存会失配；旧扫描、登记与自动同步在各自后续检查中阻塞。切换媒体缓存用途的新分配位置不会改变已保存缓存地址，目标连接凭据可正常轮换。撤回目录使用权影响来源管理，既有任务仍按项目权限读取；停用位置则拒绝新的引用原图读取，包括完整缓存。已就绪冻结内容按项目权限保留。缓存清理仍使用独立确认，不会删除来源文件。

## 位置维护影响

超级管理员可在外部来源位置的居中详情展开“维护影响”。它默认折叠，展开或点击“刷新维护盘点”只读取数据库，不访问源目录或对象存储。平台用途位置不提供此盘点。

盘点覆盖该位置全部保留来源，包含暂停、注销和已失去数据集关联的历史；样本、数据集和项目去重，项目包括尚无任务的数据集关联。扫描、预检/登记按持久轮次计数，任务历史被清理也不会把活动轮次变成零。预览和完整缓存显示账本数量、记录字节，完整缓存另列有效读租约；这些记录不证明文件此刻可读。

- **来源位置修订变化**：旧扫描和登记在后续检查点停止写入，自动同步在后续检查中阻塞；保存配置不会同步取消所有作业。依赖旧来源修订的完整原图缓存会失配，后续回收仍受读租约保护；已有预览按当前策略和内容判断是否可复用。
- **位置停用**：拒绝新的引用原图读取，包括完整缓存；已返回或下载的字节无法收回。已有就绪冻结内容仍按项目权限独立保留。
- **撤回目录使用权**：影响来源管理与新接入；已有任务读取仍由项目权限决定，不会代替任务人员撤权。

“可关联临时输入”仅包含当前任务仍能归属该位置的记录，不是所有预测、修复或孤儿输入；按记录状态计数，包含已到期但尚未转入清理的记录，不代表运行作业或有效下载凭证。“有位置血缘的冻结版本”仅包含快照明确记录该位置的版本，托管和缺少位置血缘的历史未计入；零数量不能证明没有引用。盘点不授予归档、退役或物理回收许可。

结果附统计时间。刷新失败时保留并标记上次结果；权限失效后隐藏旧数据。配置已变化时需关闭并重新打开位置详情再盘点。

## 位置访问维护

超级管理员可在外部来源位置的居中详情展开“位置访问维护”，按以下顺序操作。它与“启用位置”配置分开，不会修改来源启用状态、删除业务记录或源文件。

1. **开始维护**：先预览已保存关系，确认后关闭该逻辑位置的新受控访问。已有访问继续收尾，不把作业取消、超时或失去心跳当作 I/O 已结束。
2. **刷新维护状态**：查看未收尾总数和最多 50 条记录。记录可能仍在执行，也可能因进程退出或落库失败而状态不确定；不会到期自动清除。无法证明实际结束时，继续保持等待并由运维核实，平台不提供强制清零。
3. **停止访问**：未收尾为零时才可预览并确认。提交时再次核对关系、状态和零记录，随后记录“受控访问已停止”。
4. **恢复访问**：等待中或已停止时均可预览并确认恢复。每次转换增加维护修订，维护前排队的扫描、登记、同步、预测或冻结授权不会随恢复复活；需要重新发起。已有任务可在当前项目权限下建立新的读取请求。

每次预览有效五分钟，切换位置、账号、配置或状态后需重新预览。权限失效隐藏旧证据；刷新失败保留带时间的上次状态并暂停操作。已有独立冻结媒体继续按原权限读取，远端推理已取得的临时副本和已经下载的字节无法撤回。

首次部署默认不开放维护控制。运维须先核实该部署命名空间全部 API 与队列消费者已采用新访问协议，再设置 `STORAGE_MAINTENANCE_PROTOCOL_ENABLED=true`；空账本不能证明旧进程已退出。详见[部署核验](/dev/concepts/storage-connections#位置访问维护协议)。

维护仅覆盖平台对**这个逻辑位置**的受控读取与发布检查点。其他位置可能共享或重叠目录；候选连接验证、外部客户端及已复制到远端的输入不构成源位置静止证明。它不能证明整块挂载、服务器或桶已经静止，不授予卸载、退役或物理删除许可；平台自有缓存的清理仍走独立账本。

超级管理员还可从来源诊断的“查看此来源故障记录”进入现有审计页，核对本地来源读取、扫描和预览生成的分类及位置／样本／任务关联。详见[存储故障关联](../superadmin/audit-logs.md#存储故障关联)。记录是历史故障观测，不能代替当前位置探测。

## 更换头像存储位置

超级管理员在“存储管理 → 用途映射”的头像行选择“切换头像位置”，可选默认托管位置或已登记的全局 S3 位置。先选择目标并预览，确认旧／新位置、桶与前缀、现有头像数量及写入／完整读回／删除验证结果，再在五分钟内确认。切换只影响后续新头像；已有头像和进行中的上传继续使用各自保存的位置，不移动旧文件。

目标需允许受控读写和删除，并符合连接白名单。来源连接测试成功只说明来源访问能力，不能代替这里的实际托管验证。目标或配置变化、预览过期时重新预览。若提示历史头像缺少定位，请相关用户重新上传或选择内置头像后再操作；系统不会猜测旧头像的位置。标注文件和训练两个用途仍保持锁定，不通过修改数据库强行切换。

## 平台对象占用与后台盘点

超级管理员可在“存储管理”的“平台对象占用”查看覆盖范围，展开“查看各桶统计与时间”查看对象数、字节、最近成功采样窗口与最近尝试。盘点覆盖当前部署配置的九种用途桶；外部头像新目标若不在该端点和桶范围内，会明确提示未纳入，小计不代表所有存储位置；多个用途共用同一桶时合并显示并只计一次，不能按用途重复相加。位置详情中的节点探测与这里的对象占用是不同证据。

“对象分类”按已保存的地址或归属前缀，将实际列举的对象分为托管原件、预览与缓存、训练版本文件、临时产物、其他平台对象及未归类六项。同一对象即使被多个样本引用也只计一次；缺少可信归属或出现跨分类冲突时保留在“未归类”，不会丢掉这些字节。分类不根据桶名猜测，也不代表文件当前可读或允许删除。

训练版本文件包含其归属下准备中和保留的实际文件，不仅是最终 ZIP。到期、退休或业务已删除的对象，只要仍在桶内就继续计量；预约大小和业务记录大小不代替实际对象字节。分类旁显示已测桶数和采样窗口；未测桶保持未知，旧快照没有分类时显示“分项尚未统计”，重新完整盘点后补齐。展开“分类口径”可查看覆盖与排除范围。分项已经包含在对象总量中，不能再次相加；外部源索引规模另列。

“刷新状态”只重新读取已保存快照，不列举对象；“重新盘点”才创建后台任务。排队或执行中可查看任务进度并取消，重复提交会返回同一个活动任务。任务详情居中打开；关闭后返回存储页。盘点按页保存检查点，执行中断或短暂队列不可用由后台租约恢复，不需要重建镜像。

- **尚未统计**：没有完整成功快照，对象数与字节保持未知。
- **成功为零**：完整列举后确认为空，显示 `0` 和 `0 B`。
- **过期或失败**：成功采样超过 24 小时、最近盘点失败或取消时，保留各桶原值和原采样时间，并标明过期；可再次盘点。某桶失败不阻止继续盘点其他桶。
- **部分覆盖**：只完成部分配置桶时，覆盖显示已统计桶数，合计保持未知。全部桶都有成功快照后才提供合计；各桶采样窗口可能不同。

盘点统计采样窗口内 S3 当前可见对象及其字节，包括目录标记；对象存储在盘点期间仍可能写入，因此结果是估算，并非同一时点的原子快照。不包含历史版本、删除标记、未完成分片、供应商副本或压缩开销，也不包含外部目录/S3 原地引用的源索引规模。物理容量、磁盘可用空间和配额仍显示“未提供”，不绘制容量占比。

全局统计和任务仅向当前有效的超级管理员开放；API Key 还需全权 `*`。账号停用、降权、Key 撤销或配置变化会终止在途盘点，不发布之后读取的结果。视频资产失败与重试继续使用原有权限和入口。

在“视频资产失败”点击“重试”后，居中任务详情展示当前阶段和最终成功／失败计数，关闭后刷新失败列表；也可从后台任务或完成通知重新打开。海报、时间表分别展示其重试结果，元数据已生成不代表海报已恢复。队列投递尚未确认时，可回到失败列表重试；任务仍等待实际处理结果。元数据尚未准备好时，分块和帧缓存保留原有等待提示。此任务没有取消按钮；执行端状态未知时会保留等待，需核实原媒体输出的处理状态。

展开“增量账目与周期对账”可查看临时输入写入／清理、托管原件受控新增的已确认变化及未决操作。托管原件覆盖数据集直传、ZIP、连接器、目录复制、Task 和辅助原件；只计最终受控写入，不计浏览器暂存、准备中的分片或退役。完整读回、返回的不可变版本和当前对象一致且真实收尾后才确认新增；无版本、null 版本、应答不明或当前已被替换保持未知。业务发布失败不抹去已确认的物理事实。这里仍为部分覆盖，不能据此推算整个平台的实时总量；其他用途及外部写入可能形成未解释变化。精确版本删除后若仍有旧版本回露、删除标记或并发不明，不会假定当前对象字节已减少。

周期盘点默认关闭。超级管理员可显式开启并填写1至168小时的间隔，默认24小时；开启后首次尽快调度，已有盘点运行时不另起一轮。关闭只停止后续调度；当前任务可在任务详情另行取消。权限或存储配置变化后计划暂停，修正后需明确重新开启。首次盘点建立对象级基准，后续完整成功轮次才可比较；失败和取消保留已有成功结果。

## 新托管原件的创建与直传隔离

浏览器上传时，上传 URL 指向暂存对象；点击完成后，后端先完整计算摘要，再条件创建独立的最终原件并完整回读确认。原上传 URL 再次使用只会修改暂存区，不能覆盖已接受的最终原件。大文件完成阶段需要等待读取和校验结束。

ZIP、连接器复制和目录托管复制也使用同一创建流程。每次创建保存实际成功响应和内容证据，只有核验完成才关联样本。去重、业务回滚或提交结果不明时，已创建对象由独立账本继续记录，不立即删除；连接器字节预算按实际消费累计。结果不明的创建不会自动重试覆盖同一最终键，需要核对责任记录。

这套规则覆盖新创建。历史原件和扫描登记没有创建回执，不因内容相同补造证明；真实版本号与缺失版本分别保存。创建成功不代表专属存储权限，也不表示所有读取入口已固定底层版本，物理回收仍关闭。

## 托管原件保留与回收预演

超级管理员可在“平台对象占用”展开“托管原件保留与回收预演”。展开和刷新只读取数据库，不扫描目录或桶、不探测原件、不提交回收任务。详情居中展示历史数据集/样本身份、保留期限、当前引用及阻断原因。

删除托管数据集或样本时，平台在同一事务保存已登记原件的位置记录；逻辑删除不会因此删除原件。记录独立于业务关系保留，未知旧存储身份也会明确记录。未指定保留期限时按无限期保护，平台没有预设生产保留天数。

- **仍有保护要求**：发现当前样本、内容位置、任务、任务数据集关联、保留训练快照、主动学习历史或相关记录上的有效保留要求。归档数据、失败及取消的训练快照仍可能需要原件。
- **保留中**：没有上述保护要求，但相关记录的共同保留期限尚未结束或仍为无限期。
- **资格待核实**：期限条件已满足，仍缺少必要的存储、内容或保护证据。策略条件候选也不等于可以删除。

统计单位是位置记录，不是独立物理对象。同一原件可对应多条记录，已记录大小会重复累计；未知大小单独列出，不以零替代，也不提供可释放容量。时间表示本次数据库观测，刷新失败保留并标记上次结果，权限失效隐藏旧证据。

### 设置期限与登记保留要求

在原件居中详情展开“保留设置与要求”，可分别查看本条期限、相关记录共同保护期限和有效要求。平台按同桶同键保守归组，可能包含不同端点；任一相关记录无限期则整组无限期，否则共同保护至最晚期限。调整本条不会替其他记录解除保护。

“调整本条期限”可选择无限期或指定未来截止时间。输入时间按界面注明的浏览器时区解释，保存为带时区时间；填写原因后先预览，再确认。缩短无限期或既有期限会明确提示，确认时若时间已过、策略或相关要求已变化，则须刷新并重新预览。

“登记保留要求”用于记录备份保留或迁移观察责任，填写内部引用编号和原因。编号仅用字母、数字及 `. _ : -`，不要填写路径、链接或凭据。要求登记后持续有效，不按时间或任务状态自动解除；它保护所有相关保留记录。引用编号只是声明，不能证明备份真实存在、内容可恢复或迁移已验证。

相关要求按有效优先、登记时间从新到旧分页展示。只有登记记录能解除自己的要求；其他记录提供“打开登记记录”。解除前填写独立原因并预览确认，保留登记和解除历史，不修改任何期限，也不解除其他要求。空列表只表示没有已登记要求，未登记来源的覆盖仍未知。

这些设置只作用于已登记托管原件的保留预演，不是S3对象锁，也不涵盖仍活跃原件、外部原件、缓存、训练副本或其他独立清理器。即使期限结束并解除所有已知要求，独占所有权、现场副本和真实恢复/迁移资格仍需另行核验，当前不提供物理删除操作。

### 核验原件完整内容

在原件详情展开完整核验区，可显式创建一次后台核验，并查看分页历史。展开或刷新历史只查数据库；启动后由Worker重新读取完整对象，将SHA-256和大小与这条记录的可信历史内容比较。单次上限5GiB、协作读取预算60秒；没有可信历史摘要、存储身份不能匹配或超过预算时，界面显示阻断原因，不读取对象。

结果区分本次相符、对象缺失、对象或内容变化、无法核验、失败及取消。相符表示在所示时间完成的观测，不能保证之后同键未被替换。历史的配置/定位已变化时会明确标记，旧结果继续保留；相关记录可能有不同历史内容，不能互相代替核验。

等待中的任务可显式重派，同一任务只会被认领一次；进行中的取消先显示请求，实际读取收尾后才进入终态。若进程丢失或流关闭无法确认，未收尾责任会保留并阻止再次核验，不因超时自动视为结束。可先查看后台任务状态，由运维核实执行端，不要通过删账本强行解除。

内容核验不调整期限或保留要求，也不提供删除操作。桶内既有对象也可能被登记为托管原件；内容相符、随机文件名或配置一致都不能证明平台独占管理、足够副本或备份可恢复。

范围仅包含本功能启用后，在删除数据集或样本时捕获的已登记托管原件位置。未登记或升级前已丢失的旧位置不回填，不把空结果说成“没有遗留原件”。外部原件、完整缓存、派生预览及训练副本继续由各自规则管理。实际备份恢复点、迁移资格、独占所有权和最小副本仍须独立核验；当前预演始终不提供物理删除许可。

## 切换导出的新写入位置

超级管理员在“用途映射”的导出行选择“切换导出位置”，选择默认托管位置或已登记的全局 S3，先验证并预览，再于五分钟内确认。预览分别列出 ZIP 与独立媒体包的当前数量；验证包含条件写入、完整读回、对象和版本列举及测试对象删除。目标、配置、维护状态或权限变化后需重新预览。

切换仅影响后续新分配的导出。已有和已经开始分配的导出留在原位置，配套 ZIP 使用独立媒体包分配时的位置；命中已有导出缓存时仍可复用旧包，不会因切换而重做。ZIP、清单和首次七天下载期限保持不变，图片、视频和点云导出格式与原权限沿用既有规则。

外部 S3 的连接端点须供浏览器及下载脚本访问，链接按该端点签名。默认托管位置继续使用平台下载代理。连接密钥轮换后，平台按当前凭据核验并签发新的下载链接；已下载 ZIP 内冻结的旧链接仍受原有效期及存储方凭据撤销规则约束，不会自动改写。切换不迁移或备份旧对象。

## 切换导入暂存的新写入位置

超级管理员进入 **存储管理 → 用途映射**，在“导入暂存”行点击 **切换导入暂存位置**，选择默认托管位置或已登记的全局 S3。点击 **验证并预览**，核对目标与已有输入数量，再于五分钟内 **确认切换**。目标必须支持版本控制、条件写入、完整读回、准确版本删除及受控前缀列举；失败、权限或配置变化时不会切换，需要重新预览。

只有后续新分配使用新位置。已有预标输入、已签发的Dataset／Task直传上传、Mask格式上传和已建导入批次继续使用保存的位置，无需先完成全部在途上传。暂存与最终原件的位置独立：即使临时文件写入新位置，完成导入仍按原分配封存最终原件。切换不搬迁历史对象，也不改变格式解析、模型或结果。

外部 S3 端点须供浏览器上传和模型服务读取，链接直接按该端点签名；默认位置继续沿用现有地址映射。管理员可轮换当前连接凭据，保存地址保持，已签链接仍受原到期时间与存储方凭据撤销规则约束。

预标临时输入保留已有的固定版本清理；直传和Mask导入暂存当前没有远端自动删除。切换不会新增桶生命周期或垃圾回收，也不会自动删除旧无归属文件。仍被保存责任引用的位置不能改址或删除；标注文件和训练两个用途保持锁定。

## 切换数据集原件的新写入位置

超级管理员在 **存储管理 → 用途映射** 的“数据集原件”行打开切换对话框，选择默认托管位置或已登记的全局 S3。先 **验证并预览**，核对目标及原件、创建责任、辅助原件和退役记录数量，再于五分钟内 **确认切换**。只读来源不能作为托管目标；连接测试成功也不能代替这里的实际条件写入、完整读回与测试对象收尾验证。目标、权限、配置或用途代次变化后，需要重新预览。

只有后续新分配采用新位置，涵盖直接上传、ZIP、连接器复制、目录复制以及同用途的原始LiDAR／地图辅助文件。已有样本和已分配的在途上传仍使用原位置；切换期间无需排空全部上传。导入暂存与最终原件位置独立，数据集名称变更也不会移动原件。

读取按原件保存的endpoint、桶和完整对象键定位，当前用途绑定不会改写旧地址。平台在现有授权、维护许可和完整内容校验后返回原件；普通连接密钥轮换使用当前凭据，已冻结内容身份保持不变。凭据失效、位置停用或内容变化仍会明确失败，不改从另一个桶猜读。被当前或历史原件责任引用的位置不能改址或删除。

这项操作不搬迁历史对象，也不清理退役文件或补认未知旧数据。外部新目标不自动纳入当前部署的九桶占用和恢复范围；需要按实际位置保护数据。annotations和training两个用途仍保持锁定。

## 切换媒体缓存的新分配位置

超级管理员在 **存储管理 → 用途映射** 的“派生媒体缓存”行选择 **切换媒体缓存位置**，选择默认托管位置或已登记的全局 S3 位置。先 **验证并预览**，核对目标位置及历史记录，再于五分钟内 **确认切换**。验证实际检查条件写入、完整读回、准确删除和前缀列举；失败或无法确认收尾时不切换。目标、权限、维护状态或配置变化后须重新预览。

仅后续新分配的完整原图缓存、目录预览、普通缩略图、图片金字塔和视频派生输出使用新位置。已有及在途输出保留原位置，切回原目标也不会改写已保存的新位置。预览分别显示目录预览、原图缓存、图片金字塔、视频派生、缩略图输出和旧缩略图记录；它们是不同类型的记录，不能相加作为对象总数，也不表示全部对象当前可读。

浏览器通过平台同源的短期链接读取新普通缩略图、金字塔和视频派生输出，支持视频范围请求，无需配置外部桶 CORS 或让浏览器访问内部 S3 地址。持有链接者可在有效期内读取对应文件；链接不是登录凭据，也不允许读取其他文件。目录预览继续由现有认证入口读取；完整原图缓存由原件读取入口校验当前权限、内容和来源策略，不作为公开下载链接。

切换保留完整原图缓存的配额、TTL、读租约和已有清理规则，不改变缩略图编码、金字塔或转码算法。正常连接密钥轮换使用当前凭据；停用位置、地址不符或内容核验失败仍拒绝读取，不改从当前绑定猜读。仍被缓存或历史清理责任引用的位置不能改址或删除。

此操作不搬迁或清空缓存，不删除外部原件。外部目标及新保存地址不自动纳入现有九桶恢复；即使切回原目标，也须保留历史位置和独立恢复安排。标注文件与训练用途继续锁定。
