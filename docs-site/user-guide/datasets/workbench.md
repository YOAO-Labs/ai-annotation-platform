# 数据集工作台与视图

数据集工作台（`/datasets/:id`）是面向数据管理员与项目负责人的**独立数据集详情与治理解析界面**，通过**「数据」「来源与同步」「质量」「项目关联」「关联版本」**五个页签组织日常操作。

> **与标注工作台（Annotation Workbench）的区别**：
>
> - **数据集工作台（`/datasets/:id`）**：用于浏览与筛选数据集样本、检查原图核验状态与备用来源、管理目录同步、执行图片质量检测、查看各关联项目的标注进度与类别分布，以及从当前筛选直接冻结训练数据版本。
> - **标注工作台（`/projects/:id/workbench`）**：面向标注员与审核员的画布界面，用于对已分派的具体任务绘制几何框、多边形、掩码或点云 3D 框。

## 独立数据集详情与样本检查器

在数据集列表点击任意数据集即可进入独立详情页（列表的搜索词、类型筛选、页码与滚动位置均保存在 URL 中，返回列表时自动恢复）：

- **服务端分页表格与网格视图**：「数据」页支持在表格与网格视图间切换，仅按当前页请求详情与预览，翻页不会下载全量原图，也不会为前面所有页面的样本重复查询可用性详情。网格预览采用受控并发加载，服务繁忙时有限重试；切换页码或离开页面会自动取消尚未开始的读取。
- **最近保存的可用性观测**：列表中展示的可用性状态反映**最近保存的观测结果及观测时间**，细分为 `已核验（读取时复核）`、`变化待确认`、`完整扫描未见`、`仅预览可用`、`来源异常 / 不可用` 和 `待核验`。请注意，「缩略图可见」仅代表当前权限与缓存策略允许读取派生预览，不构成原图可编辑或可训练的证明；标注工作台与训练版本冻结始终严格核验原图字节。
- **样本检查器（Inspector）**：点击任意样本可在右侧抽屉或居中弹窗中打开可复制深链的样本检查器，集中查看：
  - 文件名、逻辑路径、MIME 媒体类型、像素宽高、SHA-256 摘要与修订号（若有前驱样本可悬停查看）；
  - 来源血缘、最近原图观测状态、完整原图缓存记录与预览缓存状态（显示「有完整缓存记录」不代表源此刻在线，仍可点击**「核验读取原图」**实时校验）；
  - 原地引用样本的[显式备用来源](./sources#远端来源离线与显式备用来源)（`reference-replicas`）配置与读取优先级调整。

## 服务端组合筛选与 Scene 筛选

服务端组合筛选会先在数据库层确定**全部匹配样本集合及总数**，再按当前页加载样本详情；因此后续跳转项目任务列表或点击「冻结当前筛选」时，作用的都是**全部匹配成员**，不受当前每页显示条数限制。

### 主筛选与高级组合筛选

在「数据」页顶部可直接按**文件名**、**来源**、**Scene** 和**可用性状态**过滤，也可展开**「更多筛选」**组合以下高级条件（填写后点击「应用筛选」生效；点击「清除更多条件」会同时清空草稿与已应用的高级条件，保留 Scene 等主条件）：

| 筛选维度                      | 匹配规则与约束                                                                                                       |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **可用性状态**                | 按 `已索引`、`原图可读 / 已核验`、`仅预览可用`、`来源异常`、`变化待确认`、`完整扫描未见` 等状态过滤。                |
| **文件扩展名**                | 按文件名后缀匹配，忽略大小写，且 `.jpg` 与 `.jpeg` 归为同组（注：后缀匹配不保证文件底层实际编码格式）。              |
| **MIME 媒体类型**             | 按入库或核验记录的媒体类型（如 `image/jpeg`、`image/png`、`image/webp`）精确或分类筛选。                             |
| **尺寸已知 / 未知与宽高范围** | 宽高范围以像素（px）为单位，仅匹配尺寸已知的样本；最小值不得大于最大值，勾选「尺寸未知」时不可同时填写宽高数值范围。 |

### Scene 筛选（时序与多模态数据集）

对于包含时序或多传感器 `Scene` 的数据集，可通过 **Scene 筛选器**按场景过滤（匹配范围包含同一 Scene 下的相机图像、点云帧与校准成员）：

- **分页加载与关键字搜索**：Scene 选项列表按页加载并支持按名称搜索；搜索或翻阅下拉选项仅改变当前展示的候选列表，不会重置已应用的样本筛选范围。
- **跨页保留已选项**：支持多选 Scene，已勾选的 Scene 即使不在当前搜索词或当前选项页中也会完整保留。
- **失效 Scene 显式报错（拒绝静默放宽）**：若 URL 链接或个人视图中保存的 Scene ID 已被删除或失效，页面会明确提示错误，**绝不会自动回退成「全部 Scene」从而无声扩大样本范围**。管理员可显式选择「全部 Scene」清除失效条件。

## 个人动态视图

当你需要反复使用某组筛选条件（例如「仅看某目录来源下宽度 ≥ 1920 且原图可读的夜视场景样本」）时，可将其保存为**个人动态视图**：

1. **保存为新视图**：在应用筛选条件后点击**「保存为新视图」**，在居中弹窗中输入视图名称。个人视图仅创建者本人可见，每个数据集最多保存 **100 个**个人视图。
2. **恢复与 URL 同步**：从视图下拉框选择已有视图，即可恢复全部已存条件并回到第 1 页；选中的视图 ID 与筛选参数会同步写入 URL。若分享或打开仅带视图 ID 的链接，页面会先加载视图定义再执行查询。
3. **更新、另存、重命名与删除**：在已选视图基础上修改筛选条件后，界面会提示「未保存修改」，支持**更新当前视图**、**另存为新视图**、**恢复原条件**、**重命名**或**删除视图**（删除视图仅移除保存的查询定义，不会删除任何样本或清空当前已展开的筛选结果）。
4. **失效保护**：若视图不存在，或视图内引用的数据来源 / Scene 已失效，系统会明确报错提示，不会自动剔除失效条件返回全量样本。

## 项目关联与分类统计

切换到数据集详情的**「项目关联」**页签，可查看当前数据集在各个已关联项目中的标注进展与标签分布：

- **按当前可见性计算项目进度**：列表分别展示该数据集在每个可见项目中的**总任务数、已标注、待审核、已完成**数量（包含通过 `primary` 多模态关联生成的任务）。统计严格按当前登录用户的项目、批次与任务可见性计算，且该项目下来自其他数据集的任务不参与计数。
- **标签对象分布统计**：选中某个关联项目后（项目选择保存在 URL 中），下方展示本数据集在该项目中的**标签类别分布**。
  - 统计口径为**已保存、有效且未取消的标注对象数（Annotation Objects）**，包含多模态相机成员上的标注；视频紧凑轨迹按 1 个对象计算（不按帧展开），尚未被人工采纳的 AI 预测候选不计入。
  - 请注意：**「标签对象数」不等于「已标注任务数」**，因为单个任务内往往包含多个目标框或多个类别。
- **一键跳转项目任务列表**：
  - 点击项目名称，可直接跳转到该项目并预置「当前数据集」筛选条件；
  - 点击某类别行的**「查看含该标签的任务」**，会跳转到项目任务列表并**同时限定当前数据集与该标签类别**（列表展示的是命中任务数）。
- **解除项目关联与影响预览**：若需解除数据集与项目的关联，必须先成功获取**影响预览**（预览失败时只可重试，不能按零影响强行提交）。确认解除关联会一并删除该项目下对应任务、标注、评论及反馈镜像；已登记的评论附件保留独立清理责任，按原保存期限和宽限期后台回收。

## 从当前筛选冻结训练数据版本

个人动态视图保存的是**查询条件**，每次打开都会动态匹配最新样本（后续新增样本只要符合条件就会出现）。当你希望将当前筛选出的样本集合、原图与已审核标注永久固化用于模型训练时，可使用**「冻结当前筛选」**：

1. **发起筛选冻结**：在数据集工作台「数据」页应用组合筛选或选择个人视图后，点击**「冻结当前筛选」**，在弹窗中选择一个你拥有训练管理权限的已关联项目。
2. **携带服务端筛选范围进入项目预检**：页面跳转到该项目的「在线学习 → 训练数据」创建流程（也可从数据集「关联版本」页签发起）。此时候选范围由服务端严格限定为**当前数据集筛选命中的全部样本所对应的项目任务**，不受数据集表格当前分页大小限制（但进入页面本身不会自动创建版本，仍需你在训练页明确选择标注状态范围并执行预检）。
3. **共享任务筛选与预检失效保护（`409` 拦截）**：
   - 预检会核对匹配任务的标注资格、分类映射以及原地引用原图的预计复制体量；
   - 若在预检完成后、点击确认创建版本前，有新任务进入当前筛选匹配范围或候选成员发生变化，服务端会返回冲突（`409`）并要求**重新预检**，防止未核对的新样本混入冻结版本。
4. **不可变训练快照**：版本构建完成后，原图副本（含原地引用图片的核验副本）、标注与划分即被永久固定。后续在数据集工作台修改个人视图、新增或删除样本、或者外部源目录发生覆盖/离线，均不会改变已发布的训练数据版本。详见[训练数据版本](../online-learning/data-versions#从数据集当前筛选创建版本)。
