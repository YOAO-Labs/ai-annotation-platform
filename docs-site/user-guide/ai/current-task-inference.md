# 当前题 AI 与二次推理

**当前题 AI** 可在图片工作台处理当前整张图片，也可在视频工作台处理当前帧并生成待审候选；**二次推理**只在图片工作台中，以已确认的标注为父对象补写属性或创建子框。两者都只执行项目已有配置，不能在工作台编辑项目编排。

## 运行当前题 AI

使用场景：不需要对整个批次跑预标，只想对正在标注的图片，或视频中的当前帧调用模型。

1. 打开图片或视频任务，点击顶部 **AI** 打开 **当前题 AI** 面板。
2. 文本模型可直接填写提示词；展开 **高级配置** 调整后端、模型和参数，然后点击 **运行当前题**。
3. 运行时核对 **本次请求** 中的模型、输入和任务范围。进度由本次作业报告；没有进度时显示等待状态。
4. 结果就绪后点击 **审阅候选** 打开标注详情，选择候选、核对类别和属性，再接受或拒绝。图片结果属于当前任务；视频生成单帧 `video_bbox` 候选。

面板按准备运行、推理中、待审阅和请求失败四个阶段显示当前主动作。高级配置始终可展开，运行中的修改用于下一轮；**重试本次请求**仍使用原任务、帧和输入。作业状态查询失败时，**重试状态查询**只恢复查询，不重复推理。

![当前题 AI 面板的待审阅阶段：主层显示待审候选数量与「审阅候选」入口](../images/sam/ai-inspector-panel.png)

审阅候选时，属性字段按候选自身的工具类型显示，修改暂存为草稿。隐藏、浮动或重新停靠标注详情后再打开，仍保留当前候选的改动；使用详情中的 **接受候选**或该候选的列表采纳按钮，会将改动随采纳一起保存。面板控件获得焦点且不在编辑文本或下拉框时，也可按 `A` 接受、`D` 拒绝；视频快捷键只处理当前帧候选。切换到另一候选会结束上一候选的属性草稿。

支持取消时，运行阶段提供 **取消本次请求**。图片作业要等后台确认后才结束取消状态；视频取消停止当前客户端请求。取消不会撤回服务端已经保存的候选。切换任务或视频帧会退出旧请求的当前视图，旧结果不会打开新任务的审阅面板；图片作业可继续在后台运行。

当前题 AI 是工作台布局面板，可停靠、组成标签、浮动或隐藏；顶部入口会显示或聚焦同一实例。位置和显隐按账号及工作类型保存，隐藏后重新打开仍保留配置。视频任务中，顶部还会在它左侧显示 **追踪**入口；两个面板可以同时显示。

如果项目管理员已在[AI 预标](../projects/ai-preannotate)中保存了项目编排，图片任务的高级配置中会显示 **运行当前题（项目编排 · N 阶段）**。它会按保存的阶段顺序执行检测、分类和属性写入，仍然把结果作为候选交给标注员审阅。视频任务不会显示这个入口：当前题 AI 只能分析当前帧；要批量跑视频编排请到 [AI 预标](../projects/ai-preannotate)，要追踪一条轨迹请用[视频 AI 追踪](../workbench/video-propagate)。

选中 AI 待审候选时，讨论面板显示当前任务的评论；采纳后选中正式标注，可查看和添加该标注的专属评论。

当前题 AI 与批量预标的区别是范围：图片只作用于当前任务，视频只作用于当前帧；它不改变批次状态，也不会替代批量任务历史。批量运行、并发和幂等模式见[AI 预标](../projects/ai-preannotate)。

图片当前题 AI 按当前用户对本题的编辑语义执行，而不是套用批量预标的「仅待标注任务」限制：正在标注（`in_progress`）的任务，以及仍处于草稿（`draft`）批次的任务，都可以直接运行 AI，无需先激活批次。已提交审核或已完成的任务需先撤回 / 重开；批次被管理员锁定、或本题正由其他成员编辑时，面板会给出明确的中文拒绝原因。他人编辑锁与管理员锁的保护因此不会因单题执行而放宽。

高级配置中的「采纳已加载候选（数量）」处理当前题已加载、符合来源和置信度条件且未被去重的候选；按钮显示实际可采纳数量，视频可能包含其他帧。面板主层的待审数量只统计当前帧，切换「当前帧 / 全部」不会改变批量操作范围，逐条审阅时以选中候选为准。

## 对已确认标注做二次推理

使用场景：已有一条人工或已采纳的图片 bbox / polygon 标注，希望基于这个父对象补全属性，或从中识别子物体。视频任务、旋转框、线、点和多连通多边形不提供这个入口。

二次推理只在以下条件同时满足时出现：

- 以标注员、项目管理员或超级管理员身份进入标注工作台；审核工作台不提供二次推理面板及相关开关，审核员仍可人工修改标注；
- 当前是图片任务；
- 选中的是已落库的人工标注或已采纳标注，不是 AI 待审候选；
- 当前未处于交互式 AI 工具状态；
- 项目已启用能处理该输入和输出的 backend。

操作步骤：

1. 选中父对象，在画布左上方找到二次推理胶囊。胶囊显示当前识别能力；需要文本提示的模型还会显示已输入的目标文本。悬停或点击后向右、向下展开，可直接填写文本、调节模型已有的置信度并运行。
2. 通过**更多设置**打开完整面板，选择识别能力和模型档位、核对当前对象，并展开**推理参数**调整其他配置。两个入口共用同一份置信度；切换模型后各自的参数会保留。点击右上角 **X** 返回胶囊。
3. 运行后检查结果：模型可以补写父框的缺失属性，也可以创建挂在父框下的子框。
4. 结果会立即出现在标注详情和画布中；超时或 backend 不可达时，面板会提供明确错误与重试入口。

二次推理直接更新已确认标注的属性或子标注，不走“AI 待审”候选列表。因此开始前应确认选中的父框与模型输出类型；要对整图重新生成候选，请使用当前题 AI 或批量预标。

## 控制面板显示

二次推理默认在适用的选中标注上显示胶囊。收起完整面板后回到小胶囊，悬停展开即可填写模型要求的目标文本并运行；收起不取消请求，也不清空本次文本、参数或模型档位。参数与档位会随账号保存，本次文本在刷新后清空。若不常使用，可在顶部设置窗口的“二次推理面板”开关、标注详情浮卡的 ✦ 图标，或标注右键菜单中关闭它。该偏好会跟随账号保存，重新开启后无需刷新页面。

## AI 属性溯源

标注详情中的 `✦ AI` 徽标表示某个属性键由预标、二次推理或多阶段编排写入。悬停可查看写入它的模型；人工编辑该键后，徽标会消失。一个标注的不同属性可以分别保留 AI 和人工来源。

## 与其它 AI 入口的区别

| 需要完成的事                             | 入口                                         |
| ---------------------------------------- | -------------------------------------------- |
| 在当前图片用点、框或示例与模型交互       | [图片交互式 AI](../workbench/sam-tool)       |
| 对当前图片或视频当前帧运行模型并审阅候选 | 本页“当前题 AI”                              |
| 对已确认父框补属性或检测子框             | 本页“二次推理”                               |
| 对多个任务或批次运行模型                 | [AI 预标](../projects/ai-preannotate)        |
| 跨帧追踪视频目标                         | [视频 AI 追踪](../workbench/video-propagate) |
| 接受、拒绝或清理图片候选                 | [审阅 AI 候选](./candidate-review)           |

模型不可用、输出不匹配或入口置灰时，先检查[项目 ML 模型](../projects/ml-backends)中的项目启用、能力路由和工具开关。
