# 只读站点 Agent

只读站点 Agent 已接通中心身份与传输 API，支持受控根位置、目录扫描、预检确认登记和完整原图快照。超级管理员可在“存储管理 → 站点与 Agent”完成站点、配对和位置登记，Agent 图片支持单区间 Range。引用图片支持管理员显式关联同内容备用来源和调整读取优先级。既有受控挂载和存储连接继续可用。
详见用户侧操作指南[跨网络站点与 Agent](/user-guide/datasets/site-agents)与接口契约[只读站点 Agent 与传输 API](/api/guides/site-agents)。
Agent 的目标是让中心无法入站的数据服务器主动联系平台，仅开放管理员选定的只读根；不要求集中搬迁全部原图，也不开放 shell、来源写回或删除操作。来源绝对路径只保留在 Agent 本地，平台使用根 handle 和相对路径。

## 配置与配对

独立组件支持本地配置检查。配置／凭据为运行账户拥有的 `0600` 文件，状态目录为独立 `0700` 目录；中心地址必须是 HTTPS origin，可配置内部 CA。来源根与状态目录分开，容器部署时来源只读挂载。

```sh
aap-storage-agent --config /etc/aap-storage-agent/agent.json --check
```

检查输出只有协议版本、根 handle 和预算，不会配对中心，也不验证平台已能扫描或读取该目录。独立包源码、安装及配置格式见仓库 `apps/storage-agent/README.md`。当前无需改现有后端镜像或已有本地目录部署。

## 恢复和资源边界

Agent 先完整读取、计算摘要并复核来源，再发送有界 stage；单个文件最多 64 MiB。来源读取的超时不等于物理句柄已经关闭，关闭未决会停止继续领取任务，即使中心拒绝该任务，本地也保留关闭证据等待对账。

本地完成、中心收到和业务已确认分别记录。断网或重启后重发同一个结果，只有身份和摘要匹配的终态确认才释放待确认 stage。发送的字节数不能当作中心确认进度；授权过期不再发起原图分块，中心接收时也须复验期限。当前客户端串行执行，带宽、待确认数量、状态空间和临时失败重试有明确上限。中心签发的带宽与 Agent 本地上限取较低值，原图分块和结果正文（包含目录清单）共用发送预算；HTTP／TLS 头、配对和轮询控制消息不计入正文带宽。进程重启允许一个有界首片突发。

组件检查覆盖证书、重定向拒绝和丢确认后的恢复，中心 SQL／Redis 检查覆盖回执与业务确认。`scripts/verify_site_agent.py` 在独立测试模式中复用已有镜像，将中心与 Agent 放入不同网络，来源仅只读挂载给 Agent，使用真实 HTTPS 和 Worker 验证数据集链路。实际通过范围记录在 E06 实施计划；组件检查不替代完整站点验收。

## 中心接入顺序

中心需安装 API 锁定的两个本地共享包（`aap-filesystem-read`、`aap-site-agent-contract`），并应用增量数据库迁移 `0265`（`sites`、`agent_registrations`、`agent_credentials`）、`0266`（`site_agent_commands`）和 `0267`（`dataset_reference_replicas`）。升级后须按部署方式刷新 API 进程与 Celery Worker 以加载新依赖和路由：挂载源码或使用宿主机虚拟环境的开发部署只需重启进程，无需重建现有后端镜像；生产容器构建则随镜像包含这两个共享包。

1. 超级管理员通过 `POST /api/v1/site-agents/sites` 创建站点，正文为 `name` 及可选 `region`；随后向 `/sites/{site_id}/agents` 提交 `name` 和可选 `limits`，取得一次性配对代码。管理端使用当前 JWT 或具备 `datasets:write` 的 API Key。
2. 按独立包 README 保存私有配对文件并运行 `--pairing-file`。代码十分钟有效、单次消费；中心仅保存代码和 token 的摘要。配对响应的身份凭据最长三十天有效，仅用于 Agent 接口。
3. 启动 Agent，使其主动长轮询中心并报告根 handle、修订和本地预算；管理端通过 `GET /api/v1/site-agents/agents` 查看心跳及根。中心不接收本地绝对路径。
4. 通过 `POST /api/v1/storage-locations/agent` 登记 `agent_id / root_handle / root_revision / relative_path` 及名称、使用范围与缓存策略。根和修订须匹配当前 Agent 报告；登记本身不证明目录可读。
5. 使用既有位置探测和目录浏览接口。Agent 位置由远端执行 I/O，保存的探测绑定远端根身份；来源仍选择中心执行 Worker，继续使用原有扫描、预检、确认登记流程。位置与来源相对路径各有独立边界，不把来源子目录重新绑定成位置根。

Agent 不提供位置写入、删除或预签名能力，不能用作平台用途的新写入目标。原图在中心完整核验 SHA 与图片格式后交给既有快照及授权流程；中继临时字节不等于原件副本或持久缓存。Agent 图片的扫描条目、已登记样本及任务 content 端点支持单区间 Range／强 ETag If-Range，区间始终取自完整核验后的同一快照；同内容的已验证完整缓存也支持。非 Agent 的这些图片端点仍拒绝 Range，预览和通用原件下载合同各自保持。

## 管理界面

“站点与 Agent”仅超级管理员可见。列表可按站点筛选并分页；点击详情在居中弹窗查看最后心跳、协议／身份修订、受控根、预算和关联位置。暂停派发、恢复派发、轮换和撤销使用当前身份修订；轮换前须暂停并等待活动任务结束。

新建站点后可继续添加 Agent。配对信息只在当前弹窗显示，可复制为私有 JSON 文件，关闭后不再保留；丢失或过期时按身份生命周期重新配对。Agent 报告根后，可在详情的对应根下登记相对目录，保存后跳转到既有位置详情，再执行探测和来源接入。列表刷新不会探测来源目录。

## 身份生命周期

管理接口统一位于 `/api/v1/site-agents`，仅超级管理员可管理站点和身份。`GET /sites` 与 `GET /agents` 分页读取；`POST /agents/{id}/drain` 提交 `expected_revision / draining`，停止新任务并收尾已领取任务；轮换 `/rotate` 要求已 drain 且没有 leased、received 或 unsettled 命令。`/revoke` 撤销当前身份，新任务和原图分块立即拒绝。轮换与撤销均提交 `expected_revision`，保留旧凭据摘要用于关闭回执核对。

Agent 的轮询、分块、结果接口使用独立 Bearer token 和协议版本。撤销、过期或旧修订凭据仅可向已有命令的结果接口提交元数据，供中心确认实际关闭；不会因此重新取得任务、字节上传或业务采纳资格。心跳超过六十秒显示离线，不把既有样本判为删除。

中心对单个命令保留原到期时间，最长一百二十秒；应用当前签发四十五秒。丢失轮询响应时，同一耐久 session 可重领同一命令；重投不延长授权。中心最多四个中继预算，每文件最多 64 MiB、每块最多 256 KiB，原图读取优先于探测／浏览及扫描。关闭未决继续占用责任，不按超时猜测已关闭。

同一耐久 session 丢失领取响应且原命令已过期时，中心仅重投原始过期命令供 Agent 回报关闭；Agent 不重新访问来源，也不延长授权。暂停派发仍允许收尾已领取命令和释放已确认中继。

## 兼容升级

当前中心与 Agent 使用协议1，不提供跨协议版本自动协商。升级前核对目标中心与 Agent 的协议兼容性；不兼容时先保持暂停，按兼容组合安排更新。正常升级保留 Agent 身份、凭据、受控根修订、状态目录和本地日志，不重新配对或清空待确认结果。

1. 在中心暂停该 Agent 的新派发，保留现有进程收尾。停止其受监督进程后，使用旧程序、原配置执行 `aap-storage-agent --config /etc/aap-storage-agent/agent.json --drain`，处理耐久待确认结果；同一状态目录不能同时运行两个进程。
2. 核对已领取命令的物理责任已关闭，中心业务结果已采纳或拒绝。本地 `--drain` 成功只代表完成这一轮提交，`received` 仍须等待最终确认；有未收尾结果时保留旧程序、日志与 stage，恢复连接后继续收尾，不能删除状态目录绕过。
3. 在 Agent 的独立虚拟环境升级三个匹配的包：`aap-filesystem-read`、`aap-site-agent-contract`、`aap-storage-agent`；源码安装仍使用独立组件 README 的三个本地路径。中心按实际部署方式更新 API／Worker 进程并应用数据库迁移（`0265`–`0267`）；挂载源码的开发部署无需重建后端镜像，容器化部署按标准镜像升级流程更新。
4. 使用原配置执行 `--check`，随后以原身份和状态目录启动新程序。确认中心心跳、根 handle／修订和预算正确，再恢复新派发，执行位置探测并核验一张已登记原图。根路径或挂载改变应按绑定修订处理，不能通过删除日志冒充原根。

## 数据集离线展示

来源与样本列表从数据库批量显示当前获授权的站点／Agent 名称、连接状态和最后心跳，不为列表逐张探测文件。离线、暂停、凭据过期、撤销和绑定根修订变化各有明确原因；心跳超时不删除样本，搜索和分页继续可用。

原图和已有预览分别显示。完整缓存记录保留，但不等于当前原图在线；同内容完整缓存仍可沿当前业务权限核验读取。缓存未命中且 Agent 已知不可用时，读取及时返回具体原因，连接恢复后可重试。已有冻结版本继续读取自己的固定文件。

## 显式备用来源

将第二站点的目录沿同一数据集的扫描／预检／确认流程接入后，管理员可在引用样本检查器关联已接纳的同内容图片。设置优先级后可从另一站点读取，无需集中搬迁原图；关联不复制文件、不合并样本，也不开放其他目录。

路由使用显式优先级和当前连接资格，不自动测量站点距离。主来源业务权限持续复核，备用来源还须满足当前身份、绑定根和维护许可；每次读取完整核验后再交付，断连或内容不同的副本被排除。当前只对引用图片提供此类关联，托管对象迁移仍沿既有迁移发布链路。
