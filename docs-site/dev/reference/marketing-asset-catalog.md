# 高清营销资产目录

高清营销资产是项目视频、GIF 和封面的统一采集源；不同分辨率与帧率通过衍生获得，不另录低规格文档源。静态截图独立采集。母版是可追溯的后期素材，不是一条已完成的广告。每个资产 ID
只表达一个明确目标，使用独立 Playwright 测试和独立原始视频归档。不得把
多个无关功能为了凑时长录到同一母版。

规格的代码真值源是
`apps/web/e2e/screenshots/_helpers/marketing-assets.ts`。归档器会把对应的主题、
目标、分镜和剪辑提示复制到运行 `manifest.json`。

## 时长与归档门禁

每条规格同时声明三个时长：

- **最短**：归档硬门禁。低于该时长表明操作过快或镜头不完整，录制直接失败。
- **目标**：原始母版的建议节奏，也是后期 Agent 设计主版时的参考。
- **最长**：归档硬门禁。超过上限通常表明推理、加载或自动化已卡住。

母版必须保持 **4K UHD（3840×2160）/ 60fps**。两种平台使用 1440×810 逻辑 viewport：
Linux 以 1.8 设备像素倍率渲染为 2592×1458，经 X11 / NVIDIA 采集；Mac 以 2 倍率提供
2880×1620 内容区，经 ScreenCaptureKit 单窗口采集。均按校准色块确定裁切边界，再以 Lanczos
生成 4K 交付文件。Mac 仅接纳不依赖 ML 能力、也不执行推理的已注册流程。

不依赖 ML 的批量刷新可选择 `recording-plan.mjs` 的 `MAC_MARKETING_FLOWS`，所选 flow ID 与本目录
的 asset ID 一一对应。本轮选择不包含 ML Backend、AI 推理和追踪作业视图；它是刷新范围，
不改变其他已注册流程的录制资格。项目创建、异步导出和存储连接器流程使用隔离截图夹具，
均声明 ML capability `none` 且不执行推理；实际录制仍逐项检查原有画质、帧节奏与来源门禁。

平台选择不降低质量门禁：硬件合成、120 帧 rAF 的 p95 ≤ 20ms，以及 1.1 秒校准段至少 58 个采样帧、
有效独立画面 ≥ 55fps、独立帧比例 ≥ 90% 均须通过。分辨率、帧率、有效节奏、画面信号或时长不合格时不归档。
环境与命令见[更新文档截图](../how-to/update-screenshots#高清母版统一采集与衍生)。

## 资产明细

点云录制统一使用 `nuScenes-mini` 的 `scene-0061`（`pointcloud_demo`），保留真实六相机标定和 ego 位姿。
种框明确选择 `CAM_FRONT`；标签与跨帧录制使用首帧 POKKA 货车的官方框
（`sample_annotation: 83d881a6b3d94ef3a3bc3b585cc514f8`），转换为 LiDAR 时间戳的 ISO 8855 ego 坐标。
不得复用旧室内点云的框坐标、相机名称或固定跨帧位置；人工修正应基于补偿后的位置作小幅调整。

## Google Drive 同步约定

尚未进入代码规格的后续母版维护在
`docs-site/maintainers/marketing-recording-backlog.md`。只有开始实现独立 flow 时，才把对应项目迁入本页和
`marketing-assets.ts`，避免目录把“计划”误报为“已可录制”。

本地 `.artifacts/marketing/<run_id>/` 是一次录制的不可变批次；Google Drive 的日常工作目录固定为
`AAP资产:营销素材/高清母版/current/`。更新素材时，把最新完整批次镜像到 `current/`，不要为每次运行创建新的
时间戳目录，否则相同主题会在云端反复占用空间。

```bash
rclone sync ".artifacts/marketing/<run_id>" \
  "AAP资产:营销素材/高清母版/current" \
  --checkers 8 --transfers 4

rclone check ".artifacts/marketing/<run_id>" \
  "AAP资产:营销素材/高清母版/current" \
  --one-way --checkers 8
```

`sync` 会删除目标中源端已不存在的文件，因此只允许把目标精确限定到上述 `current/`；不得对
`AAP资产:`、`营销素材/` 或 `高清母版/` 上层目录执行。需要保留里程碑时，才在人工确认后额外复制到
`AAP资产:营销素材/高清母版/archive/<run_id>/`。Rclone 凭证只保存在操作者环境中，不写入仓库或
`manifest.json`。

单条补录只增量复制该资产的 `raw/` 和 `masters/` 文件，并把新条目合并到 `current/manifest.json`，
保留已有资产及来源记录；不要把只含一条素材的批次直接 `sync` 到完整的 `current/`。
同时保留新批次自己的原始 manifest，以便核对录制来源。

## 后期 Agent 交接规则

1. 先读取运行 `manifest.json` 中的 `content`，不要只根据文件名猜测素材内容。
2. 每个 `asset_id` 是独立母版。如需组合广告，先按脚本选择多个资产，不要要求单个录制脚本混入无关功能。
3. `capture_source` 是按真实操作窗口裁切的不可变 4K60 MKV/H.264 采集源，`universal_mp4` 是同一窗口的 4K60 H.264 通用母版。两者都会去掉动作窗口外的准备画面；`project-onboarding` 的登录属于必需内容，必须保留。来源区间记录在 `source_clip_seconds`；未裁切缓存只用于生成母版，成功或失败后都会删除。平台裁剪版存入 `deliverables/`，并保留来源 `asset_id` 和 SHA-256。
4. 可删除骨架屏、网络等待和无意义停顿，但不得删除 `shots` 中构成因果关系的必需镜头。
5. 生成社交平台版前，复核敏感信息、模型结果、画面对齐和文字可读性。
6. 时长规格必须来自自然操作和必需镜头；不得通过慢放、故意放慢指针、重复动作或无信息静帧满足最短时长。如自然流程短于当前最短值，应降低该资产的时长规格，或增加与主题直接相关的必需镜头。

## 内容与流畅度合同

- 图像和视频锚点以 `normalized_media` 坐标保存，并映射到画布中实际渲染媒体的边界；不得把包含 letterbox 的整个 stage 当作媒体区域。
- 每项人工标注必须等待类别选择器出现，按锚点声明选择精确类别，并等待创建或更新 API 成功后才能结束录制。
- AI 项目必须至少包含“有意义的真实目标提示 → 候选结果 → 人工审阅/采纳 → 已保存结果”；只录点击或等待中的前半段不合格。
- 指针输入逐帧使用受信任的 Playwright 鼠标事件按 60Hz 节拍发送。采集器还会在正式流程前录制 GPU 合成层校准动画，要求至少 58 个采样帧、有效独立画面不低于 55fps 且独立帧占比不低于 90%；这些实测值写入 manifest，只有容器标称 `60fps` 不能通过门禁。
